### 2. 异常分支测试系统化

**测试模式标准化**:
```csharp
// 标准异常分支测试模板
[Fact]
public async Task MethodName_Should_Return_Failure_When_Service_Fails()
{
    // Arrange - 失败分支设置
    _mockService.Setup(x => x.Method()).ReturnsAsync(ServiceResult<T>.Failure("错误信息"));
    
    // Act - 执行测试
    var result = await _service.Method();
    
    // Assert - 验证失败结果
    result.Should().NotBeNull();
    result.IsSuccess.Should().BeFalse();
    result.ErrorMessage.Should().Be("错误信息");
}
```
