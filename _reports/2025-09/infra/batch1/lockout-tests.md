## 最小用例：核心场景

### TC-001: 连续5次失败→被锁定

**测试步骤**:
1. 使用测试用户 `testuser` (确保存在)
2. 连续5次使用错误密码登录
3. 检查第5次后的响应

**预期结果**:
```json
// 第1-4次失败响应
{
  "success": false,
  "message": "用户名或密码错误"
}

// 第5次失败后，用户被锁定
{
  "success": false, 
  "message": "用户名或密码错误"
}

// 第6次尝试登录
{
  "success": false,
  "message": "账户已被锁定，请在 15 分钟后重试"
}
```

**验证点**:
- [ ] 前4次失败不锁定
- [ ] 第5次失败触发锁定
- [ ] 锁定后立即拒绝访问
- [ ] 数据库中 `FailedLoginCount = 5`
- [ ] 数据库中 `LockoutEnd` 被设置

### TC-002: 解锁后成功登录

**测试步骤**:
1. 使用TC-001锁定的账户
2. 等待15分钟或手动清除 `LockoutEnd`
3. 使用正确密码登录

**预期结果**:
```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "eyJ...",
    "user": {
      "username": "testuser",
      // ... 用户信息
    }
  }
}
```

**验证点**:
- [ ] 登录成功返回令牌
- [ ] 数据库中 `FailedLoginCount = 0`
- [ ] 数据库中 `LockoutEnd = null`
- [ ] 后续登录正常工作

## 详细测试用例

### TC-003: 渐进失败测试

**测试目的**: 验证失败计数的准确性

**测试步骤**:
1. 新建测试用户 `gradual_test`
2. 执行以下登录序列：
   - 1次错误密码 → 检查计数为1
   - 1次正确密码 → 检查计数重置为0
   - 2次错误密码 → 检查计数为2
   - 1次正确密码 → 检查计数重置为0
   - 5次错误密码 → 检查锁定生效

**验证点**:
- [ ] 每次失败正确递增计数
- [ ] 成功登录重置计数
- [ ] 计数器在重置后重新累计
- [ ] 达到阈值时正确锁定

### TC-004: 锁定期边界测试

**测试目的**: 验证锁定时间的精确性

**测试步骤**:
1. 创建测试用户并触发锁定
2. 记录锁定开始时间 `lockTime`
3. 在 `lockTime + 14分59秒` 时尝试登录
4. 在 `lockTime + 15分01秒` 时尝试登录

**预期结果**:
- 14分59秒时：仍被锁定
- 15分01秒时：可以正常验证密码

**验证点**:
- [ ] 锁定期内严格拒绝
- [ ] 锁定期过后立即可用
- [ ] 时间计算准确性

### TC-005: 配置参数测试

**测试目的**: 验证配置参数的有效性

**测试前准备**:
```json
// 修改配置用于测试
{
  "AuthOptions": {
    "MaxFailedLoginAttempts": 3,
    "AccountLockoutDuration": "00:05:00"
  }
}
```

**测试步骤**:
1. 重启应用加载新配置
2. 连续3次错误登录 → 应该触发锁定
3. 等待5分钟 → 应该自动解锁

**验证点**:
- [ ] 自定义阈值生效 (3次而非5次)
- [ ] 自定义时长生效 (5分钟而非15分钟)
- [ ] 配置热加载工作正常

### TC-006: 并发登录测试

**测试目的**: 验证并发场景下的线程安全

**测试步骤**:
1. 创建测试用户
2. 同时发起5个错误密码登录请求
3. 检查最终状态

**预期结果**:
- 所有请求都应该被正确处理
- 失败计数不应超过5
- 只触发一次锁定操作

**验证点**:
- [ ] 并发计数准确
- [ ] 无重复锁定
- [ ] 数据一致性

### 数据库查询脚本

```sql
-- 检查用户锁定状态
SELECT Username, FailedLoginCount, LockoutEnd, 
       CASE 
         WHEN LockoutEnd IS NULL THEN '未锁定'
         WHEN LockoutEnd > GETUTCDATE() THEN '已锁定'
         ELSE '锁定已过期'
       END AS LockStatus
FROM Users 
WHERE Username IN ('testuser', 'gradual_test');
```
