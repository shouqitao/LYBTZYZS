# 凌隐宝堂中医诊所管理系统 - 发布版本

## 🎉 版本信息
- **版本**: v2.0 Release
- **发布日期**: 2025年8月2日
- **架构**: .NET 8 + WPF桌面应用

## ✨ 新增功能

### 🔍 全面的模糊查询支持
本次发布为所有控制器的列表查询添加了完整的模糊查询功能：

- **用户管理**: 支持用户名、真实姓名、邮箱、电话号码等模糊搜索
- **患者档案**: 支持姓名、电话、身份证号、地址、性别、年龄范围等筛选
- **医生管理**: 支持基本关键词搜索和状态筛选
- **中药材库**: 支持药材名称、产地、功效等模糊查询
- **验方模板**: 支持模板名称和基本属性搜索
- **处方管理**: 支持患者姓名、医生姓名、诊断等筛选
- **挂号管理**: 支持患者和医生姓名、挂号类型、状态等搜索
- **排队管理**: 支持患者和医生姓名、队列类型、状态等筛选
- **病历档案**: 支持患者姓名、医生姓名、诊断、主诉等搜索
- **账单管理**: 支持基本搜索功能
- **药房管理**: 支持处方相关信息搜索

### 🏗️ 系统架构优化
- 修正了所有控制器的分页查询实现
- 统一使用正确的PaginationRequest模式
- 修复了QueueStatus枚举引用问题
- 确保了所有API的类型安全性

## 🚀 快速启动

### 系统要求
- Windows 10/11
- .NET 8 Runtime
- SQL Server 2016 或更高版本

### 启动步骤
1. 双击 `start-lybt-system.bat` 启动WebAPI服务器
2. 等待服务器完全启动（看到"LYBT中医诊所管理系统启动成功"消息）
3. 访问 https://localhost:7001/swagger 查看API文档

### 默认登录信息
- **用户名**: sysadmin
- **密码**: Admin@123456

## 📊 API端点

系统提供完整的RESTful API，包括：

- **用户管理** (`/api/v1/Users`)
- **患者档案** (`/api/v1/Patients`) 
- **医生管理** (`/api/v1/Doctors`)
- **中药材库** (`/api/v1/Herbs`)
- **验方模板** (`/api/v1/FormulaTemplates`)
- **处方管理** (`/api/v1/Prescriptions`)
- **挂号管理** (`/api/v1/Registration`)
- **排队管理** (`/api/v1/Queueing`)
- **病历档案** (`/api/v1/Records`)
- **账单管理** (`/api/v1/Billing`)
- **药房管理** (`/api/v1/Pharmacy`)
- **身份认证** (`/api/v1/Auth`)

每个端点都支持：
- GET - 列表查询（支持模糊搜索和分页）
- GET/{id} - 获取详情
- POST - 新增
- PUT - 更新
- DELETE - 删除

## 🔍 查询功能说明

### 基本查询参数
所有列表接口都支持以下基本参数：
- `page`: 页码（从1开始）
- `pageSize`: 每页大小（默认20）
- `keyword`: 通用关键词搜索

### 高级筛选
各模块根据业务特点支持不同的筛选条件，如：
- 日期范围筛选
- 状态筛选  
- 枚举类型筛选
- 数值范围筛选

## 🚨 注意事项

1. **首次启动**: 系统会自动创建数据库和初始化数据
2. **端口占用**: 确保7001端口未被占用
3. **防火墙**: 可能需要允许应用通过防火墙
4. **数据库权限**: 确保SQL Server连接权限正确
