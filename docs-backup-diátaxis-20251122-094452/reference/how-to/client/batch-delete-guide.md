# 批量删除功能使用指南

**Issue #2150 - Desktop端管理界面批量删除功能**

## 概述

批量删除功能允许用户一次性选择和删除多个数据项,适用于以下管理模块:
- 中药材管理
- 患者管理
- 验方管理
- 用户管理

本文档介绍批量删除功能的使用方法、注意事项和最佳实践。

---

## 功能特性

### 1. 多选功能
- **CheckBox列**: 每行前显示checkbox,支持逐个勾选
- **表头全选**: 点击表头checkbox一键全选/取消全选
- **三态显示**: 表头checkbox根据选择状态自动切换:
  - ☑️ 全选: 所有行已选中
  - ☐ 未选: 无行选中
  - ◼️ 部分选中: 部分行选中

### 2. 快捷键支持
- **Ctrl+A**: 快速全选/取消全选
- **便捷操作**: 无需鼠标即可完成全选操作

### 3. 批量删除流程
1. 勾选需要删除的数据项
2. 点击"批量删除"按钮
3. 确认删除对话框(显示删除数量)
4. 系统逐个删除(部分失败不影响其他)
5. 显示删除结果(成功数、失败数、失败项列表)

## 使用方法

### 中药材管理 - 批量删除

**场景**: 删除过期或不再使用的中药材

**步骤**:

1. **进入中药材管理页面**
   - 导航: 主菜单 → 数据管理 → 中药材管理

2. **勾选药材**
   - 方式1: 逐个勾选每行前的checkbox
   - 方式2: 点击表头checkbox全选所有药材
   - 方式3: 按Ctrl+A快捷键全选

3. **查看选中数量**
   - 表格下方显示"已选择 X 项"

4. **点击批量删除按钮**
   - 位置: 表格下方红色"批量删除"按钮

5. **确认删除**
   - 对话框提示: "确定要删除选中的 X 个中药材吗? 此操作不可恢复!"
   - 点击"确定"执行删除

6. **查看结果**
   - 成功提示: "批量删除完成! 成功：X个 失败：X个"
   - 如有失败项,显示失败药材名称列表

**⚠️ 注意事项**:
- 已被验方引用的药材无法删除(会在失败列表中显示)
- 删除操作不可恢复,请谨慎操作
- 建议删除前导出数据备份

---

### 患者管理 - 批量删除

**场景**: 删除测试数据或已转院患者

**步骤**:

1. **进入患者管理页面**
   - 导航: 主菜单 → 数据管理 → 患者管理

2. **筛选患者**(可选)
   - 使用搜索框或筛选条件缩小范围
   - 例如: 筛选"状态=停诊"的患者

3. **勾选患者**
   - 勾选需要删除的患者记录

4. **批量删除**
   - 点击"批量删除"按钮
   - 确认对话框会显示即将删除的患者数量

5. **查看结果**
   - 系统显示删除成功和失败的统计信息

**⚠️ 注意事项**:
- 有病历记录的患者无法删除
- 建议先归档而非删除(保留历史数据)

---

### 验方管理 - 批量删除

**场景**: 删除重复或错误的验方记录

**步骤**:

1. **进入验方管理页面**
   - 导航: 主菜单 → 数据管理 → 验方管理

2. **搜索验方**(可选)
   - 使用搜索框查找特定验方
   - 可按名称、分类等筛选

3. **选择验方**
   - 勾选需要删除的验方
   - 支持全选或部分选择

4. **执行删除**
   - 点击"批量删除"
   - 确认删除数量和验方名称

5. **结果反馈**
   - 查看删除结果统计

**⚠️ 注意事项**:
- 已被处方引用的验方无法删除
- 建议使用"停用"功能而非直接删除

---

### 用户管理 - 批量删除

**场景**: 删除离职员工账户

**步骤**:

1. **进入用户管理页面**
   - 导航: 主菜单 → 系统设置 → 用户管理

2. **筛选用户**
   - 例如: 筛选"状态=停用"的用户

3. **勾选用户**
   - **禁止删除当前登录用户**: 系统会自动跳过

4. **批量删除**
   - 点击"批量删除"
   - 确认删除用户列表

5. **结果反馈**
   - 如尝试删除当前用户,会在失败列表显示

**⚠️ 特殊规则**:
- **不能删除当前登录用户**(系统自动阻止)
- **不能删除管理员账户**(如果有权限限制)
- 删除用户后,其创建的数据仍保留(如病历、处方)

## 快捷键说明

| 快捷键 | 功能 | 适用场景 |
|--------|------|---------|
| **Ctrl+A** | 全选/取消全选 | 需要选择所有数据时 |
| **空格** | 切换当前行选择状态 | 键盘导航时快速选择 |

**使用技巧**:
1. **全选筛选结果**: 先筛选 → 再Ctrl+A全选 → 批量删除
2. **排除特定行**: Ctrl+A全选 → 取消勾选不需要删除的行
3. **分批删除**: 筛选 → 全选 → 删除 → 再筛选 → 再删除

## 注意事项

### 业务规则

1. **权限控制**:
   - 用户管理: 不能删除当前登录用户
   - 需要相应模块的删除权限

2. **引用完整性**:
   - 被引用的数据无法删除(如被验方引用的药材)
   - 系统会在删除结果中标注失败原因

3. **删除确认**:
   - 所有批量删除操作都需要用户确认
   - 对话框显示删除数量,防止误操作

4. **部分失败处理**:
   - 逐个删除,部分失败不影响其他
   - 失败项目会在结果中列出(最多显示前5项)

### 性能提示

- **大批量删除**: 如需删除100+项,建议分批操作(每次50项以内)
- **网络延迟**: 删除过程中请勿关闭窗口,等待操作完成
- **UI响应**: 删除期间可能有短暂加载状态,属于正常现象

### 数据安全

- **不可恢复**: 删除操作不可撤销,无回收站功能
- **备份建议**: 重要数据删除前请先导出备份
- **替代方案**: 考虑使用"停用"功能代替删除(保留历史数据)

## 常见问题

### Q1: 为什么有些数据无法删除?

**A**: 可能原因:
- 数据被其他模块引用(如药材被验方使用)
- 用户尝试删除当前登录账户(用户管理)
- 缺少删除权限
- 数据状态不允许删除(如已完成的处方)

**解决方案**: 查看删除结果中的失败原因,根据提示调整

### Q2: 批量删除后数据还能恢复吗?

**A**: **不能恢复**。删除操作是永久性的,没有回收站功能。建议:
- 删除前仔细确认选择的数据
- 重要数据请先导出备份
- 考虑使用"停用"功能而非删除

### Q3: 全选后如何排除某些行?

**A**: 两种方法:
1. **Ctrl+A全选 → 取消勾选不需要的行**
2. **先筛选 → 再全选**(只选择筛选结果)

### Q4: 批量删除卡住了怎么办?

**A**:
- **等待一段时间**: 大批量删除可能需要几秒钟
- **不要关闭窗口**: 删除过程中请勿操作
- **查看进度**: 部分模块会显示删除进度
- **联系管理员**: 如长时间无响应,请联系系统管理员

### Q5: 为什么表头checkbox显示为方块(◼️)?

**A**: 这是**部分选中状态**,表示:
- 当前页有部分行被选中
- 不是全选也不是全未选
- 点击可切换为全选状态

### Q6: Ctrl+A无效怎么办?

**A**: 检查:
- 光标是否在表格区域内(点击表格后再按Ctrl+A)
- 浏览器或系统是否拦截了快捷键
- 也可以直接点击表头checkbox实现全选

## 最佳实践

### 1. 删除前筛选

**推荐做法**:
```
搜索/筛选 → 确认结果 → 全选 → 批量删除
```

**示例**: 删除停诊患者
1. 筛选条件: "状态=停诊"
2. 确认筛选结果都是需要删除的患者
3. Ctrl+A全选筛选结果
4. 批量删除

### 2. 分批次删除

**场景**: 删除大量数据(100+项)

**推荐做法**:
- 每次选择50项以内
- 删除完成后再选择下一批
- 避免一次性删除过多导致超时

### 3. 数据备份

**重要操作前**:
1. 导出当前数据为Excel
2. 确认备份文件完整
3. 再执行批量删除

### 4. 使用停用功能

**替代删除**:
- 对于可能恢复的数据,使用"停用"而非删除
- 停用的数据可以随时重新启用
- 保留历史数据,便于追溯
