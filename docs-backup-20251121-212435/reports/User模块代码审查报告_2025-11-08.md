**问题描述**: 两个私有异步方法使用 `async void` 而非 `async Task`，可能导致异常无法捕获。

**影响**: 运行时异常可能导致应用崩溃，且无法通过try-catch捕获。

```csharp
/// <summary>
/// 检查当前用户是否可以管理目标用户
/// 权限规则：
/// - SuperAdmin（100）可以管理 Admin 和 Doctor
/// - Admin（10）可以管理 Doctor，但不能管理 Admin 或 SuperAdmin
/// - Doctor（1）只能修改自己的信息
/// </summary>
private bool CanManageUser(UserRole? currentUserRole, UserRole? targetUserRole)
{
    if (!currentUserRole.HasValue || !targetUserRole.HasValue)
        return false;

    return currentUserRole.Value switch
    {
        UserRole.SuperAdmin => true,
        UserRole.Admin => targetUserRole.Value == UserRole.Doctor,
        UserRole.Doctor => false,
        _ => false
    };
}
```

**评价**: 
- ✅ 权限规则清晰
- ✅ 保护最后一个SuperAdmin/Admin不被删除
- ✅ 基于JWT Claims的身份验证

### 4. 拼音码功能已修复 ✅

**问题历史**: NPinyin库存在.NET 8兼容性问题（NU1701警告）

**修复方案**: 替换为 `hyjiacan.pinyin4net v4.1.1`（原生.NET 8支持）

**修复后代码**:
```csharp
public static string GetPinYinCode(string? text)
{
    if (string.IsNullOrWhiteSpace(text))
        return string.Empty;

    try
    {
        // 使用hyjiacan.pinyin4net获取拼音首字母
        var initials = Pinyin4Net.GetPinyin(
            text,
            PinyinFormat.UPPERCASE,
            caseSpread: false,
            firstLetterOnly: true,
            multiFirstLetter: false);

        // 去除方括号和空格，例如："[l][w][m]" → "LWM"
        return initials
            .Replace("[", string.Empty)
            .Replace("]", string.Empty)
            .Replace(" ", string.Empty)
            .ToUpperInvariant();
    }
    catch
    {
        return GetPinYinCodeFallback(text);
    }
}
```

**测试结果**:
- ✅ "张韶涵" → "ZSH" ✓
- ✅ "刘伟明" → "LWM" ✓
- ✅ "刘伟明子" → "LWMZ" ✓

**评价**: 修复彻底，包含降级方案（fallback），符合鲁棒性要求。

**相关文件**:
- `src/Shared/LYBT.Shared.Utilities/Text/PinYinHelper.cs`
- `Directory.Packages.props` (添加 hyjiacan.pinyin4net v4.1.1)

### 5. AutoMapper配置规范 ✅

```csharp
public class UserMappingProfile : Profile
{
    public UserMappingProfile()
```
