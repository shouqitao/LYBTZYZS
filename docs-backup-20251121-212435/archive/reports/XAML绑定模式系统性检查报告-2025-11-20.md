## 🔍 检查方法

### 1. 只读属性识别流程
```
Read ViewModel → 识别只读属性 → 检查XAML绑定 → 验证绑定模式
```

### 2. 只读属性类型
按照`xaml-binding-checklist.md`标准，识别以下类型：
- **Server生成属性**: CreatedAt, UpdatedAt, ConsultationDate
- **计算属性**: HerbCount, Step1CompletedAtText, PrescriptionDisabled
- **表达式属性**: `=> !IsEditMode`

### 3. 检查标准
所有只读属性的XAML绑定必须明确指定`Mode=OneWay`，即使控件默认绑定模式是OneWay（如TextBlock），也需要明确指定以保持一致性和防止未来错误。

```xml
<!-- 修复前 (Line 78) -->

<!-- 修复后 -->

```

#### 问题2: Step1CompletedAtVisibility 绑定缺少Mode=OneWay

```xml
<!-- 修复后 -->
<TextBlock Visibility="{Binding Step1CompletedAtVisibility, Mode=OneWay}" />
```

#### 问题3: PrescriptionDisabled 绑定缺少Mode=OneWay（RadioButton）
```xml
<!-- 修复前 (Line 181) -->
<RadioButton Content="不开处方"
            IsChecked="{Binding PrescriptionDisabled}" />

<!-- 修复后 -->
<RadioButton Content="不开处方"
            IsChecked="{Binding PrescriptionDisabled, Mode=OneWay}" />
```

**影响分析**:
- ⚠️ **问题3是高风险问题**: RadioButton的`IsChecked`默认绑定模式是**TwoWay**
- 如果用户点击"不开处方"，WPF会尝试将`true`写回`PrescriptionDisabled`属性
- `PrescriptionDisabled`是只读计算属性（无setter），会导致**运行时绑定错误**
- 这是本次检查中唯一可能立即触发错误的绑定问题

- `HasTCMDiagnosis`: XAML中未使用

## 📚 最佳实践总结

### 1. XAML绑定模式原则
```xml
<!-- ✅ 推荐：明确指定绑定模式 -->
<TextBlock Text="{Binding ReadOnlyProperty, Mode=OneWay}" />

<!-- ❌ 不推荐：依赖默认绑定模式 -->
<TextBlock Text="{Binding ReadOnlyProperty}" />
```

### 2. 只读属性识别 Checklist
- [ ] `private set` 或无setter
- [ ] 计算属性（`=>`表达式）
- [ ] Server生成属性（CreatedAt, UpdatedAt等）
- [ ] 表达式属性（如`IsReadOnly => !IsEditMode`）

### 3. 高风险控件
以下控件默认使用**TwoWay**绑定，绑定只读属性时**必须**明确指定`Mode=OneWay`：
- `<TextBox Text="{Binding ...}" />`
- `<CheckBox IsChecked="{Binding ...}" />`
- `<RadioButton IsChecked="{Binding ...}" />`
- `<ComboBox SelectedItem="{Binding ...}" />`
- `<DatePicker SelectedDate="{Binding ...}" />`

### 4. 低风险控件（仍建议明确指定）
以下控件默认使用**OneWay**绑定，但为保持一致性，仍建议明确指定：
- `<TextBlock Text="{Binding ...}" />`
- `<Label Content="{Binding ...}" />`
- `<ContentControl Content="{Binding ...}" />`
