# 用户体验验证清单 (UX Checklist)

**用途**: 验证功能的用户体验质量，确保易用性和一致性
**适用阶段**: Design阶段和Implementation阶段
**强制级别**: 可选 (SHOULD) - 建议用于面向用户的功能

---

## 1. 交互设计 (Interaction Design)

### 1.1 响应速度 (Response Time)
- [ ] **页面加载速度** - 初始加载≤2秒
- [ ] **操作响应速度** - 按钮点击/表单提交≤1秒
- [ ] **搜索响应速度** - 搜索结果返回≤1秒
- [ ] **长时操作提示** - 超过2秒的操作显示进度指示器

### 1.2 反馈机制 (Feedback Mechanism)
- [ ] **操作成功反馈** - 成功操作显示明确提示（绿色通知/勾选图标）
- [ ] **操作失败反馈** - 失败操作显示清晰错误信息（红色通知/错误详情）
- [ ] **加载状态反馈** - 加载过程显示Loading动画/进度条
- [ ] **禁用状态反馈** - 不可用功能显示禁用状态（灰色按钮）

### 1.3 错误处理 (Error Handling)
- [ ] **错误提示友好** - 错误消息使用通俗语言，避免技术术语
- [ ] **错误提示具体** - 明确告知用户哪里出错，如何修复
- [ ] **表单验证即时** - 输入框失焦时立即验证，不等提交
- [ ] **错误恢复机制** - 提供重试/撤销/返回上一步等恢复选项

---

## 2. 界面设计 (UI Design)

### 2.1 视觉一致性 (Visual Consistency)
- [ ] **颜色使用一致** - 主题色/强调色/警告色使用统一
- [ ] **字体使用一致** - 字体族/大小/粗细遵循设计规范
- [ ] **图标使用一致** - 同类操作使用相同图标风格
- [ ] **布局结构一致** - 列表/表单/对话框布局遵循统一模式

### 2.2 信息层次 (Information Hierarchy)
- [ ] **标题层级清晰** - H1/H2/H3层级分明，视觉区分明显
- [ ] **重要信息突出** - 关键数据/操作按钮使用强调色/较大字号
- [ ] **次要信息弱化** - 辅助信息使用较淡颜色/较小字号
- [ ] **空白使用合理** - 留白充足，避免拥挤

### 2.3 可读性 (Readability)
- [ ] **字体大小适中** - 正文≥14px，确保阅读舒适
- [ ] **行高合理** - 行高≥1.5倍字体大小
- [ ] **对比度充足** - 文本与背景对比度≥4.5:1（WCAG AA标准）
- [ ] **关键信息可扫描** - 使用加粗/颜色突出关键词

---

## 3. 导航与信息架构 (Navigation & IA)

### 3.1 导航设计 (Navigation Design)
- [ ] **导航位置固定** - 主导航位置一致，易于找到
- [ ] **面包屑导航** - 深层页面提供面包屑，明确当前位置
- [ ] **返回功能** - 提供明确的返回上一级/主页的方式
- [ ] **导航标签清晰** - 导航项名称简洁明了，避免歧义

### 3.2 信息查找 (Information Finding)
- [ ] **搜索功能易用** - 搜索框位置明显，支持模糊搜索
- [ ] **搜索结果相关** - 搜索结果按相关性排序
- [ ] **筛选功能完整** - 提供合理的筛选/排序选项
- [ ] **关键操作3次点击内** - 核心功能3次点击内可到达

### 3.3 页面结构 (Page Structure)
- [ ] **首屏信息完整** - 首屏包含核心信息/操作入口
- [ ] **滚动合理** - 避免过长页面，合理分页/分组
- [ ] **固定头部** - 长页面固定头部导航
- [ ] **返回顶部** - 长页面提供返回顶部按钮

---

## 4. 表单设计 (Form Design)

### 4.1 表单布局 (Form Layout)
- [ ] **表单结构清晰** - 逻辑分组，使用标题/分隔线
- [ ] **标签对齐** - 标签与输入框对齐方式一致（左对齐/上对齐）
- [ ] **必填项标识** - 必填字段明确标注（红色星号）
- [ ] **帮助文本** - 复杂字段提供帮助文本/示例

### 4.2 输入控件选择 (Input Control Selection)
- [ ] **控件类型合理** - 日期用日期选择器，枚举用下拉框/单选框
- [ ] **输入提示** - 输入框提供Placeholder示例
- [ ] **默认值合理** - 常用选项设为默认值
- [ ] **自动聚焦** - 表单打开时自动聚焦第一个输入框

### 4.3 表单验证 (Form Validation)
- [ ] **验证即时** - 输入框失焦时立即验证
- [ ] **验证提示清晰** - 错误信息显示在输入框下方，红色字体
- [ ] **验证规则明确** - 提前告知验证规则（密码长度≥8等）
- [ ] **提交前整体验证** - 提交前再次验证所有字段

### 4.4 表单提交 (Form Submission)
- [ ] **提交按钮状态** - 验证通过前禁用提交按钮
- [ ] **提交反馈** - 提交中显示Loading，成功/失败显示明确提示
- [ ] **防止重复提交** - 提交中禁用提交按钮
- [ ] **数据保留** - 提交失败时保留已填数据

---

## 5. 数据展示 (Data Presentation)

### 5.1 列表/表格设计 (List/Table Design)
- [ ] **列宽合理** - 列宽根据内容自动调整或固定
- [ ] **表头固定** - 长表格固定表头
- [ ] **分页/虚拟滚动** - 大数据集使用分页或虚拟滚动
- [ ] **排序/筛选** - 提供列排序、筛选功能

### 5.2 数据可读性 (Data Readability)
- [ ] **数据格式化** - 日期/金额/百分比格式统一
- [ ] **空状态处理** - 无数据时显示友好提示，提供操作引导
- [ ] **数据截断** - 过长文本使用省略号，提供Tooltip查看完整内容
- [ ] **数据对齐** - 数字右对齐，文本左对齐

### 5.3 数据操作 (Data Operations)
- [ ] **批量操作** - 支持多选批量操作（批量删除/导出等）
- [ ] **快捷操作** - 行内提供快捷操作按钮（编辑/删除/查看）
- [ ] **操作确认** - 危险操作（删除）二次确认
- [ ] **撤销机制** - 重要操作提供撤销选项

---

## 6. 对话框与通知 (Dialogs & Notifications)

### 6.1 对话框设计 (Dialog Design)
- [ ] **模态对话框合理** - 重要操作/确认使用模态对话框
- [ ] **对话框标题清晰** - 标题明确说明对话框用途
- [ ] **按钮位置一致** - 确认按钮在右侧，取消在左侧
- [ ] **ESC关闭** - 对话框支持ESC键关闭

### 6.2 通知设计 (Notification Design)
- [ ] **通知位置固定** - 通知位置一致（右上角/中间）
- [ ] **通知自动消失** - 成功通知3秒后自动消失
- [ ] **通知可手动关闭** - 提供关闭按钮
- [ ] **通知不阻塞操作** - 通知不遮挡主要内容

### 6.3 确认对话框 (Confirmation Dialogs)
- [ ] **确认内容具体** - 明确告知操作内容和影响
- [ ] **按钮文本具体** - 使用"删除"而非"确定"
- [ ] **危险操作突出** - 危险操作按钮使用警告色（红色）

---

## 7. 性能感知 (Perceived Performance)

### 7.1 加载优化 (Loading Optimization)
- [ ] **骨架屏** - 数据加载时显示骨架屏而非空白
- [ ] **懒加载** - 图片/组件按需加载
- [ ] **乐观更新** - 操作立即反馈，后台异步保存
- [ ] **预加载** - 预加载可能访问的资源

### 7.2 响应式设计 (Responsive Design)
- [ ] **界面即时响应** - 按钮点击有视觉反馈（按下效果）
- [ ] **动画流畅** - 动画帧率≥60fps
- [ ] **无卡顿** - 长列表滚动流畅，无明显卡顿

---

## 8. 无障碍访问 (Accessibility - 基础)

### 8.1 键盘导航 (Keyboard Navigation)
- [ ] **Tab键导航** - 所有交互元素可通过Tab键访问
- [ ] **Tab顺序合理** - Tab顺序符合逻辑（从左到右，从上到下）
- [ ] **焦点可视** - 焦点元素有明显视觉反馈（边框/高亮）
- [ ] **Enter提交** - 表单支持Enter键提交

### 8.2 语义化 (Semantic HTML)
- [ ] **使用语义化标签** - 使用button/input/label等语义化元素
- [ ] **表单标签关联** - label与input通过for/id关联
- [ ] **Alt文本** - 图片提供有意义的Alt文本

---

## 9. 移动端适配 (Mobile Optimization - 可选)

### 9.1 触摸优化 (Touch Optimization)
- [ ] **按钮尺寸** - 触摸目标≥44x44px
- [ ] **按钮间距** - 按钮间距≥8px，避免误触
- [ ] **手势支持** - 支持滑动/长按等常见手势

### 9.2 布局自适应 (Responsive Layout)
- [ ] **响应式布局** - 不同屏幕尺寸下布局合理
- [ ] **字体自适应** - 移动端字体大小适中
- [ ] **图片自适应** - 图片根据屏幕尺寸缩放

---

## 10. 一致性检查 (Consistency Check)

### 10.1 与现有功能一致 (Consistency with Existing Features)
- [ ] **交互模式一致** - 与现有功能的交互方式保持一致
- [ ] **术语使用一致** - 术语/标签与现有功能保持一致
- [ ] **视觉风格一致** - 颜色/字体/图标与现有功能保持一致

### 10.2 平台规范一致 (Platform Guidelines Consistency)
- [ ] **WPF规范** - 符合WPF应用设计规范
- [ ] **Windows规范** - 符合Windows应用通用规范
- [ ] **医疗行业规范** - 符合医疗软件设计规范
