# LYBT.Module.Patients 模块说明

## 📌 模块简介

该模块用于管理中医诊所系统中的患者基本信息，包括：

- 患者新增、修改、删除
- 列表展示、搜索功能
- 模块内逻辑清晰、支持扩展

## 📁 项目结构

- `Enums/`：枚举类（性别）
- `Interfaces/`：服务与仓储接口
- `Models/`：领域模型与 DTO 数据传输对象
- `Repositories/`：仓储实现（当前为内存模拟）
- `Services/`：业务实现（校验、转换、逻辑）
- `Extensions/`：DTO 与模型的映射转换器
- `PatientsModule.cs`：模块注册类（用于 Prism 注入）

## ✅ 特性

- 使用 DTO 模式拆分业务模型与展示模型
- 使用 `[Description]` 注释所有枚举
- 所有必填字段前后端双重校验
- 所有代码含完整中文注释
