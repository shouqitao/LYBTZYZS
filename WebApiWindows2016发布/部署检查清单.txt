===============================================
   LYBT WebAPI 部署检查清单
===============================================

□ 环境准备
  □ Windows Server 2016 或更高版本
  □ .NET 8.0 Runtime 已安装
  □ SQL Server 已安装并运行
  □ 防火墙规则已配置

□ 数据库配置
  □ 创建数据库 LYBT
  □ 配置数据库用户权限
  □ 更新连接字符串
  □ 运行数据库初始化脚本

□ 应用程序配置
  □ 修改 appsettings.Production.json
  □ 设置 JWT 密钥（至少32字符）
  □ 配置日志路径
  □ 设置环境变量

□ 发布步骤
  □ 运行 publish-production.bat
  □ 检查发布输出无错误
  □ 复制配置文件到发布目录
  □ 设置文件夹权限

□ 服务配置
  □ 选择部署方式（控制台/服务/IIS）
  □ 配置自动启动
  □ 设置服务账户
  □ 配置服务恢复选项

□ 测试验证
  □ 启动应用程序
  □ 访问 Swagger 文档
  □ 测试登录功能
  □ 验证数据库连接
  □ 检查日志生成

□ 安全检查
  □ 修改默认密码
  □ 启用 HTTPS（生产环境）
  □ 限制端口访问
  □ 配置备份策略

□ 监控配置
  □ 配置健康检查
  □ 设置日志轮转
  □ 配置性能监控
  □ 设置告警通知
