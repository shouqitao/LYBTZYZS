## MODIFIED Requirements

### Requirement: REQ-SHELL-001 Shell层紧凑布局

登录后的Shell布局 SHALL 最小化固定占用空间，最大化工作区可用面积。

**Acceptance Criteria:**
- 顶部工具栏高度**48px**（从60px压缩）
- 内容区外边距**12px**（从20px压缩）
- 内容区内边距**12px**（从20px压缩）
- Shell层总固定占用不超过**96px**（从140px优化）
- 1080p分辨率下，二级工作界面可用高度不低于**838px**

#### Scenario: Shell层空间效率
- **GIVEN** 用户使用1920×1080分辨率显示器
- **WHEN** 用户进入任意二级工作界面
- **THEN** Shell层固定占用（Header + 边距）不超过96px
- **AND** 工作区可用高度至少为838px（不含界面内部固定元素）

### Requirement: REQ-SHELL-002 顶部工具栏状态集成

登录后的顶部工具栏 SHALL 在**48px高度内**集成时间显示、API状态指示器和用户菜单。

**Acceptance Criteria:**
- 顶部工具栏高度**48px**
- 左侧显示系统名称（字号适配48px高度）
- 右侧从左到右依次为：时间 -> API状态 -> 用户菜单 -> 退出登录按钮
- 时间格式为HH:mm
- API状态使用圆点指示器 + 文字标签
- 用户菜单包含：用户名称、下拉菜单（修改个人信息、修改密码）
- 所有元素垂直居中，适配紧凑高度

#### Scenario: 顶部栏右侧布局
- **GIVEN** 用户已登录
- **WHEN** 用户查看顶部工具栏
- **THEN** 右侧显示当前时间(HH:mm格式)
- **AND** 时间右侧显示API状态指示器
- **AND** API状态右侧显示用户菜单（含用户名和下拉箭头）
- **AND** 最右侧显示退出登录按钮

#### Scenario: 顶部栏API状态显示正常
- **GIVEN** 用户已登录
- **AND** API服务连接正常
- **WHEN** 用户查看顶部工具栏
- **THEN** API状态显示绿色圆点
- **AND** 圆点旁显示"正常"文字

#### Scenario: 顶部栏API状态失败
- **GIVEN** 用户已登录
- **AND** API服务连接失败
- **WHEN** 用户查看顶部工具栏
- **THEN** API状态显示红色圆点
- **AND** 圆点旁显示"连接失败"文字
- **AND** 显示"重试"链接按钮

## ADDED Requirements

### Requirement: REQ-SHELL-004 用户菜单

顶部工具栏 SHALL 包含用户菜单，提供账户相关操作的统一入口。

**Acceptance Criteria:**
- 用户菜单显示当前用户名和下拉箭头
- 点击用户菜单展开下拉面板
- 下拉面板包含：用户角色显示、修改个人信息、修改密码三个选项
- 下拉面板点击外部区域自动关闭
- 菜单项点击后触发相应导航或对话框

#### Scenario: 用户菜单展开
- **GIVEN** 用户已登录
- **WHEN** 用户点击顶部栏的用户名区域
- **THEN** 展开用户菜单下拉面板
- **AND** 面板显示当前用户角色
- **AND** 面板显示"修改个人信息"选项
- **AND** 面板显示"修改密码"选项

#### Scenario: 修改个人信息
- **GIVEN** 用户菜单已展开
- **WHEN** 用户点击"修改个人信息"
- **THEN** 导航到个人信息编辑页面
- **AND** 用户菜单自动关闭

#### Scenario: 修改密码
- **GIVEN** 用户菜单已展开
- **WHEN** 用户点击"修改密码"
- **THEN** 打开修改密码对话框
- **AND** 用户菜单自动关闭

#### Scenario: 菜单外部点击关闭
- **GIVEN** 用户菜单已展开
- **WHEN** 用户点击菜单外部区域
- **THEN** 用户菜单自动关闭
