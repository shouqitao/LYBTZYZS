# Design: refactor-medicalcase-ui

## Architecture Overview

本次重构仅涉及UI层（View和XAML资源），不修改ViewModel业务逻辑和数据绑定。

```
重构范围:
┌─────────────────────────────────────────────────────────────┐
│                    MedicalCaseWorkspaceView                 │
│  ┌────────────────────┬────────────────────────────────┐   │
│  │  ConsultationPanel │    PrescriptionEditorPanel     │   │
│  │      (40%)         │          (60%)                 │   │
│  └────────────────────┴────────────────────────────────┘   │
│                      BottomActionBar                        │
└─────────────────────────────────────────────────────────────┘
```

## Target Resolution

- **主目标**: 1920x1080 (Full HD)
- **最小支持**: 1366x768
- **设计策略**: 使用相对布局(*星号)和百分比，避免硬编码像素值

## Design System

### 1. 颜色规范

```xaml
<!-- 主色调 -->
<Color x:Key="PrimaryColor">#2196F3</Color>        <!-- 蓝色 - 主要操作 -->
<Color x:Key="PrimaryDarkColor">#1976D2</Color>    <!-- 深蓝 - 悬停态 -->

<!-- 功能色 -->
<Color x:Key="SuccessColor">#4CAF50</Color>        <!-- 绿色 - 确认/完成 -->
<Color x:Key="WarningColor">#FF9800</Color>        <!-- 橙色 - 暂停/警告 -->
<Color x:Key="DangerColor">#F44336</Color>         <!-- 红色 - 取消/删除 -->

<!-- 中性色 -->
<Color x:Key="BackgroundColor">#F5F5F5</Color>     <!-- 页面背景 -->
<Color x:Key="SurfaceColor">#FFFFFF</Color>        <!-- 卡片背景 -->
<Color x:Key="BorderColor">#E0E0E0</Color>         <!-- 边框 -->
<Color x:Key="TextPrimaryColor">#333333</Color>    <!-- 主文本 -->
<Color x:Key="TextSecondaryColor">#666666</Color>  <!-- 次要文本 -->
<Color x:Key="TextHintColor">#999999</Color>       <!-- 提示文本 -->
```

### 2. 间距规范 (4px网格)

```
xs: 4px   - 紧凑间距
sm: 8px   - 元素内间距
md: 16px  - 区块间距
lg: 24px  - 主区域间距
xl: 32px  - 页面边距
```

### 3. 字体规范

```
标题: 16px, Bold, TextPrimaryColor
副标题: 14px, SemiBold, TextPrimaryColor
正文: 13px, Regular, TextPrimaryColor
辅助: 12px, Regular, TextSecondaryColor
提示: 11px, Regular, TextHintColor
```

### 4. 按钮样式

| 类型 | 用途 | 背景 | 前景 | 边框 |
|------|------|------|------|------|
| Primary | 主要操作(完成看诊) | SuccessColor | White | None |
| Secondary | 次要操作(打印) | PrimaryColor | White | None |
| Outline | 导入/辅助操作 | Transparent | PrimaryColor | PrimaryColor |
| Warning | 暂停操作 | WarningColor | White | None |
| Danger | 取消/删除 | DangerColor | White | None |

### 底部操作栏重构

**Before (问题):**
- 状态文本冗长: "诊断状态: 已完成 | 处方状态: 待开方"
- 按钮排列不合理

**After (改进):**
```
┌───────────────────────────────────────────────────────────────┐
│ [暂停看诊]     ●已诊断  ●待开方      [打印处方笺] [完成看诊] │
└───────────────────────────────────────────────────────────────┘

- 暂停看诊: 左侧，橙色次要按钮
- 状态指示: 中间，使用小圆点+简短文本
  - ● 绿色 = 已完成
  - ● 灰色 = 待处理
  - ● 黄色 = 进行中
- 打印/完成: 右侧，按重要性排列
```

## Implementation Notes

### 不引入第三方控件
- 所有样式使用WPF原生控件 + 自定义样式
- 按钮圆角使用 `Border.CornerRadius`
- 阴影效果使用 `DropShadowEffect`（谨慎使用，避免性能问题）

### MVVM兼容性
- 仅修改XAML，不改变数据绑定路径
- 保持现有Command绑定不变
- ViewModel层无需修改

### 响应式设计
- 使用Grid的星号(*)列定义
- 使用MinWidth/MaxWidth约束
- 测试1920x1080和1366x768两种分辨率
