# OpenSpec Proposal: enhance-prescription-print

## Summary

增强处方打印功能，实现完整的打印预览和打印对话框，支持打印机选择、纸张格式设置，并优化布局使其与Word模板完全一致。

## Motivation

### 现状问题

1. **打印预览缺少工具栏**：当前预览窗口没有打印按钮和关闭按钮
2. **无法选择打印机**：直接打印时无法选择目标打印机
3. **布局与模板不一致**：
   - 内容未实现两端对齐
   - 头部信息和底部签名区域未固定位置
   - 中间处方区域空白时未保持适当间距
4. **视觉效果不佳**：预览窗口背景色不协调

### 业务需求

- 提供标准打印对话框，支持打印机选择和打印设置
- 预览界面提供明确的打印和关闭操作
- 布局完全匹配Word模板：头部固定、底部固定、中间自适应

## Requirements

### 功能需求

#### REQ-001: 打印预览工具栏

- 预览窗口顶部显示工具栏
- 包含"打印"按钮：点击弹出系统打印对话框
- 包含"关闭"按钮：关闭预览窗口
- 可选：缩放控制按钮

#### REQ-002: 打印对话框

- 使用系统PrintDialog控件
- 支持选择打印机
- 支持设置打印份数
- 支持纸张方向和尺寸（默认A5纵向）
- 确认打印后关闭预览窗口

#### REQ-003: 布局优化 - 两端对齐

- 文档整体使用两端对齐(TextAlignment.Justify)
- 患者信息行使用表格或固定间距实现对齐
- 药材列表4列等宽对齐

#### REQ-004: 布局优化 - 固定区域

- **头部区域（固定）**：
  - 诊所名称标题
  - 患者信息（姓名/性别/年龄/时间）
  - 门诊号/科别/电话
  - 住址/诊断/诊见
- **中间区域（自适应）**：
  - Rp. 标记
  - 药材列表（4列格式）
  - 剂数和用法
  - 空白时保持适当间距
- **底部区域（固定在页面底部）**：
  - 分隔线
  - 医师签字/审核/调配
  - 诊疗费/药费/治疗费/合计

#### REQ-005: 视觉优化

- 预览窗口背景使用白色
- 文档区域清晰可见
- 工具栏与文档区域视觉分离

### 非功能需求

- NFR-001: 打印对话框响应时间 < 200ms
- NFR-002: 预览窗口打开时间 < 500ms
- NFR-003: 打印输出与预览一致

### 核心功能清单

1. **打印机选择**
   - 下拉列表显示可用打印机
   - 显示打印机状态（就绪/脱机/错误）
   - 默认选择系统默认打印机

2. **打印份数**
   - 数字输入框，默认1
   - 支持上下调整按钮

3. **纸张设置**
   - 纸张尺寸：A5（固定，处方专用）
   - 方向：纵向（固定）

4. **页面导航**
   - 上一页/下一页按钮
   - 当前页/总页数显示

5. **缩放控制**
   - 放大/缩小按钮
   - 缩放百分比显示
   - 适合页面宽度/高度

## Technical Approach

### 方案A: 自定义打印预览窗口（推荐）

创建专用的打印预览UserControl/Window：
- 左侧设置面板（打印机、份数等）
- 右侧文档预览区域（DocumentViewer）
- 底部页面导航和缩放控制

**优点**：
- 完全控制UI布局和交互
- 可扩展性强
- 符合现代应用设计规范

**缺点**：
- 开发工作量较大
- 需要处理打印机枚举等系统交互

### 方案B: 使用PrintDialogX库

集成开源PrintDialogX库：
- NuGet安装：`PrintDialogX`
- 依赖：Wpf.Ui (≥4.0.0)

**优点**：
- 功能完整，开箱即用
- UI美观，经过验证
- 减少开发时间

**缺点**：
- 引入额外依赖
- 可能需要样式定制以匹配应用主题

### 方案C: 简化版 - 系统PrintDialog + 自定义预览

保持当前自定义预览窗口，打印时调用系统PrintDialog：
- 预览窗口只负责显示
- 打印按钮触发系统PrintDialog
- 系统对话框处理打印机选择等

**优点**：
- 改动最小
- 使用用户熟悉的系统对话框

**缺点**：
- 预览和打印设置分离
- 用户体验不够流畅

### 实现选择

建议采用**方案A**（自定义打印预览窗口），可参考PrintDialogX的设计理念，但自行实现以避免依赖问题。如时间紧迫，可先采用**方案C**快速上线。
