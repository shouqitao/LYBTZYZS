# 医案模块手动测试检查清单

OpenSpec: refactor-viewmodel-layer Phase 4.1.2

## 测试环境准备

- [ ] 确保数据库已连接
- [ ] 使用Admin账户登录
- [ ] 确认有至少一个患者数据

---

## A. 临床工作区 (Clinical Mode)

### A1. 新建医案流程

- [ ] 从患者选择页面选择一个患者
- [ ] 验证工作区显示**"看诊中"**标题
- [ ] 验证显示**"编辑中"**状态
- [ ] 验证**暂存按钮**可见
- [ ] 验证**完成看诊按钮**可见
- [ ] 验证**编辑按钮**不可见 (因为已在编辑模式)

### A2. 诊断面板操作

- [ ] 输入主诉内容
- [ ] 输入中医诊断
- [ ] 验证表单可正常编辑

### A3. 处方面板操作

- [ ] 添加药材到处方
- [ ] 修改药材剂量
- [ ] 删除药材
- [ ] 验证处方计算正确

### A4. 暂存操作

- [ ] 点击**暂存**按钮
- [ ] 验证保存成功提示
- [ ] 验证数据已持久化

### A5. 完成看诊操作

- [ ] 点击**完成看诊**按钮
- [ ] 验证确认对话框出现
- [ ] 确认完成
- [ ] 验证返回患者选择页面

---

## B. 管理工作区 (Management Mode)

### B1. 查看已完成医案

- [ ] 打开医案管理页面
- [ ] 选择一个已完成的医案
- [ ] 验证工作区显示**"查看医案"**标题
- [ ] 验证显示**"只读"**状态
- [ ] 验证**编辑按钮**在右上角可见 (如果有权限)

### B2. 进入编辑模式

- [ ] 点击**编辑**按钮
- [ ] 验证状态变为**"历史编辑中"** (橙色)
- [ ] 验证**保存按钮**出现
- [ ] 验证诊断和处方面板变为可编辑

### B3. 保存编辑

- [ ] 修改诊断内容
- [ ] 点击**保存**按钮
- [ ] 验证保存成功

### B4. 返回列表

- [ ] 点击**返回医案列表**按钮
- [ ] 验证正确返回到医案管理页面

---

## C. 权限测试

- [ ] 验证**编辑按钮不可见**
- [ ] 验证处于**只读模式**

### C2. 管理员权限

- [ ] 用Admin账户查看任意医案
- [ ] 验证**编辑按钮可见**
- [ ] 验证可进入编辑模式
