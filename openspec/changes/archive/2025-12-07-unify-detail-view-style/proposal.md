# OpenSpec Proposal: unify-detail-view-style

## 概述

统一所有实体详情查看页（DetailView）的UI风格和操作模式，提升用户体验一致性和操作流畅度。

## 背景

当前系统存在5个详情查看页面，各自采用不同的布局结构、样式定义和操作模式：

| 视图 | 布局结构 | 表单布局 | 本地样式 | 加载指示 |
|------|----------|----------|----------|----------|
| PatientDetailView | 3行布局 | 2列垂直 | 4个重复定义 | Loading遮罩 |
| HerbDetailView | 3行布局 | 2列垂直 | 4个重复定义 | Loading遮罩 |
| UserDetailView | 2行ScrollViewer | 单行水平 | 内联样式 | 无 |
| FormulaDetailView | 3行布局 | 4列表格 | 引用共享 | ProgressBar |
| MedicalCaseDetailView | 2行布局 | 卡片式 | 引用共享 | ProgressBar遮罩 |

## 问题分析

### UI风格不一致
1. **布局结构差异**：3行 vs 2行布局，ScrollViewer位置不统一
2. **表单排列差异**：2列垂直、单行水平、4列表格、卡片式混用
3. **样式重复定义**：FormLabelStyle、EditableTextBoxStyle等在多个视图中重复
4. **加载指示差异**：遮罩+文字、ProgressBar、无加载指示

### 操作风格不一致
1. **编辑按钮位置**：有的在底部按钮栏，有的在表单内，有的在顶部工具栏
2. **列表页存在"编辑"按钮**：用户需先查看再编辑时，要先点击"查看"进入详情页，再返回列表点击"编辑"，操作不流畅
3. **按钮样式差异**：各视图使用不同的按钮样式引用

## 解决方案

### 1. 统一UI风格

采用标准化的详情页布局模板：

```
┌─────────────────────────────────────────────────────┐
│ [返回] 页面标题                          [编辑按钮] │  ← 顶部工具栏
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │ 表单内容区域（统一2列布局）                  │   │  ← ScrollViewer包裹
│  │ 标签: 值    标签: 值                        │   │
│  │ 标签: 值    标签: 值                        │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
├─────────────────────────────────────────────────────┤
│ 状态信息                              [操作按钮组] │  ← 底部操作栏
└─────────────────────────────────────────────────────┘
```

### 2. 统一操作流程

**核心改进：将"编辑"按钮从列表页移至详情页右上角**

- **列表页**：移除"编辑"按钮，保留"查看"、"删除"等按钮
- **详情页**：右上角工具栏固定放置"编辑"按钮
- **操作流程**：查看 → 详情页 → 编辑（无需返回列表）

### 3. 样式统一

- 将重复的本地样式提取到 `UnifiedComponents.xaml`
- 所有详情页引用共享样式资源
- 统一加载指示器样式（Loading遮罩+文字）

## 影响范围

### 需修改的详情视图（5个）
- `PatientDetailView.xaml` - 添加右上角编辑按钮
- `HerbDetailView.xaml` - 添加右上角编辑按钮
- `UserDetailView.xaml` - 重构布局，添加右上角编辑按钮
- `FormulaDetailView.xaml` - 添加右上角编辑按钮
- `MedicalCaseDetailView.xaml` - 调整编辑按钮位置

### 需修改的列表视图（5个）
- `PatientManagementView.xaml` - 移除编辑按钮
- `HerbManagementView.xaml` - 移除编辑按钮
- `UserManagementView.xaml` - 移除编辑按钮
- `FormulaManagementView.xaml` - 移除编辑按钮
- `MedicalCaseManagementView.xaml` - 移除编辑按钮

### 样式文件
- `UnifiedComponents.xaml` - 添加详情页共享样式

## 验收标准

1. 所有详情页采用统一的3行布局结构
2. 所有详情页右上角有"编辑"按钮
3. 所有列表页操作列不再包含"编辑"按钮
4. 所有详情页使用统一的共享样式
5. 所有详情页有一致的加载指示器
6. 编译通过，无运行时错误

## 风险评估

- **低风险**：UI层变更，不涉及业务逻辑
- **兼容性**：ViewModel层EditCommand保持不变，仅调整触发位置

## 时间线

- Phase 1: 创建共享样式基础设施
- Phase 2: 重构详情页布局和样式
- Phase 3: 修改列表页移除编辑按钮
- Phase 4: 测试验证
