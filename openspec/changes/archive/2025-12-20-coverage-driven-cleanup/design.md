# Design: coverage-driven-cleanup

## 技术架构

### 覆盖率收集流程

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  dotnet test    │────▶│ coverlet.collector│────▶│ coverage.xml   │
│  --collect:XPlat│     │  (数据收集器)    │     │  (Cobertura格式)│
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                         │
                                                         ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  HTML Report    │◀────│ ReportGenerator │◀────│  Merged Report  │
│  (可视化报告)   │     │  (报告生成器)   │     │  (合并后报告)   │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

### 覆盖率数据结构

**Cobertura XML格式**:
```xml
<coverage line-rate="0.65" branch-rate="0.45">
  <packages>
    <package name="LYBT.Module.Auth" line-rate="0.72">
      <classes>
        <class name="AuthService" filename="..." line-rate="0.85">
          <methods>
            <method name="LoginAsync" line-rate="1.0" />
            <method name="ValidateToken" line-rate="0.0" />  <!-- 零覆盖候选 -->
          </methods>
        </class>
      </classes>
    </package>
  </packages>
</coverage>
```

### 零覆盖识别策略

| 类型 | 识别方式 | 处理策略 |
|------|---------|---------|
| **完全零覆盖类** | `class line-rate="0"` | 高优先级清理候选 |
| **零覆盖方法** | `method line-rate="0"` | 需评估是否死代码 |
| **预期零覆盖** | 接口/抽象类/DTO | 排除在清理范围外 |
| **测试辅助类** | `*.Tests`程序集 | 不纳入覆盖统计 |

### 死代码确认流程

```
零覆盖类 ──▶ grep引用分析 ──▶ DI注册检查 ──▶ 反射使用检查 ──▶ 确认删除
                │                │                │
                ▼                ▼                ▼
            有引用?          有注册?          有反射?
                │                │                │
                ▼                ▼                ▼
              保留            保留            保留
```

## 配置详情

### 测试项目csproj更新

为所有测试项目添加:
```xml
<ItemGroup>
  <PackageReference Include="coverlet.collector">
    <IncludeAssets>runtime; build; native; contentfiles; analyzers</IncludeAssets>
    <PrivateAssets>all</PrivateAssets>
  </PackageReference>
</ItemGroup>
```

### 优化后的.runsettings

```xml
<?xml version="1.0" encoding="utf-8"?>
<RunSettings>
  <RunConfiguration>
    <ResultsDirectory>BIN\TestResults</ResultsDirectory>
    <MaxCpuCount>0</MaxCpuCount>
    <TestSessionTimeout>600000</TestSessionTimeout>
    <TargetPlatform>x64</TargetPlatform>
  </RunConfiguration>

  <DataCollectionRunSettings>
    <DataCollectors>
      <DataCollector friendlyName="XPlat code coverage">
        <Configuration>
          <Format>cobertura,opencover</Format>

          <!-- 排除规则 -->
          <Exclude>
            [*.Tests]*,
            [*]*.Designer,
            [*]*.g.cs,
            [*]*.Generated.*,
            [*]*AutoGeneratedProgram*,
            [LYBT.WebAPI]Program,
            [*]*.Migrations.*,
            [*]*.Views.*,
            [*]*.Resources.*
          </Exclude>

          <!-- 仅包含LYBT程序集 -->
          <Include>
            [LYBT.*]*
          </Include>

          <!-- 排除属性标记的代码 -->
          <ExcludeByAttribute>
            Obsolete,
            GeneratedCodeAttribute,
            CompilerGeneratedAttribute,
            ExcludeFromCodeCoverageAttribute
          </ExcludeByAttribute>

          <!-- 跳过自动属性（getter/setter） -->
          <SkipAutoProps>true</SkipAutoProps>
        </Configuration>
      </DataCollector>
    </DataCollectors>
  </DataCollectionRunSettings>
</RunSettings>
```

### 覆盖率收集脚本

**scripts/collect-coverage.ps1**:
```powershell
#!/usr/bin/env pwsh
param(
    [string]$Filter = "",
    [switch]$GenerateReport,
    [string]$OutputDir = "BIN/TestResults"
)

$ErrorActionPreference = "Stop"

# 清理旧结果
if (Test-Path $OutputDir) {
    Remove-Item -Recurse -Force $OutputDir
}

# 运行测试收集覆盖率
$testArgs = @(
    "test", "LYBT.All.sln",
    "--settings", "tests/.runsettings",
    "--collect:XPlat Code Coverage",
    "--results-directory", $OutputDir,
    "--no-build"
)

if ($Filter) {
    $testArgs += "--filter", $Filter
}

dotnet @testArgs

# 合并报告
if ($GenerateReport) {
    $coverageFiles = Get-ChildItem -Path $OutputDir -Recurse -Filter "coverage.cobertura.xml"
    $reports = ($coverageFiles | ForEach-Object { $_.FullName }) -join ";"

    dotnet tool run reportgenerator `
        -reports:"$reports" `
        -targetdir:"$OutputDir/CoverageReport" `
        -reporttypes:"Html;Cobertura;TextSummary"

    Write-Host "Coverage report generated at: $OutputDir/CoverageReport/index.html"
}
```

## 限制条件

1. **测试运行时间**: 全量测试预计15-30分钟
2. **覆盖率精度**: 仅统计单元测试覆盖，不含手动测试
3. **动态代码**: 反射调用的代码可能显示零覆盖但实际使用
4. **UI代码**: XAML绑定的代码路径难以通过单元测试覆盖
