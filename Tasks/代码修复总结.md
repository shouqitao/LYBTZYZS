## 修复的问题列表

### 1. 认证模块 (Auth) 问题修复

#### 问题1.1: logout接口参数验证问题
- **问题描述**: logout接口要求客户端提供Username参数，不合理
- **原因分析**: 用户名应该从JWT token中获取，而不是让客户端提供
- **修复方案**: 修改AuthController.Logout方法，从JWT token中自动获取用户名
- **修改文件**: `src/Backend/Services/LYBT.WebAPI/Controllers/AuthController.cs`
- **修复代码**:
  ```csharp
  [HttpPost("logout")]
  public async Task<ApiResponse<object>> Logout() {
      var username = User?.Identity?.Name ?? string.Empty;
      if (string.IsNullOrEmpty(username)) {
          return ApiResponse<object>.Fail("无效的用户身份", 401);
      }
      var dto = new LogoutRequestDto { Username = username };
      await _authService.LogoutAsync(dto);
      return ApiResponse<object>.Success(new { }, "登出成功");
  }
  ```

#### 问题1.2: changeSysAdminPassword密码验证失败
- **问题描述**: sysadmin密码验证不匹配，无法修改密码
- **原因分析**: 数据库中的密码哈希与当前验证逻辑不一致
- **修复方案**: 修改数据库初始化服务，确保每次启动时密码哈希一致性
- **修改文件**: 
  - `src/Backend/Core/LYBT.Infrastructure/Database/DatabaseInitializationService.cs`
  - `src/Backend/Core/LYBT.Common/Helpers/PasswordHelper.cs`
- **修复代码**: 在InitializeAdminSecretsAsync中添加密码哈希一致性检查

### 2. 用户管理模块 (Users) 问题修复

#### 问题2.1: add接口DTO验证错误
- **问题描述**: UserCreateDto中有重复的角色字段导致验证混淆
- **原因分析**: DTO中同时存在Roles(List)和Role(单个)字段
- **修复方案**: 简化UserCreateDto，只保留单个Role字段
- **修改文件**: `src/Backend/Core/LYBT.Models/Users/Dtos/UserCreateDto.cs`
- **修复代码**: 移除Roles字段，优化验证注解

#### 问题2.2: batchEnable批量操作500错误
- **问题描述**: 批量操作接口返回500内部服务器错误
- **原因分析**: JSON字段名与DTO属性名不匹配，缺少异常处理
- **修复方案**: 
  1. 修改UserBatchIdsDto，支持userIds和ids两种字段名
  2. 在控制器中添加异常处理
- **修改文件**: 
  - `src/Backend/Core/LYBT.Models/Users/Dtos/BatchIdsDto.cs`
  - `src/Backend/Services/LYBT.WebAPI/Controllers/UsersController.cs`
- **修复代码**: 添加JsonPropertyName注解和try-catch异常处理

### 3. 患者管理模块 (Patients) 问题修复

#### 问题3.1: search接口keyword参数要求过严格
- **问题描述**: search接口强制要求keyword参数，不支持空搜索
- **原因分析**: 参数没有默认值，导致空查询失败
- **修复方案**: 为keyword参数设置默认值空字符串
- **修改文件**: `src/Backend/Services/LYBT.WebAPI/Controllers/PatientsController.cs`
- **修复代码**: 
  ```csharp
  public async Task<ActionResult<ApiResponse<List<PatientDetailDto>>>> Search([FromQuery] string keyword = "")
  ```
