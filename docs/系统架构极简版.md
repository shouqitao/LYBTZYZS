# 凌隐宝堂中医诊所系统 - 极简架构版

## 更新时间：2025-01-08

## 一、极简模块架构（9个）

### 基础设施（3个）
1. **Infrastructure** - 基础设施层
2. **Models** - 领域模型
3. **Shared.Models** - 共享DTO

### 业务模块（6个）
1. **Auth** - 认证授权
2. **Users** - 用户管理（用户即医生）
3. **Patients** - 患者档案
4. **Consultation** - 看诊管理
5. **Prescriptions** - 处方管理
6. **MedicalCase** - 病例管理

### 辅助模块（2个）
1. **Herbs** - 药材管理
2. **Formula** - 验方管理

## 二、核心理念

### 用户即医生
- 取消角色区分，所有系统用户都是医生
- UserModel包含医生所需的所有字段
- 简化权限管理，专注业务功能

### 极简流程
```
医生登录 → 患者建档 → 看诊 → 开方
```

## 三、模块职责

### Auth（认证）
- JWT Token生成与验证
- 登录/登出管理
- 密码管理

### Users（用户/医生）
- 用户账号管理
- 医生信息维护
- 包含字段：姓名、职称、科室、专长、执业证号等

### Patients（患者）
- 患者档案管理
- 就诊历史记录
- 基本信息维护

### Consultation（看诊）
- 中医四诊记录
- 诊断过程管理
- 治疗建议

### Prescriptions（处方）
- 处方创建
- 药材配伍
- 剂量管理

### MedicalCase（病例）
- 完整诊疗记录
- 病例归档
- 历史查询

### Herbs（药材）
- 药材信息
- 库存管理
- 价格维护

### Formula（验方）
- 经典方剂
- 验方模板
- 常用配方

## 四、数据模型简化

### UserModel（用户即医生）
```csharp
public class UserModel {
    // 基本信息
    public Guid Id { get; set; }
    public string UserName { get; set; }
    public string RealName { get; set; }
    public string Email { get; set; }
    
    // 医生信息
    public string? Title { get; set; }          // 职称
    public string? Department { get; set; }     // 科室
    public string? Specialty { get; set; }      // 专长
    public string? LicenseNumber { get; set; }  // 执业证号
    public string? EmployeeNumber { get; set; } // 工号
}
```

## 五、API设计

### 认证相关
- POST /api/auth/login - 登录
- POST /api/auth/logout - 登出

### 用户（医生）管理
- GET /api/users - 获取所有医生
- GET /api/users/{id} - 获取医生详情
- POST /api/users - 创建医生账号
- PUT /api/users/{id} - 更新医生信息

### 患者管理
- GET /api/patients - 患者列表
- POST /api/patients - 新建患者
- GET /api/patients/{id} - 患者详情

### 看诊流程
- POST /api/consultation - 创建诊疗记录
- PUT /api/consultation/{id} - 更新诊疗
- GET /api/consultation/patient/{patientId} - 患者诊疗历史

### 处方管理
- POST /api/prescriptions - 开具处方
- GET /api/prescriptions/{id} - 处方详情
- GET /api/prescriptions/patient/{patientId} - 患者处方历史
