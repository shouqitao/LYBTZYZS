# 统一性能优化系统配置指南

## 概述

凌隐宝堂中医诊所系统的性能优化模块提供三大核心功能：
- **统一缓存管理** - 智能多层缓存策略
- **数据库性能优化** - 查询优化和批处理
- **异步处理管理** - 任务队列和并发控制

## 核心组件

### 1. 统一缓存管理器 (IUnifiedCacheManager)

```csharp
// 服务注入
services.AddScoped<IUnifiedCacheManager, UnifiedCacheManager>();

// 使用示例
public class MyService
{
    private readonly IUnifiedCacheManager _cache;
    
    public async Task<User> GetUserAsync(string userId)
    {
        return await _cache.GetOrSetAsync($"user:{userId}", 
            async () => await _userRepository.GetByIdAsync(userId),
            TimeSpan.FromMinutes(30));
    }
}
```

**主要功能**：
- ✅ 多层缓存支持（内存+分布式）
- ✅ 智能压缩（自动压缩大于1KB的数据）
- ✅ 批处理操作（提升并发性能）
- ✅ 统计分析（命中率、内存使用）
- ✅ 模式匹配清理

## 使用场景

### 1. 高频查询优化

**场景**: 患者信息频繁查询
```csharp
public async Task<PatientDto> GetPatientAsync(Guid patientId)
{
    // 使用缓存减少数据库访问
    return await _cache.GetOrSetAsync($"patient:{patientId}", 
        async () => 
        {

            return _mapper.Map<PatientDto>(patient);
        }, 
        TimeSpan.FromMinutes(15));
```

## 常见问题解决

### Q: 缓存命中率低怎么办？

**A**: 
1. 检查缓存键命名是否合理
2. 调整过期时间策略
3. 启用统计分析找出热点数据
4. 考虑预加载常用数据

### Q: 数据库查询慢怎么办？

**A**:
1. 使用性能分析器找出瓶颈
2. 检查索引使用建议
3. 启用查询优化选项
4. 考虑读写分离

### Q: 异步任务堆积怎么办？

**A**:
1. 增加并发数配置
2. 优化任务处理逻辑
3. 启用批处理优化
4. 监控系统资源使用

## 升级指南

从旧系统迁移到统一性能优化系统：

### 第一步：更新服务注册

```csharp
// 旧的方式
services.AddMemoryCache();

// 新的方式
services.RegisterPerformanceServices(configManager);
```

### 第二步：替换缓存调用

```csharp
// 旧的方式
var cached = _memoryCache.Get<User>(key);
if (cached == null)
{
    cached = await GetUserFromDb();
    _memoryCache.Set(key, cached, TimeSpan.FromMinutes(30));
}

// 新的方式
var cached = await _unifiedCache.GetOrSetAsync(key,
    async () => await GetUserFromDb(),
    TimeSpan.FromMinutes(30));
```

### 第三步：启用性能监控

```csharp
// 添加性能监控端点
app.MapGet("/api/performance/cache-stats", async (IUnifiedCacheManager cache) =>
{
    return await cache.GetStatisticsAsync();
});
```

## 监控指标

建议监控的关键指标：

### 缓存指标
- 命中率 > 90%
- 内存使用 < 系统内存的20%
- 平均响应时间 < 10ms

### 数据库指标
- 慢查询比例 < 1%
- 平均查询时间 < 100ms
- 连接池使用率 < 80%

### 异步处理指标
- 任务成功率 > 99%
- 队列积压 < 100个任务
- 平均处理时间 < 配置超时时间的50%

通过持续监控这些指标，可以及时发现性能问题并进行优化调整。
