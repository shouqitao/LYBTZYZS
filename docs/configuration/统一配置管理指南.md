# 统一配置管理系统指南

## 概述

凌隐宝堂中医诊所系统采用统一配置管理架构，提供：
- 环境变量和配置文件的统一管理
- 加密的秘钥管理
- 配置验证和类型安全
- 开发/生产环境配置隔离

## 架构组件

### 1. 配置管理接口

```csharp
IConfigurationManager - 统一配置管理器
ISecretManager - 秘钥管理器
IEnvironmentManager - 环境管理器
```

### 2. 配置选项类

```csharp
JwtOptions - JWT认证配置
SecurityOptions - 安全配置
CacheOptions - 缓存配置
DatabaseOptions - 数据库配置
```

## 配置文件结构

### 主配置文件 (appsettings.json)

```json
{
  "JwtOptions": {
    "Secret": "${JWT_SECRET}",
    "Issuer": "LYBT.WebAPI",
    "Audience": "LYBT.Client",
    "ExpireMinutes": 480
  },
  "CacheOptions": {
    "DefaultExpiryMinutes": 30,
    "CacheType": "Memory",
    "MemoryCache": {
      "SizeLimit": 200,
      "CompactionPercentage": 0.10
    }
  }
}
```

### 环境配置文件 (.env)

```bash
# JWT配置
JWT_SECRET=你的32个字符以上的强密钥

# 数据库配置
ConnectionStrings__DefaultConnection=Server=localhost;Database=LYBTDB;Trusted_Connection=True

# 管理员配置
ADMIN_DEFAULT_PASSWORD=你的强管理员密码
USER_DEFAULT_PASSWORD=你的默认用户密码
```

## 环境变量格式

系统支持多种环境变量格式：

1. **原始格式**: `JWT_SECRET`
2. **ASP.NET Core格式**: `JwtOptions:Secret` → `JwtOptions__Secret`
3. **带前缀格式**: `LYBT_JWT_SECRET`

## 使用示例

### 1. 获取配置

```csharp
// 注入配置管理器
public class MyService
{
    private readonly IConfigurationManager _configManager;
    
    public MyService(IConfigurationManager configManager)
    {
        _configManager = configManager;
    }
    
    public void UseConfiguration()
    {
        // 获取强类型配置
        var jwtOptions = _configManager.GetSection<JwtOptions>("JwtOptions");
        
        // 获取连接字符串
        var connectionString = _configManager.GetConnectionString();
        
        // 获取单个值
        var apiKey = _configManager.GetValue("API_KEY", "default-value");
    }
}
```

### 2. 使用秘钥管理器

```csharp
public class AuthService
{
    private readonly ISecretManager _secretManager;
    
    public AuthService(ISecretManager secretManager)
    {
        _secretManager = secretManager;
    }
    
    public async Task<string> GetJwtSecret()
    {
        // 从环境变量或加密存储获取
        return _secretManager.GetSecret("JWT_SECRET");
    }
    
    public async Task StoreSecret()
    {
        // 加密存储秘钥
        await _secretManager.SetSecretAsync("NEW_SECRET", "secret-value");
    }
}
```

### 3. 环境管理

```csharp

```

## 配置验证

### 自动验证

系统启动时自动验证：
- 必需配置项存在性
- 配置值格式正确性
- 生产环境安全要求
- 秘钥强度要求

### 手动验证

```csharp
public void ValidateConfiguration()
{
    var configManager = serviceProvider.GetRequiredService<IConfigurationManager>();
    var validationResult = configManager.ValidateConfiguration();
    
    if (validationResult != ValidationResult.Success)
    {
        throw new InvalidOperationException($"配置验证失败: {validationResult.ErrorMessage}");
    }
}
```

## 安全最佳实践

### 1. 秘钥管理

- ✅ 使用环境变量存储敏感信息
- ✅ JWT密钥至少32个字符
- ✅ 生产环境使用强密码
- ❌ 不要在配置文件中存储明文密码

### 2. 环境隔离

```json
// 开发环境 (appsettings.Development.json)
{
  "Security": {
    "Environment": {
      "HideServerInfo": false,
      "EnableSensitiveDataLogging": true
    }
  }
}

// 生产环境 (appsettings.Production.json)
{
  "Security": {
    "Environment": {
      "HideServerInfo": true,
      "EnableSensitiveDataLogging": false
    }
  }
}
```

### 3. 配置加密

系统自动加密存储敏感配置：

```csharp
// 加密存储
await secretManager.SetSecretAsync("DATABASE_PASSWORD", "sensitive-password");

// 自动解密获取
var password = secretManager.GetSecret("DATABASE_PASSWORD");
```

## 常见问题

### Q: 如何在开发环境中设置配置？

A: 创建 `.env` 文件或使用 `appsettings.Development.json`

### Q: 生产环境如何管理秘钥？

A: 使用环境变量或外部秘钥管理服务（如Azure Key Vault）

### Q: 配置验证失败怎么办？

A: 检查日志中的详细错误信息，确保所有必需配置都已设置

### Q: 如何添加新的配置选项？

A: 1. 创建配置选项类；2. 在ConfigurationExtensions中注册；3. 更新配置文件
