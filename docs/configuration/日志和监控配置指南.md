# 统一日志和监控系统配置指南

## 概述

凌隐宝堂中医诊所系统的日志和监控模块提供完整的系统可观测性：
- **统一日志管理** - 结构化日志记录和分析
- **性能跟踪** - 实时性能监控和分析
- **智能告警** - 基于规则的自动告警系统
- **健康监控** - 系统组件健康状态检查

## 使用场景

### 1. 业务操作日志记录

**场景**: 患者挂号操作全程追踪
```csharp
public async Task<RegistrationResult> RegisterPatientAsync(RegistrationRequest request)
{
    var operationId = Guid.NewGuid().ToString();
    
    using var tracker = _logger.StartPerformanceTracking("PatientRegistration");
    tracker.AddContext("OperationId", operationId);
    tracker.AddContext("PatientName", request.PatientName);
    
    try
    {
        // 记录开始
        await _logger.LogOperationAsync("PatientRegistration", "Started", 
            new { OperationId = operationId, Request = request });
        
        // 验证患者信息
        tracker.Checkpoint("ValidationStarted");
        await ValidatePatientInfo(request);
        tracker.Checkpoint("ValidationCompleted");
        
        // 创建挂号记录
        tracker.Checkpoint("RegistrationStarted");
        var registration = await CreateRegistration(request);
        tracker.Checkpoint("RegistrationCompleted");
        
        // 记录成功
        await _logger.LogOperationAsync("PatientRegistration", "Success", 
            new { RegistrationId = registration.Id, OperationId = operationId }, 
            tracker.Duration);
        
        return new RegistrationResult { Success = true, RegistrationId = registration.Id };
    }
    catch (Exception ex)
    {
        await _logger.LogErrorAsync(ex, "患者挂号失败", 
            new { OperationId = operationId, Request = request });
        
        await _logger.LogOperationAsync("PatientRegistration", "Failed", 
            new { OperationId = operationId, Error = ex.Message }, 
            tracker.Duration);
        
        throw;
    }
}
```

### 2. 安全事件监控

**场景**: 登录安全监控
```csharp
public async Task<LoginResult> LoginAsync(LoginRequest request)
{
    var ipAddress = _httpContext.Connection.RemoteIpAddress?.ToString();
    
    try
    {
        var user = await _userService.ValidateCredentialsAsync(request.Username, request.Password);
        
        if (user == null)
        {
            await _logger.LogSecurityEventAsync(
                SecurityEventType.LoginFailed,
                $"用户 {request.Username} 登录失败：无效凭据",
                request.Username,
                ipAddress,
                new { AttemptTime = DateTime.UtcNow }
            );
            
            return new LoginResult { Success = false, Message = "用户名或密码错误" };
        }
        
        await _logger.LogSecurityEventAsync(
            SecurityEventType.Login,
            $"用户 {user.Username} 成功登录",
            user.Id.ToString(),
            ipAddress,
            new { LoginTime = DateTime.UtcNow, UserRole = user.Role }
        );
        
        return new LoginResult { Success = true, Token = GenerateToken(user) };
    }
    catch (Exception ex)
    {
        await _logger.LogErrorAsync(ex, "登录处理异常", 
            new { Username = request.Username, IpAddress = ipAddress });
        throw;
    }
}
```

### 3. 性能瓶颈分析

**场景**: 数据库查询性能监控
```csharp
public async Task<List<Patient>> SearchPatientsAsync(SearchCriteria criteria)
{
    using var tracker = _logger.StartPerformanceTracking("PatientSearch");
    
    try
    {
        // 添加查询上下文
        tracker.AddContext("SearchType", criteria.Type);
        tracker.AddContext("FilterCount", criteria.Filters.Count);
        
        // 开始数据库查询
        tracker.Checkpoint("DatabaseQueryStart");
        
        var query = BuildSearchQuery(criteria);
        tracker.AddMetric("QueryComplexity", CalculateComplexity(query));
        
        var results = await _dbContext.Patients
            .Where(query)
            .ToListAsync();
        
        tracker.Checkpoint("DatabaseQueryEnd");
        
        // 记录查询结果指标
        tracker.AddMetric("ResultCount", results.Count);
        tracker.AddMetric("DatabaseQueries", 1);
        
        // 如果查询时间过长，记录警告
        if (tracker.Duration > TimeSpan.FromSeconds(2))
        {
            await _logger.LogWarningAsync("患者搜索查询时间过长", 
                new { 
                    Duration = tracker.Duration.TotalMilliseconds,
                    Criteria = criteria,
                    ResultCount = results.Count
                });
        }
        
        await tracker.CompleteAsync($"Found {results.Count} patients");
        return results;
    }
    catch (Exception ex)
    {
        await tracker.CompleteAsync("Failed");
        await _logger.LogErrorAsync(ex, "患者搜索失败", criteria);
        throw;
    }
}
```

### 4. 系统健康监控

**场景**: 定期健康检查
```csharp
[ApiController]
[Route("api/health")]
public class HealthController : ControllerBase
{
    private readonly IUnifiedMonitor _monitor;
    
    [HttpGet]
    public async Task<IActionResult> GetHealth()
    {
        var health = await _monitor.GetSystemHealthAsync();
        
        var response = new
        {
            Status = health.OverallStatus.ToString(),
            Timestamp = health.CheckTime,
            Score = health.HealthScore,
            Components = health.Components.Select(c => new
            {
                Name = c.Key,
                Status = c.Value.Status.ToString(),
                ResponseTime = c.Value.ResponseTimeMs,
                Description = c.Value.Description
            })
        };
        
        return health.OverallStatus == HealthStatus.Healthy 
            ? Ok(response) 
            : StatusCode(503, response);
    }
    
    [HttpGet("metrics")]
    public async Task<IActionResult> GetMetrics()
    {
        var report = await _monitor.GetPerformanceReportAsync(TimeSpan.FromHours(1));
        
        return Ok(new
        {
            GeneratedAt = report.GeneratedAt,
            TimeRange = report.TimeRange,
            Trends = report.Trends.Select(t => new
            {
                Metric = t.MetricName,
                Direction = t.Direction.ToString(),
                Change = $"{t.ChangePercent:F2}%",
                DataPoints = t.DataPoints.Count
            }),
            Anomalies = report.Anomalies.Select(a => new
            {
                Metric = a.MetricName,
                Type = a.Type.ToString(),
                Severity = a.Severity.ToString(),
                Deviation = $"{a.DeviationPercent:F2}%"
            })
        });
    }
}
```

## 常见问题解决

### Q: 日志量过大怎么办？

**A**: 
1. 调整日志级别，生产环境使用Information级别
2. 启用日志轮转和压缩
3. 定期清理过期日志
4. 考虑将日志发送到外部系统（如ELK）

### Q: 性能跟踪影响系统性能？

**A**:
1. 性能跟踪开销 < 2ms，影响微乎其微
2. 可以通过配置选择性启用
3. 使用异步日志记录避免阻塞
4. 生产环境可调整采样率

### Q: 告警太多怎么办？

**A**:
1. 调整告警阈值，避免误报
2. 设置合理的静默期
3. 使用告警分级，重要告警优先处理
4. 定期回顾和优化告警规则

### Q: 如何集成外部监控系统？

**A**:
1. 使用Webhook将告警发送到外部系统
2. 通过API导出监控数据
3. 支持标准格式（Prometheus、Grafana等）
4. 考虑使用OpenTelemetry标准
