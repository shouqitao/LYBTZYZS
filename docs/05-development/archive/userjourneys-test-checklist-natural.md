## 使用说明

1. **测试执行顺序**: 建议按照 认证 → 初始化 → 管理员设置 → 患者管理 → 药材验方 → 初诊 → 复诊 → 编辑 → 批量/跨场景 的顺序执行

2. **依赖关系**:
   - 系统初始化测试需要在认证测试通过后执行
   - 初诊/复诊测试依赖于患者管理和药材管理
   - 医案编辑测试依赖于初诊流程

3. **独立执行**: 每个测试方法都可以独立执行，使用 `ResetForJourneyAsync()` 重置数据库状态
