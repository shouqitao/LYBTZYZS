# LYBT WebAPI 快速部署指南

## 🚀 30秒快速部署

### 准备工作（仅首次需要）

1. **服务器端准备**（以管理员身份运行）：
```cmd
# 复制脚本到服务器
# 运行环境初始化
setup-server.bat
```

2. **本地配置检查**：
```cmd
# 测试中文编码
test-encoding.bat

# 检查配置参数
notepad scripts\auto-deploy.bat
```

### 一键部署

```cmd
# 执行自动部署
scripts\auto-deploy.bat
```

## ⚡ 部署流程

```
本地编译 → 打包压缩 → 上传服务器 → 自动重启 → 验证完成
   ↓           ↓           ↓           ↓           ↓
  30秒        10秒        20秒        15秒        5秒
```

**总耗时：约80秒**

## 🔧 配置参数（重要）

编辑 `scripts\auto-deploy.bat`：
```batch
set "SERVER_IP=192.168.190.243"      # 改为你的服务器IP
set "SERVER_USER=Administrator"      # 改为你的用户名
```

## ✅ 部署成功标志

看到以下信息表示部署成功：
```
✅ 部署完成！
🌐 服务地址: http://192.168.190.243:5297
```

## 🛠 快速故障排除

| 问题 | 解决方案 |
|------|----------|
| 中文乱码 | 运行 `test-encoding.bat` |
| 连接失败 | 检查服务器IP和网络 |
| 权限错误 | 以管理员身份运行 |
| 端口占用 | 停止现有服务进程 |

## 📱 验证部署

访问：http://192.168.190.243:5297/health

返回：`{"status":"healthy","timestamp":"2024-xx-xx"}`

## 🔄 回滚操作

如果部署失败，自动使用备份：
```
C:\LYBT\Backup\WebAPI_[日期时间]\
```
