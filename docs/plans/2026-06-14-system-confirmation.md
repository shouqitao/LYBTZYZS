> **版本**: v1.0

---

## 一、系统概述

凌隐宝堂中医诊所管理系统（LYBTZYZS）是面向小型中医诊所（1-3 名医生）的诊疗管理平台。系统支持**远程联网模式**和**本地离线模式**双运行，业务代码完全模式无关——切换模式仅需更改连接地址，无需修改代码。

**技术栈**: .NET 8 + WPF/Prism + ASP.NET Core + EF Core + SQL Server

---

## 二、角色体系

| 角色 | 权限值 | 职责 |
|------|--------|------|
| 前台接待 (Receptionist) | 0 | 患者登记、挂号管理、身份证读卡 |
| 中医医生 (Doctor) | 1 | 诊疗全流程：诊断、处方、打印、验方管理 |
| 诊所管理员 (Admin) | 10 | 用户管理、药材库、数据审核、系统配置 |
| 超级管理员 (SuperAdmin) | 100 | 系统初始化、诊断工具、密码重置 |

## 四、双运行模式

| 维度 | 远程模式 | 本地模式 |
|------|----------|----------|
| 数据库 | SQL Server | SQL Server LocalDB |
| API | 独立 ASP.NET Core 进程 | 嵌入式 Kestrel（Desktop 进程内） |
| 认证 | JWT + RefreshToken（8h/7d） | 简化 JWT（1 年有效期） |
| 同步 | 需要 | 不需要 |
| 打印日志 | 创建 MedicalPrintLog | 不创建 |
| 用户规模 | 多用户 | 单用户（Mutex） |

## 五、安全机制

| 机制 | 说明 |
|------|------|
| 密码哈希 | BCrypt（含角色前缀） |
| JWT 认证 | 签名验证 + 过期检查 |
| 角色权限 | 4 级层次模型（0/1/10/100） |
| 资源所有权 | 验方/医案操作检查创建者 |
| 打印保护 | PrintCount > 0 阻止删除/取消 |
| 医案锁定 | 完成次日起锁定，编辑需原因 |
| 软删除 | 全局查询过滤器，恢复需 Admin |
| 引用完整性 | 药材/患者删除前检查引用 |
| 本地权限 | JWT Claims 角色检查（Admin/Doctor/Receptionist） |
| DPAPI 加密 | 照片/密码/Token 加密存储 |
