## 三、Sprint 详细评估

### 3.1 Sprint 1: 安全加固与数据完整性 (33 项)

**就绪度: 可直接执行**

| 分组 | 任务数 | 描述 | 依赖 |
|------|--------|------|------|
| X3: Token Family 撤销 | 6 | 登录/角色变更/删除/重置密码/修改密码/禁用后撤销 Token | 无 |
| X7: 引用检查修复 | 10 | 患者 (6) + 药材 (4) 的 CanDelete 实际查询实现 | 无 |
| S1: 密码哈希 Bug | 1 | 修复旧密码覆盖新密码 | 无 |
| S2: 权限矩阵修复 | 9 | Receptionist 角色 + AdminOnly 解除 + 保护检查 | X3 (Token 撤销) |
| S3: EditReason 强制校验 | 4 | 锁定后编辑必须提供修改原因 | 无 |
| 架构新增 | 3 | 索引修复 + SensitiveData 标记 + 硬编码移除 | 无 |

**建议执行顺序**:
1. T1-S1-01 (密码哈希 Bug) -- 最小独立修复，验证开发流程
2. A1-01/02/03 (架构 3 项) -- 独立小修复
3. T1-X3-01~06 (Token 撤销) -- 安全核心
4. T1-S2-01~09 (权限矩阵) -- 依赖 X3
5. T1-X7-01~10 (引用检查) -- 可与 S2 并行
6. T1-S3-01~04 (EditReason) -- 可与 X7 并行

**风险**: Token 撤销涉及 `TokenRevocationService` 多场景联动，需充分测试 (现有 123 Desktop Foundation 测试 + 集成测试覆盖)。

### 3.2 Sprint 2: 核心功能修复 (51 项)

**就绪度: 打印重构 (X8) 需先做详细设计**

| 分组 | 任务数 | 描述 | 前置条件 |
|------|--------|------|----------|
| X8: 打印层级重构 | 12 | IsPrinted/PrintVersion 从 Prescription 迁移到 MedicalCase | **需设计文档** |
| X5: 字段验证值对齐 | 15 | 密码长度/字段长度/配置值对齐 | 无 |
| S4: 功能 Bug/审计 | 15 | FormulaMapper/TotalPrice/SensitiveData/患者状态 | 无 |
| 架构新增 | 4 | AllowAnonymous 移除/Rate Limiting/索引/测试迁移 | 无 |
| PRD 修订 | 5 | 药材/打印细节 PRD 接受 | 无 (文档修改) |

**打印重构设计要点** (X8, 12 项):
- 新增 `MedicalCase.IsPrinted`/`PrintVersion`/`PrintCount`/`LastPrintedAt` 字段
- 新增 `MedicalCasePrintLog` 实体替换 `PrescriptionPrintLog`
- 新增 `PrintType` 枚举
- EF Migration 必须处理数据迁移 (现有 PrescriptionPrintLog 数据)
- 打印回写链: `PrintHandler` -> `MedicalCase` 属性更新

**风险**: 实体变更 + EF Migration + 打印回写链 = 结构性变更，需严格测试。

### 3.3 Sprint 3: 体系统一与文档同步 (73 项) -- 最大 Sprint

**就绪度: 需建立 MCCEE 错误码映射表**

| 分组 | 任务数 | 描述 | 前置条件 |
|------|--------|------|----------|
| X1: 错误码 MCCEE 统一 | 15 | 全模块错误码迁移到 5 位 MCCEE 编码 | **需错误码映射表** |
| X4: Service 层 ErrorCode 替代 | 5 | 硬编码字符串替换为 ErrorCode 常量 | X1 完成 |
| X6: 分页筛选迁移 Repository | 6 | 内存过滤改为 IQueryable 链 | 无 |
| 架构新增 | 9 | 术语修复(136 处) + 异常体系切换 + 测试合并 | X1+X4 完成 |
| 文档同步 | 16 | 系统概览/数据模型/架构文档更新 | 代码修改完成 |
| PRD 修订 | 16 | 认证/错误/日志/同步/配置 PRD 接受 | 无 (文档修改) |
| 标准固化 | 6 | 6 条架构测试规则写入 NetArchTest | 无 |

**建议**: 考虑拆分为 Sprint 3a (代码变更: X1+X4+X6+架构 = 35 项) 和 Sprint 3b (文档+标准: 文档+PRD+标准 = 38 项)。

**风险**: 错误码全量迁移影响所有 API 返回值，需要:
1. 建立 `旧错误码 -> 新 MCCEE 编码` 映射表
2. 客户端 `ClientErrorMessageMapper` 同步更新
3. 集成测试验证全部端点返回值
