## 附录：修复的关键代码示例

```csharp
// Before: 潜在null引用异常
var updated = await _service.GetByIdAsync(id);
return Success(updated, "更新成功");

// After: 安全的null检查
var updated = await _service.GetByIdAsync(id);
if (updated == null)
{
    return BusinessFail<Dto>("更新后查询失败", ApiErrorCodes.NOT_FOUND);
}
return Success(updated, "更新成功");
```
