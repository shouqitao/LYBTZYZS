## ⚠️ 高优先级问题 (High - 2周内修复)

### H-001: WPF async void 反模式

**影响**: 🟠 High - 潜在的应用程序崩溃风险  
**位置**: 14个WPF ViewModels中发现41个async void用法

**问题文件**:

- `src/Client/Desktop/Modules/Users/ViewModels/UserManagementViewModel.cs:71-72`
- `src/Client/Desktop/Modules/Patients/ViewModels/PatientManagementViewModel.cs:89-90`
- `src/Client/Desktop/Modules/MedicalCase/ViewModels/MedicalCaseManagementViewModel.cs:102-103`

**问题描述**:

```csharp
// ❌ async void - 无法捕获异常，可能导致崩溃
ResetPasswordCommand = new DelegateCommand(async () => await ExecuteResetPasswordAsync());

// ✅ 正确做法 - 使用AsyncRelayCommand
ResetPasswordCommand = new AsyncRelayCommand(ExecuteResetPasswordAsync);
```

**建议**: 替换为AsyncRelayCommand或IAsyncCommand

### H-002: ConfigureAwait缺失

**影响**: 🟠 High - 潜在死锁风险  
**统计**: 仅在8个文件中正确使用ConfigureAwait，其他400+个async调用缺失

**问题描述**:

```csharp
// ❌ 缺失ConfigureAwait - 可能导致UI线程死锁
var result = await _userService.GetPagedAsync(query);

// ✅ 正确使用 - 在非UI线程中避免死锁  
var result = await _userService.GetPagedAsync(query).ConfigureAwait(false);
```

**建议**: 在所有非UI线程的async调用中添加ConfigureAwait(false)

### H-003: 命名空间不一致

**影响**: 🟠 High - 代码组织混乱  
**问题统计**: 35个文件命名空间与文件夹结构不匹配

**问题示例**:

```csharp
// ❌ 不一致
namespace LYBT.Desktop.Users.ViewModels     // 文件位置与命名空间不匹配
namespace LYBT.Module.Users.Services       // 缺少层次结构

// ✅ 标准格式
namespace LYBT.Desktop.Modules.Users.ViewModels
namespace LYBT.Server.Modules.Users.Services  
```

**建议**: 统一命名空间格式为 `项目名.层次.模块.类型`

### H-004: DTO命名冲突风险

**影响**: 🟠 High - 类型混淆和维护困难  
**位置**: 多个模块存在同名DTO

**问题描述**:

```csharp
// ❌ 多个模块都有UserDto，可能产生冲突
LYBT.Shared.Models.Contracts.Users.UserDto
LYBT.Shared.Models.Contracts.Auth.UserDto
LYBT.Desktop.Models.UserDto
```

**建议**: DTO保持当前位置，但确保全局唯一性：

- 添加模块前缀：AuthUserDto, UsersUserDto
- 或使用不同命名：UserInfoDto, UserLoginDto
