# PRD 模板（CCPM 风格）

- 文档日期：YYYY-MM-DD
- 项目经理：ccpm（Claude Code Project Manager）
- 关联范围：<代码路径/解决方案/上下游系统>

## 背景（Problem & Context）
- 业务/技术背景，现状问题与证据（包含文件路径与简要行号引用）。

## 目标（Goals）
- 可度量目标（构建、性能、稳定性、体验、流程）。

## 非目标（Non-Goals）
- 明确本次不做的内容，防止范围蔓延。

## 用户场景（User Stories）
- 角色 + 诉求 + 价值。

## 范围与边界（Scope）
- In Scope：
  - …
- Out of Scope：
  - …

## 需求明细（Requirements）
- R1 …（必须）
- R2 …（应做）
- R3 …（可做）

## 成功指标（Success Metrics）
- …（量化指标）

## 验收标准（Acceptance Criteria）
- 命令或步骤 + 期望结果（0 错误、产物路径、行为一致）。

## 里程碑与实施步骤（Milestones）
- 提交 1：…
- 提交 2：…
- 提交 3：…

## 风险与缓解（Risks & Mitigations）
- 风险 A → 缓解 …

## 依赖与前置（Dependencies & Preconditions）
- SDK/工具/服务/环境变量/凭据。

## 回滚策略（Rollback）
- 按提交粒度回滚及数据回退策略。

## 测试计划（Testing）
- 构建/单测/集成/冒烟/手测清单。

## 产出物（Deliverables）
- 代码/配置/文档/脚本/说明。
- 完成总结（路径）：`docs/prds-summary/PRD-<slug>-<YYYYMMDD>-SUMMARY.md`（按 `docs/ccpm/PRD-SUMMARY-TEMPLATE.md` 生成）
