## 一、项目概览

### 1.1 项目简介
凌隐宝堂中医诊所诊疗系统（LYBTZYZS）是基于 .NET 8 的企业级中医诊所管理系统，采用 Web API 后端 + WPF 桌面前端架构，专为中医诊所的日常运营管理而设计。

### 1.2 技术架构
- **后端框架**: .NET 8, ASP.NET Core Web API
- **前端框架**: WPF (.NET 8), Prism.DryIoc 9.0.537
- **数据库**: SQL Server + Entity Framework Core 8.0.17
- **认证机制**: JWT Bearer Token
- **API文档**: Swagger/Swashbuckle 9.0.1
- **HTTP客户端**: Refit
- **对象映射**: AutoMapper

### 1.3 系统特色
- 纯中医诊疗体系，支持中医四诊（望闻问切）
- 完整的中药材和验方管理
- 模块化架构设计，易于扩展
- 统一的数据访问层和API响应格式
- 完善的权限管理和操作审计
