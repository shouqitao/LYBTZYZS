# 控件集成指南

## 概述

本指南说明如何将新创建的控件集成到现有模块中，以及如何使用BaseListView来创建标准化的列表页面。

## 1. 使用列表项控件

### 1.1 基本用法

在ItemsControl或ListBox中使用控件：

```xml
<ItemsControl ItemsSource="{Binding Items}">
    <ItemsControl.ItemTemplate>
        <DataTemplate>
            <controls:HerbListItemControl Data="{Binding}"/>
        </DataTemplate>
    </ItemsControl.ItemTemplate>
</ItemsControl>
```

### 1.2 添加命名空间引用

```xml
<!-- 根据控件类型添加相应的命名空间 -->
xmlns:herbControls="clr-namespace:LYBT.WPF.Client.Controls.Herbs;assembly=LYBT.WPF.Client.Core"
xmlns:patientControls="clr-namespace:LYBT.WPF.Client.Controls.Patients;assembly=LYBT.WPF.Client.Core"
xmlns:doctorControls="clr-namespace:LYBT.WPF.Client.Controls.Doctors;assembly=LYBT.WPF.Client.Core"
<!-- 其他控件命名空间... -->
```

## 2. 使用BaseListView创建列表页面

### 2.1 创建新的列表视图

```xml
<base:BaseListView x:Class="YourNamespace.YourListView"
                   xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                   xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
                   xmlns:base="clr-namespace:LYBT.WPF.Client.Core.Views.Base;assembly=LYBT.WPF.Client.Core"
                   prism:ViewModelLocator.AutoWireViewModel="True"
                   Title="页面标题">
    
    <!-- 筛选内容 -->
    <base:BaseListView.FilterContent>
        <!-- 添加筛选控件 -->
    </base:BaseListView.FilterContent>
    
    <!-- 列表内容 -->
    <base:BaseListView.ListContent>
        <!-- 添加列表展示 -->
    </base:BaseListView.ListContent>
</base:BaseListView>
```

### 2.2 创建对应的ViewModel

继承自BaseListViewModel：

```csharp
public class YourListViewModel : BaseListViewModel
{
    public YourListViewModel(IRegionManager regionManager) 
        : base(regionManager)
    {
    }

    protected override async Task LoadDataAsync()
    {
        // 实现数据加载逻辑
    }

    protected override void OnAddNew()
    {
        // 实现新增逻辑
    }
}
```

## 3. 实际案例

### 3.1 患者管理模块集成示例

**View (PatientManagementViewNew.xaml):**
```xml
<base:BaseListView.ListContent>
    <ScrollViewer VerticalScrollBarVisibility="Auto">
        <ItemsControl ItemsSource="{Binding Patients}">
            <ItemsControl.ItemTemplate>
                <DataTemplate>
                    <controls:PatientListItemControl Data="{Binding}"/>
                </DataTemplate>
            </ItemsControl.ItemTemplate>
        </ItemsControl>
    </ScrollViewer>
</base:BaseListView.ListContent>
```

**ViewModel:**
```csharp
public ObservableCollection<PatientDto> Patients { get; set; }

protected override async Task LoadDataAsync()
{
    var response = await _patientService.GetPagedAsync(query);
    if (response.Success)
    {
        Patients = new ObservableCollection<PatientDto>(response.Data.Items);
    }
}
```

### 3.2 中药材管理模块集成示例（支持批量操作）

**View:**
```xml
<ItemsControl.ItemTemplate>
    <DataTemplate>
        <Grid>
            <Grid.ColumnDefinitions>
                <ColumnDefinition Width="30"/>
                <ColumnDefinition Width="*"/>
            </Grid.ColumnDefinitions>
            <CheckBox Grid.Column="0" IsChecked="{Binding IsSelected}"/>
            <controls:HerbListItemControl Grid.Column="1" Data="{Binding}"/>
        </Grid>
    </DataTemplate>
</ItemsControl.ItemTemplate>
```

## 4. 命令绑定

控件中的按钮命令通过RelativeSource绑定到列表的DataContext：

```xml
Command="{Binding DataContext.EditCommand, RelativeSource={RelativeSource AncestorType=ItemsControl}}"
CommandParameter="{Binding}"
```

在ViewModel中定义对应的命令：

```csharp
public ICommand EditCommand { get; private set; }

private void InitializeCommands()
{
    EditCommand = new DelegateCommand<YourDto>(OnEdit);
}

private void OnEdit(YourDto item)
{
    // 处理编辑逻辑
}
```

## 5. 迁移现有模块

### 5.1 迁移步骤

1. **创建新视图**：使用BaseListView创建新的视图文件
2. **创建新ViewModel**：继承BaseListViewModel
3. **迁移业务逻辑**：将原有的业务逻辑迁移到新的ViewModel
4. **更新路由**：在模块注册中更新视图路由
5. **测试功能**：确保所有功能正常工作

### 5.2 注意事项

- 确保DTO类型与控件的Data属性类型匹配
- 命令绑定需要在ViewModel中正确初始化
- 分页、搜索等功能已在BaseListViewModel中实现，直接使用即可

## 6. 常见问题

### Q: 控件无法显示数据
A: 检查Data属性绑定是否正确，确保传入的是正确的DTO类型

### Q: 命令无法触发
A: 检查RelativeSource绑定是否正确，确保命令在ViewModel中已初始化

### Q: 样式不一致
A: 确保引入了正确的样式资源，检查是否有样式覆盖

## 7. 最佳实践

1. **保持一致性**：所有列表页面应使用统一的BaseListView
2. **复用控件**：尽可能使用已创建的列表项控件
3. **扩展而非修改**：需要特殊功能时，扩展现有控件而不是修改
4. **性能优化**：大数据量时使用虚拟化技术
5. **响应式设计**：确保控件在不同分辨率下正常显示
