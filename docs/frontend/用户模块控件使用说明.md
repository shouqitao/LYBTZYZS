# 用户模块控件使用说明

## 用户模块的控件体系

用户模块使用了不同类型的控件来实现不同的功能：

### 1. 列表展示控件

#### UserListItemControl
- **用途**：在用户列表中显示单个用户信息
- **对应DTO**：UserDto
- **显示内容**：
  - 用户头像（使用用户名首字母）
  - 用户名
  - 真实姓名
  - 角色
  - 状态（启用/禁用）
  - 邮箱
- **操作按钮**：
  - 编辑
  - 启用/禁用切换

### 2. 编辑对话框

#### UserAddEditDialog
- **用途**：新增或编辑用户信息
- **对应DTO**：
  - 新增时：UserCreateDto
  - 编辑时：UserUpdateDto
- **功能特点**：
  - 支持新增和编辑两种模式
  - 新增时可以输入用户名，编辑时用户名不可修改
  - 包含表单验证
  - 使用对话框形式展示

### 3. 其他可能需要的控件（尚未实现）

#### UserDetailView（用户详情页）
- **用途**：显示用户的完整详细信息
- **对应DTO**：UserDetailDto
- **建议包含**：
  - 基本信息展示
  - 登录历史
  - 操作日志
  - 权限信息

#### ChangePasswordDialog（修改密码对话框）
- **用途**：用户修改自己的密码
- **对应DTO**：ChangePasswordDto
- **建议包含**：
  - 旧密码输入
  - 新密码输入
  - 确认密码输入
  - 密码强度提示

#### ResetPasswordDialog（重置密码对话框）
- **用途**：管理员重置其他用户的密码
- **对应DTO**：ResetPasswordDto
- **建议包含**：
  - 新密码输入
  - 确认密码输入
  - 是否要求用户下次登录时修改密码

#### UserProfileDialog（个人资料编辑对话框）
- **用途**：用户编辑自己的个人资料
- **对应DTO**：ChangeProfileDto
- **建议包含**：
  - 真实姓名
  - 邮箱
  - 电话
  - 部门
  - 职位
  - 头像上传

## 控件使用流程

### 1. 用户列表页面
```xml
<!-- UserManagementView.xaml -->
<ItemsControl ItemsSource="{Binding Users}">
    <ItemsControl.ItemTemplate>
        <DataTemplate>
            <controls:UserListItemControl Data="{Binding}"/>
        </DataTemplate>
    </ItemsControl.ItemTemplate>
</ItemsControl>
```

### 2. 打开编辑对话框
```csharp
// UserManagementViewModel.cs
private void OnEditUser(UserDto user)
{
    var parameters = new DialogParameters
    {
        { "UserId", user.Id },
        { "EditMode", true }
    };
    
    _dialogService.ShowDialog("UserAddEditDialog", parameters, result =>
    {
        if (result.Result == ButtonResult.OK)
        {
            // 刷新列表
            _ = LoadDataAsync();
        }
    });
}
```

### 3. 新增用户
```csharp
private void OnAddUser()
{
    var parameters = new DialogParameters
    {
        { "EditMode", false }
    };
    
    _dialogService.ShowDialog("UserAddEditDialog", parameters, result =>
    {
        if (result.Result == ButtonResult.OK)
        {
            // 刷新列表
            _ = LoadDataAsync();
        }
    });
}
```

## 最佳实践

1. **列表控件**用于展示和快速操作
2. **对话框**用于复杂的表单输入和编辑
3. **详情页**用于展示完整信息
4. **遵循MVVM模式**，使用命令和数据绑定
5. **统一的交互方式**，保持用户体验一致性

## 总结

用户模块的控件设计遵循了以下原则：
- **列表项控件**（UserListItemControl）用于列表展示
- **对话框控件**（UserAddEditDialog）用于编辑操作
- **不同的DTO对应不同的使用场景**
- **控件之间通过对话框服务和导航服务进行交互**
