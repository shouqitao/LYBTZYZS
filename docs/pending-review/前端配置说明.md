# LYBT 前端客户端配置说明

## 概述

LYBT前端客户端现已支持可配置的API服务器地址，可以通过修改配置文件轻松切换不同的服务器环境。

## 配置文件位置

配置文件名称：`appsettings.json`
配置文件位置：前端可执行文件同目录下

### 开发版本
- 路径：`src/Frontend/BIN/LYBT.Desktop/appsettings.json`
- 默认API地址：`http://localhost:5927/`

### 生产版本
- 路径：`BIN/LYBT.Desktop.Configurable/appsettings.json`
- 默认API地址：`http://192.168.190.243:5000/`

## 配置文件格式

```json
{
  "ApiSettings": {
    "BaseUrl": "http://localhost:5927/",
    "TimeoutSeconds": 60
  },
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft": "Warning",
      "Microsoft.Hosting.Lifetime": "Information"
    }
  }
}
```

## 配置参数详解

### ApiSettings 部分

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `BaseUrl` | API服务器基础地址 | `http://localhost:5927/` | `http://192.168.190.243:5000/` |
| `TimeoutSeconds` | 请求超时时间（秒） | `60` | `30`, `60`, `120` |

**BaseUrl 格式要求：**
- 必须以 `http://` 或 `https://` 开头
- 必须以 `/` 结尾
- 包含完整的协议、主机和端口信息

### Logging 部分

控制应用程序日志输出级别，一般情况下不需要修改。

## 使用步骤

### 修改API服务器地址

1. **找到配置文件**
   - 在前端应用程序目录中找到 `appsettings.json` 文件

2. **编辑配置文件**
   - 使用任何文本编辑器打开 `appsettings.json`
   - 修改 `ApiSettings.BaseUrl` 的值为目标服务器地址
   - 根据需要调整 `TimeoutSeconds` 值

3. **保存并重启**
   - 保存配置文件
   - 重启前端应用程序使配置生效

### 验证配置

1. **启动前端应用程序**
2. **尝试登录**
   - 用户名：`sysadmin`
   - 密码：`Admin@123456`
3. **观察连接状态**
   - 如果连接成功，配置正确
   - 如果连接失败，检查服务器地址和网络连接

## 故障排除

### 常见问题

1. **无法连接到API服务器**
   - 检查 `BaseUrl` 是否正确
   - 确认API服务器正在运行
   - 验证网络连接和防火墙设置

2. **请求超时**
   - 增加 `TimeoutSeconds` 值
   - 检查网络延迟情况

3. **配置不生效**
   - 确认已重启应用程序
   - 检查JSON格式是否正确
   - 确认配置文件路径正确

4. **JSON格式错误**
   - 使用JSON验证工具检查格式
   - 注意逗号、引号和大括号的正确使用

### 配置验证清单

- [ ] `BaseUrl` 以 `http://` 或 `https://` 开头
- [ ] `BaseUrl` 以 `/` 结尾
- [ ] JSON格式正确无语法错误
- [ ] API服务器地址可以访问
- [ ] 已重启前端应用程序

## 技术实现

### 配置加载机制

前端应用程序使用 .NET 配置系统加载配置：

1. **启动时加载**：应用程序启动时自动加载配置文件
2. **缓存机制**：配置信息被缓存以提高性能
3. **故障回退**：如果配置文件加载失败，使用默认配置
4. **线程安全**：配置加载过程是线程安全的

### 默认配置

如果配置文件不存在或加载失败，系统将使用以下默认配置：

```csharp
BaseUrl = "http://localhost:5927/"
TimeoutSeconds = 60
```

## 部署建议

### 开发环境
- 使用默认的本地配置（localhost:5927）
- 适合本地调试和开发

### 测试环境
- 配置为测试服务器地址
- 增加超时时间以应对可能的网络延迟

### 生产环境
- 使用生产服务器地址
- 考虑使用HTTPS以提高安全性
- 设置合适的超时时间

## 安全注意事项

1. **HTTPS使用**：生产环境建议使用HTTPS协议
2. **网络安全**：确保API服务器的网络安全配置
3. **访问控制**：限制对配置文件的访问权限
4. **敏感信息**：不要在配置文件中存储敏感信息
