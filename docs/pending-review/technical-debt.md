# 技术债务清单

更新日期：2025-01-30

## 1. 架构和设计问题

### 1.1 DTO位置不规范 ⚠️
**问题描述**：部分DTO错误地放置在`LYBT.Models`项目中，应该迁移到`LYBT.Shared.Models`
**影响范围**：所有模块
**建议方案**：按照三层模型设计，将所有DTO迁移到Shared.Models项目
**优先级**：高
**相关文档**：
- [DTO迁移计划](./development/DTO_MIGRATION_PLAN.md)
- [三层模型设计](./architecture/THREE_LAYER_MODEL_DESIGN.md)

### 1.2 临时DTO映射 ⚠️
**问题描述**：HerbsController中存在临时的本地DTO到共享DTO的映射方法
**影响范围**：药材模块
**建议方案**：统一使用共享DTO，移除临时映射
**优先级**：中
**代码位置**：`HerbsController.MapToSharedDto()`方法

## 2. API设计问题

### 2.1 非标准REST路由 ⚠️
**问题描述**：使用非标准的路由设计（如POST /add, POST /paged）
**影响范围**：所有控制器
**建议方案**：逐步迁移到标准REST风格
**优先级**：低
**示例**：
```
当前：POST /api/v1/users/add
标准：POST /api/v1/users

当前：POST /api/v1/users/paged
标准：GET /api/v1/users?page=1&size=20
```

### 2.2 缺失的接口实现 🔴
**问题描述**：部分控制器返回404占位符
**影响范围**：
- UsersController: 修改密码、重置密码等
- PatientsController: 导入、导出、统计等
- HerbsController: 导入、导出、统计等
- DoctorsController: 排班管理等
**建议方案**：按业务优先级逐步实现
**优先级**：中-高

## 8. 性能优化

### 8.1 缺少查询优化 ⚠️
**问题描述**：部分查询未使用索引，存在N+1问题
**影响范围**：列表查询、关联查询
**建议方案**：
- 添加适当的数据库索引
- 使用Include预加载关联数据
- 实现查询结果缓存
**优先级**：中

### 8.2 缓存策略简单 ⚠️
**问题描述**：只使用内存缓存，未实现分布式缓存
**影响范围**：药材列表等高频查询
**建议方案**：集成Redis等分布式缓存
**优先级**：低
