# 统计功能开发计划

## 概述
统计功能在医疗系统中特别重要，但为了快速交付核心功能，我们采用分阶段实现策略。

## 实施方案

### 第一阶段：基础统计（当前）
- [x] 在列表页面显示记录总数
- [x] 在列表页面显示筛选结果数量
- [ ] 在列表顶部显示简单汇总信息

**实现方式**：
```csharp
// 在各个列表 ViewModel 中
public class RecordListViewModel
{
    public int TotalRecords => PagedResult?.TotalCount ?? 0;
    public string StatisticsSummary => $"共 {TotalRecords} 条记录";
}
```

### 第二阶段：增强统计（3个月内）
- [ ] 列表页面顶部统计卡片
  - [ ] 今日新增数量
  - [ ] 本周/本月汇总
  - [ ] 状态分布（饼图）
- [ ] 日期范围筛选功能
- [ ] 简单的数据导出（Excel）

### 第三阶段：统计API（6个月内）
- [ ] 后端统计专用API
  ```csharp
  [HttpGet("api/v1/statistics/dashboard")]
  [HttpGet("api/v1/statistics/realtime")]
  [HttpGet("api/v1/statistics/trends")]
  ```
- [ ] 统计数据缓存机制
- [ ] 前端统计服务层

### 第四阶段：完整统计模块（未来版本）
- [ ] 独立的统计仪表板页面
- [ ] 实时数据推送（SignalR）
- [ ] 数据趋势分析
- [ ] 自定义报表
- [ ] 高级数据导出

## 技术架构

### 后端设计
```csharp
// 统计DTO
public class DashboardStatisticsDto
{
    public RegistrationStatistics Registration { get; set; }
    public ConsultationStatistics Consultation { get; set; }
    public PhysiotherapyStatistics Physiotherapy { get; set; }
    public FinancialStatistics Financial { get; set; }
}

// 统计服务接口
public interface IStatisticsService
{
    Task<DashboardStatistics> GetDashboardStatisticsAsync(DateTime? date);
    Task<RealtimeStatistics> GetRealtimeStatisticsAsync();
}
```

### 缓存策略
- 实时数据：5分钟缓存
- 日统计：1小时缓存
- 月/年统计：24小时缓存

### 性能优化
1. 数据库层面
   - 创建统计专用视图
   - 添加必要索引
   - 考虑汇总表

2. 应用层面
   - Redis缓存
   - 异步计算
   - 分页加载

## 优先级考虑

### 高优先级统计
1. 今日挂号数、待诊人数
2. 医生工作量统计
3. 收入统计

### 中优先级统计
1. 患者就诊趋势
2. 药材使用统计
3. 理疗项目统计

### 低优先级统计
1. 历史数据对比
2. 预测分析
3. 自定义报表

## 注意事项
1. 统计数据的准确性是首要考虑
2. 避免影响主业务性能
3. 提供数据导出功能供进一步分析
4. 考虑数据隐私和权限控制
