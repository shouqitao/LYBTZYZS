## 技术方案（架构设计）

### B-21：安全增强（已完成）

**需求**：Token 族旋转 + 安全审计 (US-AUTH-006/007)

**现状**：
- Token 族旋转：❌ 未实现（AuthService 无 RevokeAllUserTokensAsync）
- 安全审计：⚠️ 部分实现（LoginCommandHandler 中有 SecurityAuditService，但不完整）

**涉及文件**：
- `src/Server/Modules/LYBT.Module.Auth/Services/AuthService.cs`
- `src/Server/Modules/LYBT.Module.Auth/Interfaces/IAuthService.cs`
- `src/Server/Modules/LYBT.Module.Auth/Services/SecurityAuditService.cs`
- `src/Server/Modules/LYBT.Module.Auth/Interfaces/ISecurityAuditService.cs`

**技术方案**：
1. **Token 族旋转**：
   - IAuthService 添加 `Task<Result<bool>> RevokeAllUserTokensAsync(Guid userId, string reason, CancellationToken ct)`
   - AuthService 实现：批量撤销用户所有 Token（`IsRevoked = true`、`RevokedReason = reason`）
   - 触发场景：登录踢出、角色变更、删除用户、重置密码、修改密码、禁用用户

2. **安全审计完善**：
   - ISecurityAuditService 添加 `Task RecordEventAsync(SecurityAuditEvent evt, CancellationToken ct)`
   - 记录事件：登录成功/失败、令牌刷新/撤销/重放检测、密码修改、角色变更
   - SecurityAuditEvent 包含：UserId、EventType、IpAddress、UserAgent、Details

**验收标准**：
- `dotnet build --no-incremental` 0 错误 0 警告
- 架构测试通过
- 新增单元测试验证 Token 撤销和审计日志记录
