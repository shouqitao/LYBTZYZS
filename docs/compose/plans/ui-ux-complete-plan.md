```markdown

## 1. 设计系统（引用 design-spec.md）

- P0/P1/P2 分级

- 22 个页面 × 4 角色
- 每个操作的权限级别

## 4. 导航流程图（按角色）
- Sysadmin 登录后路径
- Admin 登录后路径
- Doctor 登录后路径
- Receptionist 登录后路径

## 5. 每页详细规格
### 5.1 登录界面
    - 布局图（ASCII 图示）
    - 控件清单（10+ 控件，含类型/位置/大小/说明）
    - 每个按钮的逻辑（前置条件→点击逻辑→后置动作）
    - 状态流转图
    - 异常处理表（异常类型→展示方式→恢复方式）
### 5.2 主界面
    ...（每个页面同样详细）
### 5.3-5.22 其他页面

## 6. 跨页数据流
- PatientId/RegistrationId/MedicalCaseId 等传递路径
- 导航参数方式

## 7. 状态机定义
- Registration: Waiting→InProgress→Completed→Cancelled
- MedicalCase: Draft→Active→Completed→Locked
- Patient/Herb/Formula/User: Enabled↔Disabled

## 8. 验证规则汇总
- 15+ 字段的必填/格式/范围/唯一性

## 9. API 端点映射
- 40+ 端点的页面操作→API→方法→请求→响应→权限

## 10. 共享控件复用矩阵
- 15 个共享控件的使用页面和关键属性
```
