## 一、设计系统概要

### 核心设计 Token（必须遵循）

| Token | 值 | 用途 |
|-------|-----|------|
| **窗口规格** | 1440×900, MinWidth=1024, MinHeight=768 | 所有设计稿统一 |
| **表面层次** | L0=#FAF8F5, L1=#FFF, L2=#FFF, L3=#FFF | 暖灰底色 |
| **品牌色** | TcmGreen=#2E8B57, TcmGold=#DAA520, TcmOrange=#E65100 | 中医特色 |
| **间距 Token** | XS=4, S=8, M=12, L=16, XL=24, XXL=32 | 统一间距 |
| **投影系统** | Elevation1/2/3 三级 | 卡片/面板/弹窗 |
| **字体** | MDIX 默认 (Segoe UI / Noto Sans CJK) | 不自定义 |

### 布局模式（3 种）

| 模式 | 用途 | 页面 |
|------|------|------|
| **主窗口** | 侧边栏 + ContentRegion + 状态栏 | MainWindow |
| **Master-Detail** | 列表 + 详情面板 | 患者/挂号/药材/验方/用户 |
| **卡片网格** | 功能入口仪表盘 | Admin/Sysadmin/Clinical 首页 |

## 五、Prompt 模板（核心）

每个 CLI 生成的 prompt 必须包含：

```
设计一个中医诊所管理系统的 [页面名称] 界面。

## 技术约束
- 分辨率: 1440×900
- 框架: WPF + MaterialDesignInXAML
- 主题: 暖色调，Light 模式

## 设计 Token
- 页面底色: #FAF8F5（暖灰白）
- 面板/卡片: #FFFFFF
- 品牌绿: #2E8B57（药材/确认）
- 品牌金: #DAA520（处方/警告）
- 品牌橙: #E65100（编辑/进行中）
- 间距: XS=4, S=8, M=12, L=16, XL=24
- 投影: 卡片 Elevation1, 面板 Elevation2, 弹窗 Elevation3
- 圆角: 卡片 12px, 主卡片 16px

## 布局模式
[选择: 主窗口 / Master-Detail / 卡片网格]

## 核心功能
[列出该页面的功能点]

## 交互要求
[列出关键交互]

## 禁止事项
- 不要编造品牌名，使用"中医诊所管理系统"
- 不要使用硬编码颜色
- 不要使用非 MDIX 控件
```
