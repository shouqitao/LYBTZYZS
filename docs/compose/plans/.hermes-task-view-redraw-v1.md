## 2) 对齐约束（必须遵守）
- 设计稿 SSOT： Designs/*.pen（含双帧、居中、铺满规则）
- 组件库： C1-C10 + BulkBar/SectionCard，所有新增 UI 必须复用
- 文字居中：所有文字默认居中对齐（除明确左对齐的长文本输入）
- 输入框：编辑态描边可见（主字段 #6D4C41 / 次字段 #C9B8A6）
- 铺满：主内容区 fill_container，右侧不预留大面积空白
- 医案详情：标题行含患者信息（无单独主治医生行）；工作流三态不放在详情页；底部操作按钮右置（保存/完成/打印）

- 导航/Shell/状态栏不动
