## 方法

1. **自动化脚本**（PowerShell/Python 均可）：扫描 `.cs` → 提取类型/方法/可见性/行号 → 生成统计
2. **Roslyn 采样校准**：抽 3-5 个文件用 Roslyn/手读对比正则提取的准确率（说明误差）
3. **重复聚类**：按方法名 group by + 参数类型相似度初筛
4. **死方法初筛**：方法名全仓 grep 调用计数 = 0 的候选
