| 2 | 读身份证 | CardReader US-CARD-001 | ✅ | 读卡 + PRD-15 降级链代码完整 |

## [S3] 旅程 3：外出义诊/离线（医生）🔴🚨 根本性疑虑

```
切本地 → 本地登录 → 本地查患者 → 本地建医案 → 本地开方 → 网络恢复 → 同步
```

| # | 步骤 | 模块/US | 状态 | 说明 |
|---|------|--------|:---:|------|
| 1 | 切换本地 | Shell FR-05 / US-SHELL-007 | ✅ | SwitchingApiClient + ModeSwitchValidator + 未结医案阻断 |
| 2 | 本地登录 | Auth AUTH-009/012 | ⚠️ | 本地 JWT 1 年，自动登录端点在；但**服务端不可撤销**（D3） |
| 3 | **本地安全** | Auth 本地 /refresh | 🔴 | **接受任意 JWT 无签名校验**（D8 安全 bug） |
| 4 | **本地查患者** | Patients (LocalWebAPI) | 🔴🚧❓ | **审计发现 LocalWebAPI/Controllers 无 PatientsController**（仅 HerbsController）→ 本地模式患者操作可能 404（**待核验**） |
| 5 | 本地建医案 | MedicalCases (LocalWebAPI) | ❓ | LocalWebAPI 的 MedicalCase 覆盖范围未在审计中明确（**待核验**） |
| 6 | 本地开方 | Herbs (LocalWebAPI) | ✅ | LocalWebAPI 有 HerbsController |
| 7 | **网络恢复同步** | Sync | 🔴🚧🚨 | **Sync 是 v2.0 延期项**！v1.0 双模式切换存在，但**本地录入的数据无同步机制回远程** |

**旅程结论**：🔴🚨 **根本性产品矛盾**。
- **矛盾**：双模式切换是 v1.0 核心架构（SwitchingApiClient），但**医案数据同步被明确延期到 v2.0**。这意味着 v1.0 切本地后录入的医案/处方**无法回到远程库**——本地成为数据孤岛。
- **待核验**：LocalWebAPI 的 Controller 覆盖范围（Patients/MedicalCases 是否在本地可用）。
- **这是端到端地图揭示的最大问题**——per-module 审计看不到，因为它横跨双模式架构 + v1.0/v2.0 范围边界。**需你澄清双模式 v1.0 的真实意图**。

## [S9] 端到端地图揭示的「新发现」（per-module 审计看不到的）

### 🚨 N1：双模式 v1.0 根本矛盾（旅程 3）
- **双模式切换**（SwitchingApiClient、LocalDB、US-SHELL-007）是 v1.0 核心架构
- 但 **MedicalCase 数据同步明确延期到 v2.0**
- 后果：v1.0 切本地录入的医案/处方**无法回到远程库**——本地是数据孤岛
- **这是 per-module 审计无法发现的**，因为它横跨架构 + 范围边界
- **必须由你澄清**：v1.0 双模式的真实意图是什么？本地是临时降级（数据可丢）？还是需要某种手动/部分同步？

### ❓ N2：LocalWebAPI Controller 覆盖范围未核验（旅程 3）
- Patients 审计发现 LocalWebAPI/Controllers **只有 HerbsController**
- 若 Patients/MedicalCases/Registration 在 LocalWebAPI 无对应 Controller，本地模式这些操作全 404
- **需核验**：LocalWebAPI 到底暴露了哪些 Controller（决定本地模式能用哪些功能）

### 🔴 N3：权限策略错配让 Receptionist 角色完全不可用（旅程 1/6）
- Registration 类级 `DoctorOrAdmin` → 前台无法挂号/取消
- Herbs `DoctorOrAdmin` → 前台无法查药材
- **前台这个角色在当前代码里基本无法完成任何本职工作**——这是最严重的角色级故障

### 🔴 N4：vision 三大卖点的实现状态
| 卖点 | 状态 | 卡点 |
|------|------|------|
| 复诊病历 10s 调阅（30-60×） | 🔴 | MC-008/009 历史聚合缺失，看不到既往诊疗 |
| 处方开具 <3min（验方导入） | ⚠️ | 验方导入部分可用，但打印无回写 |
| 药材库 <1h 初始化（Excel） | 🔴 | Excel 导入服务不存在 |
