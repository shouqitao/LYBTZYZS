## 配置药材组成

### 药材搜索技巧

在添加药材时，系统支持多种搜索方式：

**方式1: 名称搜索**
```
输入: 人参
结果: 人参, 西洋参, 党参 (包含"参"的所有药材)
```

**方式2: 拼音搜索**
```
输入: RS
结果: 人参 (拼音码匹配)
```

**方式3: 分类筛选**
```
1. 选择分类"补气药"
2. 筛选后搜索"参"
3. 结果: 人参, 党参, 黄芪等补气药
```

### 用量单位标准

系统支持的常见单位：

| 单位 | 适用药材 | 示例 |
|------|---------|------|
| 克 (g) | 大部分药材 | 人参 9克 |
| 付 | 动物类药材 | 蝉蜕 3付 |
| 枚 | 果实类药材 | 大枣 5枚 |
| 片 | 切片类药材 | 生姜 3片 |

**推荐使用**: 统一使用"克"作为单位，便于药房配药和价格计算

### 药材用量建议

**成人常用剂量范围**:
```
轻药（如甘草、陈皮）: 3-6克
中药（如白术、茯苓）: 9-12克
重药（如人参、黄芪）: 9-15克
毒性药（如附子、半夏）: 3-9克
```

**特殊用药**:
- 先煎药材（如生石膏）: 15-30克
- 后下药材（如薄荷）: 3-6克
- 包煎药材（如车前子）: 9-15克

### 调整药材用量

如果需要修改已添加的药材用量：

1. 在药材列表中找到该药材行
2. 直接点击"用量"单元格
3. 修改数值
4. 回车确认（系统自动重新计算总价）

**示例**:
```
原配方: 人参 9克 → 修改为 → 人参 15克
总价自动更新: 63.6元 → 93.6元
```

## 克隆和复制验方

### 为什么使用克隆功能？

当你需要创建类似的验方时，克隆功能可以大幅提升效率：

**使用场景**:
1. 基于经典方剂创建加减方
2. 为不同患者调整剂量
3. 创建个人验方库

**效率对比**:
```
手动录入:  5-10分钟/方 (录入4-10味药材)
克隆功能:  30秒-1分钟  (仅调整需要修改的部分)
```

### 克隆验方步骤

#### 示例: 从四君子汤创建六君子汤

**背景知识**: 六君子汤 = 四君子汤 + 陈皮 + 半夏

**步骤1**: 选择源验方
1. 在方剂列表中找到"四君子汤"
2. 点击该行的"克隆"按钮

**步骤2**: 编辑克隆验方
系统自动打开编辑对话框，已预填原验方信息：
```
方剂名称*: [四君子汤_副本______________]
方剂分类:  [补益方 ▼]
功效说明:  [益气健脾，补中益气___________]
用法用量:  [水煎服，日一剂______________]

药材组成 (4味):
- 人参 9克
- 白术 12克
- 茯苓 12克
- 甘草 6克
```

**步骤3**: 修改验方信息
1. 修改名称: `四君子汤_副本` → `六君子汤`
2. 修改功效: 添加 `燥湿化痰`
3. 添加新药材:
   - 陈皮 9克
   - 半夏 9克

**步骤4**: 保存新验方
```
最终配方:
- 人参 9克
- 白术 12克
- 茯苓 12克
- 甘草 6克
- 陈皮 9克  ← 新增
- 半夏 9克  ← 新增
```

**结果验证**:
方剂列表现在有2条记录：
```
方剂列表 (共2条)
┌──────────────────────────────────────────┐
│ 名称       │ 分类   │ 药材数 │ 总价   │ 操作│
├──────────────────────────────────────────┤
│ 四君子汤   │ 补益方 │ 4味    │ 63.6元 │ [编辑]│
│ 六君子汤   │ 补益方 │ 6味    │ 81.6元 │ [编辑]│
└──────────────────────────────────────────┘
```

### 克隆功能注意事项

**克隆的内容**:
- ✅ 方剂名称（自动添加"_副本"后缀）
- ✅ 分类、功效、用法
- ✅ 所有药材及用量
- ✅ 备注信息

**不会克隆的内容**:
- ❌ 共享状态（克隆后默认不共享）
- ❌ 创建时间和创建人（使用当前时间和用户）

**最佳实践**:
1. 克隆后立即修改方剂名称，避免混淆
2. 根据实际需求调整药材和用量
3. 更新功效说明以反映加减变化

## Excel批量导入

### 下载导入模板

**步骤1**: 获取标准模板
1. 在方剂管理界面点击"导入"按钮
2. 点击"下载模板"链接
3. 保存为 `验方导入模板.xlsx`

**步骤2**: 查看模板结构
打开Excel文件，表头如下：
```
| 方剂名称* | 分类 | 功效说明 | 用法用量 | 药材组成* | 备注 |
|----------|------|---------|---------|----------|------|
| 示例方剂 | 补益方| 补气    | 水煎服   | 人参9g,白术12g | - |
```

**字段说明**:
- **方剂名称**: 必填，不能重复
- **分类**: 可选，建议填写（补益方/清热方等）
- **功效说明**: 可选，建议填写
- **用法用量**: 可选
- **药材组成**: 必填，格式 `药材名称1 用量1单位,药材名称2 用量2单位,...`
- **备注**: 可选

### 准备导入数据

让我们批量导入10个经典方剂：

**示例数据**:
```excel
方剂名称*      | 分类   | 功效说明              | 用法用量  | 药材组成*
补中益气汤     | 补益方 | 补中益气,升阳举陷      | 水煎服    | 黄芪15g,党参10g,白术10g,甘草5g,当归10g,陈皮6g,升麻3g,柴胡3g
四物汤         | 补益方 | 补血调血              | 水煎服    | 当归10g,川芎8g,白芍12g,熟地黄12g
银翘散         | 解表方 | 辛凉解表,清热解毒      | 水煎服    | 金银花15g,连翘15g,桔梗10g,薄荷6g,竹叶6g,生甘草5g,荆芥穗5g,淡豆豉10g,牛蒡子10g
```

**Excel填写技巧**:
1. 使用中文逗号或英文逗号分隔药材
2. 药材名称与用量之间可有可无空格
3. 单位统一使用"g"或"克"
4. 确保药材名称与系统中的药材库一致

1. 点击"导入"按钮

3. 点击"打开"

**步骤2**: 选择导入策略
系统弹出策略选择对话框：
```
┌─────────────────────────────────────┐
│ 选择导入策略                         │

```

**策略说明**:
| 策略 | 适用场景 | 优缺点 |
|------|---------|--------|
| 跳过重复项 | 首次大批量导入 | ✅ 安全，不覆盖现有数据<br>❌ 无法更新已有方剂 |
| 更新重复项 | 数据同步和更新 | ✅ 可批量更新方剂信息<br>⚠️ 会覆盖现有数据 |
| 报错停止 | 严格质量控制 | ✅ 强制检查数据质量<br>❌ 需人工处理每个重复项 |

**推荐选择**: 首次导入选择"跳过重复项"

### 智能药材匹配

系统提供智能药材匹配功能，降低导入失败率：

**匹配策略**:
1. **精确匹配**: 药材名称完全一致
2. **别名匹配**: 支持常见药材别名
   - 例如: "当归" ←→ "当归身"/"当归头"/"当归尾"
3. **拼音匹配**: 模糊匹配拼音码

**导入日志示例**:
```
✓ 第1行: 精确匹配 - 人参
✓ 第2行: 别名匹配 - "当归身" → "当归"
⚠ 第3行: 拼音匹配 - "huangqi" → "黄芪"
✗ 第4行: 匹配失败 - "未知药材X"
```

### 处理导入失败项

如果导入失败，可以采取以下措施：

**方法1: 修正Excel数据**
1. 点击"查看详情"导出失败记录
2. 修正Excel中的错误数据
3. 重新导入失败的记录

**方法2: 补充药材库**
如果失败原因是"药材不存在"：
1. 进入"药材管理"模块
2. 添加缺失的药材
3. 返回方剂管理，重新导入

**方法3: 手动录入**
对于少量失败记录，可以手动创建验方

## 验方验证与维护

### 什么是验方验证？

验方验证是检查方剂中的药材是否仍然有效的过程。

**验证目的**:
- ✅ 确保药材未被删除
- ✅ 检查药材价格是否更新
- ✅ 维护验方数据完整性

**常见问题**:
```
问题: 验方中的"冬虫夏草"在药材库中被删除了
结果: 验方无法正常使用，需要替换或删除该药材
```

### 查看待验证验方

**步骤1**: 进入验证界面
1. 点击"待验证"标签页
2. 系统自动扫描所有验方
3. 列出包含无效药材的验方

**待验证列表**:
```
待验证验方 (共3条)
┌────────────────────────────────────────────┐
│ 方剂名称 │ 无效药材     │ 原因     │ 操作  │
├────────────────────────────────────────────┤
│ 六味地黄丸│ 熟地黄      │ 已删除   │ [验证] │
│ 玉屏风散  │ 防风        │ 已删除   │ [验证] │
│ 补中益气汤│ 党参        │ 价格过期 │ [验证] │
└────────────────────────────────────────────┘
```

**步骤2**: 选择处理方案
根据实际情况选择：
- **替换药材**: 适用于有替代品的情况
- **删除药材**: 适用于该药材不影响方剂主要功效
- **删除验方**: 适用于验方已过时或无法修复

**步骤3**: 确认验证
点击"确定"后，系统更新验方信息，验证完成。

### 批量验证验方

如果有多个验方需要验证：

**步骤1**: 勾选待验证验方
```
☑ 六味地黄丸 (熟地黄已删除)
☑ 玉屏风散 (防风已删除)
☐ 补中益气汤 (党参价格过期)
```

**步骤2**: 点击"批量验证"
系统逐个处理勾选的验方，对于相同的无效药材，可以应用统一的处理方案。

## 共享验方管理

### 什么是共享验方？

共享验方是标记为"共享"状态的方剂，可以被其他医生查看和使用。

**共享验方的价值**:
- 📚 积累团队验方库
- 🏥 新医生学习前辈经验
- 🔄 统一常用方剂配置
- 📊 提高开方效率

**应用场景**:
```
场景1: 老医生将常用验方设为共享
→ 年轻医生可以直接使用，无需重复录入

场景2: 药房主任标准化经典方剂
→ 所有医生开方时使用统一配方，减少配药错误
```

### 设置验方为共享

**步骤1**: 编辑验方
1. 在方剂列表中选择要共享的验方
2. 点击"编辑"按钮

**步骤2**: 勾选共享选项
在编辑对话框中：
```
□ 设为共享验方
  (勾选后，其他医生可查看和使用此验方)
```

**步骤3**: 保存更改
勾选"设为共享验方"后点击"保存"。

**验证结果**:
方剂列表中该验方显示"共享"标记：
```
┌──────────────────────────────────────────┐
│ 名称       │ 分类   │ 共享 │ 药材数 │ 操作│
├──────────────────────────────────────────┤
│ 四君子汤   │ 补益方 │  ✓  │ 4味    │ [编辑]│
└──────────────────────────────────────────┘
```

### 查看共享验方

**步骤1**: 切换验方来源
在方剂列表顶部，点击"共享验方"标签：

### 使用共享验方

**方法1: 直接克隆**
1. 在共享验方列表中选择方剂
2. 点击"克隆"按钮
3. 克隆后的验方属于你的个人验方，可自由修改

**方法2: 在处方中引用**
在开具处方时：
1. 选择"从验方库选择"
2. 可同时看到"我的验方"和"共享验方"
3. 选择共享验方后自动加载药材配置

**注意事项**:
- ✅ 可以克隆共享验方到个人验方库
- ✅ 可以在处方中直接引用共享验方
- ❌ 不能编辑其他医生的共享验方
- ❌ 不能删除其他医生的共享验方

## 常见问题与解决

### Q1: 保存验方时提示"方剂名称重复"？

**原因**: 系统中已存在同名方剂

**解决方法**:
1. 修改方剂名称，添加个人标识
   - 例如: `四君子汤` → `四君子汤_张医生`
2. 或使用克隆功能，系统会自动添加"_副本"后缀
3. 或查询现有方剂，确认是否可以直接使用

### Q2: 添加药材时找不到需要的药材？

**原因**: 药材库中不存在该药材

**解决方法**:
1. 确认药材名称是否正确（中医药材常有别名）
2. 尝试使用拼音搜索
3. 联系管理员添加药材到药材库
4. 或使用类似功效的替代药材

### Q3: Excel导入失败，提示"药材组成格式错误"？

**原因**: 药材组成列格式不正确

**正确格式**:
```
✓ 正确: 人参9g,白术12g,茯苓12g,甘草6g
✓ 正确: 人参 9克,白术 12克,茯苓 12克
✗ 错误: 人参9克 白术12克  (缺少逗号分隔)
✗ 错误: 人参,白术,茯苓    (缺少用量)
```

**解决方法**:
1. 下载系统提供的导入模板
2. 参考模板示例填写数据
3. 确保药材之间使用逗号分隔
4. 确保每个药材都包含用量和单位

### Q4: 验方总价与实际不符？

**原因**: 药材价格已更新，但验方未重新计算

**解决方法**:
1. 打开验方编辑界面
2. 系统会自动使用最新药材价格重新计算
3. 保存验方即可更新总价

**自动更新机制**:
- ✅ 每次打开验方时自动更新价格
- ✅ 药材库价格变动时不影响历史处方
- ✅ 验方价格仅用于参考，实际处方价格以开方时为准

### Q5: 克隆的验方能否修改药材用量？

**回答**: 可以，克隆功能完全复制验方数据，克隆后的验方完全独立，可以自由修改。

**操作步骤**:
1. 克隆验方后自动进入编辑界面
2. 调整任意药材的用量
3. 添加或删除药材
4. 修改方剂名称、分类等信息
5. 保存为新的验方

### Q6: 共享验方可以删除吗？

**回答**:
- 自己创建的共享验方可以删除
- 其他医生创建的共享验方无法删除

**最佳实践**:
- 谨慎删除共享验方，因为可能被其他医生引用
- 如需停用，建议先取消共享，观察一段时间后再删除
- 删除前检查该验方的使用次数

### Q7: 导入的验方如何批量修改分类？

**解决方法1: Excel批量更新**
1. 导出所有验方
2. 在Excel中修改分类列
3. 选择"更新重复项"策略重新导入

**解决方法2: 逐个编辑**
1. 在方剂列表中筛选需要修改的验方
2. 逐个点击"编辑"
3. 修改分类后保存
