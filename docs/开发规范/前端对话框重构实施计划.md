# 前端对话框重构实施计划

## 项目概况

- **总共需要重构**: 409 处对话框使用
- **涉及文件数**: 47 个
- **预计工作量**: 40-60 小时

## 重构策略

### 分阶段实施

由于工作量较大，建议分三个阶段实施：

1. **第一阶段**：替换所有 MessageBox.Show（约 60%）
2. **第二阶段**：重构简单对话框（约 25%）
3. **第三阶段**：重构复杂对话框（约 15%）

### 优先级排序

基于以下因素确定优先级：
- 使用频率
- 业务重要性
- 重构难度
- 依赖关系

## 第一阶段：MessageBox 替换（预计 16 小时）

### 目标
替换所有 `MessageBox.Show` 调用为 `ICommonDialogService`

### 工作内容

1. **创建自动化脚本**（2小时）
   - Python 脚本自动替换简单的 MessageBox.Show
   - 处理不同的 MessageBox 类型

2. **批量替换**（8小时）
   - 信息提示：`ShowInformationAsync`
   - 错误提示：`ShowErrorAsync`
   - 警告提示：`ShowWarningAsync`
   - 确认对话框：`ShowConfirmationAsync`

3. **手动调整**（4小时）
   - 处理复杂的条件判断
   - 调整异步调用

4. **测试验证**（2小时）
   - 编译检查
   - 基本功能测试

### 影响的主要文件
- BaseManagementViewModel（9处）
- 各种 DialogViewModel（约 50 处）
- 业务 ViewModel（约 200 处）

## 技术要点

### 1. ViewModel 注入模式
```csharp
public MyViewModel(
    IDialogService dialogService,
    ICommonDialogService commonDialogService,
    IMyService myService)
{
    _dialogService = dialogService;
    _commonDialogService = commonDialogService;
    _myService = myService;
}
```

### 2. 异步处理模式
```csharp
// 原代码
if (MessageBox.Show("确认？", "提示", MessageBoxButton.YesNo) == MessageBoxResult.Yes)
{
    DoSomething();
}

// 重构后
if (await _commonDialogService.ShowConfirmationAsync("确认？"))
{
    DoSomething();
}
```

### 3. 对话框参数传递
```csharp
var parameters = new DialogParameters
{
    { "Id", itemId },
    { "Mode", EditMode.Update }
};

_dialogService.ShowDialog("EditDialog", parameters, result =>
{
    if (result.Result == ButtonResult.OK)
    {
        var updatedItem = result.Parameters.GetValue<MyItem>("UpdatedItem");
        // 处理更新
    }
});
```

## 风险管理

### 潜在风险
1. **兼容性问题**：某些对话框可能依赖特定的 Window 特性
2. **异步转换**：从同步到异步可能影响业务流程
3. **测试覆盖**：大量修改需要充分的测试

### 缓解措施
1. **逐步迁移**：保持新旧代码并存，逐步切换
2. **充分测试**：每个模块完成后进行完整测试
3. **版本控制**：每个阶段创建分支，便于回滚
