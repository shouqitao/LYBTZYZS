## 📋 任务概述

基于现有的UserFriendlyErrorService，实现增强的错误处理系统，提供上下文相关错误信息、一键修复建议和智能错误恢复机制。

## 🎯 核心目标达成

### ✅ 1. 上下文感知错误处理
- **ErrorContext类**: 提供丰富的错误上下文信息（操作名称、模块、实体等）
- **GetContextualError方法**: 基于业务上下文生成精确的错误描述
- **模块特定错误消息**: 针对处方、患者、中药材等不同模块提供专业化错误提示

### ✅ 2. 智能一键修复建议
- **SmartFixAction类**: 可执行的修复操作定义
- **FixActionType枚举**: 8种修复操作类型（重试、重新登录、网络检查等）
- **GenerateSmartFixActions方法**: 根据错误类型和上下文智能生成修复建议
- **Command绑定**: 修复操作可直接绑定到UI按钮

### ✅ 3. 智能自动错误恢复
- **TryAutoRecoverAsync方法**: 异步自动恢复机制
- **RecoveryResult类**: 详细的恢复结果报告
- **默认恢复策略**: 网络连接、超时、权限等常见错误的自动处理
- **自定义恢复策略**: 支持注册业务特定的恢复逻辑

### ✅ 4. SmartLoadingManager深度集成
- **构造函数注入**: UserFriendlyErrorService接收SmartLoadingManager实例
- **加载状态管理**: 错误处理期间的优雅加载反馈
- **分层加载**: 自动恢复使用独立的层级2加载状态

### 自动恢复策略实现
```csharp
// 网络连接恢复
RegisterRecoveryStrategy("connection", async (ex, ctx) => {
    await Task.Delay(1000); // 等待网络恢复
    return true; // 假设恢复成功
});

// 超时重试机制
RegisterRecoveryStrategy("timeout", async (ex, ctx) => {
    if (ctx.RetryCount < 3) {
        ctx.RetryCount++;
        await Task.Delay(ctx.RetryCount * 1000); // 指数退避
        return true;
    }
    return false;
});
```
