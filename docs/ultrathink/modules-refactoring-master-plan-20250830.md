## 🏗️ 标准重构模板

### 三层架构标准
```csharp
// 1. Core Service - CRUD操作 (~150-200行)
public class [Module]ServiceCore
{
    // 基础CRUD、状态管理、验证
}

// 2. Query Service - 复杂查询 (~100-150行)  
public class [Module]QueryService
{
    // 分页查询、搜索、筛选、推荐
}

// 3. Business Service - 业务逻辑 (~80-120行)
public class [Module]BusinessService
{
    // 业务规则、复杂操作、集成逻辑
}

// 4. Main Service - 组合器 (~100-150行)
public class [Module]Service : I[Module]Service
{
    // 纯委托模式，组合三个专门服务
}
```

### 目录结构标准
```
Services/
├── [Module]Service.cs (主服务组合器)
├── Core/
│   └── [Module]ServiceCore.cs (核心CRUD)
├── [Module]QueryService.cs (复杂查询)
└── [Module]BusinessService.cs (业务逻辑)
```
