- [ ] 预约挂号API
- [ ] 号源管理
- [ ] 退号处理

#### API设计
```
POST   /api/registrations - 创建挂号
GET    /api/registrations - 查询挂号列表
GET    /api/registrations/{id} - 挂号详情

GET    /api/registrations/appointments - 预约列表
POST   /api/registrations/quick - 快速挂号
```

- [ ] 队列模型设计（QueueModel）

- [ ] 叫号机制
- [ ] 优先级管理
- [ ] 过号处理

2. **看诊队列**: 等待医生
3. **缴费队列**: 等待收费
4. **取药队列**: 等待发药
