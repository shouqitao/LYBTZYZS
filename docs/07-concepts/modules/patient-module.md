## 概述

患者管理模块实现中医诊所患者档案的全生命周期电子化管理，支持远程和本地双模式运行。核心解决纸质病历检索困难、数据分散、敏感信息保护不足等问题，为医案管理和处方开具提供基础数据支撑。

## 核心能力

| 能力 | 说明 |
|------|------|
| 档案管理 CRUD | 患者信息增删改查，自动生成拼音码 (PinYinCode)，身份证号唯一性校验 |
| 快速检索 | 按姓名/拼音码关键词搜索，支持分页浏览和 OutputCache 缓存加速 |
| 批量操作 | Excel 导入（最多 1000 行，部分成功模式）和导出（按关键词筛选） |
| 敏感数据保护 | 身份证号/手机号 AES-256 加密存储 + 脱敏展示（部分掩码/哈希掩码） |
| 引用检查 | 删除前检查医案关联，有关联时禁止删除并建议改用禁用功能 |
| 状态管理 | 启用/禁用切换，禁用后限制新医案创建并按角色脱敏展示 |

## 角色权限

| 角色 | 权限 |
|------|------|
| SuperAdmin | 全部患者 CRUD + 状态管理（启用/禁用） |
| Admin | 全部患者 CRUD + 状态管理（启用/禁用） |
| Doctor | 创建/查看/更新/删除全部患者（Restore 为 Admin-only）；可见禁用患者，列表标注状态 |
| Receptionist | 创建、查看列表/详情、更新患者（CRU，无删除权限；自动过滤禁用患者） |

## 关键业务规则

1. **查重规则**：新患者登记时按手机号/身份证号查重，已存在则提示直接使用现有档案
2. **软删除机制**：患者删除采用软删除（IsDeleted=true），保留历史记录
3. **引用保护**：删除前检查是否有关联医案，有关联则拒绝删除并建议使用禁用功能
4. **敏感字段加密**：L1 高敏感字段（IdNumber、PhoneNumber）在本地 SQLite 中通过 EF Core Value Converter 透明加密（AES-256 + DPAPI 密钥保护），加密字段不支持 LIKE 搜索
5. **最后就诊时间自动更新**：每次创建医案后自动更新 LastVisitTime 和 VisitCount
6. **双模式支持**：远程模式（HTTP API + SQL Server）和本地模式（SQLite + NPOI 本地解析）均完整支持
