# 系统简化调整说明

## 调整背景

根据凌隐宝堂中医诊所的实际运营模式，系统进行了以下简化调整：
- 诊所目前**不接受预约**，只支持**现场挂号**
- 医生管理以基本信息为主，无需复杂的排班管理
- 暂不需要评价打分功能

## 模块调整详情

### 1. Doctors（医生）模块简化

#### 移除的功能
- ❌ 复杂的排班管理（周模板、时段设置等）
- ❌ 评价打分系统
- ❌ 医生排行榜
- ❌ 工作统计（接诊量、满意度等）
- ❌ 擅长疾病管理
- ❌ 学术成就记录

#### 保留的功能
- ✅ 医生基础信息CRUD
- ✅ 医生与用户账号关联
- ✅ 医生状态管理（在职、休假、离职）
- ✅ 简单的专长和职称信息
- ✅ 挂号费设置

#### 新增的简化功能
- ✅ **休息时间设置** - 医生可设置某天休息不出诊
- ✅ **获取某天出诊医生** - 排除休息的医生

### 2. Registration（挂号）模块调整

#### 调整为现场挂号模式
- ✅ **现场挂号** - 患者到诊所直接挂号
- ✅ **排队号生成** - 按医生当天自动递增
- ✅ **今日挂号列表** - 查看当天所有挂号
- ✅ **挂号状态流转** - 等待→就诊中→已完成

#### 预留接口
- 🔄 **当天挂号限制** - 预留接口，后续开发
- 🔄 **挂号时间段** - 预留字段，暂不使用

### 3. 相关影响

#### Queueing（排队）模块
- 与Registration模块联动
- 添加挂号ID关联
- 添加排队号字段
- 支持状态同步更新

#### 其他模块
- **Consultation（就诊）** - 简化为基于现场挂号
- **Appointment（预约）** - 暂不开发

## API接口调整

### 医生相关

#### 简化后的接口
```
GET  /api/v1/doctors                      - 获取医生列表
GET  /api/v1/doctors/{id}                 - 获取医生详情
POST /api/v1/doctors                      - 新增医生
PUT  /api/v1/doctors/{id}                 - 更新医生信息
DELETE /api/v1/doctors/{id}               - 删除医生

# 休息管理
POST /api/v1/doctors/{id}/rest           - 设置休息日期
GET  /api/v1/doctors/{id}/rest-records   - 获取休息记录
GET  /api/v1/doctors/available/{date}    - 获取某天出诊医生
```

#### 移除的接口
```
# 排班管理（已移除）
- /api/v1/doctors/{id}/schedules
- /api/v1/doctors/{id}/schedules/weekly-template
- /api/v1/doctors/{id}/available-slots

# 评价系统（已移除）
- /api/v1/doctors/{id}/rating
- /api/v1/doctors/ranking/{type}
```

### 挂号相关

#### 现场挂号接口
```
# 基础操作
POST /api/v1/registrations                - 现场挂号
GET  /api/v1/registrations/today          - 今日挂号列表
GET  /api/v1/registrations/{id}           - 挂号详情
PUT  /api/v1/registrations/{id}/cancel    - 取消挂号

# 就诊流程
POST /api/v1/registrations/{id}/start     - 开始就诊
POST /api/v1/registrations/{id}/complete  - 完成就诊
GET  /api/v1/registrations/current/{doctorId}  - 当前就诊
GET  /api/v1/registrations/next/{doctorId}     - 下一位患者

# 统计
GET  /api/v1/registrations/stats/{doctorId}    - 医生今日统计
```

## 业务流程简化

### 现场挂号流程
1. 患者到达诊所
2. 前台创建挂号（选择医生）
3. 系统生成排队号
4. 患者等待叫号
5. 医生叫号开始就诊
6. 就诊完成

### 医生工作流程
1. 医生登录系统
2. 查看今日挂号列表
3. 叫号接诊
4. 完成就诊
5. 呼叫下一位

## 注意事项

1. **数据迁移** - 如果已有排班数据，需要清理
2. **接口兼容** - 前端需要适配新的简化接口
3. **权限控制** - 休息日期设置需要医生本人或管理员权限
4. **状态管理** - 挂号和排队状态需要保持同步

## 总结

此次简化调整使系统更贴合诊所实际运营模式，降低了系统复杂度，提高了可维护性。同时保留了扩展接口，便于后续功能升级。
