### 2. UserCommandHandler待实现逻辑

**文件**: `ViewModels/Components/UserCommandHandler.cs:278`
**问题**: ChangePasswordAsync方法包含TODO标记

```csharp
// TODO: 实现修改密码逻辑（应该调用认证服务）
public virtual async Task<ServiceResult> ChangePasswordAsync(...)
{
    // 当前实现调用_repository.ChangePasswordAsync
}
```

**分析**：
- 注释提示"应该调用认证服务"
- 但实际实现调用UserRepository.ChangePasswordAsync
- UserRepository进一步调用IUserApi.ChangePasswordAsync
- 此逻辑路径实际上是合理的（用户密码管理属于Users模块职责）

**建议**：
- 移除TODO标记（当前实现已经合理）
- 或者明确为何认为应该调用认证服务（需要架构讨论）

**优先级**：低（功能正常，仅注释不清晰）
