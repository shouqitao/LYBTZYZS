## 2. 需求澄清

### 2.1 核心问题

**Q1**: 用户原始需求是"完善所有用户管理功能"，但实际上90%功能已实现，是否只需修复重置密码功能？

**A1**: 经过代码库分析，确认只需修复管理员重置用户密码功能的调用链。其他功能已完整实现：
- 用户CRUD（增删改查）✅
- 用户状态管理（启用/禁用）✅
- 个人资料编辑 ✅
- 用户修改自己的密码 ✅
- 批量操作 ✅

**Q2**: 重置密码功能的业务规则是什么？

**A2**: 基于现有代码分析：
1. **谁可以重置**：仅管理员（SuperAdmin/Admin）可以为其他用户重置密码
2. **重置方式**：
   - 管理员手动输入新密码（≥8字符）
   - 或使用"生成随机密码"功能（12位复杂密码）
3. **安全选项**：
   - 可选：要求用户下次登录时修改密码（默认启用）
   - 可选：发送通知给用户（可选）
4. **密码规则**：
   - 最小长度：8字符
   - 复杂度：随机生成包含大小写字母、数字、特殊符号

**Q3**: Server端API返回什么？

**A3**: 基于Server端代码分析：
- 请求DTO: `ResetPasswordRequestDto { string? NewPassword }`
  - 如果NewPassword为空，Server端自动生成随机密码
- 响应DTO: `ResetPasswordResponseDto { string NewPassword }`
  - 返回最终设置的密码（用于显示给管理员）

### 2.2 业务规则

1. **权限控制**:
   - SuperAdmin可以重置所有用户密码
   - Admin可以重置Doctor密码
   - Doctor不能重置任何人密码
   - 用户不能重置自己的密码（应使用ChangePasswordDialog）

2. **密码生成规则** (已在ResetPasswordDialogViewModel实现):
   ```csharp
   长度：12字符
   组成：至少2个小写字母 + 至少2个大写字母 + 至少2个数字 + 至少2个特殊符号
   特殊符号集：!@#$%^&*()_+-=[]{}
   ```

3. **审计日志**:
   - Server端已记录：`LogOperation("重置用户密码", new { AutoGenerated = ... }, userId)`
   - Client端需记录：操作用户、目标用户、操作时间

4. **用户体验**:
   - 重置成功后显示新密码（需要管理员记录或复制）
   - 可选择"发送通知"（当前Mock，未实现邮件/短信通知）
   - 可选择"要求下次登录修改"（Server端支持，但当前未实现强制修改逻辑）

```csharp
// 修改ConfirmAsync方法（约line 260）
private async Task ConfirmAsync()
{
    try
    {
        if (!ValidatePasswords()) return;
        if (_targetUserId == Guid.Empty) { SetError("无效的用户ID"); return; }
        
        SetIsBusy(true, "正在重置密码...");
        
        // 调用CommandHandler
        var result = await _commandHandler.ResetPasswordAsync(_targetUserId, NewPassword);
        
        if (result.success && result.response != null)
        {
            await ShowSuccessMessageAsync($"密码重置成功！\n\n新密码: {result.response.NewPassword}");
            RequestClose?.Invoke(new DialogResult(ButtonResult.OK));
            Logger.LogInformation("用户 {UserId} 密码重置成功", _targetUserId);
        }
        else
        {
            SetError(result.errorMessage ?? "密码重置失败");
        }
    }
    catch (Exception ex)
    {
        Logger.LogError(ex, "重置密码时发生异常");
        await ShowErrorMessageAsync($"重置密码失败: {ex.Message}");
    }
    finally
    {
        SetIsBusy(false);
    }
}
```
