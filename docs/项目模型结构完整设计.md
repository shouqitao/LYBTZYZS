## 1. 模型架构概览

### 1.1 三层模型架构

```
┌─────────────────────────────────────────────────────────┐
│                   前端业务模型层                         │
│  ┌──────────────────────────────────────────────────┐  │
│  │          WPF客户端模型 (*.Info)                  │  │
│  │    PatientInfo, DoctorInfo, RegistrationInfo    │  │
│  └──────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
                            ↕ AutoMapper
┌─────────────────────────────────────────────────────────┐
│                  共享契约模型层                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │           数据传输对象 (*.Dto)                   │  │
│  │    PatientDto, DoctorDto, RegistrationDto       │  │
│  └──────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
                            ↕ Entity Framework
┌─────────────────────────────────────────────────────────┐
│                   后端实体模型层                         │
│  ┌──────────────────────────────────────────────────┐  │
│  │            数据库实体 (Entity)                   │  │
│  │      Patient, Doctor, Registration, etc.        │  │
│  └──────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
                            ↕ SQL Queries
┌─────────────────────────────────────────────────────────┐
│                     数据库表结构                        │
│         Patients, Doctors, Registrations, etc.         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 模型设计原则

1. **单一职责原则**: 每个模型只负责特定的业务领域
2. **开闭原则**: 基类设计支持扩展，不需修改现有代码
3. **依赖倒置**: 前端依赖抽象接口，不依赖具体实现
4. **数据一致性**: 前后端通过DTO契约保证数据格式一致
5. **业务语义化**: 模型和字段命名体现真实业务含义

### 2.1 基础实体类

#### BaseEntity - 所有实体的基类
```csharp
public abstract class BaseEntity
{
    /// <summary>唯一标识</summary>
    [Key]
    public Guid Id { get; set; } = Guid.NewGuid();
    
    /// <summary>创建时间</summary>
    [Required]
    public DateTime CreateTime { get; set; } = DateTime.Now;
    
    /// <summary>更新时间</summary>
    public DateTime? UpdateTime { get; set; }
    
    /// <summary>创建者</summary>
    [MaxLength(50)]
    public string? CreatedBy { get; set; }
    
    /// <summary>更新者</summary>
    [MaxLength(50)]
    public string? UpdatedBy { get; set; }
    
    /// <summary>是否激活</summary>
    public bool IsActive { get; set; } = true;
    
    /// <summary>是否已删除(软删除)</summary>
    public bool IsDeleted { get; set; } = false;
}
```

### 6.1 AutoMapper配置示例

#### PatientMappingProfile - 患者模型映射
```csharp
public class PatientMappingProfile : Profile
{
    public PatientMappingProfile()
    {
        // Entity -> DTO
        CreateMap<Patient, PatientDto>()
            .ForMember(dest => dest.GenderDisplay, opt => opt.MapFrom(src => src.Gender.GetDescription()));
            
        CreateMap<Patient, PatientDetailDto>()
            .IncludeBase<Patient, PatientDto>();
        
        // DTO -> Entity
        CreateMap<PatientCreateDto, Patient>()
            .ForMember(dest => dest.PatientNo, opt => opt.Ignore()) // 系统生成
            .ForMember(dest => dest.PinYinCode, opt => opt.MapFrom(src => GeneratePinYinCode(src.Name)))
            .ForMember(dest => dest.Age, opt => opt.MapFrom(src => CalculateAge(src.BirthDate)));
            
        CreateMap<PatientUpdateDto, Patient>()
            .ForMember(dest => dest.PatientNo, opt => opt.Ignore()) // 不允许修改编号
            .ForMember(dest => dest.PinYinCode, opt => opt.MapFrom(src => GeneratePinYinCode(src.Name)))
            .ForMember(dest => dest.Age, opt => opt.MapFrom(src => CalculateAge(src.BirthDate)));
        
        // DTO -> Frontend Model
        CreateMap<PatientDto, PatientInfo>();
        CreateMap<PatientDetailDto, PatientInfo>();
        
        // Frontend Model -> DTO
        CreateMap<PatientInfo, PatientUpdateDto>();
    }
    
    private string GeneratePinYinCode(string name)
    {
        // 拼音码生成逻辑
        return name.ToUpper(); // 简化实现
    }
    
    private int? CalculateAge(DateTime? birthDate)
    {
        if (!birthDate.HasValue) return null;
        
        var today = DateTime.Today;
        var age = today.Year - birthDate.Value.Year;
        if (birthDate.Value.Date > today.AddYears(-age))
            age--;
        return age;
    }
}
```

```csharp
public class AppDbContext : DbContext

        // 药材-处方明细关系 (一对多)

            .HasOne(pd => pd.Herb)
            .WithMany(h => h.PrescriptionDetails)
            .HasForeignKey(pd => pd.HerbId)
            .OnDelete(DeleteBehavior.Restrict);
        
        // 验方模板-药材关系 (多对多，通过中间表)
        modelBuilder.Entity<FormulaTemplateHerb>()
            .HasKey(fth => new { fth.FormulaTemplateId, fth.HerbId }); // 复合主键
            
        modelBuilder.Entity<FormulaTemplateHerb>()
            .HasOne(fth => fth.FormulaTemplate)
            .WithMany(ft => ft.Herbs)
            .HasForeignKey(fth => fth.FormulaTemplateId)
            .OnDelete(DeleteBehavior.Cascade);
            
        modelBuilder.Entity<FormulaTemplateHerb>()
            .HasOne(fth => fth.Herb)
            .WithMany(h => h.FormulaTemplateHerbs)
            .HasForeignKey(fth => fth.HerbId)
            .OnDelete(DeleteBehavior.Restrict);
            
        // 软删除全局过滤器
        foreach (var entityType in modelBuilder.Model.GetEntityTypes())
        {
            if (typeof(BaseEntity).IsAssignableFrom(entityType.ClrType))
            {
                var parameter = Expression.Parameter(entityType.ClrType, "e");
                var property = Expression.Property(parameter, nameof(BaseEntity.IsDeleted));
                var filter = Expression.Lambda(
                    Expression.Equal(property, Expression.Constant(false)),
                    parameter);
                modelBuilder.Entity(entityType.ClrType).HasQueryFilter(filter);
            }
        }
    }
```

## 7. 数据库设计

### 7.1 表结构设计原则

1. **命名约定**:
   - 表名：Pascal命名法，复数形式 (Users, Patients)
   - 字段名：Pascal命名法 (CreateTime, PatientName)
   - 主键：统一使用 Id
   - 外键：实体名 + Id (PatientId, DoctorId)

2. **数据类型**:
   - 主键：UNIQUEIDENTIFIER (Guid)
   - 字符串：NVARCHAR，根据业务需求设定长度
   - 金额：DECIMAL(10,2)
   - 日期：DATETIME2
   - 布尔：BIT

3. **约束设计**:
   - 所有表都有主键约束
   - 关键字段添加唯一约束
   - 外键关系设置适当的删除行为
   - 必填字段设置NOT NULL约束
