# 凌隐宝堂中医诊所系统 - 最终业务流程设计

## 一、业务模式定位

### 1.1 诊所运营模式
- **类型**：纯中医诊所（只看诊，不售药）
- **收费模式**：先付看诊费，后看诊
- **处方模式**：开具处方，患者自行到药房抓药
- **定位**：可复用的中医诊所管理软件

### 1.2 核心价值
- 简化医生看诊流程
- 规范处方管理
- 积累诊疗经验
- 支持多诊所部署

## 二、完整业务流程

### 2.1 就诊流程图
```
患者到诊所
    ↓
现金支付看诊费（诊所前台收取）
    ↓
医生查询患者（支持姓名/拼音/电话/身份证）
    ↓
    ├─ 老患者：选择并加载历史信息
    └─ 新患者：创建档案（可用身份证读卡器）
    ↓
四诊信息采集（望闻问切）
    ↓
辨证分析（诊断）
    ↓
开具处方（含参考价格）
    ↓
打印处方单（2份）
    ↓
患者持处方去药房抓药（外部流程）
    ↓
系统记录完整就诊信息（用于查阅学习）
```

### 2.1.1 患者接待详细流程
```
输入查询条件（姓名/拼音/电话/身份证）
    ↓
    ├─ 查询到患者 → 显示列表 → 选择患者 → 加载信息 → 开始看诊
    │
    ├─ 查无此人 → 提示"是否新建？"
    │              ├─ 是 → 新建患者档案 → 保存 → 开始看诊
    │              └─ 否 → 返回查询
    │
    └─ 使用身份证读卡器
         ↓
       读取身份证信息
         ↓
       自动查询匹配
         ├─ 找到患者 → 加载完整信息 → 开始看诊
         └─ 未找到 → 提示"是否保存为新患者？"
                     ├─ 是 → 创建患者 → 开始看诊
                     └─ 否 → 仅显示信息
```

### 2.2 关键业务规则

#### 看诊费处理
- 系统**不处理**看诊费支付
- 看诊费由前台**现金收取**
- 先付费后看诊（隐含挂号）
- 无需退费流程

#### 处方生命周期
- **生成**：医生完成诊疗后生成
- **有效期**：完成就诊即失效（一人一方原则）
- **用途**：打印给患者 + 存档查阅
- **状态**：不可修改，只能作废重开（当天）

#### 药品价格
- 只做**参考价格**计算
- 实际收费在药房完成
- 支持折扣设置（给患者参考）
- 价格数据由管理员维护

## 三、系统功能边界

### 3.1 系统负责
✅ 患者信息管理
✅ 诊疗过程记录
✅ 处方生成打印
✅ 验方模板管理
✅ 历史记录查询
✅ 诊疗经验积累
✅ 参考价格计算
✅ 基础统计分析

### 3.2 系统不负责
❌ 挂号排队（直接选择患者）
❌ 收费管理（现金收取）
❌ 药品库存（药房管理）
❌ 药品销售（药房负责）
❌ 退费处理（无此流程）
❌ 医保对接（现金支付）
❌ 预约管理（到店就诊）

## 四、数据管理策略

### 4.1 处方编号规则
- **格式**：RX20250108001
  - RX：处方前缀（Prescription）
  - 20250108：日期（年月日）
  - 001：当日序号（3位）
- **唯一性**：全局唯一
- **连续性**：按日期连续编号

### 4.2 数据修改规则
| 数据类型 | 修改规则 | 说明 |
|---------|---------|------|
| 患者信息 | 随时可改 | 基础信息更新 |
| 四诊记录 | 当天可改 | 隔天只读 |
| 诊断结果 | 当天可改 | 隔天只读 |
| 处方 | 当天可作废重开 | 隔天只读 |
| 验方 | 只能禁用 | 保持历史完整性 |

### 4.3 打印控制
- **打印次数**：不限制
- **打印记录**：记录每次打印（时间、操作人）
- **打印内容**：
  - 诊所信息（从配置读取）
  - 患者信息
  - 诊断结果
  - 处方内容
  - 价格信息
  - 用法说明
  - 医生签名栏

## 六、用户角色与权限（简化版）

### 6.1 角色定义
| 角色 | 权限范围 |
|------|---------|
| 医生 | 看诊、开方、查询本人患者 |
