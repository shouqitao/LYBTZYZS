# 验方管理模块设计规范

## 一、核心概念定义

### 1.1 验方（Formula）
- **定义**：中医经典处方模板，包含固定的药材组合和剂量
- **用途**：作为处方开具的快速模板，提高开方效率
- **特点**：可复用、可共享、可组合

## 二、功能规范

### 2.1 验方创建与管理

#### 创建规则
- 医生可以创建个人验方
- 验方名称在创建者范围内唯一（不同医生可以有同名验方）
- 创建时自动生成快照，记录药材组成和剂量

#### 管理规则
- 验方只能禁用，不能删除（保持历史记录完整性）
- 修改验方时创建新版本（快照机制）
- 支持验方的启用/禁用状态切换

### 2.2 验方共享机制

#### 共享规则
- 医生可将个人验方设置为共享状态
- 共享验方对其他医生可见
- 管理员可以查看和管理所有验方

#### 共享行为
- **实时更新**：共享验方被修改时，使用者看到最新版本
- **另存为己有**：其他医生可将共享验方保存为个人验方
- **权限控制**：只有创建者可修改原始验方

### 2.3 经典验方管理

#### 管理权限
- 仅管理员可创建和维护经典验方
- 经典验方对所有用户可见（启用状态下）
- 经典验方具有更高的推荐优先级

#### 分类体系
- 按功效分类（解表、清热、温里、补益等）
- 按适应症分类（感冒、咳嗽、胃痛等）
- 支持多级分类和标签系统

## 三、数据模型设计

### 3.1 验方基础信息
```csharp
public class Formula
{
    public Guid Id { get; set; }
    public string Name { get; set; }              // 验方名称
    public string CreatorId { get; set; }         // 创建者ID
    public string CreatorName { get; set; }       // 创建者姓名
    public FormulaType Type { get; set; }         // 类型：个人/共享/经典
    public string Category { get; set; }          // 分类
    public string Indication { get; set; }        // 适应症
    public string Description { get; set; }       // 说明
    public bool IsShared { get; set; }           // 是否共享
    public bool IsEnabled { get; set; }          // 是否启用
    public DateTime CreateTime { get; set; }      // 创建时间
    public DateTime UpdateTime { get; set; }      // 更新时间
}
```

### 3.2 验方快照
```csharp
public class FormulaSnapshot
{
    public Guid Id { get; set; }
    public Guid FormulaId { get; set; }          // 关联验方ID
    public int Version { get; set; }             // 版本号
    public List<FormulaHerb> Herbs { get; set; } // 药材组成
    public DateTime SnapshotTime { get; set; }   // 快照时间
    public string ModifiedBy { get; set; }       // 修改者
    public string ChangeReason { get; set; }     // 修改原因
}
```

## 四、业务流程

### 4.1 处方开具时使用验方

#### 单个验方使用
1. 医生选择验方
2. 系统加载验方最新版本的药材组成
3. 自动填充到处方中
4. 医生可调整剂量

#### 多个验方组合
1. 医生选择多个验方
2. 系统合并药材列表
3. **相同药材处理规则**：
   - 取各验方中的最小剂量（安全原则）
   - 提示医生手动调整
4. 生成合并后的处方

### 4.2 验方版本管理

#### 版本控制策略
- 每次修改创建新快照
- 保留所有历史版本
- 处方记录引用特定版本的快照

#### 版本追溯
- 可查看验方的修改历史
- 可比较不同版本的差异
- 可恢复到历史版本

## 六、界面设计要求

### 6.1 验方列表页面
- 分类筛选：个人/共享/经典
- 搜索功能：按名称、适应症、药材
- 排序选项：使用频率、更新时间、创建时间
- 批量操作：启用/禁用、导出

### 6.2 验方详情页面
- 基本信息展示
- 药材组成列表（可编辑）
- 版本历史记录
- 使用统计（管理员可见）
- 操作按钮：编辑、共享、另存为

### 6.3 验方选择器（处方开具时）
- 快速搜索
- 常用验方置顶
- 多选支持
- 预览功能
- 剂量冲突提示

## 七、特殊业务规则

### 7.1 验方命名规范
- 长度限制：2-50个字符
- 支持中文、英文、数字
- 不允许特殊字符
- 建议格式：[功效]+[主药]+方

### 7.2 剂量安全规则
- 设置药材的最大日剂量
- 超出安全剂量时警告
- 毒性药材特殊标记
- 配伍禁忌自动检查

### 7.3 审计要求
- 记录所有验方的创建、修改、共享操作
- 记录验方在处方中的使用情况
- 支持使用频率统计
- 支持效果反馈收集

## 八、技术实现要点
