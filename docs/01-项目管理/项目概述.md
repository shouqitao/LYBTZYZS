## 一、项目基本信息

### 1.1 项目名称

**中文名称**: 凌隐宝堂中医诊所管理系统  
**英文名称**: Lingyin Baotang Traditional Chinese Medicine Clinic Management System  
**项目代号**: LYBTZYZS  

### 1.2 项目背景

#### 业务背景
凌隐宝堂是一家专注于传统中医诊疗的医疗机构，致力于为患者提供专业的中医诊断、治疗和康复服务。随着诊所规模的扩大和患者数量的增长，传统的手工管理方式已无法满足现代化管理需求。

#### 技术背景
现有的中医诊所管理系统大多功能单一、用户体验差，缺乏针对中医特色业务的深度支持。本项目旨在开发一套专门针对中医诊所业务特点的现代化管理系统。

### 1.3 项目目标

#### 业务目标
1. **提升运营效率**: 将患者挂号、诊疗、开方、取药等流程数字化，提高工作效率50%以上
2. **优化患者体验**: 缩短患者等待时间，提供便捷的预约和查询服务
3. **规范业务流程**: 建立标准化的中医诊疗流程，确保医疗质量和安全
4. **数据驱动决策**: 通过数据分析支持诊所运营决策和业务优化

#### 技术目标
1. **系统稳定性**: 系统可用性达到99.5%以上
2. **性能要求**: 支持50+并发用户，响应时间<2秒
3. **数据安全**: 确保患者隐私和医疗数据安全
4. **可扩展性**: 支持业务规模扩展和功能模块添加

### 1.4 项目范围

#### 功能范围
```
🏥 中医诊所完整业务流程
├── 👥 用户管理 (医生、护士、前台、管理员)
├── 📋 患者管理 (档案建立、信息维护)  
├── 📅 预约挂号 (在线预约、现场挂号)
├── 🩺 诊断治疗 (病历记录、诊断开方)
├── 💊 处方管理 (中药处方、配方模板)
├── 🏪 药房管理 (库存管理、配药发药)
├── 💰 收费结算 (费用计算、支付管理)
├── 📊 统计分析 (业务数据、运营报表)
└── ⚙️ 系统管理 (权限配置、参数设置)
```

#### 技术范围
- **后端服务**: .NET 8 Web API
- **前端应用**: WPF桌面应用
- **数据库**: SQL Server 2019+
- **部署环境**: Windows Server 2019+
- **集成接口**: 支持第三方系统对接

#### 非功能需求
- **性能**: 支持50并发用户，响应时间<2秒
- **可用性**: 系统可用性99.5%，故障恢复时间<1小时
- **安全性**: 符合医疗数据安全标准，支持数据加密
- **可维护性**: 代码覆盖率>80%，关键功能自动化测试

### 3.2 技术栈

#### 后端技术栈
- **.NET 8.0**: 现代化的跨平台开发框架
- **ASP.NET Core Web API**: RESTful API服务
- **Entity Framework Core 8.0**: ORM数据访问
- **AutoMapper**: 对象映射
- **JWT Bearer**: 身份认证授权
- **Swagger**: API文档和测试

#### 前端技术栈
- **WPF (.NET 8)**: Windows桌面应用开发
- **Prism.DryIoc**: MVVM框架和依赖注入
- **Material Design**: 现代化UI设计
- **Refit**: HTTP客户端库
- **CommunityToolkit.Mvvm**: MVVM工具包

#### 数据库技术
- **SQL Server 2019+**: 关系型数据库
- **Entity Framework Migrations**: 数据库版本管理
- **SQL Server Integration Services**: 数据集成(可选)

#### 开发工具
- **Visual Studio 2022**: 主要开发IDE
- **Git + GitHub**: 源码版本控制
- **Postman**: API测试工具
- **SQL Server Management Studio**: 数据库管理
