# Desktop 设计标准（Design Tokens & 规范）

> **版本**: v1.0 | **日期**: 2026-08-22
> **基准**: login.pen（经 MCP 优化后的最终版本）
> **用途**: 所有后续页面设计的统一标准，CLI/MCP 生成时必须遵循

---

## 1. 色彩系统

### 品牌色（从 login.pen 提取）

| Token | 值 | 用途 |
|-------|-----|------|
| `$primary` | `#6D4C41` | 主色（按钮/选中态/品牌标识） |
| `$primary-dark` | `#4E342E` | 深主色（渐变终点/侧边栏） |
| `$primary-deep` | `#3E2723` | 最深主色（侧边栏背景） |
| `$accent` | `#FFB300` | 强调色（琥珀色/分隔线/重要标记） |

### 背景色

| Token | 值 | 用途 |
|-------|-----|------|
| `$bg-warm` | `#FBF7F3` | 页面底色（暖灰白） |
| `$surface-0` | `#FAF8F5` | L0 层级（最底层） |
| `$surface-1` | `#FFFFFF` | L1 层级（面板/卡片） |

### 文字色

| Token | 值 | 用途 |
|-------|-----|------|
| `$text-primary` | `#2F2A26` | 主要文字（标题/内容） |
| `$text-secondary` | `#8D8078` | 次要文字（标签/说明/版权） |

### 功能色

| Token | 值 | 用途 |
|-------|-----|------|
| `$success` | `#2E7D32` | 成功/在线/连接正常 |
| `$border-soft` | `#C9C1B9` | 边框/分隔线 |

### 色彩使用规则

```
✅ 主要操作按钮：$primary 渐变 → $primary-dark
✅ 选中态：$primary 填充
✅ 未选中态：transparent + $primary 文字
✅ 成功状态：$success（绿色文字/指示灯）
✅ 次要信息：$text-secondary
✅ 页面底色：$bg-warm（暖灰白）
✅ 卡片/面板：$surface-1（白色）
```

## 2. 字体系统

### 字体家族

| Token | 字体 | 用途 |
|-------|------|------|
| `$font-brand` | Noto Serif SC | 品牌名称/标题（衬线体） |
| `$font-body` | Noto Sans SC | 正文/标签/按钮（无衬线体） |

### 字号层级

| 层级 | 字号 | 字重 | 用途 | 对应元素 |
|------|------|------|------|----------|
| 品牌名 | 36px | 600 (SemiBold) | 系统名称 | 凌隐宝堂中医诊所 |
| 页面标题 | 24px | 600 (SemiBold) | 页面主标题 | 欢迎登录 |
| 副标题 | 14px | 400 (Normal) | 说明文字 | 请使用您的账号登录 |
| 输入内容 | 15px | 400 (Normal) | 输入框文字 | admin / •••••••• |
| 标签 | 13px | 500 (Medium) | 表单标签 | 用户名/密码 |
| 按钮文字 | 14px | 500 (Medium) | 按钮内文字 | 登录/API配置 |
| 切换文字 | 13px | 400 (Normal) | 模式切换 | 远程模式/本地模式 |
| 状态文字 | 13px | 500 (Medium) | 状态指示 | API 已连接 |
| 辅助文字 | 12px | 400 (Normal) | 版本/版权/分隔 | © 2026 |
| 标语 | 13px | 400 (Normal) | 品牌标语 | 让中医诊疗更智能 |

## 5. 布局规范

### 页面尺寸

| 参数 | 值 |
|------|-----|
| 基准画布 | 1920 × 1080 |
| 常用窗口 | 1440 × 900 |
| 最小尺寸 | 1280 × 720 |

### 主窗口三栏布局

```
┌──────────────────────────────────────────────────────┐
│  头栏（48px）                                        │
├──────┬───────────────────────────────────────────────┤
│      │                                               │
│ 侧边 │              内容区                            │
│ 栏   │                                               │
│      │                                               │
│240/64│                                               │
│      │                                               │
├──────┴───────────────────────────────────────────────┤
│  状态栏（32px）                                      │
└──────────────────────────────────────────────────────┘
```

### 侧边栏

| 参数 | 值 |
|------|-----|
| 展开宽度 | 240px |
| 收拢宽度 | 64px（仅图标居中，文字入 Tooltip） |
| 背景色 | `$primary-dark` (#4E342E) |
| 容器内边距 | 12（收拢 8 12） |
| 项间距 | 4 |
| 菜单项高度 | 38px |
| 菜单项圆角 | 10 |
| 图标尺寸 | 18 |
| 菜单字号 | 13px（选中 500 / 未选中 400） |
| 组标题 | 11px 600 #C9B8A6 |
| 选中态 | $primary 填充 + 白色文字/图标 |
| 未选中态 | 透明 + #E8DDD4 文字/图标 |

### 头栏

| 参数 | 值 |
|------|-----|
| 高度 | 48px |
| 背景色 | `$primary` (#6D4C41) |
| 内边距 | 0 16（pen 中 0 8~0 12 视状态） |
| 内容 | 左：品牌标识 $accent + 凌隐宝堂中医诊所 $on-primary；右：分隔线 + 头像 + 用户姓名/角色（程序级信息，不含页面名/通知铃） |

### 状态栏

| 参数 | 值 |
|------|-----|
| 高度 | 32px |
| 背景色 | `$bg-warm` (#FBF7F3) |
| 边框 | 顶部 1px #E9DFD7 |
| 内容 | 左：● API 状态 $success + 远程/本地模式；右：时间（程序级，不含「共N条」） |

### 中间区域（内容级容器 — 后续页面母版）

| 层级 | 元素 | 定值 |
|------|------|------|
| 外容器 `主内容区` | 背景/布局/间距 | `$bg-warm` / vertical gap 16 / padding 16 四周 |
| 工具条 `工具栏` | 高度/圆角/描边/内边距 | 56 / 12 / 1px #E9DFD7 / 0 16，gap 8 |
| 内容横排 `内容区` | 布局/间距 | horizontal gap 16，padding 0（外边距由外容器统一管） |
| 卡片 | 圆角/描边 | 12 / 1px #E9DFD7；详情面板 padding 16 gap 12 |
| 分割线 | 宽度/颜色 | 1px #E9DFD7 |

## 6. 按钮规范

### 主按钮（Primary）

```
填充：gradient($primary → $primary-dark)
圆角：24px
高度：48px
文字：白色，14px，Medium
内边距：水平 24px
```

### 次要按钮（Secondary）

```
填充：transparent
边框：1px $border-soft
圆角：16px
文字：$primary，14px，Medium
```

### 切换按钮（Toggle）

```
选中态：$primary 填充，白色文字
未选中态：transparent，$primary 文字
圆角：16px
```

### 图标按钮

```
填充：transparent
圆角：50%（圆形）
尺寸：32×32 或 40×40
图标：24×24，$text-secondary
```

## 7. 输入框规范

```
高度：50px

输入文字：15px，Normal，$text-primary
占位符：15px，Normal，$text-secondary
聚焦态：$primary 边框

## 8. 登录页面布局（基准设计）

```

  欢迎标题（24px，SemiBold，$text-primary）

```

背景：$bg-warm
边框：顶部 1px $border-soft

```

## 9. CLI Prompt 模板

设计新页面时，使用以下模板生成 prompt：

```
凌隐宝堂中医诊所[页面名称]页面。
Material Design 风格，暖色调，1440x900 桌面窗口。
系统名称显示为"凌隐宝堂中医诊所"，不要编造品牌名。

色彩系统：
- 主色 $primary: #6D4C41（按钮/选中态）
- 深主色 $primary-dark: #4E342E（渐变终点）
- 最深主色 $primary-deep: #3E2723（侧边栏）
- 强调色 $accent: #FFB300（琥珀色）
- 页面底色 $bg-warm: #FBF7F3
- 文字主色 $text-primary: #2F2A26
- 文字次色 $text-secondary: #8D8078
- 成功色 $success: #2E7D32
- 边框色 $border-soft: #C9C1B9

字体：Noto Sans SC（正文）/ Noto Serif SC（品牌）
字号：品牌名36px/标题24px/副标题14px/输入15px/标签13px/按钮14px/辅助12px

布局：
- 三栏：侧边栏(240px) + 内容区 + 状态栏(32px)
- 头栏高度 48px
- 卡片圆角 12px，按钮圆角 24px(主)/16px(次)

[具体页面内容描述]
```

## 10. 设计审查清单

每个新页面设计完成后，检查：

```
□ 色彩是否使用 Token（无硬编码颜色）
□ 字号是否符合层级规范
□ 间距是否使用 Token
□ 圆角是否符合元素类型
□ 按钮风格是否统一
□ 文字颜色对比度是否足够
□ 布局是否在 1440×900 内完整显示
□ 系统名称显示为"凌隐宝堂中医诊所"
□ 底部状态栏包含连接模式 + API 状态
□ 侧边栏菜单项与角色匹配
```
