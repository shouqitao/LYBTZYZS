# LYBT.Desktop.Workbench.Receptionist 接待员工作台项目文档

## 项目概览

**项目名称**: LYBT.Desktop.Workbench.Receptionist  
**项目类型**: WPF接待员专用工作台  
**技术框架**: .NET 8.0, WPF, Prism.DryIoc 8.1.97  
**业务领域**: 患者接待和预约管理专用界面  
**更新时间**: 2025-09-01

## 项目定位

### 核心功能
LYBT.Desktop.Workbench.Receptionist是专为接待员角色设计的患者服务工作台，提供：

1. **患者接待**: 新患者接待和老患者信息确认
2. **预约管理**: 患者预约安排和时间协调
3. **挂号服务**: 快速挂号和科室分配
4. **信息登记**: 患者基本信息录入和维护
5. **导诊服务**: 为患者提供就诊指导和科室引导

### 业务场景
- **患者接待**: 处理患者到诊接待和基本信息登记
- **预约管理**: 安排患者预约时间和医生安排
- **挂号服务**: 快速完成患者挂号和缴费
- **信息咨询**: 为患者解答诊疗流程和费用问题
- **就诊引导**: 指导患者完成各项就诊手续

### 关键操作流程
1. **新患者接待**: 身份验证 → 信息登记 → 科室选择 → 挂号缴费 → 引导就诊
2. **预约管理**: 查询时间 → 医生安排 → 预约确认 → 提醒设置 → 预约单打印
3. **老患者服务**: 身份确认 → 信息更新 → 快速挂号 → 历史查询 → 就诊引导
