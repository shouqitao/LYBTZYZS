# 凌隐宝堂中医诊所系统 - 系统模块最终版

## 更新时间：2025-01-08

## 一、最终模块架构（10个）

### 核心基础设施（3个）
1. **LYBT.Infrastructure** - 基础设施层（数据访问、日志、缓存）
2. **LYBT.Models** - 领域模型层
3. **LYBT.Shared.Models** - 共享DTO模型

### 业务模块（7个）

#### 1. 系统基础（2个）
- **Auth** - 身份认证和授权（JWT认证）
- **Users** - 用户管理（系统用户CRUD）

#### 2. 人员管理（2个）
- **Patients** - 患者档案管理
- **Doctors** - 医生信息管理

#### 3. 诊疗核心（3个）
- **Consultation** - 看诊管理（中医四诊核心）
- **MedicalCase** - 医疗案例（诊疗流程记录）
- **Prescriptions** - 处方管理

#### 4. 药材管理（2个）
- **Herbs** - 中药材管理（库存、价格）
- **Formula** - 验方管理（包含模板功能）

## 三、核心业务流程

### 极简诊疗流程
```
患者建档(Patients) → 医生看诊(Consultation) → 开具处方(Prescriptions)
```

### 流程说明
1. **患者管理**：Patients模块管理患者基本信息和档案
2. **诊疗过程**：医生通过Consultation进行四诊和诊断
3. **处方管理**：开具和管理中药处方
4. **案例记录**：MedicalCase记录完整诊疗过程
5. **药材支持**：Herbs提供药材信息，Formula提供验方参考

## 六、模块详细说明

### Auth模块
- JWT Token认证
- 角色权限管理
- 登录日志记录

### Users模块

- 密码管理

### Patients模块

### Doctors模块

- 排班管理

### Consultation模块

### MedicalCase模块

- 多次就诊关联

### Prescriptions模块
- 处方创建和管理
- 药材配伍
- 用法用量
- 处方历史

### Herbs模块
- 药材信息维护
- 库存管理
- 价格管理
- 药材分类

### Formula模块
- 经典方剂管理
- 验方模板
- 常用配方
- 模板转处方

## 七、开发优势

1. **极简架构**
   - 仅10个模块，易于理解和维护
   - 清晰的职责划分
   - 最小化的模块依赖

2. **专注核心**
   - 聚焦中医诊疗核心功能
   - 去除非必要的辅助功能
   - 保留扩展能力

3. **快速开发**
   - 减少50%以上的代码量
   - 降低系统复杂度
   - 加快开发和测试速度

4. **易于扩展**
   - 模块化设计便于添加新功能
   - 标准化接口便于集成
   - 预留扩展点

## 八、部署建议

### 最小部署
- 必需模块：Auth, Users, Patients, Doctors, Consultation
- 数据库：SQL Server Express即可
- 服务器：单台服务器即可

### 标准部署
- 全部10个模块
- SQL Server Standard
- Web服务器 + 数据库服务器
