# 诊疗台UI需求完整规格

## 记录时间：2025-09-29
## 记录人：项目经理需求调研

## 一、整体架构设计

### 1.1 响应式布局策略
- **小屏(≤1080p)**: Tab切换模式 (诊断Tab + 处方Tab)
- **大屏(≥2.5K)**: 双界面并排模式 (诊断模块 | 处方模块)
- **中间尺寸**: 需要实际调试决定，通过视觉效果确定临界点

### 1.2 两大核心模块
1. **诊断模块** - 基于现有设计框架
2. **处方模块** - 新的4×6可编辑网格设计

## 二、诊断模块设计（已确定）

### 2.1 布局结构
```
┌─────────────┬─────────────┐
│   望诊      │    闻诊     │  第1-2行（2×2）
├─────────────┼─────────────┤
│   问诊      │    切诊     │
├─────────────┼─────────────┤
│   主诉      │   现病史    │  第3行
├─────────────┴─────────────┤
│         诊断（大输入框）      │  第4行
├───────────────────────────┤
│       备注/医嘱            │  第5行
└───────────────────────────┘
```

### 2.2 字段特性
- 四诊(望闻问切)：可选填，2×2网格布局
- 主诉+现病史：可选填，1×2布局
- 诊断结果：大输入框
- 备注/医嘱：底部区域
- 所有字段均为非必填

### 3.2 网格规格
- **基础规格**: 4列×6行 = 24个药位
- **扩展机制**: 超过24个药物后自动添加行
- **显示格式**: 药名+剂量（如：当归 12g）
- **打印兼容**: 与打印处方格式一致

### 3.3 编辑交互设计

#### 编辑方式（双重支持）
1. **双击编辑**: 双击格子直接进入编辑模式
2. **光标选中**: 光标选中单元格 + 回车进入编辑模式

#### 编辑流程
1. 编辑药名 → 回车确定 → 自动跳转到剂量字段
2. 编辑剂量 → 回车确定 → 自动跳转到下一个药材字段
3. 循环顺序：药材→剂量→药材→剂量...

#### 导航方式（兼容设计）
- **顺序导航**: Tab/回车按从左到右、从上到下顺序移动
- **方向键导航**: 上下左右箭头键在网格中自由移动焦点
- **混合模式**: 两种导航方式同时支持，提供最大灵活性

## 四、技术约束与要求

### 4.1 响应式适配
- 支持1080p到4K的主流分辨率
- 基于窗口宽度断点触发布局变化
- DPI自动缩放字体和控件大小

### 4.2 现有架构集成
- 基于Prism.DryIoc模块化架构
- 遵循MVVM设计模式
- 集成现有的15%完成度的Consultation模块框架

### 4.3 用户体验优先级
1. **功能可用性** - 确保所有屏幕尺寸下功能正常
2. **操作效率** - 快速录入，减少鼠标依赖
3. **视觉协调** - 美观且专业的医疗界面
