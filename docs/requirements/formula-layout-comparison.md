## 方案A：8列DataGrid布局（完全参考处方）

### 视觉布局

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 验方详情                                                          [返回]      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ ┌────────────── 基本信息 ──────────────┐                                    │
│ │ 验方名称：[桂枝汤            ]  拼音码：[gjt    ]                          │
│ │ 性味归经：[辛甘温，归心、肺、膀胱经                    ]                   │
│ │ 功效*：[解肌发表，调和营卫                              ]                   │
│ │ 用法：[水煎服，日一剂                                    ]                   │
│ └──────────────────────────────────────┘                                    │
│                                                                              │
│ ┌────────────── 药材组成 ──────────────┐                                    │
│ │ [添加药材] [导入验方] [清空验方]                                           │
│ │                                                                            │
│ │ ┌─────────────────────────────────────────────────────────────────┐      │
│ │ │ 药材1  │用量1│ 药材2  │用量2│ 药材3  │用量3│ 药材4  │用量4│      │      │
│ │ ├────────┼────┼────────┼────┼────────┼────┼────────┼────┤      │      │
│ │ │[桂枝▼] │ 9  │[白芍▼] │ 9  │[生姜▼] │ 9  │[大枣▼] │ 3  │      │      │
│ │ │[甘草▼] │ 6  │        │    │        │    │        │    │      │      │
│ │ │        │    │        │    │        │    │        │    │      │      │
│ │ └────────┴────┴────────┴────┴────────┴────┴────────┴────┘      │      │
│ │                                                                            │
│ │ 说明：                                                                     │
│ │ • 在"药材1"下拉框输入拼音码（如"gz"）快速定位"桂枝"                       │
│ │ • 输入用量后按Enter或Tab键，焦点自动跳到"药材2"                          │
│ │ • 一行可录入4味药材，适合快速连续录入                                     │

│                                                                              │

### 详细说明

#### 1. **布局结构**
- **药材编辑区域**：一个8列DataGrid
  - 列1: 药材1（ComboBox，可输入拼音码）
  - 列2: 用量1（TextBox，数字输入）
  - 列3: 药材2（ComboBox）
  - 列4: 用量2（TextBox）
  - 列5: 药材3（ComboBox）
  - 列6: 用量3（TextBox）
  - 列7: 药材4（ComboBox）
  - 列8: 用量4（TextBox）

#### 2. **录入流程**（横向录入）
```
步骤1: 点击"药材1"下拉框
    ↓
步骤2: 输入拼音码"gz"，下拉框过滤显示"桂枝"、"甘草"等
    ↓
步骤3: 选择"桂枝"
    ↓
步骤4: 在"用量1"输入"9"，按Enter
    ↓
步骤5: 焦点自动跳转到"药材2"（继续录入下一味药）
    ↓
步骤6: 重复步骤2-5，一行录入4味药材
    ↓
步骤7: 按Enter或点击下一行，继续录入更多药材
```

#### 3. **实际示例**

假设录入"桂枝汤"（5味药材）：

**第1行**：
```
| 桂枝 | 9 | 白芍 | 9 | 生姜 | 9 | 大枣 | 3 |
```

**第2行**：
```
| 甘草 | 6 |      |   |      |   |      |   |
```

#### 4. **优点分析**

✅ **快速连续录入**
- 一行录入4味药材，减少鼠标点击
- 焦点自动跳转，提高录入速度
- 适合熟悉验方的用户快速录入

✅ **拼音码快速定位**
- 输入"gz"即可过滤出"桂枝"、"甘草"
- 减少滚动查找时间

✅ **与处方一致**
- 用户在处方模块已熟悉此操作方式
- 学习成本低

✅ **代码实现简单**
- 直接参考处方模块代码
- 复用HerbFilterManager
- 复用焦点跳转逻辑

#### 5. **缺点分析**

❌ **屏幕宽度要求高**
- 8列布局需要至少1280px宽度
- 小屏幕用户需要横向滚动

❌ **缺少详细字段**
- 无法显示"炮制方法"、"用法"、"单位"等字段
- 只有药材名称和用量

❌ **编辑已有药材不便**
- 如果要修改第5味药材的"炮制方法"
- 需要先在8列布局中找到该药材
- 然后可能需要额外对话框编辑详细信息

#### 6. **适用场景**

✅ **适合**：
- 快速新建验方（连续录入多味药材）
- 熟悉验方组成的用户
- 桌面端大屏幕用户

❌ **不适合**：
- 需要详细编辑炮制方法、用法等字段
- 小屏幕用户（<1280px）

### 视觉布局

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 验方详情                                                          [返回]      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ ┌────────────── 基本信息 ──────────────┐                                    │
│ │ 验方名称：[桂枝汤            ]  拼音码：[gjt    ]                          │
│ │ 性味归经：[辛甘温，归心、肺、膀胱经                    ]                   │
│ │ 功效*：[解肌发表，调和营卫                              ]                   │
│ │ 用法：[水煎服，日一剂                                    ]                   │
│ └──────────────────────────────────────┘                                    │
│                                                                              │
│ ┌────────────── 快速录入区 ──────────────┐                                  │

│ │ │ 药材1  │用量1│ 药材2  │用量2│ 药材3  │用量3│ 药材4  │用量4│      │      │

### 详细说明

#### 1. **布局结构**

分为两个独立区域：

**区域1：快速录入区（上方）**
- 8列DataGrid（药材1-4 + 用量1-4）
- 用于快速连续录入多味药材
- 录入完成后点击"添加到列表"按钮

**区域2：详细列表区（下方）**
- 传统7列DataGrid
  - 序号、药材名称、用量、单位、炮制方法、用法、操作
- 显示所有已添加的药材及完整信息
- 可点击"编辑"按钮修改单个药材的详细信息

#### 2. **录入流程**

**流程1：快速录入多味药材**
```
步骤1: 在快速录入区，输入"桂枝 9 白芍 9 生姜 9 大枣 3"
    ↓
步骤2: 点击"添加到列表"按钮
    ↓
步骤3: 4味药材自动添加到下方详细列表
    ↓
步骤4: 快速录入区自动清空，可继续录入下一批
```

**流程2：添加单个药材（带详细信息）**
```
步骤1: 点击详细列表区的"添加单个药材"按钮
    ↓
步骤2: 弹出"药材详细编辑对话框"
    ↓
步骤3: 填写完整信息（药材名称、用量、单位、炮制方法、用法）
    ↓
步骤4: 确定后添加到详细列表
```

**流程3：编辑已有药材**
```
步骤1: 在详细列表中点击某行的"编辑"按钮
    ↓
步骤2: 弹出"药材详细编辑对话框"（预填充现有数据）
    ↓
步骤3: 修改炮制方法、用法等详细字段
    ↓
步骤4: 确定后更新详细列表
```

#### 3. **实际示例**

假设录入"桂枝汤"（5味药材）：

**场景1：使用快速录入**
1. 快速录入区输入：`桂枝 9 | 白芍 9 | 生姜 9 | 大枣 3`
2. 点击"添加到列表"
3. 快速录入区输入：`甘草 6`
4. 点击"添加到列表"

**场景2：补充详细信息**
1. 在详细列表中找到"甘草"那一行
2. 点击"编辑"按钮
3. 在对话框中填写"炮制方法：炙"
4. 确定保存

#### 4. **优点分析**

✅ **快速录入 + 详细编辑兼顾**
- 快速录入区：适合连续录入多味药材
- 详细列表区：适合编辑完整信息

✅ **信息完整**
- 详细列表显示所有字段（炮制方法、用法等）
- 无需额外对话框即可查看完整信息

✅ **灵活性高**
- 用户可选择使用快速录入或单个添加
- 根据不同场景选择不同录入方式

✅ **操作明确**
- 快速录入区和详细列表区职责清晰
- "添加到列表"按钮明确表达数据流向

#### 5. **缺点分析**

❌ **界面复杂**
- 两个编辑区域，用户需理解区别
- 学习成本高于方案A

❌ **数据同步逻辑复杂**
- 快速录入区 → 详细列表区的数据流
- 需要处理数据转换和验证

❌ **屏幕空间占用大**
- 快速录入区 + 详细列表区，垂直空间需求大
- 可能需要滚动查看

❌ **代码实现复杂**
- 需要两套数据绑定逻辑
- 需要处理快速录入区与详细列表的同步

#### 6. **适用场景**

✅ **适合**：
- 需要详细编辑炮制方法、用法等字段
- 新建验方 + 编辑详细信息的混合场景
- 对界面复杂度不敏感的用户

❌ **不适合**：
- 纯快速录入场景（方案A更简洁）
- 追求简洁界面的用户

## 技术实现难度对比

### 方案A（8列DataGrid）

**需要实现的组件**：
1. ✅ FormulaHerbFilterManager（拼音码过滤）
2. ✅ 8列DataGrid XAML布局
3. ✅ 焦点跳转逻辑（PreviewKeyDown事件）
4. ⚠️ 药材详细编辑对话框（新增，用于编辑炮制方法、用法）

**代码复用度**：
- ✅ 高：PrescriptionView的8列布局可直接参考
- ✅ 高：HerbFilterManager逻辑可直接复用
- ✅ 高：焦点跳转逻辑可直接复用

**预估工作量**：
- 前端XAML：4小时
- ViewModel逻辑：4小时
- 药材详细编辑对话框：6小时
- **总计：约14小时**

**需要实现的组件**：

**预估工作量**：
- 前端XAML（两个区域）：8小时
- ViewModel逻辑（数据同步）：8小时
- 药材详细编辑对话框：6小时
- **总计：约22小时**
