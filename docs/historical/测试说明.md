# LYBTZYZS Postman API 测试说明文档

## 概述

本文档提供LYBTZYZS中医诊所管理系统WebAPI的Postman测试集合使用说明。该测试集合基于`WebAPI-Documentation.md`自动生成，包含了系统中所有17个主要业务模块的完整API测试用例。

## 文件说明

- **Collection文件**: `LYBTZYZS-API-Collection.json`
- **格式版本**: Postman Collection v2.1.0
- **测试覆盖**: 17个业务模块，共100+个API接口
- **服务器地址**: http://192.168.190.243:5000

## 快速开始

### 1. 导入Collection

1. 打开Postman应用程序
2. 点击左上角的"Import"按钮
3. 选择"File"选项卡
4. 选择`LYBTZYZS-API-Collection.json`文件
5. 点击"Import"完成导入

### 2. 配置环境变量

Collection中已预设环境变量，导入后会自动配置：

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `baseUrl` | http://192.168.190.243:5000 | API服务器基础URL |
| `token` | (空) | JWT认证令牌，登录后自动获取 |
| `newUserId` | (空) | 新创建用户的ID，用于后续测试 |
| `newPatientId` | (空) | 新创建患者的ID，用于后续测试 |
| `newDoctorId` | (空) | 新创建医生的ID，用于后续测试 |
| `newHerbId` | (空) | 新创建药材的ID，用于后续测试 |
| `newPrescriptionId` | (空) | 新创建处方的ID，用于后续测试 |

### 3. 执行登录流程

**重要**: 在测试其他接口之前，必须先执行登录获取认证令牌。

1. 展开"1. 认证模块 (Auth)"文件夹
2. 运行"用户登录"接口
3. 系统会自动将返回的token保存到环境变量中
4. 后续所有接口将自动使用此token进行认证

**默认测试账号**:
- 用户名: `admin`
- 密码: `admin123`

## 模块说明

### 核心业务模块

#### 1. 认证模块 (Auth)
- **用户登录**: 获取JWT访问令牌
- **用户登出**: 注销当前会话
- **修改管理员密码**: 更新系统管理员密码

#### 2. 用户管理模块 (Users)
- **分页查询用户**: 支持关键词、角色、状态筛选
- **新增用户**: 创建新用户账号
- **更新用户信息**: 修改用户基本信息
- **获取用户详情**: 查看用户详细信息
- **密码管理**: 修改密码、重置密码
- **状态管理**: 启用/禁用用户账号

#### 3. 患者管理模块 (Patients)
- **患者档案管理**: 新增、更新、查询患者信息
- **分页搜索**: 支持多条件筛选
- **快速创建**: 适用于快速看诊场景
- **病历历史**: 查看患者历史就诊记录
- **批量操作**: 批量启用/禁用患者档案

#### 4. 医生管理模块 (Doctors)
- **医生档案管理**: 完整的医生信息管理
- **资质管理**: 职称、科室、专长等信息
- **用户关联**: 检查用户与医生档案的关联关系
- **在职状态**: 管理医生的工作状态

#### 5. 药材管理模块 (Herbs)
- **库存管理**: 药材入库、出库、盘点
- **状态监控**: 缺货、即将过期药材提醒
- **分类管理**: 按类别组织药材
- **统计分析**: 库存统计和报表

#### 6. 处方管理模块 (Prescriptions)
- **开具处方**: 创建中药处方
- **处方审核**: 处方的审核和确认流程
- **作废管理**: 处方作废和退回
- **历史查询**: 处方历史记录查询

### 业务流程模块

#### 11. 药房管理模块 (Pharmacy)

#### 14. 治疗室管理模块 (TreatmentRoom)

## 认证和授权

### JWT Token认证

系统使用JWT Bearer Token进行身份验证：

1. **获取Token**: 通过登录接口获取
2. **自动设置**: 登录成功后token自动保存到环境变量
3. **自动携带**: 所有需要认证的接口自动携带token
4. **Token刷新**: Token过期需要重新登录

### 权限级别

| 角色 | 权限描述 | 测试覆盖 |
|------|----------|----------|
| Admin | 系统管理员，完全访问权限 | ✅ 全部接口 |
| DiagnosingDoctor | 主治医生，诊疗相关功能 | ✅ 患者、诊疗、处方相关 |
| PharmacyStaff | 药剂师，药房管理功能 | ✅ 药材、药房相关 |
| CashierStaff | 收费员，费用结算功能 | ✅ 费用、结算相关 |
| Staff | 挂号员，挂号排队功能 | ✅ 挂号、排队相关 |

## 常见问题处理

### 1. 认证失败

**症状**: 接口返回401 Unauthorized
**解决方案**: 
- 检查是否已执行登录接口
- 确认token是否已保存到环境变量
- 检查token是否已过期

### 2. 数据关联错误

**症状**: 接口返回404 Not Found或关联数据错误
**解决方案**:
- 按推荐顺序执行测试，确保依赖数据存在
- 检查环境变量中的ID是否正确
- 手动更新环境变量中的测试数据ID

### 3. 服务器连接失败

**症状**: 无法连接到服务器
**解决方案**:
- 检查baseUrl环境变量是否正确
- 确认API服务器是否正常运行
- 检查网络连接和防火墙设置

### 4. 测试数据冲突

**症状**: 重复数据错误或约束冲突
**解决方案**:
- 修改测试数据中的唯一字段（如用户名、手机号）
- 清理测试数据库或使用全新的测试环境
- 为测试数据添加时间戳或随机后缀
