## 🏗️ 架构设计特色

### 混合架构模式 - 前后端不同策略
项目采用了独特的混合架构设计，前后端使用最适合的架构模式：

#### 后端：传统三层架构（稳定可靠）
```
Controller (RESTful API控制器)
    ├── Service (业务服务层)
    └── Repository (数据访问层)
```

#### 前端：UltraThink双层架构（现代高效）
```
主Module (纯委托层，统一服务入口)
    ├── QueryService (复杂查询专业层)
    └── BusinessService (业务逻辑+CRUD层)
```

### 架构优势分析
1. **技术适配**: 前后端各用最适合的架构模式
2. **风险分散**: 前端创新，后端稳定
3. **团队协作**: 前后端可独立优化架构
4. **渐进升级**: 可逐步演进，不影响整体稳定性
