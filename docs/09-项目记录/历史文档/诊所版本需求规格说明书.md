# 凌隐宝堂中医诊所系统 - 诊所版本需求规格说明书

## 一、版本定位

### 1.1 版本说明
- **版本名称**：诊所版（Clinic Edition）
- **版本号**：V1.0
- **目标用户**：中小型传统中医诊所
- **核心价值**：纯中医诊疗流程，快速看诊，高效开方
- **实现状态**：✅ **已完成核心功能** (2025-08-07)

### 1.2 版本特点
- ✅ **纯中医化**：完全移除西医检查内容，专注中医四诊辨证论治
- ✅ **流程简化**：患者直接看诊，医生一站式完成四诊、辨证、开方、打印
- ✅ **验方集成**：内置验方模板库，支持一键应用和手动调整
- ✅ **操作便捷**：搜索过滤、数量调整、实时预览等人性化功能
- ✅ **即装即用**：WPF桌面应用，无需复杂部署配置

## 二、核心业务流程

### 2.1 简化诊疗流程 ✅ **已实现**
```
患者选择/新建 → 中医四诊记录 → 辨证论治 → 验方应用/手动组方 → 处方打印 → 完成
```

### 2.2 流程说明
1. **患者管理**：快速搜索现有患者或新建患者档案
2. **中医四诊**：望诊、闻诊、问诊、切诊 + 舌诊、脉诊专项记录
3. **辨证论治**：记录中医诊断、治疗原则、医嘱建议
4. **处方开具**：
   - 验方一键应用：从验方库选择经典方剂快速应用
   - 手动组方：搜索药材、调整剂量、个性化组方
5. **处方打印**：标准化处方单，包含诊所信息、患者信息、药材清单
