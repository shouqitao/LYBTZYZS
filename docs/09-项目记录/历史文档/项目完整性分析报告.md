## 一、项目概况

凌隐宝堂中医诊所诊疗系统是一个基于 .NET 8 的企业级中医诊所管理系统，采用 Web API 后端 + WPF 桌面前端架构。

### 技术栈
- **后端**：.NET 8, ASP.NET Core Web API, Entity Framework Core 8
- **前端**：WPF (.NET 8), Prism.DryIoc, Refit
- **数据库**：SQL Server
- **认证**：JWT Bearer Token
- **API文档**：Swagger/Swashbuckle
