1. **UsersController**

2. **PatientsController**
   - 移除: Search, BatchImport, BatchDelete, Archive
   - 新增: toggle-status 统一接口

3. **HerbsController**
   - 移除: GetPaged, GetActive, Add
   - 增强: 价格和库存筛选功能

4. **PrescriptionsController**
   - 修复: PUT 路由缺少 ID 参数
   - 移除: 重复的分页接口
