## 1. 项目概述

### 1.1 项目定位

凌隐宝堂中医诊所诊疗系统（LYBTZYZS）是一个专为中医诊所设计的全流程数字化管理平台，覆盖从患者挂号、医生诊疗、处方开具、药房管理到收费结算的完整业务链条。

### 1.2 核心价值

- **业务全覆盖**：涵盖中医诊所所有核心业务流程
- **中医特色**：专门针对中医诊疗特点设计（四诊、中药处方、验方等）
- **高度模块化**：15个独立业务模块，易于扩展和维护
- **现代化架构**：基于.NET 8最新技术栈，性能优越

### 1.3 系统特点

- 前后端分离架构
- RESTful API设计
- JWT Token认证
- 实时数据同步
- 离线工作支持
- 多级缓存策略

#### 4.4.2 服务封装

```csharp
public class PatientService : IPatientService
{
    private readonly IPatientApiService _apiService;
    private readonly IMapper _mapper;

    public async Task<ServiceResult<PatientInfo>> GetByIdAsync(Guid id)
    {
        try
        {
            var response = await _apiService.GetPatientByIdAsync(id);
            if (response.IsSuccessStatusCode)
            {
                var patientInfo = _mapper.Map<PatientInfo>(response.Content);
                return ServiceResult<PatientInfo>.Success(patientInfo);
            }
            return ServiceResult<PatientInfo>.Failure(response.Error.Message);
        }
        catch (Exception ex)
        {
            return ServiceResult<PatientInfo>.Failure(ex.Message);
        }
    }
}
```

## 6. API接口规范

### 6.1 RESTful设计原则

#### 6.1.1 URL设计规范

```
GET    /api/v1/patients          # 获取患者列表
GET    /api/v1/patients/{id}     # 获取单个患者
POST   /api/v1/patients          # 创建患者
PUT    /api/v1/patients/{id}     # 更新患者
DELETE /api/v1/patients/{id}     # 删除患者
PATCH  /api/v1/patients/{id}     # 部分更新

# 嵌套资源
GET    /api/v1/patients/{id}/prescriptions     # 获取患者的处方列表
POST   /api/v1/patients/{id}/prescriptions     # 为患者创建处方
```

#### 6.1.2 HTTP状态码使用

| 状态码 | 含义                    | 使用场景        |
| --- | --------------------- | ----------- |
| 200 | OK                    | GET成功、PUT成功 |
| 201 | Created               | POST成功创建资源  |
| 204 | No Content            | DELETE成功    |
| 400 | Bad Request           | 请求参数错误      |
| 401 | Unauthorized          | 未认证         |
| 403 | Forbidden             | 无权限         |
| 404 | Not Found             | 资源不存在       |
| 409 | Conflict              | 资源冲突        |
| 500 | Internal Server Error | 服务器错误       |

## 8. 开发规范

### 8.1 编码规范

#### 8.1.1 命名规范

- **类名**: PascalCase（如 PatientService）
- **接口**: I前缀 + PascalCase（如 IPatientService）
- **方法名**: PascalCase（如 GetPatientById）
- **变量名**: camelCase（如 patientName）
- **常量**: 全大写下划线分隔（如 MAX_RETRY_COUNT）
- **私有字段**: _前缀 + camelCase（如 _patientRepository）

#### 8.1.2 异步方法规范

```csharp
// 异步方法必须以Async结尾
public async Task<Patient> GetPatientByIdAsync(Guid id)
{
    return await _repository.GetByIdAsync(id);
}

// 避免异步方法同步阻塞
// 错误示例
var result = GetPatientByIdAsync(id).Result; // 避免

// 正确示例
var result = await GetPatientByIdAsync(id);
```

#### 8.4.2 缓存策略

```csharp
public async Task<Patient> GetPatientWithCacheAsync(Guid id)
{
    var cacheKey = $"patient_{id}";

    // 尝试从缓存获取
    var cached = await _cache.GetAsync<Patient>(cacheKey);
    if (cached != null) return cached;

    // 从数据库获取
    var patient = await _repository.GetByIdAsync(id);

    // 存入缓存
    await _cache.SetAsync(cacheKey, patient, TimeSpan.FromMinutes(5));

    return patient;
}
```
