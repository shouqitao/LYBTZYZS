#### 关键算法
```csharp
// 滚动方向预测
public (int StartIndex, int Count) PredictNextRange(
    int currentIndex, int scrollDirection, int viewportSize)
{
    var preloadCount = Math.Max(1, (int)(viewportSize * _preloadMultiplier));
    
    return scrollDirection switch
    {
        1 => (currentIndex + viewportSize, preloadCount),     // 向下
        -1 => (Math.Max(0, currentIndex - preloadCount), preloadCount), // 向上
        _ => (Math.Max(0, currentIndex - preloadCount/2), preloadCount)  // 静止
    };
}
```
