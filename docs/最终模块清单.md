# 凌隐宝堂中医诊所系统 - 最终模块清单

## 更新时间：2025-01-08

## 一、最终保留模块（11个）

### 核心基础设施（3个）
1. **LYBT.Infrastructure** - 基础设施层（数据访问、日志等）
2. **LYBT.Models** - 领域模型层
3. **LYBT.Shared.Models** - 共享DTO模型

### 业务模块（8个）

#### 用户与权限（2个）
- **Auth** - 身份认证和授权
- **Users** - 用户管理

#### 人员管理（2个）
- **Patients** - 患者档案管理
- **Doctors** - 医生管理

#### 诊疗核心（2个）
- **Consultation** - 看诊管理（核心诊疗模块）
- **MedicalCase** - 医疗案例（统一诊疗流程管理）

#### 处方与药材（4个）
- **Prescriptions** - 处方管理
- **Herbs** - 中药材管理
- **Formula** - 验方管理（新增）
- **FormulaTemplates** - 验方模板（待整合到Formula）

## 二、已删除模块汇总（11个）

1. **Registration** - 挂号模块
2. **TreatmentRoom** - 治疗室模块
3. **TreatmentPlan** - 治疗方案模块
4. **Billing** - 收费模块
5. **DiagnosisTreatment** - 诊断治疗模块
6. **Records** - 病历档案模块
7. **Sync** - 数据同步模块
8. **Diagnostics** - 诊断模块
9. **Cashier** - 收银模块
10. **Queueing** - 排队模块
11. **Pharmacy** - 药房模块

## 三、极简业务流程

```
患者建档 → 医生看诊 → 开具处方
```

### 流程说明
1. **患者管理**：通过Patients模块管理患者信息
2. **看诊过程**：医生通过Consultation模块进行诊疗
3. **处方开具**：在诊疗过程中开具Prescriptions
4. **全程记录**：MedicalCase记录整个诊疗案例

## 五、模块职责定义

### 基础模块
- **Auth**: JWT认证、权限管理
- **Users**: 系统用户CRUD
- **Patients**: 患者档案管理
- **Doctors**: 医生信息管理

### 核心模块
- **Consultation**: 中医四诊、诊断、治疗建议
- **MedicalCase**: 完整诊疗记录管理
- **Prescriptions**: 处方创建、管理、历史记录

### 支撑模块
- **Herbs**: 药材库存、价格管理
- **Formula/FormulaTemplates**: 经典方剂、常用验方

## 六、技术特点

1. **极简架构**：仅保留核心业务功能
2. **清晰职责**：每个模块单一职责
3. **松耦合**：模块间依赖最小化
4. **易维护**：代码量大幅减少，复杂度降低

## 七、开发建议

## 八、总结

系统从最初的21个模块精简至11个核心模块，实现了：
- **架构精简**：减少48%的模块数量
- **流程简化**：核心流程仅3步
- **维护简单**：代码复杂度大幅降低
- **扩展灵活**：保留了必要的扩展能力

当前架构适合MVP快速开发和迭代。
