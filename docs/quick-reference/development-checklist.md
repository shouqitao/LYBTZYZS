### ✅ 架构合规检查
- [ ] **三层架构遵循**

- [ ] **依赖方向检查**
  - [ ] Controller → Service → Repository 依赖链正确

- [ ] **模块边界检查**

## 🎯 常见问题快速检查

### ❌ 编译问题快速诊断
```bash
# 1. 清理重建
dotnet clean LYBT.All.sln
dotnet restore LYBT.All.sln
dotnet build LYBT.All.sln -c Release

# 2. 检查依赖
dotnet list LYBT.All.sln package --outdated

# 3. 查看详细错误
dotnet build LYBT.All.sln -c Release --verbosity detailed
```

### ❌ 测试失败快速诊断
```bash
# 1. 运行特定测试
dotnet test --filter "TestCategory!=Integration"

# 2. 查看测试输出
dotnet test --logger "console;verbosity=detailed"

# 3. 调试模式运行
dotnet test --logger "console;verbosity=normal" --blame
```

### ❌ 数据库问题快速诊断
```bash
# 1. 检查迁移状态
dotnet ef migrations list

# 2. 应用待处理迁移
dotnet ef database update

# 3. 生成新迁移
dotnet ef migrations add MigrationName
```

## 📝 检查清单使用指南

### 🎯 使用原则
1. **逐项检查**：不要跳过任何检查项
2. **及时记录**：发现问题及时记录并跟踪
3. **持续改进**：根据实际情况调整检查项
4. **团队协作**：团队统一检查标准

### 📊 检查结果记录
```
✅ 通过 - 检查项完全满足要求
⚠️ 警告 - 存在小问题，但不影响功能
❌ 不通过 - 存在严重问题，必须修复
🔄 进行中 - 正在处理中
📝 备注 - 需要特别说明的情况
```

### 🔄 持续改进
- 定期回顾和更新检查清单
- 根据团队反馈优化检查项
- 保持检查清单的实用性和有效性
