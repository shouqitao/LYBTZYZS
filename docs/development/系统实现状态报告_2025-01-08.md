## 项目概述

凌隐宝堂中医诊所诊疗系统是基于.NET 8的纯中医诊所管理系统，采用简化架构设计，专注于中医诊疗核心流程。

### 技术架构
- **后端**: .NET 8 + ASP.NET Core Web API + Entity Framework Core 8.0.17
- **前端**: WPF (.NET 8) + Prism.DryIoc 9.0.537
- **数据库**: SQL Server
- **认证**: JWT Bearer Token
- **API文档**: Swagger/OpenAPI
