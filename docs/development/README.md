## 维护规则
1. 新增开发专题时，优先将通用规范写入本索引表；大篇幅报告如无持续价值可直接放入 `docs/reports/`。
2. 过期或被取代的实现总结请在文首注明，并按需要迁移至 `docs/reports/archive/`。
3. 跨目录引用规范类文档时，请更新 `docs/index.md` 与相关任务文档的链接。
