## 📋 代码质量门禁清单

### 1. 编译质量门禁
- [ ] **零错误要求**: 不允许任何编译错误
- [ ] **警告控制**: 警告数量 < 10个（排除XML注释）
- [ ] **静态分析**: RunCodeAnalysis=true 通过
- [ ] **Nullable检查**: 启用nullable引用类型检查

### 2. 架构质量门禁
- [ ] **模块注册**: 所有模块必须完成Prism容器注册
- [ ] **基类继承**: 所有ViewModel必须继承UnifiedViewModelBase
- [ ] **服务注入**: 禁止使用Container.Resolve，必须构造函数注入
- [ ] **依赖方向**: 严格遵循模块依赖方向，禁止循环依赖

### 3. MVP合规性门禁
- [ ] **功能对齐**: 功能必须符合MVP需求，禁止超前设计
- [ ] **复杂度控制**: 单个ViewModel不超过500行
- [ ] **接口简化**: 接口设计遵循KISS原则
- [ ] **业务聚焦**: 专注中医诊所实际需求

### 4. 性能质量门禁
- [ ] **编译时间**: Desktop解决方案编译时间 < 5秒
- [ ] **应用大小**: 发布包大小 < 100MB
- [ ] **模块大小**: 单个模块DLL < 3MB
- [ ] **启动性能**: 理论启动时间 < 10秒（基于编译时间推算）

### 5. 代码整洁度门禁
- [ ] **TODO管理**: 新增TODO必须有Issue跟踪
- [ ] **死代码清理**: 禁止提交被注释的大块代码
- [ ] **命名规范**: 遵循PascalCase/camelCase命名约定
- [ ] **异步规范**: IO操作必须使用async/await
