## 🔧 主要修复内容

### 1. 事件系统重构
**问题**: EventArgs直接类型与Prism PubSubEvent<T>不兼容  
**解决方案**: 
- 迁移所有事件从原始类型到EventArgs包装类
- 创建5个新的Prism事件类
- 更新所有事件发布和订阅代码

### 2. DTO契约完善
**问题**: 缺少处方相关DTO属性  
**解决方案**:
- 为`PrescriptionCreateDto`添加: ConsultationId, DosageForm, Quantity, Usage, TotalAmount
- 为`PrescriptionItemCreateDto`添加: Subtotal, Usage, Note
- 修复API方法调用不匹配

### 3. 模型属性补充
**问题**: 前端模型缺少必要属性  
**解决方案**:
- `PatientInfo`: 添加IsActive属性
- `ConsultationInfo`: 添加Symptoms属性
- `PrescriptionInfo`: 添加TotalAmount, Usage, DosageForm属性
- `PrescriptionItemInfo`: 添加Note属性别名

### 4. API服务方法对齐
**问题**: API服务方法名称不一致  
**解决方案**:
- `CreateAsync` → `StartConsultationAsync`
- `UpdateAsync` → `UpdateConsultationAsync`
- `CreatePrescriptionAsync` → `CreateAsync`
