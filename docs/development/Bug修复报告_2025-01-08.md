### BUG-005: 实现真正的处方打印功能
**问题**: 处方打印功能未完全实现
**解决方案**: 使用WPF FlowDocument实现专业打印
```csharp
public async Task<bool> PrintPrescriptionAsync(object medicalRecord)
{
    var printDialog = new PrintDialog();
    if (printDialog.ShowDialog() != true) return false;
    
    var flowDoc = CreatePrintDocument(medicalRecord);
    flowDoc.PageWidth = printDialog.PrintableAreaWidth;
    flowDoc.PageHeight = printDialog.PrintableAreaHeight;
    
    DocumentPaginator paginator = ((IDocumentPaginatorSource)flowDoc).DocumentPaginator;
    printDialog.PrintDocument(paginator, "处方打印");
    return true;
}
```
**功能特性**:
- 支持打印预览
- 专业的处方格式排版
- 自动页面适配

### BUG-008: 数据缓存机制实现
**问题**: 频繁的API调用影响用户体验
**解决方案**: 实现智能缓存策略
```csharp
private const int HERBS_CACHE_DURATION_MINUTES = 30;
private const int FORMULAS_CACHE_DURATION_MINUTES = 60;
private const int PATIENTS_CACHE_DURATION_MINUTES = 10;

private async Task<List<HerbDto>> LoadHerbsWithCache()
{
    if (_allHerbs != null && _herbsCacheTime.HasValue && 
        DateTime.Now.Subtract(_herbsCacheTime.Value).TotalMinutes < HERBS_CACHE_DURATION_MINUTES)
    {
        return _allHerbs;
    }
    
    _allHerbs = await _herbApiService.GetAllAsync();
    _herbsCacheTime = DateTime.Now;
    return _allHerbs;
}
```
**缓存策略**:
- 中药材数据缓存30分钟
- 验方数据缓存60分钟  
- 患者数据缓存10分钟
