## 三、简化后的业务流程

### 原流程（复杂）
```
挂号(Registration) → 排队(Queueing) → 看诊(Consultation) → 
缴费(Billing) → 药房/理疗室(Pharmacy/TreatmentRoom)
```

### 新流程（简化）
```
患者接待(Patients) → 看诊(Consultation) → 开方(Prescriptions)
         ↑                    ↓
      医疗案例(MedicalCase)贯穿全程
```

## 四、功能整合说明

1. **患者管理（Patients）**
   - 整合原Registration（挂号）的基础功能
   - 简化为患者信息管理和接待功能

2. **医疗案例（MedicalCase）**
   - 作为诊疗流程的聚合根
   - 包含原Records（病历档案）功能
   - 贯穿整个诊疗过程

3. **用户管理（Users）**
   - 通过角色管理替代独立的Doctors模块
   - 医生作为具有特定角色的用户
