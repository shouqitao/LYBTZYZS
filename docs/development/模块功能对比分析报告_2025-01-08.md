## 一、系统架构概述

### 1.1 确认的系统定位
- **系统类型**: 简化版中医诊所管理系统
- **核心业务流程**: 患者 → 看诊 → 处方 → 中药材管理
- **技术架构**: .NET 8 + WPF + SQL Server
- **删除的复杂模块**: 无挂号、排队、收费、医生管理等传统HIS功能

### 1.2 架构层次结构
```

```
