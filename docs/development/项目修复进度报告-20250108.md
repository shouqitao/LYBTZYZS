## 一、项目概述

凌隐宝堂中医诊所诊疗系统（LYBTZYZS）是一个基于.NET 8的企业级中医诊所管理系统，采用Web API后端 + WPF桌面前端架构。本次工作主要完成了系统从中西医结合模式到纯中医模式的转型，并修复了大量关键技术问题。

### 3.5 特殊问题修复

#### AutoMapper 15配置问题 ✅

- **问题**: CS1729错误 - MapperConfiguration不包含采用1个参数的构造函数
- **原因**: AutoMapper 15.0需要ILoggerFactory参数
- **解决方案**:
  
  ```csharp
  var mapperConfig = new MapperConfiguration(cfg =>
  {
    cfg.AddProfile(new MappingProfile());
  }, NullLoggerFactory.Instance);  // 添加ILoggerFactory参数
  ```
