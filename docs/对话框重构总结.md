# 对话框重构总结

## 概述

完成了凌隐宝堂中医诊所管理系统前端对话框从传统 WPF 模式到 Prism 依赖注入模式的重构工作。

## 重构成果

### 第一阶段：高频模块（已完成）

1. **批量替换 MessageBox.Show**
   - 创建了 `ICommonDialogService` 接口
   - 实现了两个版本：`CommonDialogService`（基于 MessageBox）和 `PrismDialogService`（基于 Prism）
   - 使用 Python 脚本自动替换了 372 个 MessageBox.Show 调用
   - 所有模块现在使用统一的对话框服务

2. **创建通用对话框模板**
   - `ConfirmationDialog` - 确认对话框
   - `InformationDialog` - 信息对话框
   - 实现了 IDialogAware 接口

### 第二阶段：中频模块（已完成）

1. **重构 View 对话框为 IDialogAware 模式**
   - ViewRoleDialog - 角色详情对话框
   - ViewHerbDialog - 中药材详情对话框
   - ViewDoctorDialog - 医生详情对话框
   - ViewRegistrationDialog - 挂号详情对话框
   - ViewRecordDialog - 病历详情对话框
   - ViewFormulaTemplateDialog - 验方模板详情对话框
   - ViewPrescriptionDialog - 处方详情对话框

2. **更新对话框调用方式**
   - 所有管理 ViewModel 现在使用 `IDialogService` 调用对话框
   - 通过 `DialogParameters` 传递参数
   - 支持异步回调处理

### 第三阶段：低频模块（待实施）

## 技术改进

### 1. 统一的对话框服务接口

```csharp
public interface ICommonDialogService
{
    Task<bool> ShowConfirmationAsync(string message, string title = "确认");
    Task ShowInformationAsync(string message, string title = "信息");
    Task ShowWarningAsync(string message, string title = "警告");
    Task ShowErrorAsync(string message, string title = "错误");
    Task<string?> ShowInputAsync(string message, string title = "输入", string defaultValue = "");
    Task<string?> ShowOpenFileDialogAsync(string filter = "All Files (*.*)|*.*", string title = "打开文件");
}
```

### 2. IDialogAware 实现模式

```csharp
public class ViewDialogViewModel : BindableBase, IDialogAware
{
    public string Title { get; set; }
    public event Action<IDialogResult>? RequestClose;

    public void OnDialogOpened(IDialogParameters parameters)
    {
        if (parameters.ContainsKey("id"))
        {
            var id = parameters.GetValue<Guid>("id");
            _ = LoadDataAsync(id);
        }
    }
}
```

### 3. 使用 IDialogService 调用对话框

```csharp
var parameters = new DialogParameters
{
    { "herbId", item.Id }
};

_dialogService.ShowDialog("ViewHerbDialog", parameters, result =>
{
    // 处理对话框结果
});
```

## 注意事项

1. **编码规范**：所有 Python 脚本使用 UTF-8 编码，Windows 环境需特殊处理
2. **依赖注入**：确保所有使用对话框的类都注入了 `IDialogService`
3. **对话框注册**：所有对话框必须在模块的 `RegisterDialogs` 方法中注册
4. **参数传递**：使用 `DialogParameters` 传递参数，避免直接传递复杂对象
