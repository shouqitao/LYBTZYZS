# 产品文档 (01-product)

> 版本: v2.0 | 日期: 2026-06-15 | 状态: 重建

凌隐宝堂中医诊所管理系统是一款为中医诊所量身定制的全流程数字化诊疗平台。系统以「医案」为核心聚合根，覆盖从患者登记、中医诊断、处方开具到打印输出的完整临床工作流，采用双模式架构（远程 SQL Server + 本地 LocalDB）确保诊所无论在线或离线均可持续诊疗。本目录回答「为谁做」和「为什么做」的问题，详细需求规格（10 模块 / 141 US）见 [`../02-requirements/`](../02-requirements/)。
