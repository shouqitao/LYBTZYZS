# 产品概述

## 概述

凌隐宝堂中医诊所管理系统 (LYBTZYZS) 是一套专为中医诊所设计的数字化诊疗管理软件。系统覆盖从患者登记、中医诊断、处方开具到药材管理的完整业务流程，支持远程 (服务端) 和本地 (离线) 双模式运行。

---

## 核心功能

| 模块 | 说明 |
|------|------|
| **认证 (Auth)** | 用户登录、自动登录、Token 管理、会话超时控制 |
| **用户管理 (Users)** | 系统用户的增删改查、角色分配、权限控制 |
| **患者管理 (Patients)** | 患者档案的创建、维护、搜索 (拼音码)、导入导出 |
| **药材管理 (Herbs)** | 中药材库的维护、分类、启用/禁用、价格管理 |
| **验方管理 (Formulas)** | 经验方模板的创建、药材组成编辑、共享与复用 |
| **医案管理 (MedicalCase)** | 核心模块。完整诊疗记录管理，含诊断 (Consultation) 和处方 (Prescription) |
| **数据同步 (Sync)** | 本地模式与远程服务端之间的双向数据同步 |
| **打印管理 (Printing)** | MedicalCase 聚合根能力，v1.0 处方打印、打印版本管理、打印日志 |

---

## 双模式特性

系统支持两种运行模式，手动切换:

| 维度 | 远程模式 | 本地模式 |
|------|----------|----------|
| **数据链路** | WPF → HTTP API → Controller → Service → SQL Server | WPF → DataSource → SQLite |
| **认证方式** | JWT Token (服务端验证) | LocalAuthService (本地验证) |
| **适用场景** | 诊所内网环境 | 外出诊疗、网络不可用 |
| **数据同步** | 不需要 | 通过 Sync 模块双向同步 |

---

## 目标用户

- **中医诊所** -- 日常诊疗业务的数字化管理
- **中医医生** -- 诊断开方、患者管理、验方积累
- **诊所管理员** -- 系统配置、用户管理、数据维护
