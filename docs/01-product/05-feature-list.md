# 凌隐宝堂中医诊所管理系统 — 功能清单

> **版本**: v1.0 | **更新日期**: 2026-05-05
> **产品定位**: 面向小型中医诊所（1-3 名医生）的全流程数字化诊疗管理平台

---

## 一、产品概述

凌隐宝堂中医诊所管理系统覆盖从**患者登记**到**处方打印**的完整中医诊疗流程，同时支持远程和本地两种运行模式，确保医生在任何网络条件下都能正常工作。

### 核心价值

| 痛点 | 解决方案 | 效果 |
|------|---------|------|
| 复诊翻找纸质病历每次 5-10 分钟 | 拼音码/姓名/手机号即时搜索 | **< 10 秒**调出患者全部历史 |
| 手写处方 10-15 分钟，计算易出错 | 验方一键导入 + 费用自动计算 | 开方时间降至 **1-2 分钟**，零计算错误 |
| 经验方散落个人笔记，人员离职即丢失 | 数字化验方库，团队共享复用 | 经验方 **100% 可传承** |
| 外出诊疗或网络故障无法工作 | 本地模式完整运行，事后同步 | 核心流程 **100% 可用** |

### 整体效率提升

| 环节 | 纸质流程 | 系统目标 | 提升幅度 |
|------|---------|---------|---------|
| 患者信息调阅 | 5-10 分钟 | < 10 秒 | 30-60 倍 |
| 诊断记录 | 3-5 分钟（手写） | 2-3 分钟（电子化） | 1.5-2 倍 |
| 处方开具（复诊） | 10-15 分钟（手写） | < 3 分钟（复制+调整） | 3-5 倍 |
| 费用计算 | 2-3 分钟（手算） | 即时自动 | 消除人工计算 |
| 处方打印 | 3-5 分钟（手写） | < 30 秒 | 6-10 倍 |
| **完整复诊流程** | **25-40 分钟** | **< 10 分钟** | **2.5-4 倍** |

## 二、核心业务场景

### 场景一：首诊全流程

**角色**: 前台接待（登记/挂号）→ 医生（诊疗）

**流程**: 患者登记 → 挂号分诊 → 中医诊断 → 开具处方 → 保存打印

#### 当前痛点

- 新患者手写登记表，字迹辨认困难，身份证号 18 位手动输入出错率约 5%
- 望闻问切、辨证论治全靠手写，耗时 3-5 分钟
- 手写处方需反复查阅药材价格，计算费用易出错（约 5% 错误率）
- 药房因字迹辨认不清，日均 3-5 次电话确认

#### 功能清单

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **患者登记** | 创建患者档案（姓名、性别、年龄、手机号等） | 必须 |
| **患者搜索** | 按姓名、拼音码、手机号快速检索 | 必须 |
| **身份证读卡** | 华大 HD100 读卡器自动填充患者信息 | 推荐 |
| **患者信息管理** | 查看、编辑患者详细信息 | 必须 |
| **挂号分诊** | 前台创建挂号，医生从队列中接诊 | 必须 |
| **挂号队列** | 实时查看候诊队列，支持取消挂号 | 必须 |
| **创建医案** | 为患者创建新的诊疗记录 | 必须 |
| **中医诊断** | 记录现病史、望诊、闻诊、问诊、切诊、辨证论治 | 必须 |
| **标记处方需求** | 诊断后标记是否需要开具处方 | 必须 |
| **开具处方** | 搜索药材、设置剂量和帖数，费用自动计算 | 必须 |
| **导入验方** | 从验方库一键导入药材到处方 | 推荐 |
| **聚合保存** | 医案 + 诊断 + 处方一次性保存，不会出现数据不一致 | 必须 |
| **处方打印** | A5 处方打印，打印预览、版本管理 | 推荐 |
| **完成医案** | 锁定诊疗记录，保留完整历史 | 必须 |

#### 量化价值

- 患者登记：手写 1-2 分钟 → **刷卡 < 30 秒**
- 处方费用：手算约 5% 错误率 → **100% 自动计算，零错误**
- 打印发票：手写 3-5 分钟 → **打印 < 30 秒**
- 完整首诊流程：纸质 30-45 分钟 → **系统 < 15 分钟**

---

### 场景二：复诊高效流程

**角色**: 医生

**流程**: 搜索患者 → 历史回顾 → 本次诊断 → 处方延续 → 保存打印

#### 当前痛点

- 复诊翻找纸质病历每次 5-10 分钟，日均 6-12 次（复诊占比约 40%）
- 复诊需重新手写整张处方，无法复用上次处方
- 患者积累 5000-10000 份病历后，检索越来越慢

#### 功能清单

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **拼音码快速检索** | 输入拼音首字母即时匹配患者 | 必须 |
| **历史医案列表** | 查看患者全部历史诊疗记录 | 必须 |
| **跨医案搜索** | 按诊断、处方内容搜索历史记录 | 推荐 |
| **复制历史处方** | 选择历史处方一键复制到当前医案 | 推荐 |
| **处方微调** | 在复制的基础上增减药材、调整剂量 | 必须 |
| **挂起医案** | 临时挂起当前医案，稍后继续处理 | 必须 |
| **医案权限控制** | 医生只看自己的医案，管理员可看全部 | 必须 |

#### 量化价值

- 患者信息调阅：翻找 5-10 分钟 → **搜索 < 10 秒**（提升 30-60 倍）
- 处方开具：手写 10-15 分钟 → **复制 + 微调 < 3 分钟**（提升 3-5 倍）
- 日均 6-12 次复诊，每次节省 10+ 分钟 → **每日节省 1-2 小时**

### 场景三：药材与验方管理

**角色**: 管理员（药材维护）→ 医生（验方积累）

**流程**: 药材录入 → 验方创建 → 验方验证 → 临床使用

#### 当前痛点

- 药材库初始化（300-500 种）手工录入需数天
- 药材价格变动需逐条通知医生，处方用药价格不准确
- 经验方仅在个人记忆或笔记中，人员离职即丢失
- 团队间无法共享经验方，新人学习成本高

#### 功能清单

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **药材录入** | 创建药材信息（名称、拼音码、分类、单位、价格） | 必须 |
| **药材列表** | 分页浏览、按分类筛选 | 必须 |
| **药材详情** | 查看药材完整信息和状态 | 必须 |
| **药材编辑** | 更新价格、分类等信息 | 必须 |
| **药材删除** | 软删除，保留历史引用完整性 | 必须 |
| **启用/禁用** | 禁用的药材不出现在处方搜索中，历史处方标注"已禁用" | 推荐 |
| **Excel 批量导入** | 通过 Excel 文件批量导入药材，大幅缩短初始化时间 | 推荐 |
| **导出数据** | 导出药材数据用于备份或迁移 | 推荐 |
| **验方创建** | 创建经验方（名称、描述、药材组成、剂量） | 必须 |
| **验方列表** | 查看个人和共享验方 | 必须 |
| **验方详情** | 查看验方完整组成和适应证 | 必须 |
| **验方编辑** | 修改验方药材组成和剂量 | 必须 |
| **验方删除** | 软删除，保留引用完整性 | 必须 |
| **验方启用/禁用** | 控制验方是否可用于临床 | 必须 |
| **验方共享** | 将个人经验方共享给团队成员 | 推荐 |
| **验方导入到处方** | 在开具处方时一键导入验方药材列表 | 推荐 |
| **验方批量导入** | 通过 Excel 批量导入验方 | 可选 |

#### 量化价值

- 药材库初始化：逐条录入数天 → **Excel 导入 < 1 小时**
- 药材价格更新：逐条通知 → **系统即时生效**
- 经验方传承：0% 可复用 → **100% 数字化管理**
- 开方效率提升：凭记忆选药 → **验方一键导入，开方时间从 5-10 分钟降至 1-2 分钟**

### 场景四：系统管理与运维

**角色**: 管理员

**流程**: 用户管理 → 数据同步 → 系统配置 → 健康监控

#### 功能清单

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **用户管理** | 创建、编辑、删除用户账号，分配角色 | 必须 |
| **角色权限控制** | 四级权限体系（超级管理员 / 管理员 / 医生 / 前台） | 必须 |
| **密码管理** | 密码策略、管理员重置、个人修改密码 | 推荐 |
| **账户状态管理** | 启用/禁用用户账号 | 推荐 |
| **数据同步** | 本地与远程数据双向同步（药材、患者、验方） | 推荐 |
| **同步差异检测** | SHA256 哈希比对，仅同步变更部分，节省带宽 | 推荐 |
| **离线模式切换** | 远程/本地模式无缝切换 | 必须 |
| **系统健康检查** | 数据库、磁盘、内存状态实时监控 | 可选 |
| **运行时诊断** | 系统参数、数据库信息查看（超级管理员专用） | 可选 |
| **结构化日志** | 操作审计、敏感数据自动脱敏 | 推荐 |
| **全局异常处理** | 统一错误提示，错误码体系，不暴露内部细节 | 推荐 |
| **系统配置** | 分页参数、会话超时、缓存策略等运行时配置 | 必须 |

#### 量化价值

- 用户管理：集中化管理，一键启用/禁用
- 数据同步：离线工作不丢失数据，事后一键同步
- 系统运维：健康检查提前预警，避免突发故障

## 三、技术保障

### 离线能力

| 特性 | 说明 |
|------|------|
| 双模式运行 | 支持远程（连接服务器）和本地（独立运行）两种模式 |
| 离线完整诊疗 | 本地模式下可完成全部诊疗流程，不依赖网络 |
| 事后同步 | 恢复网络后一键同步本地数据到服务器 |
| 差异检测 | 仅同步变更数据，避免全量传输 |

### 数据安全

| 特性 | 说明 |
|------|------|
| 身份认证 | JWT 令牌认证，自动登录，滑动刷新 |
| 重放攻击防护 | 请求签名检测，防止令牌被盗用 |
| 角色权限 | 四级权限体系，细粒度资源级访问控制 |
| 数据完整性 | 医案聚合保存事务保证，零数据丢失 |
| 操作审计 | 100% 写操作有审计记录，字段级变更追踪 |
| 敏感数据脱敏 | 日志中自动隐藏身份证号、手机号等敏感信息 |

### 性能指标

| 指标 | 目标 |
|------|------|
| 简单查询响应 | < 500ms |
| 列表查询（分页 20 条） | < 1 秒 |
| 医案聚合保存（诊断+处方） | < 2 秒 |
| 桌面端启动 | < 5 秒 |
| 页面切换 | < 1 秒 |

### 系统可靠性

| 指标 | 目标 |
|------|------|
| 数据完整性 | 0 数据丢失（事务保证） |
| 离线可用性 | 核心流程 100% 可用 |
| 操作可追溯 | 100% 写操作有审计记录 |
| 测试覆盖 | 2000+ 自动化测试 |

## 四、角色与权限一览

> 角色定义、授权策略和完整权限矩阵详见 [user-roles.md](04-user-roles.md)。

| 角色 | 典型用户 | 权限范围 |

## 五、版本规划

### v1.0 — 核心诊疗流程（当前版本）

**范围**: 15 个功能模块，138 项功能需求

| 优先级 | 功能数量 | 说明 |
|--------|---------|------|
| **必须** | 51 项 | 系统无此功能则不可用的最小功能集 |
| **推荐** | 54 项 | 显著提升诊疗效率但非阻断 |
| **可选** | 33 项 | 锦上添花，可延后交付 |

**已包含**: 完整中医诊疗流程、四级角色权限、离线模式、数据同步、处方打印、身份证读卡器集成

### 后续版本 — 扩展与集成

| 功能 | 说明 |
|------|------|
| 医案数据同步 | 聚合根多表级联同步 |
| 自动同步提示 | 网络状态检测 + 自动同步 |
| 用户数据同步 | 用户实体加入同步范围 |
| 字段级加密 | 身份证号、手机号等敏感字段加密存储 |

### 不在范围内

以下功能不在当前和规划版本中：

| 功能 | 原因 |
|------|------|
| 西医诊断和处方 | 产品定位为中医诊所专用 |
| 医保对接和费用结算 | 涉及第三方接口，复杂度高 |
| 药房发药管理 | 超出诊疗流程范围 |
| 库存进销存 | 独立业务域，后续版本考虑 |
| 排班和预约管理 | 小型诊所需求不强烈 |
| 移动端（iOS/Android） | 仅支持 Windows 桌面端 |
