## 概述

凌隐宝堂中医诊所管理系统是为中医诊所量身定制的全流程数字化诊疗平台。系统以「医案」为核心聚合根，覆盖从患者登记、中医诊断、处方开具到打印输出的完整临床工作流。独创的双模式架构（远程 SQL Server + 本地 LocalDB）确保诊所无论在线或离线均可持续诊疗；中医专属的验方管理、药材配伍、辨证论治等功能，区别于通用诊所管理软件，真正贴合中医师的工作习惯与诊疗逻辑。

## 按角色的价值主张

### Doctor · 李医生（中医师）

| 维度 | 描述 |
|------|------|
| **Who（目标用户）** | 拥有多年临床经验的中医师，日均接诊 20 名患者，复诊率约 40%，依赖完整病史做出辨证施治决策。 |
| **Why（动机与痛点）** | 纸质病历堆积如山，找一个复诊患者的历史记录要翻 5-10 分钟；手写处方字迹潦草，药房常打电话确认药名和剂量；外出看诊断网后回来手工抄录诊疗记录，费时且易遗漏。核心诉求：把时间还给临床，而不是消耗在文书和检索上。 |
| **What Before（现有替代方案）** | 纸质病历本 + 手写处方笺。患者信息靠翻找纸堆，处方靠手写复写，验方靠记忆或个人笔记本，费用靠心算或计算器。外出义诊时带纸质记录，回诊所后手工补录。 |
| **How（我们的解决方案）** | ① **10 秒病史调取** — 按姓名/拼音码/手机号秒级检索，完整呈现患者全部历史医案（诊断 + 处方 + 费用）；② **一键验方导入** — 从个人验方库一键导入经验方到处方，自动填充药材和剂量，开方时间从 5-10 分钟缩短至 1-2 分钟；③ **处方复制延续** — 复诊时一键复制上次处方，仅微调变更药材；④ **自动计价** — 处方费用实时自动计算，消除手工算错的风险；⑤ **标准打印** — 处方打印清晰规范，药房不再来电确认；⑥ **离线诊疗** — 本地模式支持断网环境下完整接诊，事后自动同步。 |
| **What After（期望成果）** | 接诊效率提升 40%+，复诊调档从 5 分钟降至 10 秒；处方零手写，药房配药零确认电话；外出义诊不再需要事后补录；每日可多看 4-6 名患者或提前下班。 |
| **Alternatives（替代方案对比）** | **纸质记录** — 检索慢、字迹不清、无法统计；**通用诊所软件** — 缺少验方管理、中医诊断模板、药材配伍等中医专属功能；**Excel** — 无法承载临床工作流，无打印处方能力；**手写处方** — 药房识别困难，无法复用历史处方。 |

### Admin · 王主任（诊所管理者）

| 维度 | 描述 |
|------|------|
| **Who（目标用户）** | 中医诊所运营管理者，兼顾行政与偶尔临床工作，负责药材价格维护、医案审核、用户账号生命周期管理。 |
| **Why（动机与痛点）** | 每月 1-2 次大批量药材调价，400+ 味药材逐条修改费时费力；不确定价格变更是否会追溯影响已打印的历史处方；400+ 味药材初始化需要逐条手工录入；员工离职后账号忘记禁用，存在安全隐患；医案审核靠人工翻阅，难以快速发现金额异常。 |
| **What Before（现有替代方案）** | Excel 维护药材清单和价格，手工逐条更新；纸质审批流程管理用户账号；人工逐份审阅医案找异常。无系统化的数据保护机制。 |
| **How（我们的解决方案）** | ① **价格快照隔离** — 处方打印时锁定药材价格快照，后续调价不影响历史处方，彻底消除追溯影响顾虑；② **批量药材管理** — 支持药材的批量导入、批量调价，400+ 味药材从数天缩短至数小时；③ **医案审核看板** — 集中展示待审核医案，金额异常自动标记，审核效率提升数倍；④ **4 级权限体系** — SuperAdmin / Admin / Doctor / Receptionist 角色精细管控，账号创建/禁用一键操作；⑤ **操作审计日志** — 全系统关键操作留痕，满足合规与追溯需求。 |
| **What After（期望成果）** | 药材调价从整天缩短至 1-2 小时，且历史处方价格不受影响；医案异常发现从被动抽查变为主动预警；人员变动时账号即时管控，安全风险降至最低；诊所运营数据可量化、可追溯。 |
| **Alternatives（替代方案对比）** | **Excel** — 无处方关联、无价格快照、无审计能力；**通用诊所软件** — 缺少中医药材库管理、无价格快照隔离机制；**纸质审批** — 流程慢、无留痕、易遗漏；**无系统** — 完全依赖个人记忆和手工台账。 |

### Receptionist · 小张（前台接待）

| 维度 | 描述 |
|------|------|
| **Who（目标用户）** | 诊所前台接待人员，高峰时段每小时需处理 10+ 名患者登记，需要快速准确完成挂号和基本信息采集。 |
| **Why（动机与痛点）** | 高峰期手工填写登记表，排队等候时间长，患者体验差；老患者记不清是否在系统中有记录，手工查重效率低，导致重复建档；不知道医生当前看诊进度，无法给候诊患者合理的等待时间估计，频繁被追问。 |
| **What Before（现有替代方案）** | 纸质登记表，手工填写患者姓名、年龄、联系方式；凭记忆或翻登记本判断是否老患者；候诊信息靠走到诊室门口观察。 |
| **How（我们的解决方案）** | ① **3 秒身份证登记** — 身份证读卡器集成，刷身份证自动填充姓名、性别、年龄、地址等基本信息；② **智能患者匹配** — 输入手机号或姓名时自动检索已有患者，避免重复建档；③ **候诊队列可视化** — 实时显示各医生当前看诊进度和候诊排队情况，可准确告知患者预计等待时间；④ **一键挂号** — 老患者调出档案后一键创建当日就诊记录，全程 30 秒内完成。 |
| **What After（期望成果）** | 患者登记从 3 分钟/人降至 30 秒/人；重复建档率降至接近零；候诊患者不再频繁追问等待时间，前台可主动告知；高峰时段不再手忙脚乱，患者满意度显著提升。 |
| **Alternatives（替代方案对比）** | **纸质登记表** — 慢、易错、难检索、无法去重；**通用诊所软件** — 缺少身份证读卡器集成、缺少中医候诊队列；**手工台账** — 无实时性、无法与医生端联动。 |

## 核心差异化

凌隐宝堂中医诊所管理系统与市面替代方案的核心差异点：

1. **中医原生设计** — 不是通用诊所软件的"中医版"，而是从数据模型到工作流完全围绕中医诊疗构建：以「医案」为核心聚合根，辨证论治、验方管理、药材配伍等中医专属功能贯穿始终。

2. **双模式离线优先架构** — 独创的远程 SQL Server + 本地 LocalDB 双模式，支持断网环境下完整诊疗，事后双向同步。中医师外出义诊、社区服务不再受网络限制，这是绝大多数诊所管理软件不具备的能力。

3. **价格快照隔离** — 处方打印时锁定药材价格快照，后续调价不影响历史处方。这一机制解决了中医诊所"调价是否追溯"的核心管理焦虑，通用软件鲜有此设计。

4. **打印保护与审计** — 处方打印后修改受限，配合完整操作审计日志，既满足医疗文书合规要求，又防止随意篡改已打印处方。

5. **身份证读卡器深度集成** — 前台登记环节与硬件身份证读卡器直接对接，3 秒完成患者信息采集，消除手工填表的效率瓶颈和数据错误。
