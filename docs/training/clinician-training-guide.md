## 第一部分：5 步工作流程指示器 ⭐

### 什么是工作流程指示器？

工作流程指示器位于医案编辑界面顶部，显示您当前在看诊流程中的哪个阶段。

### 5 个步骤

```
① 四诊采集 → ② 中医辨证 → ③ 处方决策 → ④ 处方编辑 → ⑤ 完成看诊
   [蓝色]     [灰色]      [灰色]      [灰色]      [灰色]
```

**步骤说明**:

1. **四诊采集** - 记录患者主诉、现病史
2. **中医辨证** - 进行舌诊、脉诊，确定中医诊断
3. **处方决策** - 决定是否需要开处方
4. **处方编辑** - 添加药材、设置剂量
5. **完成看诊** - 完成并归档医案

### 颜色含义

- 🔵 **蓝色** = 当前激活步骤（您现在在这里）
- 🟢 **绿色** = 已完成步骤（已通过）
- ⚪ **灰色** = 待完成步骤（还未到达）

### 自动前进规则

**好消息**：步骤会自动前进！您不需要手动切换。

```
填写现病史（≥5 字）     → 自动前进到步骤 2
└─ 现病史字段显示绿色 ✓

完成中医诊断             → 自动前进到步骤 3
└─ 诊断字段显示绿色 ✓

决定是否需要处方         → 自动前进到步骤 4
└─ 系统记录您的决定

添加处方药材             → 自动前进到步骤 5
└─ 可以完成看诊了！
```

### 实用提示

💡 **提示 1**: 如果步骤没有自动前进，检查是否填写了必填字段

💡 **提示 2**: 绿色对勾 ✓ 表示该步骤已完成

💡 **提示 3**: 您可以随时回到前面的步骤修改内容

## 第二部分：字段验证成功指示器 ✅

### 什么是验证指示器？

验证指示器是字段旁边的绿色对勾 ✓，告诉您该字段已通过验证。

### 何时出现绿色对勾？

| 字段 | 验证规则 | 指示器 |
|------|----------|--------|
| 现病史 | ≥ 5 个字符 | ✓ 绿色对勾 |
| 中医诊断 | 非空 | ✓ 绿色对勾 |
| 处方药材 | ≥ 1 味药材 | ✓ 绿色对勾 |

### 视觉示例

```
现病史: [患者主诉头痛三天_____] ✓
           └─ 5+ 字符，显示绿色对勾

中医诊断: [脾胃虚弱证_________] ✓
           └─ 非空，显示绿色对勾

共 3 味药材 ✓
           └─ 有药材，显示绿色对勾
```

### 为什么要用验证指示器？

✅ **即时反馈** - 您立即知道是否填写正确

✅ **减少错误** - 不会在最后才发现漏填

✅ **提高效率** - 不用猜测是否需要补充

✅ **增强信心** - 清楚知道进展如何

## 第三部分：现代消息通知 📢

### 什么是 Toast 通知？

Toast 通知是出现在窗口顶部的彩色消息框，提供重要操作的反馈。

### 通知类型

#### 1. 成功通知（绿色）🟢

```
✓ 医案已保存
└─ 显示 5 秒后自动消失
```

**何时出现**:
- 保存医案成功
- 完成看诊成功
- PDF 导出成功
- 导入验方成功

#### 2. 信息通知（蓝色）🔵

```
ℹ 医案已暂存，可稍后继续
└─ 显示 5 秒后自动消失
```

**何时出现**:
- 暂存医案
- 一般性操作确认

#### 3. 警告通知（黄色）🟡

```
⚠ 已清空所有药材（共 3 味）
└─ 显示 4 秒后自动消失
```

**何时出现**:
- 清空处方药材
- 删除操作

#### 4. 错误通知（红色）🔴

```
✕ 保存失败：网络连接失败
└─ 显示 4 秒后自动消失
```

**何时出现**:
- 操作失败
- 网络错误
- 验证错误

### 消息持续时间

| 类型 | 持续时间 | 原因 |
|------|----------|------|
| 成功 | 5 秒 | 重要确认，需要阅读 |
| 信息 | 5 秒 | 重要提示，需要阅读 |
| 警告 | 4 秒 | 注意事项，稍短 |
| 错误 | 4 秒 | 需要采取行动，稍短 |

### 实用提示

💡 **提示 1**: 消息会自动消失，无需手动关闭

💡 **提示 2**: 新消息会替换旧消息（不会堆叠）

💡 **提示 3**: 如果消息消失太快，可以在操作日志中查看

💡 **提示 4**: 错误消息会告诉您具体问题，请仔细阅读

## 第四部分：动态完整性检查 ✅

### 什么是完整性检查？

完整性检查显示医案是否完整，以及还缺少什么必填项。

### 在哪里看到？

位于医案编辑界面右下角：

```
┌─────────────────────────────────┐
│ 医案完整性                      │
├─────────────────────────────────┤
│ 中医诊断: [已填写] ✓            │
│ 处方决策: [已决定] ✓            │
│ 处方内容: [已完成] ✓            │
│ 剂量设置: [已设置] ✓            │
├─────────────────────────────────┤
│ 🟢 可以完成看诊                 │
└─────────────────────────────────┘
```

### 状态指示

#### 完整状态 🟢

```
✓ 可以完成看诊
```
- 所有必填项已填写
- "完成看诊"按钮可点击

#### 不完整状态 🟡

```
⚠ 尚未完成所有必填项
```
- 还有必填项未填写
- "完成看诊"按钮不可点击
- 详细列表显示缺少什么

### 实时更新

完整性检查会**实时更新**：

```
您打字 → 立即更新状态
添加药材 → 立即显示完成
删除药材 → 立即显示不完整
```

### 实用提示

💡 **提示 1**: 完整性检查是您最好的朋友 - 信任它！

💡 **提示 2**: 完成看诊前，检查完整性状态是否为绿色

💡 **提示 3**: 如果状态为黄色，看详细列表知道缺什么

💡 **提示 4**: 完整性检查自动计算，无需手动刷新

## 第五部分：新的界面布局 🖥️

### 紧凑模式（Compact Mode）

所有医案编辑现在使用**统一的紧凑布局**。

#### 优点

✅ **更简洁** - 单一布局，易于理解

✅ **更快速** - 减少屏幕空间，更快操作

✅ **一致性** - 所有模式使用相同布局

#### 布局结构

```
┌────────────────────────────────────────┐
│ [工作流程指示器]                        │
├────────────────────────────────────────┤
│                                        │
│  [患者信息]                            │
│  ┌────────────────────────────────┐   │
│  │ 四诊采集                        │   │
│  │ 现病史: [_________] ✓          │   │
│  │ 舌诊: [下拉选择]               │   │
│  │ 脉诊: [下拉选择]               │   │
│  └────────────────────────────────┘   │
│  ┌────────────────────────────────┐   │
│  │ 中医辨证                        │   │
│  │ 诊断: [_________] ✓            │   │
│  └────────────────────────────────┘   │
│  ┌────────────────────────────────┐   │
│  │ 处方编辑                        │   │
│  │ 共 3 味药材 ✓                  │   │
│  │ [药材列表]                     │   │
│  └────────────────────────────────┘   │
│                                        │
│  [医案完整性: 🟢 可以完成看诊]       │
├────────────────────────────────────────┤
│ [保存] [暂存] [完成看诊]               │
└────────────────────────────────────────┘
```

### 响应式设计

界面会自动适应窗口大小：

```
宽窗口 → 横向布局
窄窗口 → 纵向布局
```

## 第六部分：常见操作流程 🔄

### 流程 1：创建新医案并完成

**步骤**:

1. **选择患者**
   ```
   患者列表 → 选择患者 → 点击"开始看诊"
   ```

2. **四诊采集（步骤 1）**
   ```
   填写现病史（≥5 字）
   → 看到 ✓ 绿色对勾
   → 步骤自动前进到步骤 2
   ```

3. **中医辨证（步骤 2）**
   ```
   填写中医诊断
   → 看到 ✓ 绿色对勾
   → 步骤自动前进到步骤 3
   ```

4. **处方决策（步骤 3）**
   ```
   选择"需要处方"或"不需要处方"
   → 步骤自动前进到步骤 4
   ```

5. **处方编辑（步骤 4 - 如需要）**
   ```
   点击"套验方" → 选择验方 → 确认
   → 看到通知："已导入验方「XXX」，共 N 味药材"
   → 看到 ✓ 绿色对勾
   → 步骤自动前进到步骤 5
   ```

6. **完成看诊（步骤 5）**
   ```
   检查完整性：🟢 可以完成看诊
   → 点击"完成看诊"按钮
   → 看到通知："看诊完成，医案已归档"
   → 自动返回患者列表
   ```

**总耗时**: 约 2-3 分钟（熟练后）

---

### 流程 2：暂存并恢复医案

**步骤**:

1. **暂存医案**
   ```
   填写部分信息
   → 点击"暂存医案"按钮
   → 看到通知："医案已暂存，可稍后继续"
   → 可以关闭窗口
   ```

2. **恢复医案**
   ```
   重新选择同一患者
   → 点击"开始看诊"
   → 看到所有之前填写的内容
   → 工作流程指示器显示正确步骤
   → 继续填写
   ```

**使用场景**:
- 需要查阅其他资料
- 被其他事务打断
- 分次完成复杂医案

---

### 流程 3：复制历史处方

**步骤**:

1. **在当前医案中**
   ```
   点击"历史处方"按钮
   → 显示该患者的历史处方列表
   ```

2. **选择历史处方**
   ```
   选择要复制的处方
   → 点击确认
   → 看到通知："已复制历史处方，共 N 味药材"
   → 药材自动添加到当前处方
   ```

3. **调整剂量**
   ```
   根据需要调整剂数、用法
   → 完成看诊
   ```

**优势**:
- 快速复用历史方案
- 减少重复输入
- 保持治疗一致性

## 第七部分：常见问题 ❓

### Q1: 步骤指示器没有自动前进？

**A**: 检查必填字段：
- 现病史是否 ≥ 5 个字符？
- 中医诊断是否填写？
- 处方是否已添加药材？

---

### Q2: 看不到绿色对勾 ✓？

**A**: 确认字段内容：
- 现病史：至少 5 个字符
- 诊断：非空
- 处方：至少 1 味药材

---

### Q3: "完成看诊"按钮不可点击？

**A**: 检查完整性状态：
- 应该显示 🟢 "可以完成看诊"
- 如果显示 🟡 "尚未完成"，查看详细列表
- 补充缺少的必填项

---

### Q4: Toast 通知消失了，没看清？

**A**: 
- 通知显示 4-5 秒
- 可以在操作日志中查看历史通知
- 重复操作会再次显示通知

---

### Q5: 如何知道医案是否保存成功？

**A**: 
- 看到绿色通知："医案已保存"
- 检查右上角的保存指示器
- 查看医案列表确认

---

### Q6: 暂存后数据会丢失吗？

**A**: 
- ✅ 不会！暂存会保存所有数据
- ✅ 可以随时恢复
- ✅ 即使关闭窗口也没问题

---

### Q7: 工作流程指示器可以手动跳转吗？

**A**: 
- ✅ 可以！点击任意步骤跳转
- ✅ 但建议按顺序填写
- ✅ 步骤指示器只是指导，不限制操作

---

### Q8: 旧的完整模式在哪里？

**A**: 
- ❌ 已移除
- ✅ 只保留紧凑模式
- ✅ 因为用户更喜欢紧凑模式
- ✅ 代码简化 50%
