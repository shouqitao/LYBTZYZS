# 常见问题手册（FAQ）

> 版本: v1.0 | 日期: 2026-09-24

对应需求：US-SHELL-023。按频率排序，自助三步：**本文 → [../06-operations/03-troubleshooting.md](../06-operations/03-troubleshooting.md) → [support-process.md](support-process.md)**。

## 一、登录与账号（Q1–Q5）

**Q1 登录提示失败 / 密码不记得**
找诊所管理员（sysadmin）在 用户管理 里重置；初始 sysadmin 账号由初始化向导创建，口令交接见内部记录，不写在任何文档里。

**Q2 用着用着突然要重新登录**
Token 临近过期会出现会话超时提醒弹窗，点继续即可；超时后重新登录不丢已保存内容（草稿在库里）。频繁被登出→见 Q3。

**Q3 远程模式登录报服务器地址错 / 连不上**
按序检查：① 网络能否上网；② 管理员确认服务器地址填的对（初始化向导第 2 步可重新测试连接）；③ 服务器 `GET /api/v1/health` 是否 200（管理员执行）。网络断开会自动退回本地模式，网络恢复需手动切回。

**Q4 忘记自己是本地还是远程模式**
看连接状态显示（登录后主界面可见）。判断准绳：**看不到昨天录的数据**大概率是模式切错了，见 Q5。

**Q5 切了模式数据「不见了」**
本地与远程是**两套独立数据**，v1.0 不做互通（PRD 决策 N1）。切回原模式数据就回来，不会丢。有未完成医案时系统会阻止切换，先结案或保存。

## 二、导入与数据（Q6–Q8）

**Q6 患者 Excel 导入报错**
错误会指出**第几行、哪个字段**（必填缺失 / 格式不对 / 重复）。只改报错行重新上传即可；重复数据按导入时选的策略（跳过 / 更新 / 报错）处理。

**Q7 药材 / 验方想批量进系统**
药材、验方批量导入走 JSON 模板（下载模板→填写→导入）；患者走 Excel 模板。模板均从导入入口下载，不要自行改表头。

**Q8 担心导错数据**
导入前先做一次备份（系统管理 → 备份恢复）；导入事务性执行，失败整体回退，不会半截入库。

## 三、打印（Q9–Q11）

**Q9 打印按钮是灰的 / 打不出来**
医案必须是**已完成**状态才允许打印（进行中 / 草稿不能打印）；先保存结案再打。这是产品规则，不是故障。

**Q10 打印出来是空的 / 格式不对**
① 换一台打印机试（驱动问题最常见）；② 确认选对了纸张（处方笺规格）；③ 重启打印服务。仍不行→走 [support-process.md](support-process.md) 三线。

**Q11 已打印的医案还能改吗**
已打印有标记保护；需要更正走管理员流程，不要删记录（审计可统计）。

## 四、读卡器（Q12–Q13）

**Q12 读卡器没反应**
① 换 USB 口 / 重插；② 设备管理器确认驱动正常；③ 换一张卡试（排除卡本身）。仍不行→**手动录入建档**，不阻塞业务，读卡器问题事后报修。

**Q13 读卡读出来信息不对**
核对卡面信息，错的字段手工改；同一张卡反复读错→报修（管理员可跑读卡器诊断，见 sysadmin 主页诊断入口）。

## 五、更新与版本（Q14–Q16）

**Q14 怎么知道当前版本**
帮助 / 关于处查看。当前版本号规范见 [../00-governance/05-versioning-standard.md](../00-governance/05-versioning-standard.md)（0.0.x 为现阶段，属正常，不是没装上）。

**Q15 自动更新失败 / 更新后出问题**
设置里检查更新重试一次；仍失败→从 GitHub Releases 手动下载 Setup 重装。更新后功能异常→按 [support-process.md](support-process.md) §版本回退 走回退，不要手改安装目录。

**Q16 更新会不会丢数据**
更新不碰数据库；本地模式数据在 LocalDB，远程模式在服务器。升级前管理员仍建议做一次备份。

## 六、备份（Q17–Q18）

**Q17 备份多久做一次、在哪**
管理员每日增量 + 每周全量是推荐节奏；入口：系统管理 → 备份恢复。细则 [../06-operations/06-backup-recovery.md](../06-operations/06-backup-recovery.md)。

**Q18 恢复会不会覆盖新数据**
会——恢复是把库退回到备份时点，**恢复前必须确认备份点之后的录入可放弃或已另行留存**。拿不准先问管理员。
