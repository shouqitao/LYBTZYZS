# 快速上手（三角色版，每角色 ≤30 分钟）

> 版本: v1.0 | 日期: 2026-09-24

对应需求：US-SHELL-023（前台 / 医生 / 运维三类角色分别出材料）。完整操作细节以各角色培训材料为准，本文是上手路径。

## 前台（挂号 / 档案，约 25 分钟）

**第 1 步（5 分钟）登录与环境**
- 用管理员发的账号登录（密码找诊所管理员重置，见 [faq.md](faq.md)）
- 确认左下/状态区显示的是**本地模式**（数据在本机）还是**远程模式**（数据在服务器）——两种模式数据不互通，模式不对看不到昨天的数据，见 [faq.md](faq.md) Q5

**第 2 步（10 分钟）挂号三板斧**
1. 新挂号：患者姓名 / 性别 / 年龄 → 选医生 → 确认（挂错可取消，见操作手册对应章节）
2. 读卡建档：接上读卡器读取医保/身份证信息自动建档；读不出来就**手动录入**，不卡流程
3. 今日队列：查看已挂号患者列表，接诊状态一目了然

**第 3 步（10 分钟）患者建档与导入**
- 单个建档：患者 → 新建，必填只有姓名等少量字段，先建起来再说
- 批量导入：患者 → 导入 → 下载 Excel 模板 → 填好上传；报错行会指出第几行第几字段，改完重传
- 重复提示：按提示选择跳过 / 更新 / 报错（导入时可选）

**完成标志**：能独立完成 挂号 → 建档 → 导入 3 行样例。

## 医生（诊疗，约 30 分钟）

**第 1 步（5 分钟）登录**：同前台，确认模式显示正确。

**第 2 步（20 分钟）接诊主链路**
1. 从队列接诊 → 进入医案工作区
2. 写医案：主诉 / 诊断 / 处方（药材从目录选，验方可用现成模板改）
3. 保存 → **只有「已完成」状态才能打印**（草稿不打印，见 [faq.md](faq.md) Q9）
4. 打印处方笺：选打印机 → 打印（患者持单线下付费、抓药——系统不联动药房）
5. 未写完先保存草稿，下次接诊继续（未完成医案有守卫，不影响但别忘结案）

**第 3 步（5 分钟）验方模板**：目录里挑一个常用验方存为模板，下次直接套用。

**完成标志**：独立完成 接诊 → 医案 → 已完成 → 打印 全链路一次。

**进阶**：医案工作区完整操作见 [clinician-training-guide.md](clinician-training-guide.md)。

## 运维 / 管理员（约 30 分钟）

**第 1 步（10 分钟）系统就位**
- 首次登录会进入**初始化向导**（模式选择 → 连接测试 → 诊所信息 → 初始管理员 → 校验完成）；中途失败可不完成，下次登录再提示
- sysadmin 账号：管账号、管角色、管配置

**第 2 步（10 分钟）三件日常**
1. **备份**：系统管理 → 备份恢复 → 执行一次并知道恢复入口在哪（细节 [../06-operations/06-backup-recovery.md](../06-operations/06-backup-recovery.md)）
2. **账号**：建前台/医生账号、分配角色（一级管一级、不能自管）
3. **配置**：诊所名称等改完要保存并知道配置热更新生效方式

**第 3 步（10 分钟）上线与故障**
- 新机器上线照着清单走：[../06-operations/13-go-live-checklist.md](../06-operations/13-go-live-checklist.md)
- 出问题第一反应：先查 [faq.md](faq.md) → 再查 [../06-operations/03-troubleshooting.md](../06-operations/03-troubleshooting.md) → 都搞不定走 [support-process.md](support-process.md)
- 版本回退：不要手改文件，走 [../06-operations/08-deployment-rollback.md](../06-operations/08-deployment-rollback.md)

**完成标志**：能说出 备份在哪、账号怎么建、出事找谁 三件事。
