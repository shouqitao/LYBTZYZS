## 登录和账户问题

### Q1: 忘记登录密码怎么办？

**问题描述**: 用户忘记自己的登录密码无法进入系统。

**解决方案**:
1. **联系管理员**
   - 致电系统管理员或技术负责人
   - 提供您的用户名和身份信息进行验证

2. **管理员重置密码**
   - 管理员登录系统管理模块
   - 在"用户管理"中找到您的账户
   - 点击"重置密码"生成临时密码

3. **修改临时密码**
   - 使用临时密码登录系统
   - 首次登录会强制要求修改密码
   - 设置新密码并确认

**预防措施**:
- 定期更换密码（建议3个月一次）
- 使用强密码（包含大小写字母、数字、特殊字符）
- 将密码记录在安全的地方

---

### Q2: 登录后提示"权限不足"无法操作？

**问题描述**: 成功登录后，某些功能提示权限不足无法使用。

**解决方案**:
1. **确认用户角色**
   ```
   医生账户权限:
   ✅ 患者管理
   ✅ 诊疗记录
   ✅ 处方开具
   ❌ 用户管理
   ❌ 系统设置
   
   管理员账户权限:
   ✅ 所有功能模块
   ✅ 用户管理
   ✅ 系统设置
   ```

2. **申请权限提升**
   - 联系系统管理员
   - 说明需要的具体权限和使用原因
   - 等待管理员审批和权限调整

3. **使用对应功能账户**
   - 如需管理功能，请使用管理员账户登录
   - 如需诊疗功能，请使用医生账户登录

---

### Q3: 系统提示"会话超时"需要重新登录？

**问题描述**: 使用过程中系统自动退出，提示会话超时。

**解决方案**:
1. **重新登录**
   - 这是正常的安全机制
   - 重新输入用户名密码登录即可
   - 系统会保存您之前的工作数据

2. **调整会话时间**（仅管理员）
   ```
   系统设置 → 安全设置 → 会话超时时间
   默认: 2小时
   可调整范围: 30分钟 - 8小时
   ```

3. **保持会话活跃**
   - 定期点击系统界面保持活跃
   - 长时间离开时记得保存数据

## 数据录入和修改

### Q4: 患者信息录入错误如何修改？

**问题描述**: 录入患者信息时出现错误，需要修改已保存的数据。

**解决方案**:
1. **查找患者档案**
   ```
   方法一: 患者管理 → 患者列表 → 查找目标患者
   方法二: 使用搜索功能（Ctrl+F）快速查找
   方法三: 按姓名、电话、身份证号搜索
   ```

2. **编辑患者信息**
   - 点击患者姓名进入详情页
   - 点击"编辑"按钮
   - 修改错误的字段内容
   - 点击"保存"确认修改

3. **修改限制说明**
   ```
   可修改字段:
   ✅ 联系电话
   ✅ 家庭地址
   ✅ 过敏史等医疗信息
   
   限制修改字段:
   ⚠️ 姓名（需管理员权限）
   ⚠️ 身份证号（需管理员权限）
   ⚠️ 出生日期（需管理员权限）
   ```

**注意事项**:
- 重要信息修改会记录在操作日志中
- 如需修改关键身份信息请联系管理员
- 修改后系统会自动保存修改记录

---

### Q5: 诊疗记录保存后发现内容错误？

**问题描述**: 诊疗记录已保存，但发现记录内容有误需要修改。

**解决方案**:
1. **查找诊疗记录**
   ```
   患者管理 → 选择患者 → 诊疗历史 → 找到错误记录
   ```

2. **修改记录内容**
   - 点击"编辑"按钮（如有权限）
   - 修正错误的诊断或用药信息
   - 在修改说明中注明修改原因
   - 保存修改后的记录

3. **添加补充记录**
   - 如无法直接修改，可添加补充记录
   - 标明"更正前次记录"
   - 详细说明正确的诊疗信息

**安全提醒**:
- 诊疗记录修改会保留完整的修改痕迹
- 重要诊断修改建议由主治医生进行
- 系统会记录修改时间、修改人员等信息

## 打印和导出

### Q6: 处方打印格式不正确或缺失内容？

**问题描述**: 打印处方时格式混乱，或者缺失重要信息。

**解决方案**:
1. **检查打印设置**
   ```
   文件 → 打印设置 → 检查以下项目:
   - 纸张规格: A4
   - 打印方向: 纵向
   - 页边距: 默认
   - 缩放比例: 100%
   ```

2. **检查处方内容完整性**
   ```
   必须包含的信息:
   ✅ 患者姓名、性别、年龄
   ✅ 就诊日期
   ✅ 诊断信息
   ✅ 处方药物和用量
   ✅ 用法用量说明
   ✅ 医师签名
   ```

3. **重新设置打印参数**
   - 打印预览确认格式正确
   - 如仍有问题，联系技术支持
   - 可先保存为PDF格式再打印

**常见打印问题**:
| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 内容被截断 | 页边距设置不当 | 调整页边距或缩放比例 |
| 字体模糊 | 打印机分辨率低 | 检查打印机设置 |
| 缺失签名 | 医师信息未填写 | 补充医师签名信息 |

**问题描述**: 尝试导出患者数据或统计报表时，系统提示格式不支持。

**解决方案**:
1. **确认支持的导出格式**
   ```
   支持的格式:
   ✅ Excel (.xlsx)
   ✅ PDF (.pdf)
   ✅ CSV (.csv)
   ❌ Word (.doc/.docx)
   ❌ 图片格式
   ```

2. **选择正确的导出选项**
   - 数据分析使用Excel格式
   - 存档打印使用PDF格式
   - 数据处理使用CSV格式

3. **检查数据权限**
   - 确认有导出权限
   - 某些敏感数据可能限制导出
   - 联系管理员获取相应权限

## 患者管理功能

### Q8: 患者档案重复如何处理？

**问题描述**: 发现同一患者被建立了多个档案，造成信息分散。

**解决方案**:
1. **确认重复患者**
   ```
   检查标准:
   - 姓名完全相同
   - 身份证号相同
   - 联系电话相同
   - 家庭住址相似
   ```

2. **合并患者档案**（管理员操作）
   - 系统管理 → 数据管理 → 患者档案合并
   - 选择主档案（信息最完整的档案）
   - 选择需要合并的重复档案
   - 系统会自动合并诊疗记录和处方历史

3. **预防重复建档**
   - 建档前先搜索患者姓名
   - 确认患者身份证号码
   - 仔细核对联系电话

**注意事项**:
- 档案合并操作不可逆，请谨慎操作
- 合并前建议备份相关数据
- 合并后会保留完整的操作记录

---

### Q9: 如何批量导入患者信息？

**问题描述**: 需要将其他系统或纸质档案中的患者信息批量导入到系统中。

**解决方案**:
1. **下载导入模板**
   ```
   患者管理 → 批量导入 → 下载Excel模板
   ```

2. **准备导入数据**
   ```
   必填字段:
   - 姓名
   - 性别  
   - 出生日期或年龄
   
   选填字段:
   - 联系电话
   - 身份证号
   - 家庭地址
   - 过敏史
   ```

3. **执行批量导入**
   - 按模板格式整理数据
   - 上传Excel文件
   - 预览导入数据确认无误
   - 执行导入操作

**导入注意事项**:
- 检查数据格式正确性
- 避免重复导入相同患者
- 导入后验证数据完整性
- 导入失败的记录会生成错误报告

### Q11: 辨证论治如何准确记录？

**问题描述**: 在辨证论治环节，如何准确分析和记录证候。

**辨证分析步骤**:

1. **收集症状**
   ```
   主症: 患者最主要、最明显的症状
   次症: 伴随症状和体征
   舌脉: 舌象和脉象特征
   ```

2. **分析病机**
   ```
   病位分析: 确定病变部位(脏腑、经络)
   病性分析: 判断病邪性质(寒/热/虚/实)
   病势分析: 评估病情轻重缓急
   ```

3. **确定证候**
   ```
   常见证候类型:
   - 脏腑辨证: 心气虚、肾阳虚、肝郁脾虚等
   - 经络辨证: 太阳病、少阳病、厥阴病等
   - 气血辨证: 气虚、血瘀、气滞等
   ```

4. **确立治法**
   ```
   治疗原则:
   - 补虚泻实
   - 调和阴阳
   - 理气活血
   - 清热解毒等
   ```

**记录格式示例**:
```
辨证分析:
患者咳嗽2周，痰白清稀，畏寒肢冷，舌淡苔白，脉沉迟无力。
分析: 外感风寒，肺卫不宣，兼见脾肾阳虚之象。
证候: 风寒束肺证兼脾肾阳虚证
治法: 辛温解表，宣肺散寒，温补脾肾
```

## 处方开具功能

### Q12: 配伍禁忌检查提示冲突如何处理？

**问题描述**: 开具处方时系统提示药物配伍禁忌，如何正确处理。

**处理步骤**:

1. **了解禁忌类型**
   ```
   十八反(严重禁忌):
   - 甘草反: 甘遂、大戟、海藻、芫花
   - 乌头反: 贝母、瓜蒌、半夏、白蔹、白及  
   - 藜芦反: 人参、沙参、丹参、玄参、细辛、芍药
   
   十九畏(相畏禁忌):
   - 硫黄畏朴硝    - 水银畏砒霜    - 狼毒畏密陀僧
   - 巴豆畏牵牛    - 丁香畏郁金    - 川乌草乌畏犀角
   - 牙硝畏三棱    - 官桂畏赤石脂  - 人参畏五灵脂
   ```

2. **评估配伍必要性**
   - 检查是否有替代药物
   - 评估冲突药物的重要性
   - 考虑减量使用或分服

3. **调整处方**
   ```
   调整方法:
   方法1: 替换冲突药物
   方法2: 调整用药剂量
   方法3: 分开服用时间
   方法4: 添加制约药物
   ```

4. **特殊情况处理**
   - 如确需同用，需在医嘱中特别说明
   - 向患者解释用药注意事项
   - 密切观察用药反应

**安全提醒**:
- 十八反绝对不可同用
- 十九畏可考虑特殊情况下使用
- 孕妇用药需额外谨慎
- 有疑问时请咨询上级医师

### Q13: 验方应用和个性化调整？

**问题描述**: 如何正确使用系统中的验方，并根据患者情况进行个性化调整。

**验方使用流程**:

1. **选择合适验方**
   ```
   系统内置验方分类:
   - 解表剂: 麻黄汤、桂枝汤、银翘散等
   - 清热剂: 白虎汤、清营汤、黄连解毒汤等
   - 补益剂: 四君子汤、四物汤、补中益气汤等
   - 理气剂: 逍遥散、柴胡疏肝散、半夏厚朴汤等
   ```

2. **基础方应用**
   - 处方管理 → 验方库 → 选择对症方剂
   - 系统自动填入标准配方和用量
   - 检查配伍禁忌和适应症

3. **个性化调整**
   ```
   调整原则:
   - 随证加减: 根据兼夹证候调整
   - 因时制宜: 考虑季节气候因素
   - 因人制宜: 考虑年龄、体质、职业
   - 因地制宜: 考虑地理环境因素
   ```

4. **常见加减法**
   ```
   补中益气汤加减示例:
   基础方: 黄芪、党参、白术、炙甘草、当归、陈皮、升麻、柴胡
   
   兼头痛: 加川芎、蔓荆子
   兼腹泻: 加茯苓、薏苡仁
   兼失眠: 加酸枣仁、远志
   兼血瘀: 加红花、桃仁
   ```

**验方管理**:
- 可保存个人常用验方
- 记录验方使用效果
- 建立个性化验方库

## 药材管理功能

### Q14: 药材价格如何及时更新？

**问题描述**: 中药材价格波动频繁，如何保持系统中价格信息的及时性和准确性。

**价格更新方案**:

1. **定期价格调研**
   ```
   更新频率建议:
   - 常用药材: 每周更新
   - 贵重药材: 实时更新  
   - 普通药材: 每月更新
   - 季节性药材: 按季节更新
   ```

2. **价格录入流程**
   ```
   药材管理 → 价格管理 → 选择药材 → 更新价格
   需要记录:
   - 供应商信息
   - 药材规格等级
   - 更新日期和更新人
   - 价格变动原因
   ```

3. **批量价格更新**
   - 使用Excel模板批量导入
   - 按供应商分类更新
   - 设置价格变动提醒

4. **价格监控**
   ```
   监控指标:
   - 价格波动率超过20%
   - 连续上涨或下跌趋势
   - 与市场均价偏差过大
   - 供应商价格异常
   ```

**价格管理建议**:
- 建立多个供应商价格对比
- 记录价格变动历史
- 设置价格预警机制
- 定期分析价格趋势

### Q15: 如何添加系统中没有的新药材？

**问题描述**: 需要使用系统药材库中没有的新药材，如何添加到系统中。

**添加流程**:

1. **新药材信息收集**
   ```
   必填信息:
   - 药材名称(标准名称)
   - 别名(常用别名)
   - 性味归经
   - 功效主治
   - 用法用量
   - 使用注意
   ```

2. **添加药材档案**
   ```
   药材管理 → 新增药材 → 填写信息:
   基本信息:
   - 药材名称: 如"西洋参"
   - 拉丁名: 如"Panax quinquefolius"
   - 别名: 如"花旗参、洋参"
   - 药材分类: 如"补益药-补气药"
   
   药性信息:
   - 性味: 如"甘、微苦，凉"
   - 归经: 如"心、肺、肾经"
   - 功效: 如"补气养阴，清热生津"
   - 主治: 如"气虚阴亏，内热消渴"
   
   使用信息:
   ```

### Q20: 遇到系统错误代码如何处理？

#### 系统级错误

| 错误代码 | 错误描述 | 原因分析 | 解决方案 |
|----------|----------|----------|----------|
| SYS_001 | 数据库连接失败 | 网络中断或数据库服务停止 | 1. 检查网络连接<br>2. 重启数据库服务<br>3. 联系技术支持 |
| SYS_002 | 内存不足 | 系统内存使用率过高 | 1. 关闭其他程序<br>2. 重启系统<br>3. 增加内存 |
| SYS_003 | 磁盘空间不足 | 硬盘剩余空间<10% | 1. 清理临时文件<br>2. 删除不必要文件<br>3. 扩展磁盘容量 |
| SYS_004 | 权限不足 | 当前用户权限不够 | 1. 使用管理员账户<br>2. 申请相应权限<br>3. 检查账户状态 |

| 错误代码 | 错误描述 | 原因分析 | 解决方案 |
|----------|----------|----------|----------|

| BIZ_002 | 配伍禁忌冲突 | 处方中药物相反相畏 | 1. 调整冲突药物<br>2. 使用替代药材<br>3. 咨询上级医师 |
| BIZ_003 | 数据格式错误 | 输入数据不符合要求 | 1. 检查数据格式<br>2. 重新输入数据<br>3. 参考格式要求 |

#### 数据操作错误

| 错误代码 | 错误描述 | 原因分析 | 解决方案 |
|----------|----------|----------|----------|

   ```
   基本处理:
   - 刷新页面(F5)

   - 重启系统软件
   ```
