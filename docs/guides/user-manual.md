## 系统概览

### 什么是凌隐宝堂中医诊所系统？

凌隐宝堂中医诊所系统是专为小型中医诊所设计的数字化管理工具，帮助医生高效管理患者档案、诊疗记录、处方开具和药材库存。

### 核心价值
- ✅ **简单易用** - 专为中医诊所定制的简洁界面
- ✅ **数据安全** - 患者隐私信息加密存储
- ✅ **专业功能** - 支持中医四诊、配伍禁忌检查
- ✅ **合规管理** - 符合医疗数据管理规范

## 诊疗管理

### 创建新诊疗

1. **选择患者**
   - 从患者列表选择
   - 或搜索患者姓名

2. **填写主诉**
   ```
   患者主要症状和就诊原因
   例如: "咳嗽2周，伴有痰多，夜间加重"
   ```

3. **四诊记录**

   #### 望诊
   ```
   - 面色: 苍白/红润/萎黄/黧黑
   - 神态: 精神/疲倦/烦躁/淡漠  
   - 形体: 肥胖/消瘦/正常
   - 舌象: 舌质/舌苔描述
   ```

   #### 闻诊
   ```
   - 声音: 洪亮/低微/嘶哑
   - 呼吸: 平稳/气短/喘促
   - 语言: 清晰/含糊不清
   - 气味: 口气/体味等
   ```

   #### 问诊
   ```
   - 寒热: 恶寒/发热/寒热往来
   - 汗出: 自汗/盗汗/无汗
   - 头身: 头痛/身痛/困重
   - 胸腹: 胸闷/腹胀/疼痛
   - 二便: 大便/小便情况
   - 睡眠: 失眠/多梦/易醒
   - 饮食: 食欲/食量/口味
   ```

   #### 切诊
   ```
   - 脉象: 浮/沉/迟/数/滑/涩/弦/细等
   - 脉位: 左手/右手寸关尺
   - 脉力: 有力/无力
   - 脉率: 次/分
   ```

4. **辨证论治**
   ```
   - 证候分析: 根据四诊综合分析
   - 治法: 确定治疗原则
   - 方药: 选择合适方剂
   ```

### 诊断开方

1. **选择治疗方案**
   - 使用经典验方
   - 自拟处方
   - 修改现有方剂

2. **添加药物**
   ```
   药材选择 → 用量确定 → 服用方法
   例如: 
   - 黄芪 30g
   - 党参 15g  
   - 白术 12g
   - 炙甘草 6g
   ```

3. **配伍检查**
   - 系统自动检查药物配伍禁忌
   - 提示相反相畏药物
   - 建议用药调整

4. **处方确认**
   - 确认药物清单
   - 确认用法用量
   - 添加医嘱说明

## 常见问题

### 登录问题

#### Q1: 忘记密码怎么办？
**A**: 
1. 联系管理员重置密码
2. 管理员在"用户管理"中重置您的密码
3. 使用临时密码登录后立即修改

#### Q2: 登录后提示权限不足？
**A**: 
1. 确认您的用户角色是否正确
2. 联系管理员检查权限设置
3. 如需更高权限请提交申请

#### Q3: 系统提示"会话超时"？
**A**:
1. 这是正常的安全机制
