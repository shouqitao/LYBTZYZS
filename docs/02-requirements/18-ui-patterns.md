# UI/UX 交互模式规范

## Problem Statement

中医诊所管理系统的 UI 需要兼顾效率（高频操作 < 3 步完成）和准确性（防止误操作导致数据错误）。本规范定义全系统统一的交互模式，确保用户在不同模块间切换时保持一致的体验预期。

## Success Metrics

1) 核心操作（挂号、开方、打印）< 3 步完成；2) 误操作拦截率 100%（不可逆操作均有确认对话框）；3) 模块间交互模式一致率 > 95%

---

## 概述

本文档定义凌隐宝堂中医诊所管理系统的全局 UI/UX 交互规范。所有模块的界面设计应遵循本规范，确保一致的用户体验。

## 1. 列表页规范

### 1.1 搜索

| 属性 | 规范 |
|------|------|
| 搜索模式 | 即时搜索 + 防抖 (300ms) |
| 搜索框位置 | 列表上方，左对齐 |
| 搜索框行为 | 输入停止 300ms 后自动触发搜索，无需按回车 |
| 清除按钮 | 搜索框右侧显示清除按钮 (X)，点击清空搜索并重新加载完整列表 |
| 搜索范围 | 各模块定义的可搜索字段 (通常: 名称/拼音码/编号) |
| 无结果提示 | 显示"未找到匹配结果"空状态提示 |
| 加载指示 | 搜索过程中显示加载指示器 (Spinner) |

### 1.2 表格

| 属性 | 规范 |
|------|------|
| 排序 | 支持单列排序，点击列头切换升序/降序。默认排序: 按创建时间降序 |
| 行选择 | 单击行选中，高亮显示。支持 Ctrl+Click 多选 |
| 行双击 | 打开编辑/详情页 |
| 列宽 | 自动适应内容 + 可手动拖拽调整 |
| 文本截断 | 超长文本省略号截断，鼠标悬停显示完整内容 (Tooltip) |

### 1.3 分页

| 属性 | 规范 | 配置来源 |
|------|------|---------|
| 默认页大小 | 20 条/页 | PaginationOptions.DefaultPageSize |
| 可选页大小 | [10, 20, 50, 100] | PaginationOptions.PageSizeOptions |
| 页大小选择器 | 显示在分页控件左侧 | PaginationOptions.ShowPageSizeSelector |
| 分页位置 | 列表底部，居中 |
| 总数显示 | "共 N 条记录" |

### 1.4 工具栏

| 按钮 | 位置 | 说明 |
|------|------|------|
| 新增 | 表格上方右侧 | 主操作按钮，突出显示 |
| 导入 | 新增按钮旁边 | 仅支持导入的模块 (药材/验方/患者) |
| 删除 | 选中行后显示 | 次要操作，需确认 |
| 刷新 | 工具栏最右侧 | 手动刷新列表 |

## 2. 表单页规范

### 2.1 布局

| 属性 | 规范 |
|------|------|
| 默认布局 | 双列布局 |
| 短字段 (姓名/性别/年龄/电话) | 同行排列，左右各一个字段 |
| 长字段 (地址/备注/描述) | 独占一行，跨越两列宽度 |
| 必填标记 | 字段标签前显示红色 * 号 |
| 字段间距 | 垂直间距统一 (8px 或 12px) |
| 分组 | 相关字段使用 GroupBox 分组 (如: 患者基本信息 / 联系方式) |

### 2.2 校验

| 属性 | 规范 |
|------|------|
| 校验时机 | 失焦即时校验 (字段失去焦点时) + 提交时全表单校验 |
| 错误提示位置 | 字段下方，红色文字 |
| 错误字段标记 | 字段边框变为红色 |
| 提交时校验失败 | 滚动到第一个错误字段，聚焦该字段 |
| 校验规则 | 遵循各模块 PRD 的业务规则 (如: 手机号格式/身份证号校验) |

### 2.3 保存行为

| 场景 | 行为 |
|------|------|
| 新建保存成功 | 返回列表页，显示成功提示 Toast |
| 编辑保存成功 | 返回列表页，显示成功提示 Toast |
| 医案保存成功 | 弹出"是否打印处方?"提示 (特殊流程，见 R2) |
| 保存失败 | 停留在当前页，显示错误提示 (字段级 / Toast 级) |
| 取消/返回 | 如有未保存修改，弹出"放弃修改?"确认 |

### 2.4 操作按钮

| 按钮 | 位置 | 说明 |
|------|------|------|
| 保存 | 表单底部右侧 | 主操作按钮，突出显示 |
| 取消 | 保存按钮左侧 | 次要按钮，返回列表 |
| 删除 | 表单底部左侧 (仅编辑模式) | 危险操作按钮，红色 |

## 3. 对话框规范

### 3.1 删除确认

| 属性 | 规范 |
|------|------|
| 触发方式 | 单条或批量删除均弹出确认对话框 |
| 对话框标题 | "确认删除" |
| 内容 | 显示待删除内容摘要 (名称/数量) |
| 引用检查 | 如存在引用关系，显示引用详情 (如: "该患者关联了 N 个历史医案，无法删除") |
| 确认按钮 | "删除" (红色/危险样式) |
| 取消按钮 | "取消" (默认焦点在取消上，防止误操作) |

**单条删除文案示例**:
```
确认删除
确定要删除药材"甘草"吗？此操作不可撤销。
[取消] [删除]
```

**批量删除文案示例**:
```
确认批量删除
确定要删除选中的 5 条记录吗？此操作不可撤销。
[取消] [删除 5 条]
```

**引用保护文案示例**:
```
无法删除
患者"张三"关联了 3 个历史医案，无法删除。
如需停用该患者，请使用"禁用"功能。
[知道了]
```

### 3.2 导入对话框

| 步骤 | 内容 |
|------|------|
| 选择文件 | 文件选择器，支持拖拽。显示支持的文件格式 |
| 预览 | 显示待导入数据预览表格，标注重复项和错误项 |
| 重复策略 | 用户选择: 跳过重复 / 覆盖重复 |
| 执行导入 | 进度条 + 当前处理条目 |
| 结果汇总 | 成功 N 条 / 跳过 N 条 / 失败 N 条 (附失败原因) |

### 3.3 成功/失败提示

| 类型 | 展示方式 | 持续时间 |
|------|---------|---------|
| 成功提示 | Toast 通知 (右上角) | 3 秒自动消失 |
| 警告提示 | Toast 通知 (黄色) | 5 秒自动消失，可手动关闭 |
| 错误提示 | Toast 通知 (红色) | 不自动消失，需手动关闭 |
| 系统错误 | 对话框 (含错误代码 + 用户友好消息) | 手动关闭 |

## 4. 工作区模式

### 4.1 模式定义

| 模式 | 目标用户 | 可见菜单 |
|------|---------|---------|
| **Clinical (诊疗模式)** | Doctor | 患者管理、医案管理、验方管理、打印 |
| **Management (管理模式)** | Admin / SuperAdmin | 全部模块 (含用户管理、药材管理、系统设置) |

### 4.2 模式切换

| 属性 | 规范 |
|------|------|
| 切换入口 | Shell 标题栏右侧的下拉菜单，或设置面板 |
| 默认模式 | Doctor 角色默认 Clinical，Admin 默认 Management |
| 切换行为 | 切换时刷新侧边栏菜单，当前编辑页面不受影响 |
| Receptionist | 仅看到 Clinical 模式的子集 (患者管理 CRU + 读卡器 + 未完成医案简要提示，无医案创建/编辑权限) |

### 4.3 菜单可见性矩阵

| 菜单项 | Clinical | Management | 角色约束 |
|--------|----------|------------|---------|
| 患者管理 | 可见 | 可见 | 所有角色 |
| 医案管理 | 可见 | 可见 | Doctor+ |
| 验方管理 | 可见 | 可见 | Doctor+ |
| 打印 | 可见 | 可见 | Doctor+ |
| 药材管理 | 隐藏 | 可见 | Admin+ |
| 用户管理 | 隐藏 | 可见 | Admin+ |
| 数据同步 | 隐藏 | 可见 | Admin+ |
| 系统健康 | 隐藏 | 可见 | Admin+ |
| 系统设置 | 隐藏 | 可见 | SuperAdmin |

## 5. 通用交互模式

### 5.1 加载状态

| 场景 | 展示方式 |
|------|---------|
| 页面初始加载 | 骨架屏 (Skeleton) 或居中 Spinner |
| 列表刷新/搜索 | 表格区域半透明遮罩 + Spinner |
| 表单提交 | 保存按钮禁用 + 显示加载动画 |
| 导入处理 | 进度条 (如果可确定进度) 或 Spinner (不确定进度) |

### 5.2 空状态

| 场景 | 展示内容 |
|------|---------|
| 列表无数据 | 图标 + "暂无数据" + 新增按钮 |
| 搜索无结果 | 图标 + "未找到匹配结果" + 建议修改搜索条件 |
| 患者无医案 | "该患者暂无诊疗记录" + "创建医案"按钮 |

### 5.3 键盘快捷键

| 快捷键 | 功能 | 范围 |
|--------|------|------|
| Ctrl+S | 保存当前表单 | 编辑页 |
| Ctrl+N | 新建记录 | 列表页 |
| Escape | 取消编辑 / 关闭对话框 | 全局 |
| F5 | 刷新当前列表 | 列表页 |
| Delete | 删除选中记录 (触发确认) | 列表页 |
