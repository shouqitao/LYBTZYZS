# 文档归档策略

为保持文档体系精简、可追溯，所有过期或仅供历史参考的资料迁移至 `docs/reports/archive/`。归档适用场景：
- 已完成阶段（≥6 个月前）的分析/总结报告；
- 被新版本替代的指南或方案；
- 重复内容或仅保留历史痕迹的记录。

归档要求：
1. 文件移动到 `docs/reports/archive/` 后，在新索引中标注“历史归档”。
2. 如文档仍有参考价值，在正文开头添加“历史版本仅供参考”说明。
3. 若需要恢复使用，请先评估并更新内容，再迁回主目录。
