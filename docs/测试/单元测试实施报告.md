## 测试模式与最佳实践

### 1. AAA 模式
所有测试都遵循 Arrange-Act-Assert 模式：

```csharp
[Fact]
public async Task GetUsers_WithValidParameters_ReturnsOkResult()
{
    // Arrange - 准备测试数据和环境
    var expectedData = new PaginatedResult<UserDto> { ... };
    _mockService.Setup(x => x.GetPagedAsync(...)).ReturnsAsync(expectedData);
    
    // Act - 执行被测试的方法
    var result = await _controller.GetUsers(1, 10);
    
    // Assert - 验证结果
    result.Should().BeOfType<OkObjectResult>();
}
```

### 2. Mock 使用
使用 Moq 框架隔离依赖：

```csharp
_mockUserService.Setup(x => x.GetByIdAsync(It.IsAny<Guid>()))
    .ReturnsAsync(new UserDto { ... });
```

### 3. FluentAssertions
使用流式断言提高可读性：

```csharp
result.Should().NotBeNull();
result.IsSuccessStatusCode.Should().BeTrue();
result.Content.Should().HaveCount(2);
```

## 运行测试

### 命令行运行

```bash
# 运行所有测试
dotnet test

# 运行特定项目的测试
dotnet test tests/Backend/LYBT.WebAPI.Tests

# 运行并生成覆盖率报告
dotnet test /p:CollectCoverage=true
```

### Visual Studio 运行

1. 打开测试资源管理器：`测试` > `测试资源管理器`
2. 运行所有测试：点击“运行所有测试”按钮
3. 查看测试结果和覆盖率

## 问题与建议

### 发现的问题

1. **缺少集成测试**: 当前仅有单元测试，建议添加集成测试
2. **Repository 层未测试**: 数据访问层需要测试覆盖
3. **测试数据管理**: 缺少统一的测试数据生成器

### 改进建议

1. **添加测试数据生成器**
   ```csharp
   public class TestDataBuilder
   {
       public UserDto BuildUser() => ...
       public PatientDto BuildPatient() => ...
   }
   ```

2. **引入测试基类**
   ```csharp
   public abstract class TestBase
   {
       protected Mock<ILogger<T>> CreateLogger<T>() => ...
       protected void AssertServiceResult(ServiceResult result) => ...
   }
   ```

3. **添加持续集成**
   - 配置 GitHub Actions 或 Azure DevOps
   - 自动运行测试并生成覆盖率报告
