### 常见问题

**Q: 测试失败提示API服务未运行**
A: 确保先启动API服务，或使用脚本中的自动启动选项

**Q: Python测试提示缺少requests库**
A: 运行 `pip install requests` 安装依赖

**Q: .NET测试提示找不到项目**
A: 确保在项目根目录执行测试脚本
