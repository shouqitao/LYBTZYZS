## 注意事项 ⚠️

1. **优先级说明**
   - 🔴 必须完成（影响核心流程）
   - 🟡 应该完成（影响用户体验）
   - 🟢 可以延后（增值功能）

2. **依赖关系**
   - Auth/Users必须最先完成
   - Herbs必须在Prescriptions之前
   - MedicalCase依赖Registration
   - Pharmacy依赖Prescriptions

3. **风险点**
   - 库存并发控制
   - 事务一致性
   - 状态机设计
   - 性能优化
