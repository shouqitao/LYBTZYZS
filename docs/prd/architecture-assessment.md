# 架构适配性审查 PRD（MCP 优先）

## 背景与目标
- 基于“凌隐宝堂中医诊所”真实代码，对当前架构进行静态适配性评估。
- 识别缺失与过度设计，给出整改优先级与最小变更包建议（不改业务逻辑）。

## 范围与不做什么
- 范围：分层与模块边界、依赖方向、横切能力、数据与事务、配置与环境、通信与接口、构建与部署、测试与门禁、文档链路。
- 不做：任何业务逻辑改动与删除。

## 方法与工具（MCP 优先）
- 代码导航：repo/index, repo/grep, symbol/index
- 依赖分析：dependency/graph, dependency/cycles
- 质量门禁：ci/config/read, test/coverage/read
- 文档脚手架：docs/scaffold, docs/toc（若不可用则记录回退）

## 非功能需求基线（待确认）
- 可用性：SLA/容灾等级；性能：QPS/延迟目标；扩展性：水平扩展/多实例；安全：鉴权/合规；可观测性：日志/指标/追踪最小接入。

## 验收
- 形成《overview》《audit-report》与索引更新；每条结论附代码证据（文件:起始行）与 MCP 命令摘要。
