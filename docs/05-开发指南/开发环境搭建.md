## 环境要求

### 系统要求
- **操作系统**: Windows 10/11 (64位)
- **处理器**: Intel i5 或同等性能处理器
- **内存**: 最低8GB，推荐16GB
- **存储**: 至少100GB可用空间
- **网络**: 稳定的互联网连接

### 软件依赖
- **.NET 8.0 SDK**: 最新版本
- **Visual Studio 2022**: Professional或以上版本
- **SQL Server 2019**: Developer或Express版本
- **Git**: 最新版本
- **Node.js**: v18+（用于前端工具）

## 快速安装步骤

### 1. 安装开发工具

```bash
# 安装 .NET 8 SDK
winget install Microsoft.DotNet.SDK.8

# 安装 Visual Studio 2022
winget install Microsoft.VisualStudio.2022.Professional

# 安装 Git
winget install Git.Git

# 安装 SQL Server 2019
winget install Microsoft.SQLServer.2019.Developer
```

### 2. 克隆项目代码

```bash
# 克隆项目
git clone https://github.com/your-org/LYBTZYZS.git
cd LYBTZYZS

# 安装依赖
dotnet restore LYBT.All.sln
```

### 3. 配置数据库

```bash
# 创建数据库
dotnet ef database update --project src/Backend/Core/LYBT.Infrastructure --startup-project src/Backend/Services/LYBT.WebAPI
```

### 4. 启动项目

```bash
# 启动后端API
dotnet run --project src/Backend/Services/LYBT.WebAPI

# 启动前端应用（另开窗口）
dotnet run --project src/Frontend/Desktop/Shell/LYBT.WPF.Client.Shell
```
