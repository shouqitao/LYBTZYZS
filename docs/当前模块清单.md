# 凌隐宝堂中医诊所系统 - 当前模块清单

更新时间：2025-01-08

## 一、当前有效模块（13个）

### 核心模块
1. **LYBT.Infrastructure** - 基础设施层（数据访问、日志等）
2. **LYBT.Models** - 领域模型层
3. **LYBT.Shared.Models** - 共享DTO模型

### 业务模块（10个）

#### 1. 基础管理模块
- **Auth** - 身份认证和授权
- **Users** - 用户管理  
- **Patients** - 患者档案管理
- **Doctors** - 医生管理

#### 2. 诊疗核心模块  
- **Consultation** - 看诊管理（核心模块，支持中医四诊）
- **MedicalCase** - 医疗案例（统一管理整个诊疗流程）
- **Prescriptions** - 处方管理
- **Formula** - 验方管理（新增）

#### 3. 药材管理模块
- **Herbs** - 中药材管理
- **Pharmacy** - 药房管理

#### 4. 业务支撑模块
- **Queueing** - 排队叫号（工作流协调器）
- **Cashier** - 收银结算

#### 5. 保留但未完全实现的模块
- **FormulaTemplates** - 验方模板（保留，待整合到Formula）

## 三、模块职责说明

### 核心业务流程（简化后）
```
患者建档(Patients) → 排队(Queueing) → 看诊(Consultation) → 
开处方(Prescriptions) → 缴费(Cashier) → 药房(Pharmacy)
```

### 关键设计特点
1. **MedicalCase** 作为统一的病例管理器，贯穿整个诊疗流程
2. **Consultation** 是诊疗核心，集成了中医四诊功能
3. **Queueing** 作为工作流协调器，管理各环节的排队叫号
4. **Cashier** 统一处理所有收费相关业务
5. **Formula** 管理验方和方剂
