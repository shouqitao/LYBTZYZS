## 二、认证授权模块

### 2.1 用户登录功能

#### 2.1.1 功能描述
用户通过用户名和密码登录系统，系统验证身份并建立用户会话。

#### 2.1.2 输入输出
**输入参数**:
- 用户名（必填，字符串，3-20字符）
- 密码（必填，字符串，6-20字符）
- 记住我（可选，布尔值）

**输出结果**:
- 登录成功：用户信息、权限列表、会话Token
- 登录失败：错误消息、失败原因

#### 2.1.3 业务规则
- 用户名不区分大小写
- 密码连续错误3次锁定账户30分钟
- 记住我功能保持7天免登录
- 同一用户只能在一个客户端登录

#### 2.1.4 界面原型
```
┌─────────────────────────────┐
│        凌隐宝堂诊所         │
│       管理系统登录          │
├─────────────────────────────┤
│ 用户名: [________________] │
│ 密码:   [________________] │
│ □ 记住我                    │
│                             │
│   [登录]      [重置]        │
│                             │
│ 忘记密码? 联系管理员         │
└─────────────────────────────┘
```

## 三、患者管理模块

### 3.1 患者档案管理

#### 3.1.1 功能描述
建立和维护患者的完整档案信息，支持患者信息的录入、修改、查询和统计。

#### 3.1.2 数据结构
**患者基本信息**:
```json
{
  "patientId": "GUID",
  "patientNo": "P20250806001",
  "name": "张三",
  "gender": "男",
  "age": 35,
  "birthDate": "1988-03-15",
  "idCard": "110101198803151234",
  "phone": "13812345678",
  "address": "北京市朝阳区xxx路xxx号",
  "emergencyContact": "李四",
  "emergencyPhone": "13987654321",
  "bloodType": "A型",
  "maritalStatus": "已婚",
  "occupation": "软件工程师"
}
```

**医疗信息**:
```json
{
  "medicalHistory": "高血压病史5年",
  "allergyHistory": "青霉素过敏",
  "familyHistory": "父亲有糖尿病史",
  "constitution": "气虚质",
  "firstVisitDate": "2025-08-06",
  "lastVisitDate": "2025-08-06",
  "totalVisits": 1,
  "remark": "患者情况特殊，需要重点关注"
}
```

#### 3.1.3 核心功能
**F3.1.1 新增患者档案**
- **触发条件**: 前台人员选择"新增患者"
- **处理过程**: 
  1. 系统生成患者编号
  2. 录入患者基本信息
  3. 录入医疗背景信息
  4. 验证数据完整性
  5. 保存患者档案
- **验收标准**: 患者信息完整保存，编号唯一

**F3.1.2 修改患者信息**
- **触发条件**: 授权用户选择"编辑患者"
- **处理过程**: 
  1. 查询现有患者信息
  2. 允许修改可变字段
  3. 记录修改日志
  4. 保存修改结果
- **验收标准**: 信息修改成功，日志记录完整

**F3.1.3 患者信息查询**
- **查询方式**: 
  - 按姓名模糊查询
  - 按患者编号精确查询
  - 按手机号查询
  - 按身份证号查询
- **查询结果**: 显示患者列表，支持分页
- **查询性能**: 查询响应时间<3秒

### 3.2 患者统计分析

#### 3.2.1 统计维度
- **年龄分布**: 按年龄段统计患者数量
- **性别分布**: 男女患者比例
- **地区分布**: 按住址统计患者来源
- **初复诊**: 初诊、复诊患者统计
- **就诊频次**: 患者就诊次数统计

#### 3.2.2 报表功能
**患者统计报表**:

## 五、处方管理模块

### 5.1 处方开具功能

#### 5.1.1 功能描述
医生根据诊断结果开具中药处方，系统提供处方模板和智能提醒功能。

#### 5.1.2 处方结构
**处方头信息**:
```json
{
  "prescriptionId": "GUID",
  "prescriptionNo": "F20250806001",
  "patientId": "GUID",
  "doctorId": "GUID",
  "recordId": "GUID",
  "prescriptionDate": "2025-08-06",
  "diagnosis": "头痛（气血虚弱型）"
}
```

**处方内容**:
```json
{
  "herbs": [
    {
      "herbId": "GUID",
      "herbName": "党参",
      "dosage": 15,
      "unit": "克",
      "usage": "先煎",
      "remark": ""
    },
    {
      "herbId": "GUID", 
      "herbName": "白术",
      "dosage": 10,
      "unit": "克",
      "usage": "后下",
      "remark": ""
    }
  ],
  "dosageCount": 7,
  "cookingMethod": "水煎服，每日一剂，分早晚两次温服",
  "precautions": "忌食生冷、油腻食物",
  "totalPrice": 85.50

```

#### 5.1.3 处方功能
**F5.1.1 选择药材**
- **药材搜索**: 支持拼音、汉字搜索药材
- **药材分类**: 按功效分类浏览药材
- **常用药材**: 显示医生常用药材列表
- **药材信息**: 显示药材功效、用法、禁忌

**F5.1.2 设置剂量**
- **剂量输入**: 输入药材用量
- **单位选择**: 克、两、钱等单位
- **剂量检查**: 检查剂量是否合理
- **自动计算**: 计算总重量和价格

**F5.1.3 配伍检查**
- **配伍禁忌**: 检查药材配伍禁忌
- **剂量警告**: 超量或不足的剂量提醒
- **相互作用**: 提示药材相互作用
- **过敏提醒**: 根据患者过敏史提醒

### 5.2 验方模板功能

#### 5.2.1 功能描述
系统提供常用验方模板，医生可以基于模板快速开具处方，也可以保存个人经验方。

#### 5.2.2 模板分类
**经典验方**:
- 补中益气汤
- 四君子汤  
- 四物汤
- 六味地黄丸
- 逍遥散

**个人验方**:
- 医生个人总结的经验方
- 支持创建、修改、删除
- 可以设置使用频次
- 支持验方分享

**科室验方**:
- 科室内共享的验方
- 按疾病分类管理
- 支持验方评价
- 定期更新优化

#### 5.2.3 模板操作
**F5.2.1 应用模板**
- **模板搜索**: 按名称、功效搜索模板
- **一键应用**: 将模板应用到当前处方
- **修改调整**: 基于模板调整药材和剂量
- **保存为新方**: 将修改后的处方保存为新模板

**F5.2.2 管理模板**
- **创建模板**: 将当前处方保存为模板
- **编辑模板**: 修改已有模板内容
- **删除模板**: 删除不需要的模板
- **模板分类**: 对模板进行分类管理

## 六、药房管理模块

### 6.1 库存管理功能

#### 6.1.1 功能描述
管理中药材的库存信息，包括入库、出库、盘点、调拨等操作。

#### 6.1.2 药材档案
**基本信息**:
```json
{
  "herbId": "GUID",
  "herbName": "党参",
  "category": "补益类",
  "origin": "山西",
  "specification": "统装",
  "unit": "克",
  "purchasePrice": 0.08,
  "salePrice": 0.12,
  "supplier": "北京同仁堂",
  "barcode": "6901234567890"
}
```

**库存信息**:
```json
{
  "currentStock": 5000,
  "minStock": 500,
  "maxStock": 10000,
  "lastPurchaseDate": "2025-08-01",
  "lastSaleDate": "2025-08-06",
  "expiryDate": "2026-07-31",
  "batchNumber": "20250801001",
  "storageLocation": "A区-1架-3层"
}
```

#### 6.1.3 库存操作
**F6.1.1 入库管理**
- **采购入库**: 记录采购药材的入库信息
- **退货入库**: 处理退货药材的入库
- **调拨入库**: 从其他库房调入的药材
- **盘盈入库**: 盘点发现的盘盈药材

**F6.1.2 出库管理**
- **销售出库**: 配药时的药材出库
- **报损出库**: 过期、损坏药材的出库
- **调拨出库**: 调出到其他库房的药材
- **盘亏出库**: 盘点发现的盘亏药材

**F6.1.3 库存查询**
- **库存明细**: 查询药材的详细库存信息
- **库存汇总**: 按类别统计库存金额
- **低库存报警**: 显示低于最低库存的药材
- **过期药材**: 查询即将过期的药材

### 6.2 配药管理功能

#### 6.2.1 功能描述
根据处方进行药材配置，确保配药的准确性和效率。

#### 6.2.2 配药流程
**F6.2.1 接收处方**
- **处方队列**: 显示待配药的处方列表
- **处方详情**: 查看处方的详细内容
- **优先级管理**: 支持紧急处方优先处理
- **配药分配**: 将处方分配给配药员

**F6.2.2 配药操作**
- **药材定位**: 根据储位快速找到药材
- **称重配药**: 按处方剂量称重配药
- **复核检查**: 配药完成后的复核确认
- **包装标识**: 药材分包装和标识

**F6.2.3 质量控制**
- **配药检查**: 检查药材品质和数量
- **配伍检查**: 再次确认配伍无禁忌
- **标签打印**: 打印药袋标签和用法说明
- **发药确认**: 患者领药时的确认

## 七、收费结算模块

### 7.1 费用计算功能

#### 7.1.1 功能描述
根据患者的诊疗项目和药材费用，自动计算应收金额。

#### 7.1.2 收费项目
**诊疗费用**:
```json
{
  "registrationFee": 10.00,
  "consultationFee": 50.00,
  "treatmentFee": 0.00,
  "materialFee": 0.00
}
```

**药材费用**:
```json
{
  "prescriptionFee": 85.50,
  "processingFee": 5.00,
  "packagingFee": 2.00,
  "deliveryFee": 0.00
}
```

#### 7.1.3 费用规则
- **挂号费**: 按医生级别收取不同费用
- **诊疗费**: 根据诊疗项目收费
- **药费**: 按药材实际用量计算
- **优惠折扣**: 支持会员折扣和特殊优惠

### 7.2 支付管理功能

#### 7.2.1 支付方式
- **现金支付**: 传统现金收款方式
- **银行卡支付**: POS机刷卡支付
- **移动支付**: 微信、支付宝扫码支付
- **医保支付**: 医保卡刷卡支付(预留接口)

#### 7.2.2 支付流程
**F7.2.1 费用确认**

- **支付选择**: 选择支付方式

**F7.2.2 收款处理**
- **金额输入**: 输入实收金额
- **找零计算**: 自动计算找零金额
- **支付确认**: 确认支付成功
- **凭证打印**: 打印收费凭证

**F7.2.3 退款处理**
- **退款申请**: 处理退款申请
- **退款审核**: 需要主管审核确认

- **退款凭证**: 打印退款凭证
