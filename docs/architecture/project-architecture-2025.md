### 模块职责定义

**Module层 (纯委托模式)**:
- 实现业务接口 (IXxxService)
- 将请求委托给QueryService或BusinessService
- 统一异常处理和日志记录
- 不包含任何业务逻辑

**QueryService层 (查询专业化)**:
- 复杂查询和搜索功能
- 分页、筛选、统计功能
- 报表数据处理
- 只读操作，不涉及数据修改

**BusinessService层 (业务+CRUD)**:
- 基础CRUD操作 (Create, Update, Delete)
- 复杂业务流程编排
- 数据验证和业务规则
- 事务管理和状态转换
