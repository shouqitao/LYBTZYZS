# 模块功能定位 - 最终版

## 一、核心职责定位

### 1. Auth（身份认证）
- JWT令牌生成与验证
- 登录/登出管理
- 密码加密与验证
- SysAdmin特殊处理

### 2. Users（用户管理）
- 用户CRUD操作
- 角色权限管理
- 用户状态管理
- 部门职位信息

### 3. Patients（患者档案）
- 患者基础信息管理
- 过敏史记录
- 联系方式管理
- 就诊历史索引（不含详细内容）

### 4. Doctors（医生管理）
- 医生基础信息
- 专长领域
- 执业证号
- 职称信息

### 5. Registration（挂号预约）
- 挂号登记
- 预约管理
- 挂号费用设置
- 号源状态管理
- **注：不包含排班功能**

### 6. Queueing（统一排队系统）
- 看诊排队
- 收费排队
- 取药排队
- 理疗排队
- 叫号管理
- 队列状态维护

### 7. MedicalCase（医疗案例-聚合根）⭐
**职责**：管理完整就诊流程
```csharp
MedicalCase {
    Guid Id
    Guid PatientId              // 患者
    Guid DoctorId               // 主治医生
    Guid RegistrationId         // 挂号信息
    Guid? ConsultationId        // 看诊记录
    Guid? TreatmentPlanId       // 治疗方案
    Guid? PharmacyRecordId      // 药房发药记录
    Guid? TreatmentRoomId       // 理疗室记录
    MedicalCaseStatus Status    // 状态管理
    DateTime CreateTime
    DateTime? UpdateTime
}

enum MedicalCaseStatus {
    Registered,      // 已挂号
    Waiting,         // 等待就诊
    InConsultation,  // 就诊中
    Prescribed,      // 已开处方
    Paid,           // 已缴费
    Dispensed,      // 已发药
    InTreatment,    // 理疗中
    Completed       // 已完成
}
```

### 8. Consultation（看诊记录）
- 主诉、现病史

- 体格检查
- 中医四诊（望闻问切）

## 三、业务流程

```
1. 患者到院
     ↓
2. Registration（挂号）→ 创建 MedicalCase
     ↓
3. Queueing（看诊排队）
     ↓
4. Consultation（医生看诊）→ 更新 MedicalCase
     ↓
5. TreatmentPlan（制定方案）
     ├→ Prescriptions（开具处方）
     │    └→ 引用Formula（验方）
     └→ 理疗项目
     ↓
6. Queueing（收费排队）
     ↓
7. Cashier（收费结算）
     ↓
8. Queueing（取药排队）
     ↓
9. Pharmacy（发药）
     ├→ 扣减 Herbs.Stock
     ├→ 记录 PharmacyLog
     └→ 更新 MedicalCase.PharmacyRecordId
     ↓
10. Queueing（理疗排队，如需要）
     ↓
11. TreatmentRoom（理疗执行）
     └→ 更新 MedicalCase.TreatmentRoomId
```

## 五、关键设计决策

### 1. Herbs与Pharmacy的职责划分（方案C）
- **Herbs**：管理"有什么药"和"还剩多少"（状态）
- **Pharmacy**：管理"如何发药"和"库存如何变动"（行为）

### 2. TreatmentPlan与Prescriptions的关系
- **TreatmentPlan**：总体方案，包含处方ID和理疗项目
- **Prescriptions**：处方详细内容管理

### 3. Formula与Prescriptions的关系
- **Formula**：验方模板，可被多个处方引用
- **Prescriptions**：可引用多个验方组合，也可保存为新验方

### 4. MedicalCase的聚合范围
- 包含完整就诊流程的关键ID
- 增加PharmacyRecordId和TreatmentRoomId
- 维护就诊流程状态机

### 5. Registration简化
- 不包含医生排班功能
- 专注于挂号和预约管理

## 六、技术实现要点

### 验方与处方的关系实现
```csharp
// 处方服务
public class PrescriptionService {
    // 从验方创建处方
    public async Task<PrescriptionModel> CreateFromFormulas(
        List<Guid> formulaIds, 
        Guid medicalCaseId) 
    {
        var prescription = new PrescriptionModel();
        var allHerbs = new Dictionary<string, PrescriptionItem>();
        
        foreach (var formulaId in formulaIds) {
            var formula = await _formulaService.GetById(formulaId);
            foreach (var herb in formula.Herbs) {
                // 智能合并重复药材
                MergeHerbItem(allHerbs, herb);
            }
        }
        
        prescription.Items = allHerbs.Values.ToList();
        prescription.FormulaIds = formulaIds;
        return prescription;
    }
    
    // 保存处方为验方
    public async Task<FormulaModel> SaveAsFormula(
        Guid prescriptionId, 
        string formulaName) 
    {
        var prescription = await GetById(prescriptionId);
        var formula = new FormulaModel {
            Name = formulaName,
            Herbs = prescription.Items.Select(i => new FormulaHerbItem {
                HerbId = i.HerbId,
                HerbName = i.HerbName,
                Quantity = i.Quantity,
                Unit = i.Unit
            }).ToList(),
            CreatedById = prescription.DoctorId
        };
        
        return await _formulaService.Create(formula);
    }
}
```

### 库存操作的事务一致性
```csharp
// Pharmacy发药服务
public async Task<Guid> DispenseMedicine(Guid prescriptionId, Guid medicalCaseId)
{
    using (var transaction = await _context.BeginTransactionAsync())
    {
        try
        {
            // 1. 获取处方项目
            var items = await GetPrescriptionItems(prescriptionId);
            
            // 2. 创建发药记录
            var pharmacyRecord = new PharmacyRecord {
                Id = Guid.NewGuid(),
                PrescriptionId = prescriptionId,
                MedicalCaseId = medicalCaseId,
                Status = DispenseStatus.Processing
            };
            
            // 3. 检查并扣减库存
            foreach (var item in items)
            {
                var herb = await _herbRepository.GetById(item.HerbId);
                if (herb.Stock < item.Quantity)
                    throw new InsufficientStockException($"药材{herb.Name}库存不足");
                    
                var stockBefore = herb.Stock;
                herb.Stock -= item.Quantity;
                await _herbRepository.Update(herb);
                
                // 4. 记录库存变动
                await _pharmacyLogRepository.Add(new PharmacyLog
                {
                    HerbId = item.HerbId,
                    Type = OperationType.Dispense,
                    Quantity = -item.Quantity,
                    StockBefore = stockBefore,
                    StockAfter = herb.Stock,
                    RelatedId = pharmacyRecord.Id
                });
            }
            
            // 5. 更新发药记录状态
            pharmacyRecord.Status = DispenseStatus.Completed;
            await _pharmacyRepository.Add(pharmacyRecord);
            
            // 6. 更新MedicalCase
            var medicalCase = await _medicalCaseRepository.GetById(medicalCaseId);
            medicalCase.PharmacyRecordId = pharmacyRecord.Id;
            medicalCase.Status = MedicalCaseStatus.Dispensed;
            await _medicalCaseRepository.Update(medicalCase);
            
            await transaction.CommitAsync();
            return pharmacyRecord.Id;
        }
        catch
        {
            await transaction.RollbackAsync();
            throw;
        }
    }
}
```
