## 系统架构概览

LYBTZYZS采用现代化的.NET技术栈，基于清洁架构原则设计，实现前后端分离、模块化开发的企业级应用架构。

## 核心技术栈

### 后端技术
- **.NET 8.0**: 最新的.NET平台
- **ASP.NET Core Web API**: RESTful服务
- **Entity Framework Core 8.0**: ORM数据访问
- **SQL Server 2019+**: 关系型数据库
- **AutoMapper**: 对象映射
- **JWT Bearer**: 身份认证

### 前端技术  
- **WPF (.NET 8)**: Windows桌面应用
- **Prism.DryIoc**: MVVM框架
- **Material Design**: UI设计语言
- **Refit**: HTTP客户端
- **CommunityToolkit.Mvvm**: MVVM工具

### 开发工具
- **Visual Studio 2022**: 开发IDE  
- **SQL Server Management Studio**: 数据库管理
- **Git + GitHub**: 版本控制
- **Postman**: API测试

## 架构设计原则

1. **关注点分离**: 清晰的层次结构，各层职责明确
2. **依赖倒置**: 高层模块不依赖低层模块
3. **单一职责**: 每个类和方法职责单一
4. **开闭原则**: 对扩展开放，对修改封闭
5. **接口隔离**: 客户端不应依赖它不需要的接口
