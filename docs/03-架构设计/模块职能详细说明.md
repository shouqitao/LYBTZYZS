# 模块职能详细说明

## 第1周：基础设施层

### 1.1 Auth模块（身份认证）

#### 核心职能
- **身份验证**：用户名密码验证、JWT令牌生成
- **会话管理**：登录状态维护、令牌刷新、登出处理
- **安全控制**：密码加密、令牌过期、防暴力破解

#### 主要接口
```csharp
IAuthService {
    Task<LoginResponse> Login(LoginRequest request);
    Task<bool> Logout(string token);
    Task<TokenResponse> RefreshToken(string refreshToken);
    Task<bool> ValidateToken(string token);
    Task<bool> ChangePassword(ChangePasswordRequest request);
}
```

#### 数据实体
```csharp
LoginRequest {
    string Username
    string Password
    bool RememberMe
}

LoginResponse {
    string Token
    string RefreshToken
    DateTime ExpiresAt
    UserInfo User
}
```

#### 业务规则
- 密码错误3次锁定15分钟
- JWT有效期：普通8小时，记住我30天
- 支持SysAdmin特殊账户（从AdminSecrets表验证）

#### 核心职能
- **用户管理**：创建、修改、删除、查询用户
- **角色权限**：角色分配、权限控制
- **组织结构**：部门管理、职位设置

#### 主要接口

#### 数据实体
```csharp

    Guid Id
    string Username        // 登录名
    string RealName       // 真实姓名
    string PasswordHash   // 密码哈希

- 初始密码：姓名拼音首字母+123456

#### 核心职能

- **叫号服务**：叫号、过号、重新排队

```

#### 数据实体
```csharp
QueueingModel {
    Guid Id
    QueueType Type        // 看诊/收费/取药/理疗
    Guid RelatedId       // 关联ID（如RegistrationId）
    Guid PatientId
    int QueueNumber      // 排队号
    Guid? RoomId        // 诊室/窗口ID
    QueueStatus Status   // 等待中/就诊中/已完成/已过号
    DateTime JoinTime    // 入队时间
    DateTime? CallTime   // 叫号时间
    DateTime? EndTime    // 结束时间

}

enum QueueType {
    Consultation,  // 看诊
    Payment,      // 收费
    Pharmacy,     // 取药

    Called,       // 已叫号

    Completed,    // 已完成
    Skipped,      // 已过号

}
```

#### 业务规则
- 过号3次自动取消
- 支持优先级（老人/军人/急诊）
- 实时更新等待人数
- 支持多窗口/诊室

## 总结

### 开发重点

**第1-2周（基础）**：
- 重点完成认证和基础数据
- 确保权限体系完善

**第3-4周（核心）**：
- MedicalCase是核心，必须设计好状态机
- Consultation要支持中医特色
- Formula提前开发支持处方

**第5周（关键）**：
- Prescriptions是业务核心，需要精心设计
- 智能辅助功能可以逐步完善

**第6周（闭环）**：
- 确保收费和发药流程顺畅
- 库存管理要可靠

**第7周（增值）**：
- TreatmentRoom可以简化实现
- 主要功能完成即可

### 技术要点

1. **事务一致性**：发药扣库存、收费等需要事务
2. **状态机管理**：MedicalCase状态流转要严格
3. **库存并发**：考虑并发扣减问题
4. **数据关联**：通过ID关联，不要冗余存储
5. **历史追溯**：关键操作要有日志
