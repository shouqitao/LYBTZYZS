# PRD 总结目录

- **维护人**：Coder / QA
- **最后更新**：2025-09-25

本目录存放 PRD 完成后的总结报告，命名建议：`PRD-<topic>-<YYYYMMDD>-SUMMARY.md`。

## 使用说明
1. 完成 PRD 对应开发后，复制 `docs/prd/PRD-summary-template.md` 填写。
2. 将总结文件放置于本目录（或子目录），并在 `docs/prd/README.md` / 对应任务总结中加入链接。
3. 若总结对应历史 PRD（已归档于 `docs/reports/archive/ccpm`），请在文首注明“历史版本”。

---
> 提示：总结需包含交付成果、验收情况、遗留事项，便于后续迭代复盘。
