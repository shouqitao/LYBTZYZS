## 🎯 系统定位

### 目标用户
**简单中医诊所系统** - 适用于2-5人小型诊所团队：
- 👨‍⚕️ **中医医生**: 2-5人 (主要用户)
- 👩‍💼 **接待人员**: 1-2人 (患者管理)
- 👨‍💻 **系统管理员**: 1人 (用户权限管理)

### 业务规模
- **并发用户数**: <10人
- **日诊疗量**: <50人次
- **数据规模**: 小型 (适合单机部署)
- **技术复杂度**: 中等 (避免过度设计)

---

## 🏗️ 技术架构

### 核心技术栈
- **后端**: .NET 8 + ASP.NET Core Web API + EF Core 8.0.17
- **前端**: WPF (.NET 8) + Prism.DryIoc 8.1.97
- **数据库**: SQL Server (统一AppDbContext)
- **认证**: JWT Bearer Token + RBAC权限控制
- **API客户端**: Refit 8.0.0 (类型安全的REST客户端)

### 架构模式
- **后端**: UltraThink双层架构 (主Service纯委托 + QueryService查询层 + BusinessService业务层)
- **前端**: MVVM模式 + Prism模块化架构 + **统一IService接口体系 (2025-01-31完成)**
- **接口设计**: 彻底解决"接口重复定义横跨4层"问题，统一为IService接口架构
- **依赖注入**: 所有ViewModel使用IService接口注入，完全解耦具体实现
- **数据访问**: Repository模式 + 统一AppDbContext + 零SQL注入(LINQ)
- **模块化**: 8个核心业务模块 + 前后端分离设计 + 零编译错误质量标准

## 📋 核心业务模块

### 认证与用户管理
1. **Auth** - 身份认证与授权
   - JWT Token管理 (8小时/30天)
   - 角色权限控制 (Admin/Doctor)
   - 登录会话管理

2. **Users** - 用户管理
   - 医生/管理员账户
   - 基础权限分配
   - 密码安全策略

### 患者管理
3. **Patients** - 患者档案
   - 患者基础信息CRUD
   - 导入导出功能 (Excel/CSV)
   - 基础搜索和筛选
   - 就诊历史关联

### 诊疗核心流程
4. **MedicalCase** - 医疗案例管理
   - 诊疗流程容器 (1:1关联Consultation)
   - 状态管理: Registered → InProgress → Completed
   - 患者就诊记录聚合

5. **Consultation** - 看诊诊断
   - 中医四诊记录 (望闻问切)
   - 症状分析和诊断结果
   - 辨证论治过程记录

6. **Prescriptions** - 处方管理
   - 智能处方开具 (IntelligentPrescriptionService)
   - 验方模板智能应用和推荐
   - 药材配伍安全检查 (十八反十九畏)
   - 处方费用自动计算
   - 标准格式打印输出

### 中药材与验方
7. **Herbs** - 中药材管理
   - 药材基础信息CRUD (名称、单价、用法)
   - 智能拼音码自动生成 (中文字符转换)
   - 批量导入导出功能 (Excel/CSV)
   - 处方用药选择支持 (不含库存管理)
   - 药材状态管理和软删除

8. **Formula** - 验方管理
   - 经典验方模板库管理
   - 智能症状匹配推荐算法
   - 验方安全性和复杂度分析
   - 个人验方收藏和分类
   - 验方复制和调整功能
   - **已知问题**: 基础CRUD功能待完善

## 🔄 核心业务流程

### 标准诊疗流程
```
患者接待(Patients) → 创建医案(MedicalCase) → 看诊记录(Consultation) → [可选]开具处方(Prescriptions) → 完成医案
```

### 业务规则
- **医案管理**: 每次就诊创建新的MedicalCase，通过PatientId关联历史
- **诊断记录**: 一个MedicalCase对应一个Consultation (1:1关系)
- **处方开具**: 可选流程，支持验方组合和药材配伍检查
- **数据关联**: 所有模块通过Patient关联，形成完整病历

## 🎯 功能范围定义

### ✅ 当前支持功能 (v1.0)
- **患者管理**: 基础CRUD + 批量导入导出 + 高级搜索
- **诊疗记录**: 中医四诊记录 + 辨证论治 + 医案聚合
- **智能处方**: 智能开方系统 + 验方推荐 + 配伍检查 + 费用计算
- **药材管理**: 完整CRUD + 拼音码生成 + 批量操作 + 状态管理
- **验方管理**: 智能推荐算法 + 安全分析 + 模板库管理
- **用户管理**: 医生/管理员角色 + 权限控制 + 密码策略
- **系统安全**: JWT认证 + RBAC权限 + 零SQL注入 + 操作审计

### ❌ 明确不支持功能 (避免过度设计)
- **复杂统计分析**: 不适合小诊所规模，避免使用复杂度
- **企业级权限管理**: 复杂的角色权限树，小团队不需要
- **高级工作流引擎**: 固定的诊疗流程已足够
- **药材库存管理**: 药材信息仅用于处方开具，不管理库存
- **财务收费模块**: 挂号收费等功能计划v2.0开发
- **多租户支持**: 当前专注单诊所部署

### 🔮 计划功能 (v2.0)
- **挂号管理**: 预约挂号和排队功能
- **收费管理**: 诊疗费用和药材费用计算
- **报表统计**: 简化的诊疗统计报表
- **数据备份**: 自动备份和恢复功能

## 📊 数据模型关系

### 核心实体关系
```
User (用户)
  ├── MedicalCase (医案) - 创建者关系
  
Patient (患者)  
  ├── MedicalCase (医案) - 1:N 关系
  
MedicalCase (医案)
  ├── Consultation (诊断) - 1:1 关系
  └── Prescription (处方) - 1:N 关系
  
Prescription (处方)
  ├── PrescriptionItem (处方项) - 1:N 关系
  └── Formula (验方) - N:N 关系
  
PrescriptionItem (处方项)
  └── Herb (药材) - N:1 关系
```

### 数据完整性
- **引用完整性**: 所有外键约束
- **业务完整性**: 状态转换规则
- **数据一致性**: 事务处理保证
- **历史数据**: 软删除策略，保留诊疗记录
