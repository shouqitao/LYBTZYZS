## 📊 需求概览

### 系统定位
- **用户规模**: 2-5人小型中医诊所
- **系统类型**: 简单诊所实用管理系统 (非企业级平台)
- **技术复杂度**: 中等 (避免过度设计)

### 核心功能模块 (8个)
1. **Auth** - 身份认证与授权
2. **Users** - 用户管理  
3. **Patients** - 患者档案
4. **MedicalCase** - 医疗案例
5. **Consultation** - 看诊诊断
6. **Prescriptions** - 处方管理
7. **Herbs** - 中药材管理
8. **Formula** - 验方管理

### 技术架构
- **后端**: .NET 8 + ASP.NET Core + EF Core + SQL Server
- **前端**: WPF + Prism.DryIoc + Refit
- **架构模式**: UltraThink双层架构 (QueryService + BusinessService)
- **部署方式**: 传统IIS + Windows Server

### 质量标准
- **编译质量**: 零编译警告零错误
- **性能要求**: API响应 <2秒，支持10用户并发
- **安全要求**: JWT认证 + RBAC权限 + 零SQL注入
- **维护要求**: 适合小团队维护的技术复杂度

### v2.0 需求规划
- 🔮 **新增功能**: 15个计划功能 (挂号收费、报表统计等)
- 🔮 **技术升级**: 单元测试覆盖率60%、自动化部署
- 🔮 **性能优化**: 数据库索引优化、高级缓存策略

### 已移除需求 (避免过度设计)
- ❌ **AI智能功能**: 过度设计，维护成本高
- ❌ **复杂统计分析**: 不适合小诊所，增加使用复杂度
- ❌ **企业级权限管理**: 小团队不需要复杂权限树
- ❌ **批量操作功能**: 小诊所数据量少，不需要
- ❌ **Coordinator抽象层**: 3,134行冗余代码，完全未使用
