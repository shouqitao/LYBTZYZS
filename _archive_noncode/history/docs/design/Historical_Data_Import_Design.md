# 历史数据导入功能设计规范

## 一、功能概述

### 1.1 设计理念
- **智能导入**：默认导入到当前工作步骤
- **灵活选择**：支持跨阶段导入到指定步骤
- **数据追加**：不覆盖现有数据，追加并标记来源
- **跨患者借鉴**：支持查询其他患者的成功案例

## 三、数据导入规则

### 3.1 导入位置映射

| 当前位置 | 默认导入内容 | 可选导入 |
|---------|------------|---------|
| 四诊采集 | 四诊信息 | 诊断、处方 |
| 辨证分析 | 诊断结果 | 四诊、处方 |
| 处方开具 | 处方内容 | 四诊、诊断 |

### 3.2 数据追加规则

#### 四诊信息追加
```
原内容：面色苍白
导入后：面色苍白
       [导入自2024-12-20就诊：面色潮红，舌红苔黄]
```

#### 处方追加（多来源）
```
【当前处方】
麻黄 10g  桂枝 15g

【小柴胡汤】（来源：经典验方）
柴胡 24g  黄芩 9g  人参 9g

【加味】（来源：2024-12-20历史处方）
白术 15g  茯苓 20g
```

### 3.3 冲突处理

| 场景 | 处理方式 |
|-----|---------|
| 四诊重复导入 | 追加显示，分段标记来源 |
| 诊断重复导入 | 并列显示多个诊断 |
| 处方药材重复 | 提示并取最小剂量 |

## 四、权限控制

### 4.1 查看权限
- **自己的患者**：完全查看
- **其他医生的患者**：需要查询权限
- **敏感信息**：脱敏显示（姓名、电话）

### 4.2 导入权限
- **当前接诊医生**：可以导入任何历史数据
- **非接诊状态**：只能查看，不能导入

## 五、性能优化

### 5.1 查询优化
- 默认显示最近5条
- 支持分页加载
- 建立诊断关键词索引
- 缓存常用查询结果

### 5.2 导入优化
- 预加载当前患者历史
- 异步加载详情
- 批量导入使用事务

## 六、审计要求

### 6.1 操作记录
记录所有导入操作：
- 操作人
- 操作时间
- 导入来源
- 导入内容

### 6.2 数据溯源
保持数据来源链：
- 原始数据不被修改
- 导入数据标记来源
- 支持查看导入历史
