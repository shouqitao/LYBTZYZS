# 凌隐宝堂中医诊所系统 - 视频教程脚本集

> **Epic 05-P0-04: 用户支持系统 - 视频教程制作**  
> 为系统关键功能模块制作详细的视频教程脚本

## 📋 教程概述

### 教程结构
- **基础操作教程** (3个): 系统登录、界面导航、基本设置
- **核心业务教程** (5个): 患者管理、看诊诊断、处方开具、药材管理、验方应用
- **高级功能教程** (2个): 数据导入导出、系统维护

### 目标用户
- **主要用户**: 中医诊所医生、接待员
- **次要用户**: 系统管理员、技术维护人员
- **学习目标**: 30分钟内掌握基础操作，1小时内熟练使用核心功能

#### 📽️ 教程01: 系统登录与首页导览

**难度**: ⭐

**脚本内容**:
