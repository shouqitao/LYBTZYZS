# LYBT.Desktop.Workbench.Cashier 收银员工作台项目文档

## 项目概览

**项目名称**: LYBT.Desktop.Workbench.Cashier  
**项目类型**: WPF收银员专用工作台  
**技术框架**: .NET 8.0, WPF, Prism.DryIoc 8.1.97  
**业务领域**: 费用结算和支付管理专用界面  
**更新时间**: 2025-09-01

## 项目定位

### 核心功能
LYBT.Desktop.Workbench.Cashier是专为收银员角色设计的费用管理工作台，提供：

1. **费用结算**: 诊疗费用计算和患者结算
2. **支付管理**: 支持多种支付方式（现金、刷卡、移动支付）
3. **收费统计**: 日常收费数据统计和财务报表
4. **退费处理**: 退费申请和退费操作管理
5. **发票打印**: 收费凭证和发票打印功能

### 业务场景
- **患者结算**: 处理患者诊疗费用和药费结算
- **日结管理**: 每日收费统计和财务对账
- **支付处理**: 处理各种支付方式和异常情况
- **财务报表**: 生成收费统计和财务分析报表
- **票据管理**: 管理发票、收据等财务票据

## 核心功能模块

### 1. 费用结算模块
- **诊疗费用计算**: 基于诊疗项目自动计算费用
- **药费统计**: 处方药材费用汇总和计算
- **优惠折扣**: 支持会员折扣和促销活动
- **费用明细**: 详细的费用组成和明细清单

### 2. 支付管理模块
- **现金支付**: 现金收费和找零管理
- **刷卡支付**: 银行卡支付处理和确认
- **移动支付**: 支付宝、微信等移动支付集成
- **支付确认**: 支付状态确认和异常处理

### 3. 财务统计模块
- **日收入统计**: 每日收费汇总和分类统计
- **支付方式统计**: 各种支付方式的收入分析
- **退费统计**: 退费金额和退费原因统计
- **财务报表**: 月度、季度财务分析报表

### 4. 票据管理模块
- **收费凭证**: 收费单据的生成和打印
- **发票管理**: 正规发票的开具和管理
- **票据查询**: 历史票据查询和重打功能
- **票据统计**: 票据使用情况统计

### 关键操作流程
1. **患者结算**: 选择患者 → 确认费用 → 选择支付方式 → 完成结算
2. **退费处理**: 查找原单据 → 确认退费原因 → 处理退费 → 打印退费凭证
3. **日结操作**: 统计当日收入 → 核对现金 → 生成日结报表 → 数据上传
