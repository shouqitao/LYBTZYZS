# LYBT.Desktop.Workbench.Pharmacist 药师工作台项目文档

## 项目概览

**项目名称**: LYBT.Desktop.Workbench.Pharmacist  
**项目类型**: WPF药师专用工作台  
**技术框架**: .NET 8.0, WPF, Prism.DryIoc 8.1.97  
**业务领域**: 药材管理和处方审核专用界面  
**更新时间**: 2025-09-01

## 项目定位

### 核心功能
LYBT.Desktop.Workbench.Pharmacist是专为药师角色设计的药材管理工作台，提供：

1. **处方审核**: 处方合理性审核和用药安全检查
2. **药材管理**: 中药材信息维护和质量控制
3. **配伍检查**: 中药配伍禁忌和相互作用检查
4. **库存监控**: 药材库存状态监控和采购建议
5. **调剂指导**: 中药调剂规范和操作指导

### 业务场景
- **处方审核**: 审核医生开具的处方，确保用药安全
- **药材维护**: 维护药材基础信息和质量标准
- **调剂作业**: 指导药材调剂和配制过程
- **质量控制**: 药材质量检查和不良反应监控
- **专业咨询**: 为患者提供中药用药指导

## 核心功能模块

### 1. 处方审核模块
- **处方检查**: 处方格式和内容完整性检查
- **用药合理性**: 中药用量、配伍合理性审核
- **禁忌检查**: 配伍禁忌和相反药物检查
- **安全提醒**: 特殊患者用药安全提醒

### 2. 药材信息管理
- **药材档案**: 中药材基本信息和性味归经
- **质量标准**: 药材质量规格和检验标准
- **供应商管理**: 药材供应商信息和资质管理
- **价格维护**: 药材采购价和销售价管理

### 3. 配伍智能分析
- **配伍禁忌**: 十八反十九畏等配伍禁忌检查
- **相互作用**: 药物相互作用分析和提醒
- **增效组合**: 药物协同增效组合推荐
- **减毒配伍**: 毒性药材的减毒配伍建议

### 4. 调剂作业指导
- **调剂流程**: 标准中药调剂操作流程
- **特殊处理**: 特殊药材的炮制和处理方法
- **用法指导**: 中药煎煮方法和服用指导
- **标签打印**: 药品标签和用药指导单打印

```

├─────────────────────────────────────────────┤

│ ├─ 张先生-感冒方     ├─ 麻黄 6g ✓               │
│ ├─ 李女士-调理方     ├─ 桂枝 9g ✓               │

```

### 关键操作流程
1. **处方审核**: 接收处方 → 审核检查 → 配伍分析 → 审核结论 → 调剂指导
2. **药材维护**: 药材查询 → 信息编辑 → 质量标准 → 供应商关联 → 保存更新
3. **配伍检查**: 选择药材 → 配伍分析 → 禁忌提醒 → 建议方案 → 生成报告
