# Task: 设计和实现智能缓存服务系统

## Description
设计分层缓存架构，实现EnhancedCacheService支持标签失效、预热机制、防缓存击穿，将缓存命中率从40%提升至80%，显著改善API响应时间。

## Acceptance Criteria
- [ ] `EnhancedCacheService` 智能缓存服务实现
- [ ] L1内存缓存 + L2分布式缓存接口预留
- [ ] 标签化缓存失效机制（按模块、按用户失效）
- [ ] 缓存预热机制在系统启动时加载热点数据
- [ ] 防缓存击穿和缓存穿透保护
- [ ] 缓存命中率统计和性能监控
- [ ] 自动缓存容量管理和内存控制

## Technical Details
- 实现位置：`src/Server/Core/LYBT.Infrastructure/Cache/EnhancedCacheService.cs`
- 核心功能：
  - `GetOrSetAsync<T>()` - 获取或设置缓存
  - `InvalidateByTagAsync()` - 按标签批量失效
  - `WarmupCacheAsync()` - 缓存预热
  - `GetCacheStatistics()` - 缓存统计信息
- 缓存策略：
  - 患者信息：30分钟，按PatientId标签
  - 药材数据：4小时，按Category标签
  - 用户数据：1小时，按UserId标签
  - 配置数据：24小时，全局标签
- 防击穿机制：
  - 分布式锁避免并发重建
  - 热点数据永不过期策略
  - 降级机制保证服务可用性
