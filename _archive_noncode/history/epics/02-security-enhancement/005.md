# Task: 实现认证API端点和中间件升级

## Description
实现双Token机制的API端点，升级现有认证中间件支持双Token验证和黑名单检查，确保API接口向后兼容且安全性得到增强。

## Acceptance Criteria
- [ ] `/api/v1/auth/refresh` Token刷新端点实现
- [ ] `/api/v1/auth/revoke` Token撤销端点实现
- [ ] `/api/v1/auth/sessions` 会话管理端点实现
- [ ] 认证中间件升级支持双Token验证
- [ ] JWT中间件集成黑名单检查
- [ ] 现有登录/登出API保持兼容性
- [ ] API响应格式统一和错误处理

## Technical Details
- API端点实现：
  - `POST /auth/refresh` - 使用Refresh Token获取新Access Token
  - `POST /auth/revoke` - 撤销指定Token（支持当前或所有）
  - `GET /auth/sessions` - 获取用户活跃会话列表
  - `DELETE /auth/sessions/{id}` - 撤销特定会话
- 中间件升级：
  - `EnhancedJwtMiddleware` - 支持双Token验证
  - `TokenBlacklistMiddleware` - 黑名单检查集成
  - 保持与现有`JwtMiddleware`接口兼容
- 错误处理：
  - 统一错误码和消息定义
  - Token过期、撤销、无效等场景区分处理
