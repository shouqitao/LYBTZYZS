# Task: 实现前端TokenManager和自动刷新机制

## Description
为WPF客户端实现智能TokenManager，支持Access Token自动刷新、多标签页状态同步、HttpOnly Cookie管理和用户无感知的Token维护。

## Acceptance Criteria
- [ ] `TokenManager` 类实现Token生命周期管理
- [ ] Access Token过期前5分钟自动刷新
- [ ] Refresh Token安全存储（模拟HttpOnly Cookie行为）
- [ ] 多应用实例间Token状态同步（进程间通信）
- [ ] HTTP拦截器升级支持自动Token刷新
- [ ] Token刷新失败时用户友好提示和重登录
- [ ] 离线/网络异常情况下的Token处理

## Technical Details
- 实现位置：`src/Client/Desktop/Common/Services/TokenManager.cs`
- 核心功能：
  - `RefreshTokenAsync()` - 自动Token刷新
  - `IsTokenExpiringSoon()` - Token过期检查（5分钟阈值）
  - `SyncTokenState()` - 多实例状态同步
  - `HandleTokenExpired()` - Token过期处理
- WPF特定实现：
  - 使用`DispatcherTimer`进行定期检查
  - `NamedPipe`或`MemoryMappedFile`进行进程间通信
  - 安全存储使用Windows `ProtectedData`
- HTTP客户端集成：
  - 升级现有Refit配置支持Token刷新
  - `DelegatingHandler`实现自动Token注入
