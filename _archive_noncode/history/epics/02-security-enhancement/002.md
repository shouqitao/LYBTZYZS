# Task: 实现增强Token服务和双Token生成

## Description
实现双Token架构的核心服务，包括Access Token(30分钟)和Refresh Token(30天)的生成、验证、刷新逻辑，确保安全性和性能要求。

## Acceptance Criteria
- [ ] `EnhancedTokenService` 实现双Token生成逻辑
- [ ] Access Token 30分钟有效期，包含用户基础信息
- [ ] Refresh Token 30天有效期，安全随机生成
- [ ] Token验证中间件支持双Token验证
- [ ] 自动Token刷新逻辑在过期前5分钟触发
- [ ] Token密钥轮换机制和向后兼容性
- [ ] 令牌负载最小化，避免敏感信息泄露

## Technical Details
- 实现位置：`src/Server/Modules/Auth/Services/EnhancedTokenService.cs`
- 核心功能：
  - `GenerateTokenPair()` - 生成Access+Refresh Token对
  - `ValidateAccessToken()` - Access Token验证
  - `ValidateRefreshToken()` - Refresh Token验证
  - `RefreshTokenPair()` - 令牌刷新操作
- Token结构：
  - Access Token: JWT格式，包含UserId、Role、设备信息
  - Refresh Token: 安全随机字符串，数据库存储
- 安全措施：
  - HMAC-SHA256签名算法
  - Token指纹验证防篡改
  - 设备绑定防跨设备攻击
