# Task: 设计双Token数据库架构和迁移

## Description
设计和实现双Token机制所需的数据库表结构，包括用户会话管理表和令牌黑名单表，添加必要的索引和约束确保查询性能。

## Acceptance Criteria
- [ ] `UserSessions` 表设计和创建，存储用户会话和Refresh Token
- [ ] `TokenBlacklist` 表设计和创建，管理撤销的令牌
- [ ] 数据库索引优化确保令牌验证 < 10ms
- [ ] EF Core迁移文件创建和测试
- [ ] 表间关系设计和外键约束
- [ ] 数据保留策略和自动清理机制
- [ ] 数据库架构文档和ERD图

## Technical Details
- 表结构设计：
  - `UserSessions`: SessionId, UserId, RefreshToken, DeviceInfo, CreatedAt, ExpiresAt, IsActive
  - `TokenBlacklist`: Id, TokenId, TokenType, RevokedAt, ExpiresAt, Reason
- 索引策略：
  - UserSessions: (UserId, IsActive), (RefreshToken), (ExpiresAt)
  - TokenBlacklist: (TokenId, TokenType), (ExpiresAt)
- 迁移文件位置：`src/Server/Core/LYBT.Infrastructure/Migrations/`
- 清理任务：过期数据自动清理策略
