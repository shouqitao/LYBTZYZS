# Task: 实现会话管理和多设备支持

## Description
实现完整的用户会话管理体系，支持多设备登录追踪、会话状态管理、强制下线和异地登录检测，提供设备管理和会话控制功能。

## Acceptance Criteria
- [ ] `SessionManagementService` 完整会话生命周期管理
- [ ] 支持多设备同时登录和设备识别
- [ ] 异地登录检测和安全提醒机制
- [ ] 管理员强制用户下线功能
- [ ] 用户主动管理活跃会话（查看、撤销设备）
- [ ] 会话超时自动清理和通知
- [ ] 会话统计和审计日志记录

## Technical Details
- 实现位置：`src/Server/Modules/Auth/Services/SessionManagementService.cs`
- 核心功能：
  - `CreateSession()` - 创建新会话
  - `GetUserActiveSessions()` - 获取用户活跃会话
  - `RevokeSession()` - 撤销特定会话
  - `RevokeAllUserSessions()` - 撤销用户所有会话
  - `DetectAnomalousLogin()` - 异常登录检测
- API端点设计：
  - `GET /api/v1/auth/sessions` - 查看活跃会话
  - `DELETE /api/v1/auth/sessions/{sessionId}` - 撤销会话
  - `POST /api/v1/auth/sessions/revoke-all` - 撤销所有会话
- 设备识别：User-Agent、IP地址、设备指纹
