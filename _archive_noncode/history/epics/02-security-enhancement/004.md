# Task: 实现令牌黑名单服务和撤销机制

## Description
实现高性能的令牌黑名单服务，支持Access Token和Refresh Token的即时撤销，结合内存缓存和数据库持久化，确保令牌撤销响应时间<1秒。

## Acceptance Criteria
- [ ] `TokenBlacklistService` 实现令牌撤销和黑名单检查
- [ ] 支持单个Token撤销和批量撤销
- [ ] 内存缓存 + 数据库持久化双层存储
- [ ] 过期Token自动清理机制
- [ ] 令牌验证中间件集成黑名单检查
- [ ] 撤销原因记录和审计追踪
- [ ] 高并发场景下的性能优化

## Technical Details
- 实现位置：`src/Server/Modules/Auth/Services/TokenBlacklistService.cs`
- 核心功能：
  - `RevokeToken()` - 撤销单个令牌
  - `RevokeTokens()` - 批量撤销令牌
  - `IsTokenBlacklisted()` - 检查令牌是否被撤销
  - `CleanupExpiredTokens()` - 清理过期黑名单记录
- 缓存策略：
  - L1缓存：内存中维护热点撤销Token列表
  - L2存储：数据库持久化完整黑名单记录
  - 缓存预热：系统启动时加载近期撤销Token
- 性能优化：
  - BloomFilter减少数据库查询
  - 异步写入数据库，同步更新缓存
