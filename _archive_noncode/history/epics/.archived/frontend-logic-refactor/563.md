# Task 006: XAML Resource Dictionary Systematic Organization

## 目标 (Objective)

重组现有UnifiedDesignSystem.xaml为逻辑模块化的资源字典系统，建立清晰的命名约定和模块化资源管理架构。

## 背景 (Background)

当前UnifiedDesignSystem.xaml文件包含所有UI资源定义，存在以下问题：
- 单一文件过于庞大，维护困难
- 资源缺乏逻辑分组和模块化
- 命名约定不统一，查找困难
- 资源依赖关系不清晰

需要重组为模块化的资源字典系统。

## 技术要求 (Technical Requirements)

### 核心技术栈
- **ResourceDictionary重构**: 模块化拆分
- **命名约定标准化**: 统一资源命名规则
- **模块化资源管理**: 逻辑分组和依赖管理
- **XAML最佳实践**: 遵循WPF资源管理规范

### 架构模式
- **模块化设计**: 按功能域拆分资源字典
- **层次化组织**: 基础资源 → 组件资源 → 主题资源
- **依赖管理**: 清晰的资源引用关系

## 实施计划 (Implementation Plan)

### Phase 1: 资源分析与规划 (6小时)
- 分析现有UnifiedDesignSystem.xaml资源分布
- 定义模块化资源字典结构
- 制定统一命名约定标准

### Phase 2: 模块化拆分 (8小时)
- 创建基础资源字典（Colors, Fonts, Sizes）
- 创建组件资源字典（Buttons, TextBoxes, etc.）
- 创建主题资源字典（Light/Dark themes）
- 建立资源引用关系

### Phase 3: 集成验证 (4小时)
- 更新应用程序资源引用
- 验证所有XAML页面资源加载
- 性能测试和优化

## 模块化资源字典结构

### 基础资源层
```
Resources/Base/
├── Colors.xaml           # 颜色定义
├── Fonts.xaml            # 字体资源
├── Sizes.xaml            # 尺寸和间距
└── Animations.xaml       # 动画资源
```

### 组件资源层
```
Resources/Controls/
├── Buttons.xaml          # 按钮样式
├── TextInputs.xaml       # 输入控件样式
├── DataGrids.xaml        # 数据网格样式
└── Navigation.xaml       # 导航控件样式
```

### 主题资源层
```
Resources/Themes/
├── LightTheme.xaml       # 浅色主题
├── DarkTheme.xaml        # 深色主题
└── ThemeManager.xaml     # 主题管理
```

## 命名约定标准

### 资源键命名规则
- **颜色**: `Color.Primary`, `Color.Secondary`, `Color.Background`
- **样式**: `Style.Button.Primary`, `Style.TextBox.Search`
- **模板**: `Template.ListItem.Patient`, `Template.Card.Medical`
- **转换器**: `Converter.BoolToVisibility`, `Converter.DateFormat`
