## 概述

当前系统依赖注入错误只能在运行时发现，导致调试困难和用户体验差。本任务将创建Roslyn分析器，在编译时验证依赖注入配置的正确性，确保所有服务依赖都能正确解析，并验证UltraThink架构模式的合规性。

## 目标

- 编译时检测未注册的依赖服务
- 验证UltraThink双层架构模式合规性
- 检测循环依赖和不当依赖关系
- 提供清晰的编译错误和修复建议

## 验证规则设计

### 依赖注入规则
```csharp
// LYBT001: 未注册服务检测
public void AnalyzeConstructorDependencies(SyntaxNodeAnalysisContext context)
{
    var constructor = (ConstructorDeclarationSyntax)context.Node;
    foreach (var parameter in constructor.ParameterList.Parameters)
    {
        var parameterType = context.SemanticModel.GetTypeInfo(parameter.Type).Type;
        if (!IsServiceRegistered(parameterType))
        {
            context.ReportDiagnostic(Diagnostic.Create(
                UnregisteredService, 
                parameter.GetLocation(), 
                parameterType.Name));
        }
    }
}

// LYBT002: UltraThink架构验证  
public void ValidateUltraThinkArchitecture(SyntaxNodeAnalysisContext context)
{
    var classDeclaration = (ClassDeclarationSyntax)context.Node;
    var className = classDeclaration.Identifier.ValueText;
    
    // 验证双层架构模式
    if (className.EndsWith("Service") && !IsValidServiceArchitecture(classDeclaration))
    {
        context.ReportDiagnostic(Diagnostic.Create(
            ArchitectureViolation,
            classDeclaration.GetLocation(),
            className,
            "Service must follow Query/Business layer pattern"));
    }
}
```
