# Task 007: Build-Time XAML Resource Validation Pipeline

## 目标 (Objective)

创建MSBuild自定义目标，在编译时验证XAML资源引用的完整性和正确性，防止运行时资源缺失错误，确保资源字典重组后的系统稳定性。

## 背景 (Background)

在Task 006完成资源字典重组后，需要建立编译时验证机制来：
- 验证XAML中的资源引用是否存在
- 检查资源依赖关系的完整性
- 防止运行时资源加载失败
- 确保资源重构不破坏现有功能

## 技术要求 (Technical Requirements)

### 核心技术栈
- **MSBuild自定义目标**: 编译时验证集成
- **PowerShell脚本**: XAML解析和验证逻辑
- **资源引用验证**: StaticResource/DynamicResource检查
- **依赖关系分析**: 资源字典间依赖验证

### 架构模式
- **编译时验证**: 构建流程集成的质量保证
- **静态分析**: XAML文件的静态解析和检查
- **错误预防**: 编译阶段发现并阻止潜在问题

## 实施计划 (Implementation Plan)

### Phase 1: 验证脚本开发 (6小时)
- 开发XAML资源引用解析脚本
- 实现资源存在性验证逻辑
- 创建资源依赖关系检查器

### Phase 2: MSBuild集成 (6小时)
- 创建MSBuild自定义目标
- 集成验证脚本到构建流程
- 配置验证错误和警告处理

### Phase 3: 测试与优化 (2小时)
- 验证构建流程集成效果
- 优化验证性能和准确性
- 添加验证结果报告功能

## 验证范围和规则

### XAML资源引用验证
- **StaticResource引用**: 验证资源键存在性
- **DynamicResource引用**: 检查运行时资源可用性
- **Style继承**: 验证BasedOn样式引用
- **模板引用**: 检查ControlTemplate/DataTemplate

### 资源字典依赖验证
- **MergedDictionaries**: 验证资源字典文件存在
- **资源重定义**: 检查资源键冲突
- **循环依赖**: 识别资源字典循环引用
- **命名约定**: 验证资源键命名规范

## MSBuild目标结构

### 自定义MSBuild目标
```xml
<Target Name="ValidateXamlResources" BeforeTargets="Compile">
  <Exec Command="powershell -File $(MSBuildProjectDirectory)\Build\ValidateResources.ps1" 
        ContinueOnError="false" />
</Target>
```

### PowerShell验证脚本功能
- XAML文件解析和资源引用提取
- 资源字典加载和索引构建
- 资源引用完整性验证
- 验证结果报告生成
