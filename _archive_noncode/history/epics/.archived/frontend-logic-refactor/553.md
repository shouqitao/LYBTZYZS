# Task 007: Build-Time Resource Validation Pipeline

## Overview

Create MSBuild targets and PowerShell scripts to validate XAML resource references at build time, preventing runtime resource errors like missing ToolBarContainer styles and ensuring resource dictionary integrity.

## Business Justification

Runtime resource errors cause application crashes and poor user experience. Moving resource validation to build time will eliminate these errors and improve developer confidence in UI changes.

## Technical Requirements

### Core Implementation
- Create MSBuild custom target for resource validation
- Implement PowerShell script to scan XAML files for resource references
- Validate resource dictionary dependencies and circular references
- Generate clear error messages with suggested fixes

### Validation Rules
```xml
<!-- These should be validated at build time: -->
<!-- ✓ Valid: Resource exists in merged dictionaries -->
<Style x:Key="Button.Primary.Default" TargetType="Button" />
<Button Style="{StaticResource Button.Primary.Default}" />

<!-- ✗ Invalid: Missing resource reference -->
<Button Style="{StaticResource NonExistentStyle}" />

<!-- ✗ Invalid: Circular dictionary references -->
<ResourceDictionary.MergedDictionaries>
    <ResourceDictionary Source="Dictionary1.xaml" />
    <!-- Dictionary1.xaml references Dictionary2.xaml which references Dictionary1.xaml -->
</ResourceDictionary.MergedDictionaries>
```

### MSBuild Integration Features
- Custom MSBuild task that runs during BeforeBuild
- Fails build if critical resource issues are found
- Provides warnings for potential resource problems
- Integrates with Visual Studio error list

## Implementation Steps
