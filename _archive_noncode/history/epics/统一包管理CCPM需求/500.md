## 技术实施细节

### 构建脚本架构

```batch
REM scripts/build-all-cpm.bat
@echo off
echo [INFO] 开始CPM构建流程...

REM 包还原优化
dotnet restore --use-current-runtime --locked-mode
if %ERRORLEVEL% neq 0 goto :error

REM 构建优化
dotnet build --no-restore --configuration Release
if %ERRORLEVEL% neq 0 goto :error

echo [SUCCESS] CPM构建完成
goto :end

:error
echo [ERROR] 构建失败，错误代码: %ERRORLEVEL%
exit /b %ERRORLEVEL%

:end
```

### GitHub Actions工作流示例

```yaml
# .github/workflows/cpm-build.yml
name: CPM Build and Test

on:
  push:
    branches: [ master, develop ]
  pull_request:
    branches: [ master ]

jobs:
  build:
    runs-on: windows-latest
    
    steps:
    - uses: actions/checkout@v4
    
    - name: Setup .NET 8.0
      uses: actions/setup-dotnet@v4
      with:
        dotnet-version: 8.0.x
        
    - name: Cache NuGet packages
      uses: actions/cache@v4
      with:
        path: ~/.nuget/packages
        key: ${{ runner.os }}-nuget-${{ hashFiles('Directory.Packages.props', '**/packages.lock.json') }}
        restore-keys: |
          ${{ runner.os }}-nuget-
    
    - name: Restore packages (CPM)
      run: dotnet restore --locked-mode
      
    - name: Build solution
      run: dotnet build --no-restore --configuration Release
      
    - name: Run tests
      run: dotnet test --no-build --configuration Release --logger "trx" --collect:"XPlat Code Coverage"
```

### 缓存配置策略

```xml
<!-- Directory.Build.props - 全局缓存配置 -->
<Project>
  <PropertyGroup>
    <!-- CPM缓存优化 -->
    <RestorePackagesWithLockFile>true</RestorePackagesWithLockFile>
    <RestoreLockedMode Condition="'$(CI)' == 'true'">true</RestoreLockedMode>
    
    <!-- 构建缓存优化 -->
    <UseArtifactsOutput>true</UseArtifactsOutput>
    <ArtifactsPath>$(MSBuildThisFileDirectory)artifacts</ArtifactsPath>
  </PropertyGroup>
</Project>
```
