# Task: 包分类和条件引用策略

## Description
实现智能包分类和条件引用策略，基于项目名称模式自动应用相关包。前端项目自动引用WPF/Prism包，后端项目自动引用ASP.NET Core包，测试项目自动引用xUnit包，避免手动管理包引用。

## Acceptance Criteria
- [x] 设计项目分类规则（Frontend、Backend、Tests、Shared）
- [x] 实现基于项目名称模式的包组分类
- [x] 配置条件包引用逻辑在Directory.Build.props中
- [x] 验证不同类型项目自动获得正确的包引用
- [x] 创建包分类和引用规则文档

## Technical Details
- 定义项目类型匹配模式：
  - Frontend: *Desktop*, *Client*, *WPF*
  - Backend: *WebAPI*, *Services*, *Infrastructure*
  - Tests: *Tests*, *Test*
  - Shared: *Shared*, *Common*, *Entities*
- 在Directory.Build.props中实现条件包引用：
  - 使用MSBuild的Condition属性
  - 基于$(MSBuildProjectName)或$(MSBuildProjectDirectory)模式匹配
- 包组定义：
  - WPF包组：Prism.DryIoc, Microsoft.Xaml.Behaviors.Wpf等
  - Web API包组：ASP.NET Core相关包
  - 测试包组：xUnit, Moq, FluentAssertions等
  - 通用包组：AutoMapper, Newtonsoft.Json等
- 实现包引用继承机制，避免重复定义
