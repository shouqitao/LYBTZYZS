### 自动化脚本开发

#### 批量标准化脚本 `scripts/standardize-projects.ps1`

```powershell
# 项目文件批量标准化脚本

param(
    [switch]$DryRun = $false,
    [string]$ProjectType = "All"  # All, Server, Client, Tests
)

Write-Host "=== 项目文件标准化工具 ===" -ForegroundColor Green

# 1. 备份所有项目文件
Write-Host "1. 创建项目文件备份..." -ForegroundColor Yellow
$backupFolder = "backup/csproj-backup-$(Get-Date -Format 'yyyyMMdd-HHmmss')"
New-Item -ItemType Directory -Path $backupFolder -Force

$projects = Get-ChildItem -Recurse -Filter "*.csproj"
foreach ($proj in $projects) {
    $relativePath = $proj.FullName.Replace((Get-Location), "").TrimStart('\')
    $backupPath = Join-Path $backupFolder $relativePath
    $backupDir = Split-Path $backupPath -Parent
    New-Item -ItemType Directory -Path $backupDir -Force
    Copy-Item $proj.FullName $backupPath
}

Write-Host "备份完成: $($projects.Count) 个项目文件" -ForegroundColor Green

# 2. 分析项目类型和依赖
Write-Host "2. 分析项目依赖..." -ForegroundColor Yellow
$projectAnalysis = @{}

foreach ($proj in $projects) {
    $content = Get-Content $proj.FullName -Raw
    $analysis = @{
        Path = $proj.FullName
        Type = Get-ProjectType $proj
        Packages = Get-PackageReferences $content
        Projects = Get-ProjectReferences $content
        Properties = Get-ProjectProperties $content
    }
    $projectAnalysis[$proj.Name] = $analysis
}

# 3. 执行标准化
Write-Host "3. 执行项目标准化..." -ForegroundColor Yellow

foreach ($projName in $projectAnalysis.Keys) {
    $analysis = $projectAnalysis[$projName]
    
    if ($ProjectType -ne "All" -and $analysis.Type -ne $ProjectType) {
        continue
    }
    
    Write-Host "  标准化: $projName" -ForegroundColor Cyan
    
    if (-not $DryRun) {
        $standardizedContent = Get-StandardizedProject $analysis
        Set-Content -Path $analysis.Path -Value $standardizedContent -Encoding UTF8
    } else {
        Write-Host "  [DRY RUN] 将会标准化: $($analysis.Path)" -ForegroundColor Gray
    }
}

Write-Host "=== 标准化完成 ===" -ForegroundColor Green
```

#### 配置验证脚本 `scripts/validate-standardization.ps1`

```powershell
# 项目文件标准化验证脚本

Write-Host "=== 项目标准化验证 ===" -ForegroundColor Green

$issues = @()

# 1. 验证SDK风格
Write-Host "1. 验证SDK风格项目格式..." -ForegroundColor Yellow
$projects = Get-ChildItem -Recurse -Filter "*.csproj"

foreach ($proj in $projects) {
    $content = Get-Content $proj.FullName -Raw
    
    if ($content -notmatch 'Sdk="Microsoft\.NET\.Sdk"') {
        $issues += "❌ $($proj.Name): 未使用SDK风格项目格式"
    }
    
    if ($content -match '<PackageReference.*Version=') {
        $issues += "⚠️ $($proj.Name): 包含硬编码版本号，应使用CPM"
    }
}

# 2. 验证目标框架统一
Write-Host "2. 验证目标框架版本..." -ForegroundColor Yellow
$frameworks = @{}

foreach ($proj in $projects) {
    $content = Get-Content $proj.FullName -Raw
    if ($content -match '<TargetFramework>(.*?)</TargetFramework>') {
        $framework = $matches[1]
        if (-not $frameworks.ContainsKey($framework)) {
            $frameworks[$framework] = @()
        }
        $frameworks[$framework] += $proj.Name
    }
}

if ($frameworks.Count -gt 2) {  # 允许net8.0和net8.0-windows
    $issues += "❌ 目标框架版本不统一: $($frameworks.Keys -join ', ')"
}

# 3. 验证包引用规范
Write-Host "3. 验证包引用规范..." -ForegroundColor Yellow
# ... 更多验证逻辑

# 输出验证结果
if ($issues.Count -eq 0) {
    Write-Host "✅ 所有项目文件标准化验证通过" -ForegroundColor Green
} else {
    Write-Host "❌ 发现 $($issues.Count) 个问题:" -ForegroundColor Red
    foreach ($issue in $issues) {
        Write-Host "   $issue" -ForegroundColor Yellow
    }
}
```

## 风险评估

### 高风险

1. **批量修改风险**
   - 影响: 33个项目同时修改可能导致大面积编译错误
   - 缓解: 分批处理，每批验证编译成功后继续

2. **依赖关系破坏风险**
   - 影响: 项目引用关系可能在标准化过程中被破坏
   - 缓解: 详细分析现有依赖关系，保持引用完整性

### 中风险

3. **版本兼容性风险**

   - 缓解: 版本兼容性矩阵测试，渐进式升级

4. **工具稳定性风险**
   - 影响: 自动化脚本可能有bug导致项目文件损坏
   - 缓解: 完整备份机制，彻底测试脚本
