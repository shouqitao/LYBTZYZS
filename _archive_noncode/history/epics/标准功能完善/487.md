### 异步处理实现
```csharp
public class PatientImportViewModel : ViewModelBase
{
    private readonly BackgroundWorker _importWorker;
    private readonly IPatientModule _patientModule;
    
    private void StartImport()
    {
        _importWorker.RunWorkerAsync(importData);
    }
    
    private void ImportWorker_DoWork(object sender, DoWorkEventArgs e)
    {
        var result = await _patientModule.ImportPatientsAsync(data, progress);
        // 进度回调处理
    }
}
```

### API集成
- 利用现有 `PatientModule.ImportPatientsAsync(List<PatientImportDto> patients, IProgress<ImportProgressInfo> progress)`
- 使用 `PatientImportDto` 标准数据传输对象
- 实现 `IProgress<ImportProgressInfo>` 进度回调接口
