# Task: 工具配置

## Overview

配置开发环境工具，建立自动化代码质量控制基础设施。这是整个规范优化项目的前置任务，为后续代码现代化提供工具支持。

## Technical Approach

### .editorconfig 配置
基于现有代码风格创建统一的编辑器配置：

```ini
root = true

[*.cs]
indent_style = space
indent_size = 4
end_of_line = crlf
charset = utf-8
trim_trailing_whitespace = true
insert_final_newline = true

# 命名规则
dotnet_naming_rule.interfaces_should_be_prefixed_with_i.severity = error
dotnet_naming_rule.private_fields_should_be_prefixed_with_underscore.severity = error

# Using 排序
dotnet_sort_system_directives_first = true
dotnet_separate_import_directive_groups = false

# C# 12 特性支持
csharp_style_primary_constructor_parameter_precedence = true
csharp_style_expression_bodied_methods = true:suggestion
```

### StyleCop.Analyzers 配置
添加温和的代码分析器配置，不产生阻塞性警告：

```xml
<ItemGroup>
  <PackageReference Include="StyleCop.Analyzers" Version="1.2.0-beta.507">
    <PrivateAssets>all</PrivateAssets>
    <IncludeAssets>runtime; build; native; contentfiles; analyzers</IncludeAssets>
  </PackageReference>
</ItemGroup>

<PropertyGroup>
  <TreatWarningsAsErrors>false</TreatWarningsAsErrors>
  <NoWarn>SA1633;SA1200;SA1101;SA1309</NoWarn>
</PropertyGroup>
```
