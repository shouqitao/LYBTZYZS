# Task: FormulaService现代化

## Overview

将 FormulaService 从传统构造函数升级为 C# 12主构造函数，完成验方管理模块的现代化改进。

## Target File

`src/Server/Modules/LYBT.Module.Formula/Services/FormulaService.cs`

## Technical Approach

### 升级模式
应用已验证的构造函数现代化模式：

1. **语法升级**: 传统构造函数 → C# 12主构造函数
2. **逻辑保持**: 异常检查、依赖注入逻辑完全不变
3. **风格统一**: 与 UserService 黄金标准保持一致

### 实施步骤

1. **分析当前实现**: 确认 FormulaService 构造函数模式
2. **应用标准模板**: 使用已验证的 C# 12主构造函数模板
3. **保持业务逻辑**: 验方管理相关业务功能不受影响
4. **验证集成**: 确保与 Prescriptions 模块协作正常

### 预期效果

FormulaService 构造函数将从传统模式：
```csharp
public FormulaService(IFormulaQueryService queryService, IFormulaBusinessService businessService)
{
    _queryService = queryService ?? throw new ArgumentNullException(nameof(queryService));
    _businessService = businessService ?? throw new ArgumentNullException(nameof(businessService));
}
```

升级为现代化模式：
```csharp
public class FormulaService(
    IFormulaQueryService queryService,
    IFormulaBusinessService businessService) : IFormulaService
{
    private readonly IFormulaQueryService _queryService = queryService ?? throw new ArgumentNullException(nameof(queryService));
    private readonly IFormulaBusinessService _businessService = businessService ?? throw new ArgumentNullException(nameof(businessService));
}
```
