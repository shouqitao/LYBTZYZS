# Task: 代码清理

## Overview

使用自动化工具进行全项目代码清理，统一代码格式，移除未使用的代码，确保代码风格完全一致。

## Technical Approach

### 自动化清理工具

使用 .NET 内置的代码格式化和清理工具：

```bash
# 格式化所有 C# 文件
dotnet format

# 移除未使用的 using 语句和应用代码修复
dotnet format --include-generated --fix-whitespace --fix-style --fix-analyzers

# 验证格式化结果
dotnet format --verify-no-changes
```

### 清理范围

1. **Using语句清理**
   - 移除未使用的 using 语句
   - 统一 using 语句排序（System优先）
   - 确保 using 语句分组一致

2. **代码格式统一**
   - 统一缩进（4个空格）
   - 统一换行符（CRLF）
   - 统一文件编码（UTF-8）

3. **注释代码清理**
   - 移除注释掉的无用代码
   - 保留有价值的说明性注释
   - 统一注释风格

4. **代码结构优化**
   - 空行使用规范化
   - 大括号位置统一
   - 访问修饰符顺序统一

### 质量检查清单

- [ ] 所有 using 语句按标准排序
- [ ] 无未使用的 using 语句
- [ ] 代码缩进和格式完全一致
- [ ] 无注释代码残留
- [ ] 文件编码统一为 UTF-8
- [ ] 换行符统一为 CRLF
