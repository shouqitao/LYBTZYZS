# Task: 其他服务现代化

## Overview

完成剩余服务类的构造函数现代化，实现全系统构造函数风格的统一。这是构造函数现代化的收尾任务。

## Target Files

基于代码分析，需要现代化的剩余服务类：
- `src/Server/Modules/LYBT.Module.Consultation/Services/ConsultationService.cs`
- `src/Server/Modules/LYBT.Module.Prescriptions/Services/PrescriptionsService.cs`
- `src/Server/Modules/LYBT.Module.Herbs/Services/HerbService.cs`
- 其他发现使用传统构造函数的服务类

## Technical Approach

### 批量现代化策略

1. **服务发现**: 扫描所有模块，识别使用传统构造函数的服务类
2. **优先级排序**: 按业务重要性排序处理
3. **模板应用**: 应用已验证的 C# 12主构造函数模板
4. **逐个验证**: 每个服务现代化后立即测试

### 标准化检查清单

每个服务现代化需要确认：
- [ ] 使用 C# 12 主构造函数语法
- [ ] 保持异常检查逻辑 `?? throw new ArgumentNullException`
- [ ] 私有字段命名遵循 `_camelCase` 约定
- [ ] 代码风格与 UserService 一致
- [ ] 业务功能测试通过

### 业务验证重点

**ConsultationService**: 中医四诊功能验证
**PrescriptionsService**: 处方开具和打印功能验证  
**HerbService**: 中药材选择和配伍检查验证
