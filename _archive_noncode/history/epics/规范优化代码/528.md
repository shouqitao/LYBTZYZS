# Task: XML文档补充

## Overview

参考 UserQueryService 的XML文档标准，为缺失XML文档注释的公共API方法添加完整的中文文档注释，提升代码可读性和维护性。

## Target Files

重点关注以下服务的公共方法：
- `PatientQueryService` 主要查询方法
- `MedicalCaseQueryService` 医案查询方法  
- `ConsultationQueryService` 诊断查询方法
- `FormulaQueryService` 验方查询方法
- `PrescriptionsQueryService` 处方查询方法
- `HerbQueryService` 中药材查询方法

## Technical Approach

```csharp
/// <summary>

public async Task<ServiceResult<PatientDto>> GetByIdAsync(Guid id)
{
    // 实现逻辑...
}
```

### 文档补充策略

1. **优先级排序**: 核心API方法优先补充
2. **标准模板**: 使用统一的中文XML文档模板
3. **业务准确**: 文档内容准确描述业务功能
4. **参数完整**: 所有参数、返回值、异常都有说明

### 核心方法识别

**患者管理**: `GetByIdAsync`, `GetPagedAsync`, `SearchPatientsAsync`
**医案管理**: `GetMedicalCasesByPatientAsync`, `GetByIdAsync`
**诊断记录**: `GetConsultationByIdAsync`, `GetConsultationHistoryAsync`
**验方管理**: `SearchFormulasAsync`, `GetFormulaByIdAsync`
**处方管理**: `GetPrescriptionsByPatientAsync`, `GetPrescriptionHistoryAsync`
**中药材**: `SearchHerbsAsync`, `GetHerbByIdAsync`
