# DT-009 命名约定统一 - Username/UserName一致性

## 描述

统一整个代码库中的用户名字段命名约定，解决当前存在的 `Username` 和 `UserName` 混用问题，建立一致的命名标准并全面应用。

## 验收标准

- [ ] 分析现有代码库中所有用户名相关字段的命名
- [ ] 确定统一的命名标准（推荐：UserName，符合.NET约定）
- [ ] 更新所有实体类、DTO、视图模型中的字段命名
- [ ] 更新数据库字段名和相关迁移
- [ ] 更新所有相关的查询、验证和业务逻辑
- [ ] 确保前后端API契约保持一致
- [ ] 更新测试用例和Mock数据

## 技术要求

### 命名标准决策

**推荐统一为 `UserName`**：
- 符合.NET Pascal命名约定
- 与ASP.NET Core Identity一致
- 更清晰地表达"用户名称"概念
- 避免与Unix系统的username概念混淆

### 影响范围分析

**实体层（Entity）**：
```csharp
// 统一前
public class User
{
    public string Username { get; set; }  // 需要改为UserName
}

// 统一后
public class User  
{
    public string UserName { get; set; }
}
```

**DTO层**：
```csharp
// 检查所有UserDto, CreateUserDto, UpdateUserDto等
public class UserDto
{
    public string UserName { get; set; }  // 统一命名
}
```

**数据库层**：
```sql
-- 可能需要的数据库迁移
ALTER TABLE Users RENAME COLUMN Username TO UserName;
-- 或根据实际情况调整
```
