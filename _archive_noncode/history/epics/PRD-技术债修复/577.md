# DT-010 日志配置优化 - Serilog结构化日志

## 描述

升级现有日志系统到 Serilog，实现结构化日志记录，提升系统可观测性和问题诊断能力。包括日志分级、结构化输出、文件轮转和性能优化。

## 验收标准

- [ ] 集成 Serilog 替换默认的 ILogger
- [ ] 实现结构化日志输出（JSON格式）
- [ ] 配置多级日志目标（控制台、文件、错误文件）
- [ ] 实现日志文件自动轮转和压缩
- [ ] 添加关键业务操作的结构化日志记录
- [ ] 配置不同环境的日志级别策略
- [ ] 实现日志采样和性能优化
- [ ] 集成健康检查监控日志系统状态

**NuGet包依赖**：
```xml
<PackageReference Include="Serilog.AspNetCore" Version="7.0.0" />
<PackageReference Include="Serilog.Sinks.Console" Version="4.1.0" />
<PackageReference Include="Serilog.Sinks.File" Version="5.0.0" />
<PackageReference Include="Serilog.Sinks.Seq" Version="5.2.2" />
<PackageReference Include="Serilog.Enrichers.Environment" Version="2.2.0" />
<PackageReference Include="Serilog.Enrichers.Process" Version="2.0.2" />
<PackageReference Include="Serilog.Enrichers.Thread" Version="3.1.0" />
<PackageReference Include="Serilog.Settings.Configuration" Version="7.0.0" />
```

**Program.cs 集成**：
```csharp
public class Program
{
    public static void Main(string[] args)
    {
        Log.Logger = new LoggerConfiguration()
            .ReadFrom.Configuration(Configuration)
            .CreateLogger();

        try
        {
            Log.Information("凌隐宝堂诊疗系统启动中...");
            CreateHostBuilder(args).Build().Run();
        }
        catch (Exception ex)
        {
            Log.Fatal(ex, "系统启动失败");
        }
        finally
        {
            Log.CloseAndFlush();
        }
    }
}
```

### 结构化日志实现

**业务操作日志模板**：
```csharp
public static class LogEvents
{
    // 认证相关事件
    public static readonly EventId UserLogin = new(1001, "UserLogin");
    public static readonly EventId UserLogout = new(1002, "UserLogout");
    public static readonly EventId LoginFailed = new(1003, "LoginFailed");
    
    // 业务操作事件  
    public static readonly EventId PatientCreated = new(2001, "PatientCreated");
    public static readonly EventId ConsultationCreated = new(2002, "ConsultationCreated");
    public static readonly EventId PrescriptionIssued = new(2003, "PrescriptionIssued");
    
    // 系统事件
    public static readonly EventId DatabaseError = new(3001, "DatabaseError");
    public static readonly EventId ExternalServiceError = new(3002, "ExternalServiceError");
}

// 使用示例
_logger.LogInformation(LogEvents.UserLogin, 
    "用户 {UserName} 从 {IPAddress} 成功登录", 
    username, ipAddress);

_logger.LogInformation(LogEvents.PatientCreated,
    "创建患者档案 {PatientId} {PatientName} 由用户 {UserId} 操作",
    patient.Id, patient.Name, userId);
```

### 关键业务日志点
- **认证授权**：登录、登出、权限检查失败
- **患者管理**：患者创建、更新、删除操作
- **诊疗流程**：医案创建、诊断记录、处方开具
- **系统操作**：配置更改、数据库操作、外部服务调用
- **性能监控**：慢查询、高内存使用、异常响应时间
