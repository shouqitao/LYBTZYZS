# DT-001 服务接口职责分离 - Auth模块接口重构

## 描述

解决Auth模块中服务接口职责混乱的严重架构问题。当前AuthModule同时实现IAuthService和IAuthenticationService两个职责不同的接口，严重违反单一职责原则，导致架构不清晰，影响代码可维护性和测试性。

## 问题分析

### 当前问题
**Evidence来源**: `src/Client/Desktop/Modules/Auth/Services/AuthModule.cs:17`

```csharp
public class AuthModule : IAuthService, IAuthenticationService
{
    // 同时实现两个职责不同的接口
    // IAuthService: 业务认证逻辑
    // IAuthenticationService: 认证服务抽象
}
```

### 影响评估
- **Severity**: Critical (权重: 5)
- **Impact**: 5 (严重违反SOLID原则，影响整体架构)
- **Effort**: 3 (需要重构接口，但影响范围可控)
- **Priority Score**: (5 × 5) / 3 = 8.33

## 验收标准

- [ ] 创建适配器类分离接口职责
- [ ] AuthModule只实现IAuthService接口
- [ ] 新建AuthServiceAdapter实现IAuthenticationService
- [ ] 修改依赖注入注册，分离两个接口的服务注册
- [ ] 更新所有依赖IAuthenticationService的组件使用新适配器
- [ ] 确保所有现有功能正常工作
- [ ] 编译无错误无警告
- [ ] 通过相关单元测试

## 技术方案

### 适配器模式实现

**1. 创建AuthServiceAdapter类**：
```csharp
public class AuthServiceAdapter : IAuthenticationService 
{
    private readonly IAuthService _authService;
    
    public AuthServiceAdapter(IAuthService authService) 
    {
        _authService = authService ?? throw new ArgumentNullException(nameof(authService));
    }
    
    // 实现IAuthenticationService接口方法
    // 内部委托给IAuthService的相应方法
    public async Task<bool> LoginAsync(string username, string password)
    {
        return await _authService.AuthenticateAsync(username, password);
    }
    
    public async Task LogoutAsync()
    {
        await _authService.SignOutAsync();
    }
    
    public async Task<bool> IsAuthenticatedAsync()
    {
        return await _authService.IsValidSessionAsync();
    }
    
    // 其他接口方法的适配实现...
}
```

**2. 重构AuthModule类**：
```csharp
// 修改前
public class AuthModule : IAuthService, IAuthenticationService
{
    // 混合实现
}

// 修改后

{
    // 只实现IAuthService接口
    // 专注于业务认证逻辑
    
    public async Task<ServiceResult<LoginResponse>> AuthenticateAsync(string username, string password)

        // 业务认证逻辑实现
    }
    
    public async Task<ServiceResult> SignOutAsync()
    {
        // 登出逻辑实现
    }
    
    public async Task<bool> IsValidSessionAsync()
    {
        // 会话验证逻辑实现
    }
}
```

### 依赖注入重构

**修改服务注册逻辑**：
```csharp
// src/Client/Desktop/Shell/Extensions/ServiceCollectionExtensions.cs

// 修改前
containerRegistry.Register<IAuthenticationService>(container =>
    container.Resolve<AuthModule>());
containerRegistry.Register<IAuthService>(container =>
    container.Resolve<AuthModule>());

// 修改后
containerRegistry.RegisterSingleton<AuthModule>();
containerRegistry.RegisterSingleton<IAuthService>(container => 
    container.Resolve<AuthModule>());
containerRegistry.RegisterSingleton<IAuthenticationService, AuthServiceAdapter>();
```

### 接口职责明确定义

**IAuthService - 业务认证服务**：
```csharp
public interface IAuthService
{
    Task<ServiceResult<LoginResponse>> AuthenticateAsync(string username, string password);
    Task<ServiceResult> SignOutAsync();
    Task<bool> IsValidSessionAsync();
    Task<ServiceResult<UserInfo>> GetCurrentUserAsync();
    Task<ServiceResult> RefreshTokenAsync();
    // 其他业务认证相关方法
}
```

**IAuthenticationService - 认证抽象服务**：
```csharp
public interface IAuthenticationService
{
    Task<bool> LoginAsync(string username, string password);
    Task LogoutAsync();
    Task<bool> IsAuthenticatedAsync();
    Task<UserContext> GetUserContextAsync();
    // 其他抽象认证相关方法
}
```
