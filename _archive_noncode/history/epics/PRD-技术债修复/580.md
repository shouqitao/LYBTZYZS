# DT-002 依赖注入标准化 - IoC生命周期统一

## 描述

统一和标准化整个应用程序的依赖注入生命周期管理，解决当前IoC容器中混乱的服务注册模式。当前系统存在工厂委托注册、生命周期不一致、内存泄漏风险等问题，需要统一为标准的IoC注册模式。

## 问题分析

### 当前问题
**Evidence来源**: `src/Client/Desktop/Shell/Extensions/ServiceCollectionExtensions.cs:148-153`

```csharp
containerRegistry.Register<IAuthenticationService>(container =>
    container.Resolve<AuthModule>());
containerRegistry.Register<IAuthService>(container =>
    container.Resolve<AuthModule>());
```

### 影响评估
- **Severity**: Critical (权重: 5)
- **Impact**: 4 (可能导致内存泄漏和服务实例混乱)
- **Effort**: 3 (需要重构服务注册逻辑)
- **Priority Score**: (5 × 4) / 3 = 6.67

### 问题表现
1. **工厂委托滥用**：大量使用lambda工厂注册，增加复杂性
2. **生命周期不明确**：同一服务在不同地方注册为不同生命周期
3. **循环依赖风险**：复杂的工厂委托可能引发循环依赖
4. **内存泄漏隐患**：不当的生命周期管理导致对象无法正常释放
5. **测试困难**：复杂的注册逻辑难以进行单元测试

## 验收标准

- [ ] 统一所有服务的注册模式，避免工厂委托滥用
- [ ] 明确定义每个服务的生命周期（Singleton/Transient/Scoped）
- [ ] 建立服务注册的标准模板和约定
- [ ] 消除循环依赖和内存泄漏风险
- [ ] 重构ServiceCollectionExtensions使其更清晰易读
- [ ] 为所有核心服务建立标准化的注册模式

- [ ] 通过依赖注入相关的单元测试

## 技术方案

### 生命周期标准化

**1. 服务生命周期分类**：
```csharp
// 单例服务 (Singleton) - 应用程序生命周期内唯一
// 适用于：无状态服务、配置、缓存、连接管理器
public static class SingletonServices
{
    public static void RegisterSingletons(IContainerRegistry containerRegistry)
    {
        // 核心业务模块 - 单例
        containerRegistry.RegisterSingleton<AuthModule>();
        containerRegistry.RegisterSingleton<UserModule>();
        containerRegistry.RegisterSingleton<PatientModule>();
        
        // API客户端 - 单例（重用HTTP连接）
        containerRegistry.RegisterSingleton<IAuthApi, AuthApi>();
        containerRegistry.RegisterSingleton<IUserApi, UserApi>();
        
        // 配置和缓存 - 单例
        containerRegistry.RegisterSingleton<IConfigurationManager, ConfigurationManager>();
        containerRegistry.RegisterSingleton<ICacheService, MemoryCacheService>();
    }
}

// 瞬时服务 (Transient) - 每次解析创建新实例
// 适用于：轻量级服务、工具类、映射器
public static class TransientServices
{
    public static void RegisterTransients(IContainerRegistry containerRegistry)
    {
        // 映射器 - 瞬时（无状态，轻量级）
        containerRegistry.Register<IMapper, AutoMapperService>();
        
        // 验证器 - 瞬时
        containerRegistry.Register<IValidationService, ValidationService>();
        
        // 工具服务 - 瞬时
        containerRegistry.Register<IExportService, ExcelExportService>();
    }
}
```

**2. 接口到实现的标准映射**：
```csharp
public static class InterfaceBindings
{
    public static void RegisterInterfaceBindings(IContainerRegistry containerRegistry)
    {
        // 标准模式：接口指向已注册的实现
        // 避免工厂委托，使用直接映射
        
        // Auth服务映射（基于DT-001完成的接口分离）
        containerRegistry.RegisterSingleton<IAuthService>(container => 
            container.Resolve<AuthModule>());
        containerRegistry.RegisterSingleton<IAuthenticationService, AuthServiceAdapter>();
        
        // User服务映射
        containerRegistry.RegisterSingleton<IUserService>(container => 
            container.Resolve<UserModule>());
        
        // Patient服务映射
        containerRegistry.RegisterSingleton<IPatientService>(container => 
            container.Resolve<PatientModule>());
    }
}
```

### 标准化注册模板

**ServiceCollectionExtensions重构**：
```csharp
public static class ServiceCollectionExtensions
{
    public static IContainerRegistry RegisterApplicationServices(this IContainerRegistry containerRegistry)
    {
        // 按顺序注册，避免依赖问题
        RegisterInfrastructureServices(containerRegistry);
        RegisterCoreModules(containerRegistry);
        RegisterInterfaceBindings(containerRegistry);
        RegisterViewModels(containerRegistry);
        
        // 验证注册完整性
        ValidateServiceRegistrations(containerRegistry);
        
        return containerRegistry;
    }
    
    private static void RegisterInfrastructureServices(IContainerRegistry containerRegistry)
    {
        // 基础设施服务 - 最先注册，无依赖
        SingletonServices.RegisterSingletons(containerRegistry);
        TransientServices.RegisterTransients(containerRegistry);
    }
    
    private static void RegisterCoreModules(IContainerRegistry containerRegistry)
    {
        // 核心业务模块 - 按依赖顺序注册
        containerRegistry.RegisterSingleton<AuthModule>();
        containerRegistry.RegisterSingleton<UserModule>();  // 依赖Auth
        containerRegistry.RegisterSingleton<PatientModule>(); // 依赖User
        containerRegistry.RegisterSingleton<MedicalCaseModule>(); // 依赖Patient
        // ... 其他模块按依赖顺序
    }
    
    private static void RegisterInterfaceBindings(IContainerRegistry containerRegistry)
    {
        // 接口绑定 - 最后注册，依赖已注册的实现
        InterfaceBindings.RegisterInterfaceBindings(containerRegistry);
    }
}
```

### 依赖验证机制

**注册完整性验证**：
```csharp
public static class RegistrationValidator
{
    public static void ValidateServiceRegistrations(IContainerRegistry containerRegistry)
    {
        var requiredServices = GetRequiredServiceTypes();
        var missingServices = new List<Type>();
        
        foreach (var serviceType in requiredServices)
        {
            try
            {
                // 尝试解析服务，验证注册是否正确
                containerRegistry.GetContainer().Resolve(serviceType);
            }
            catch (Exception)
            {
                missingServices.Add(serviceType);
            }
        }
        
        if (missingServices.Any())
        {
            var missingServiceNames = string.Join(", ", missingServices.Select(t => t.Name));
            throw new InvalidOperationException($"以下服务未正确注册: {missingServiceNames}");
        }
    }
    
    private static Type[] GetRequiredServiceTypes()
    {
        return new[]
        {
            typeof(IAuthService),
            typeof(IAuthenticationService),
            typeof(IUserService),
            typeof(IPatientService),
            // ... 其他必需服务
        };
    }
}
```
