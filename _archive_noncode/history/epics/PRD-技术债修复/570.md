# Task 017: 代码格式化和EditorConfig配置

## 目标
建立统一的代码格式化规范和EditorConfig配置，确保代码风格一致性。

## 范围
- .editorconfig 配置文件
- C# 代码格式化规则
- XAML 格式化规则  
- 文件编码和换行符标准化
- IDE配置同步

## 验收标准
- [ ] 创建完整的 .editorconfig 文件
- [ ] 配置 C# 代码格式化规则 (缩进、大括号、空格等)
- [ ] 配置 XAML 格式化规则
- [ ] 统一文件编码为 UTF-8
- [ ] 配置换行符标准 (Windows: CRLF)

## 依赖关系
dependencies: []

## 技术要求
- 遵循 Microsoft C# 编码约定
- 支持 Visual Studio 和 VS Code
- 配置自动格式化触发器
- 集成到构建流程

## 实现提示
- 检查现有项目的格式化不一致问题
- 参考 .NET 官方 EditorConfig 模板
- 配置 IDE0* 和 CA* 规则
- 测试在不同 IDE 中的表现

## 完成条件
- 所有开发工具识别并应用格式化规则
- 现有代码批量格式化完成
- 新代码自动符合格式化标准
- 格式化规则不影响编译和运行
