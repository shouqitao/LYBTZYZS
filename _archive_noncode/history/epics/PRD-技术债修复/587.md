## Git Hooks配置

### pre-commit Hook
```bash
#!/bin/sh
# 运行快速质量检查
powershell -ExecutionPolicy Bypass -File "scripts/Check-CompileQuality.ps1" -Quick
powershell -ExecutionPolicy Bypass -File "scripts/Check-CodingStandards.ps1" -Quick
```

### pre-push Hook
```bash
#!/bin/sh
# 运行完整质量检查
powershell -ExecutionPolicy Bypass -File "scripts/Check-Architecture.ps1"
powershell -ExecutionPolicy Bypass -File "scripts/Check-TestCoverage.ps1"
```

## GitHub Actions工作流

### 质量检查流水线
```yaml
name: Code Quality Check
on: [push, pull_request]
jobs:
  quality-check:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup .NET
        uses: actions/setup-dotnet@v3
        with:
          dotnet-version: '8.0.x'
      - name: Run Quality Checks
        shell: powershell
        run: |
          ./scripts/Run-AllChecks.ps1 -CI
      - name: Upload Results
        uses: actions/upload-artifact@v3
        with:
          name: quality-reports
          path: reports/
```
