# Task: 设计诊疗流程事务定义和步骤

## Description
为MedicalCase+Consultation诊疗流程创建具体的事务定义，包括医疗案例创建、诊断记录添加、状态变更等关键步骤，确保诊疗数据的一致性。

## Acceptance Criteria
- [ ] `StartConsultationTransaction` 事务定义完成
- [ ] 包含步骤：创建医疗案例、初始化诊断记录、更新患者状态
- [ ] 每个步骤的补偿操作明确定义
- [ ] 事务执行数据传递模型 `ConsultationTransactionContext`
- [ ] 业务规则验证集成到事务步骤中
- [ ] 支持部分完成情况下的优雅处理
- [ ] 与现有MedicalCase和Consultation服务集成

## Technical Details
- 实现位置：`src/Server/Modules/MedicalCase/Transactions/`
- 核心类：
  - `StartConsultationTransaction` - 诊疗开始事务
  - `CreateMedicalCaseStep` - 创建医疗案例步骤
  - `InitializeConsultationStep` - 初始化诊断步骤  
  - `UpdatePatientStatusStep` - 患者状态更新步骤
  - `ConsultationTransactionContext` - 事务上下文
- 涉及的业务规则：
  - 患者必须存在且状态有效
  - 同一患者不能有重复的活跃案例
  - 诊断记录必须关联到有效的医疗案例
