# Task: 设计和实现事务协调器核心接口

## Description
实现补偿事务模式的核心基础设施，包括事务协调器接口、事务定义、步骤抽象和上下文管理。为后续业务事务集成奠定架构基础。

## Acceptance Criteria
- [ ] `ITransactionCoordinator` 接口定义完成，支持多步骤事务执行
- [ ] `TransactionDefinition<T>` 类实现事务配置和步骤管理
- [ ] `ITransactionStep<T>` 抽象接口支持执行和补偿操作
- [ ] `TransactionContext` 上下文管理事务状态和数据传递
- [ ] 完整的异常处理和错误恢复机制
- [ ] 基础的事务日志记录功能

## Technical Details
- 实现位置：`src/Server/Core/LYBT.Infrastructure/Transactions/`
- 核心接口：
  - `ITransactionCoordinator<T>` - 协调器接口
  - `ITransactionStep<T>` - 步骤接口  
  - `TransactionDefinition<T>` - 事务定义类
  - `TransactionContext` - 执行上下文
- 集成到现有 `AppDbContext` 和 DI 容器
- 支持取消令牌和异步执行
