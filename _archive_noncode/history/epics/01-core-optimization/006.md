# Task: 集成事务协调器到现有业务服务

## Description
将事务协调器集成到现有的MedicalCase和Prescription业务服务中，替换现有的简单数据操作为事务化操作，提供功能开关支持新旧实现切换。

## Acceptance Criteria
- [ ] MedicalCaseService 集成 StartConsultationTransaction
- [ ] PrescriptionService 集成 CreatePrescriptionTransaction  
- [ ] 现有API接口保持兼容，无破坏性变更
- [ ] 添加功能开关 `EnableTransactionMode` 支持新旧实现切换
- [ ] 事务失败时的用户友好错误消息
- [ ] 服务层异常处理适配事务错误类型
- [ ] 依赖注入配置更新注册事务相关服务

## Technical Details
- 修改位置：
  - `src/Server/Modules/MedicalCase/Services/MedicalCaseService.cs`
  - `src/Server/Modules/Prescriptions/Services/PrescriptionService.cs`
- 集成方式：
  - 通过构造函数注入事务协调器
  - 在关键业务方法中调用事务执行
  - 保留原有方法作为功能开关的降级实现
- 配置管理：
  - `appsettings.json` 添加事务配置节
  - 支持运行时动态切换（开发测试用）
