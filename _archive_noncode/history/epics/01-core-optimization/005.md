# Task: 设计处方创建事务定义和步骤

## Description
为Prescription+Herbs处方创建流程设计具体事务定义，包括处方基础信息创建、药材关联、价格计算、库存检查等步骤，确保处方数据完整性。

## Acceptance Criteria
- [ ] `CreatePrescriptionTransaction` 事务定义完成
- [ ] 包含步骤：创建处方、关联药材、计算价格、验证配伍
- [ ] 每个步骤的补偿操作明确定义（删除处方、清除关联等）
- [ ] 事务执行数据模型 `PrescriptionTransactionContext`
- [ ] 药材配伍禁忌检查集成到事务中
- [ ] 处方价格自动计算和验证
- [ ] 与现有Prescription和Herbs服务集成

## Technical Details
- 实现位置：`src/Server/Modules/Prescriptions/Transactions/`
- 核心类：
  - `CreatePrescriptionTransaction` - 处方创建事务
  - `CreatePrescriptionStep` - 创建处方基础信息
  - `AddHerbsStep` - 添加药材关联
  - `CalculatePriceStep` - 价格计算步骤
  - `ValidateHerbCompatibilityStep` - 药材配伍验证
  - `PrescriptionTransactionContext` - 事务上下文
- 涉及的业务规则：
  - 处方必须关联到有效的诊断记录
  - 药材配伍禁忌检查
  - 价格计算准确性验证
  - 处方完整性检查
