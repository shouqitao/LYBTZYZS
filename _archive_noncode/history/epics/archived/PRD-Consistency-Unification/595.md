## Environment Variable Standards

### Naming Convention
```bash
# Application Settings
LYBT_APP_NAME=LYBT System
LYBT_APP_ENVIRONMENT=Development

# Database Configuration
LYBT_DB_CONNECTION_STRING=Server=localhost;Database=LYBTDB;...
LYBT_DB_COMMAND_TIMEOUT=30

# Authentication
LYBT_JWT_SECRET_KEY=your-secret-key-here
LYBT_JWT_ISSUER=LYBT-System
LYBT_JWT_AUDIENCE=LYBT-Users

# API Configuration
LYBT_API_BASE_URL=https://localhost:7001
LYBT_API_TIMEOUT=30

# Feature Flags
LYBT_FEATURE_CACHING_ENABLED=true
LYBT_FEATURE_AUDIT_LOGGING_ENABLED=true
```

### Configuration Precedence
1. Environment Variables (highest priority)
2. appsettings.{Environment}.json
3. appsettings.json
4. Default values in configuration models (lowest priority)
