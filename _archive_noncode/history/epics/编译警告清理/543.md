# Task: StyleCop格式化警告自动修复

## Description
使用自动化工具修复大量的StyleCop格式化警告，主要包括大括号格式、空行、空格等代码风格问题。这些警告虽然不影响功能，但影响代码一致性和可读性。

主要警告类型：
- SA1013: 大括号格式问题（约2,000+个）
- SA1500: 多行语句大括号格式  
- SA1517: 文件开头空白行
- SA1108: 嵌入式注释格式
- SA1407: 算术表达式优先级

## Acceptance Criteria
- [ ] 所有SA1013大括号格式警告修复完成
- [ ] 所有SA1500多行语句大括号警告修复完成
- [ ] 所有SA1517文件开头空行警告修复完成
- [ ] 所有SA1108嵌入式注释警告修复完成
- [ ] 所有SA1407算术表达式警告修复完成
- [ ] 代码格式统一，符合项目规范
- [ ] 编译通过，无功能回归

## Technical Details
### 自动修复策略
1. **dotnet format使用**：
   ```bash
   # 格式化整个解决方案
   dotnet format LYBT.Server.sln --verbosity diagnostic
   dotnet format LYBT.Desktop.sln --verbosity diagnostic
   
   # 只修复特定警告类型
   dotnet format --include SA1013,SA1500,SA1517,SA1108,SA1407
   ```

2. **EditorConfig配置优化**：
   ```ini
   # 大括号格式规则
   csharp_new_line_before_open_brace = all
   csharp_space_after_keywords_in_control_flow_statements = true
   
   # 空行规则
   dotnet_style_require_accessibility_modifiers = always
   csharp_new_line_before_else = true
   ```

3. **分批处理策略**：
   - 第一批：处理大括号格式问题（SA1013, SA1500）
   - 第二批：处理空行和注释问题（SA1517, SA1108）
   - 第三批：处理表达式和其他格式问题（SA1407等）

### 处理顺序
1. **Server端项目** (优先)
   - LYBT.Infrastructure
   - LYBT.Entities  
   - LYBT.Module.*
   - LYBT.WebAPI

2. **Desktop端项目**
   - LYBT.Desktop.Core
   - LYBT.Desktop.Modules.*
   - LYBT.Desktop (主项目)

### 风险控制
- 使用版本控制跟踪所有变更
- 分批提交，便于回滚
- 每批修复后执行完整编译测试
