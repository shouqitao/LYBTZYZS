# 智能中医诊疗系统 - 完整技术文档

## 系统概述

智能中医诊疗系统（LYBTZYZS）是一个基于 ASP.NET Core 8.0 构建的现代化中医诊疗管理平台。系统采用模块化架构设计，为中医诊所提供从患者挂号、诊疗记录、处方开具到药房调剂的全流程数字化管理解决方案。

### 核心特性

- **模块化架构**：每个业务域独立模块，便于维护和扩展
- **多数据库支持**：每个模块独立数据库上下文，支持数据隔离
- **统一基础设施**：共享的日志、缓存、配置和认证服务
- **RESTful API**：标准化的 REST API 接口设计
- **JWT 认证**：安全的身份验证和授权机制
- **自动化文档**：Swagger/OpenAPI 自动生成的 API 文档

### 核心组件

#### 1. LYBT.WebAPI - API 网关层

- **职责**：统一 API 入口，路由管理，认证授权
- **技术栈**：ASP.NET Core 8.0, Swagger, JWT
- **特性**：
  - 统一的 API 版本控制
  - 全局异常处理中间件
  - 性能监控中间件
  - CORS 跨域支持
  - 自动 API 文档生成

#### 2. LYBT.Infrastructure - 基础设施层

- **职责**：提供统一的基础服务
- **核心服务**：
  - **认证服务**：JWT 令牌管理，用户认证
  - **日志服务**：结构化日志，审计日志
  - **缓存服务**：内存缓存，分布式缓存
  - **配置服务**：全局配置管理
  - **文件存储**：文件上传下载管理

#### 3. LYBT.Common - 共享组件层

- **职责**：提供通用工具和模型
- **内容**：
  - 通用枚举定义
  - 扩展方法集合
  - 助手类工具
  - 通用响应模型
  - 分页查询模型

#### 4. 业务模块层

每个业务模块遵循相同的架构模式：

```
LYBT.Module.[Name]/
├── Data/                    # 数据访问层
│   ├── [Name]DbContext.cs   # EF Core 上下文
│   └── [Name]DbContextFactory.cs
├── Models/                  # 领域模型
│   ├── [Name]Model.cs       # 实体模型
│   └── Dtos/               # 数据传输对象
├── Interfaces/             # 服务接口
│   ├── I[Name]Repository.cs
│   └── I[Name]Service.cs
├── Repositories/           # 数据仓储
│   └── [Name]Repository.cs
├── Services/              # 业务服务
│   └── [Name]Service.cs
├── Mapping/               # 对象映射
│   └── [Name]MappingProfile.cs
├── Migrations/            # 数据库迁移
└── [Name]Module.cs        # 模块注册
```

## 数据库设计

### 数据库架构

系统采用多数据库架构，每个模块拥有独立的数据库上下文：

```sql
-- 基础设施数据库
InfrastructureDb
├── SystemLogs           -- 系统日志
├── UserActionLogs       -- 用户操作日志
├── AuditLogs           -- 审计日志
├── PerformanceLogs     -- 性能日志
├── ErrorLogs           -- 错误日志
├── GlobalSettings      -- 全局配置
├── DiagnosisCatalog    -- 诊断目录
└── TreatmentCatalog    -- 治疗目录

-- 业务模块数据库
UsersDb, PatientsDb, DoctorsDb, ...
```

### 数据迁移管理

每个模块独立管理数据库迁移：

```bash
# 添加迁移
dotnet ef migrations add MigrationName --project LYBT.Module.Users --startup-project LYBT.WebAPI

# 更新数据库
dotnet ef database update --project LYBT.Module.Users --startup-project LYBT.WebAPI
```

## API 接口设计

### 接口规范

- **基础路径**：`/api/v{version}/[controller]`
- **版本控制**：URL 版本控制，当前版本 v1
- **认证方式**：JWT Bearer Token
- **响应格式**：统一的 `ApiResponse<T>` 格式

### 统一响应格式

```json
{
  "success": true,
  "message": "操作成功",
  "data": {},
  "timestamp": "2025-01-28T12:00:00Z",
  "errors": []
}
```

### 核心 API 端点

#### 认证相关

- `POST /api/v1/auth/login` - 用户登录
- `POST /api/v1/auth/logout` - 用户登出
- `POST /api/v1/auth/changeSysAdminPassword` - 修改管理员密码

#### 用户管理

- `GET /api/v1/users` - 获取用户列表
- `GET /api/v1/users/{id}` - 获取用户详情
- `POST /api/v1/users` - 创建用户
- `PUT /api/v1/users/{id}` - 更新用户
- `DELETE /api/v1/users/{id}` - 删除用户

#### 患者管理

- `GET /api/v1/patients` - 获取患者列表
- `GET /api/v1/patients/{id}` - 获取患者详情
- `POST /api/v1/patients` - 创建患者档案
- `PUT /api/v1/patients/{id}` - 更新患者信息
- `POST /api/v1/patients/assign-doctor` - 分配医生

#### 其他模块

每个业务模块都提供类似的 CRUD 接口，具体详见各模块的 API 文档。

## 部署架构

### 容器化部署

```dockerfile
FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS base
WORKDIR /app
EXPOSE 80
EXPOSE 443

FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY . .
RUN dotnet restore "LYBT.WebAPI/LYBT.WebAPI.csproj"
RUN dotnet build "LYBT.WebAPI/LYBT.WebAPI.csproj" -c Release -o /app/build

FROM build AS publish
RUN dotnet publish "LYBT.WebAPI/LYBT.WebAPI.csproj" -c Release -o /app/publish

FROM base AS final
WORKDIR /app
COPY --from=publish /app/publish .
ENTRYPOINT ["dotnet", "LYBT.WebAPI.dll"]
```
