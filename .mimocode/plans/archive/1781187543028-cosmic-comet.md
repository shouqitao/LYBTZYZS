# Phase 1: LocalWebAPI 统一 Service 层 — 基础设施准备

## 目标

为 Phase 2（控制器重写）奠定基础：替换 DbContext、注册模块 Service、更新架构测试。

## 前提发现

- `LocalWebApiDbContext` 是 `AppDbContext` 的精简副本（相同 DbSets、相同实体配置），仅缺少审计自动化和 IHttpContextAccessor
- `BaseRepository<T>` 构造函数接收 `AppDbContext`（非 `DbContext`），因此模块 Repository 层要求 AppDbContext
- 模块 `AddXxxModule()` 不直接依赖 AppDbContext（通过 Repository 接口间接使用）
- 架构测试 `P21` 禁止 LocalWebAPI 控制器引用 `LYBT.Module`
- 架构测试 `P20` 限制控制器可依赖的类型白名单
- `AppDbContext.HttpContextAccessor` 可选（null 时跳过 CreatedBy/UpdatedBy）

## 实施步骤

### Step 1: 替换 LocalWebApiDbContext → AppDbContext

**文件:**
- `src/Client/Desktop/LocalWebAPI/LocalWebApiProgram.cs`
  - `AddDbContext<LocalWebApiDbContext>` → `AddDbContext<AppDbContext>`
  - `GetRequiredService<LocalWebApiDbContext>()` → `GetRequiredService<AppDbContext>()`
  - 添加 `builder.Services.AddHttpContextAccessor();`
- `src/Client/Desktop/LocalWebAPI/Data/LocalWebApiSeedData.cs`
  - 参数类型 `LocalWebApiDbContext` → `AppDbContext`
  - `using LYBT.Infrastructure.Data;`
- 所有 10 个控制器中 `LocalWebApiDbContext _db` → `AppDbContext _db`
  - `AuthController.cs`, `ConfigurationController.cs`, `DiagnosticsController.cs`,
    `FormulasController.cs`, `HealthController.cs`, `HerbsController.cs`,
    `MedicalCasesController.cs`, `PatientsController.cs`, `RegistrationsController.cs`,
    `UsersController.cs`
- 删除 `src/Client/Desktop/LocalWebAPI/Data/LocalWebApiDbContext.cs`
- 测试基类: `tests/LYBT.Tests.Desktop/Integration/LocalWebAPI/LocalWebApiControllerTestBase.cs`

### Step 3: 注册模块 Service

**文件:** `src/Client/Desktop/LocalWebAPI/LocalWebApiProgram.cs`

在 `AddControllers()` 后添加:
```csharp
builder.Services.AddHttpContextAccessor();

// 注册模块 Service（与远程 WebAPI 使用相同的 Service/Repository 层）
builder.Services.AddAuthModule(builder.Configuration);
builder.Services.AddUsersModule(builder.Configuration);
builder.Services.AddPatientsModule(builder.Configuration);
builder.Services.AddHerbsModule(builder.Configuration);
builder.Services.AddFormulaModule();
builder.Services.AddMedicalCaseModule();
builder.Services.AddRegistrationModule();
builder.Services.AddSyncModule(builder.Configuration);
```

**注意:** 部分 AddXxxModule 接收 IConfiguration 参数。LocalWebApiProgram 已有 `builder.Configuration`。
如果模块注册时需要特定配置节（如 SecurityOptions），需确保 LocalWebAPI 的 appsettings.json 包含对应配置。

### Step 4: 更新架构测试

- **P20** (`P20_LocalWebAPI_Controllers_Should_Only_Inject_Allowed_Types`):

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 模块 AddXxxModule 需要远程配置（SecurityOptions/JwtOptions） | 在 LocalWebAPI appsettings.json 中添加对应配置节 |
| AppDbContext 需要 IHttpContextAccessor | Step 1 中已添加 AddHttpContextAccessor() |
| LocalWebApiSeedData 依赖 LocalWebApiDbContext 特有逻辑 | 检查 SeedAsync 实现，确认仅用标准 DbContext API |
| 双重 DbContext 注册冲突 | 仅注册 AppDbContext，删除 LocalWebApiDbContext |
| 架构测试 DesktopLayerArchTests 误报 | 确认 LocalWebAPI 不在 DesktopAssemblies 数组中 |
